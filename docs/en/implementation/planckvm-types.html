planckvm data types

Kinds of values, heads, equality and the hash.

Kinds of values

An integer is one kind and has no upper limit on its size. How many bits go into a word does not appear in the specification of the values of the language.

Heads

Every value has a head (head). The head of an m-expr is its own head symbol, and the head of any other value is the symbol of its type name.

Integers in bytecode

An integer is written in one of two ways.

  • An integer that fits a field of an instruction is written in the field as a signed integer (two's complement). The width of the field is decided by the format of the instruction (C of the ABC format is 8 bits, D of the AD format is 16 bits, and sJ of the J format is 24 bits).
  • An integer that does not fit is put in the table of constants as an integer constant, and the instruction holds the index in the table. An integer in the table of constants is the sign word (0 for 0 or more, 1 for negative), the word of the number of digits, and the 64-bit digits (from the lowest digit, the low word first).

When a value can be written both in the table of constants and in a field of an instruction, it is written in the field.

Hash

HASH returns an integer from 0 to 230-1. Values that are equal by EQ give the same value.

  • An integer is decided by its value alone. Let acc be 0 for the sign 0 or more and 1 for negative, and for each 16-bit piece d of the absolute value from the low end, repeat acc = (acc * 31 + d + 7) mod 230. The hash of 0 is 0. It does not depend on the width of a digit.
  • A float that is equal to an integer, and a complex number whose imaginary part is 0 and whose real part is equal to an integer, have the same value as that integer.
  • Other floats, complex numbers, strings, symbols and m-exprs are decided by their contents. Equal contents give the same value, and the exact values are not defined.
  • Arrays, plain arrays and functions give a value that is decided for each object and does not change while the object lives.
