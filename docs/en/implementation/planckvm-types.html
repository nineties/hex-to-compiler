planckvm data types

Every value has a type, and only an M-expression has a head. HASH returns the same value for values that are equal by EQ. An integer is one kind and has no upper limit on its size.

Types and heads

The type of an M-expression is Expr and its head is a symbol. Using head on a value that is not an M-expression is an error.

arity and arg(v, i) give, for an M-expression, the number of arguments and argument i, and for a user data, the number of fields and field i. Any other value is an error.

Integers in bytecode

An integer that fits the field of an instruction is written in the field in two's complement. An integer that does not fit goes in the constant table, and the instruction holds its index. When a value can be written either way, the field of the instruction is used.

An integer in the constant table is the sign word (0 for 0 or more, 1 for negative), the word of the number of digits, and the 64-bit digits from the lowest.

Hash

HASH returns an integer from 0 to 262-1.

  • The hash of an integer depends only on its value. Let acc be the sign, 0 (0 or more) or 1 (negative), and repeat acc = (acc * 31 + d + 7) mod 230 for each 16-bit piece d of the absolute value, from the lowest. The hash of 0 is 0.
  • A float equal to an integer, and a complex number with imaginary part 0 and a real part equal to an integer, have the same value as that integer.
  • The other floats, complex numbers, strings, symbols and M-expressions have the same value when their contents are equal. Arrays and plain arrays have a value made from their elements, so equal arrays have the same value. Functions and user data keep a value that is fixed per object.
