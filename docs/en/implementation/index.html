Implementation

Each stage is built only from the artifacts of the earlier stages. This section reads the implementation from the hand-written machine code to the syntax of planck, with links to the source. The overview shows the stages as a whole.

Build order

pforth:  xxd -r -c 8 bootstrap/pforth.xxd > pforth
plisp2:  ./pforth < bootstrap/plisp.fs bootstrap/sasm.lisp bootstrap/plisp2.sv tmp-plisp2
planck0: ./plisp2 bootstrap/sasm.lisp bootstrap/planck0.sv planck0

plisp has no executable. At every start, pforth reads bootstrap/plisp.fs and assembles it.

Scope of each implementation

planck0 is the minimal implementation written in sasm. planck1 is planckvm without float and complex, and planck is the whole of planckvm. planck1 is the same as planck except where the tables say otherwise. The specification is in the reference.
