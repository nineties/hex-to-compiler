Implementation

This section reads the implementation of planck from the hand-written machine code up to the syntax of planck, with links to the source lines. The overview shows the stages as a whole.

Build order

pforth:  xxd -r -c 8 pforth.xxd > pforth
plisp2:  ./pforth < plisp.fs sasm.lisp plisp2.sv tmp-plisp2
planck0: ./plisp2 sasm.lisp planck0.sv planck0

plisp has no executable. At every start, pforth reads plisp.fs and assembles the Lisp, and that Lisp compiles plisp2.sv with sasm.lisp. planck0 is compiled by the same sasm.lisp on top of plisp2. After planck0, the rest is assembled at run time. planck0 reads init.pk, peg.pk and syntax.pk as M-expressions, and the syntax of planck takes effect when syntax.pk replaces parse.
