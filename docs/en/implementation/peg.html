The packrat parser

planck/peg.pk (322 lines of M-expressions) is a parser that interprets a PEG. The grammar is M-expression data. The parser memoizes the result of each rule at each position.

The grammar as data

The forms of parsing expressions, the right-hand sides of rules, are at the top of the file.

planck/peg.pk:4–21

" A grammar is data. A parsing expression is one of "
"   \"text\"          the text, after blanks and comments "
"   Tight{\"text\"}   the text, without skipping blanks "
"   Key{\"word\"}     the word, not followed by a letter, a digit or _ "
"   name            the rule name (a symbol) "
"   f               a function: f(p) returns the new position or -1, and sets peg_pv "
"   Seq{e, ...}     sequence. The value is Tuple{v, ...} "
"   Choice{e, ...}  ordered choice "
"   Many{e}, Many1{e}, Option{e}  the values are Tuple{v, ...}, Option gives Tuple{} or Tuple{v} "
"   And{e}, Not{e}  lookahead "
"   Delimited{e, sep}, Delimited1{e, sep}  e separated by sep. The value is Tuple{v, ...} "
"   Same{}          succeeds when the next token is on the same line "
"   Act{e, f}       applies f to the value of e. f is an expression evaluated by _define_rule "
"   Prev{}          the previous definition of the rule (only as an alternative of _define_rule) "
"   Fail{}          never matches "

" Results of rules are memoized for each position. "
" Direct left recursion (sum ::= sum \"+\" term | term) is handled by growing the seed. "

One or more repetitions of "7" are Many1{"7"}. To take their count as the value, write Act{Many1{"7"}, t -> arity(t)}. Giving it a name with _define_rule makes it a rule.

i_define.pk

_define_rule('sevens, 'Act{Many1{"7"}, t -> arity(t)})
println(peg_parse('sevens, "7 7 7 rest"))
println(sevens{| 7 7 7 7 |})

Output

Tuple{3, "rest"}
4

A rule defined without ::= is also usable in sevens{| ... |}. ::= itself is translated to a call of _define_rule (Defining the syntax).

Interpretation

peg_px(e, p) tries the parsing expression e at the position p. On success it returns the next position and puts the value in peg_pv. A failure is -1. peg_px, peg_call_rule and peg_run_rule call each other, so their names are declared first with Def{name, none} and defined later with Set (planck/peg.pk:114–116).

planck/peg.pk:212–217

Set{peg_px, Lambda{Tuple{e, p}, Do{
    Def{t, Apply{typeof, Tuple{e}}},
    If{Apply{_eq, Tuple{t, Quote{string}}}, Apply{peg_lit, Tuple{e, Apply{peg_skip_ws, Tuple{p}}}},
    If{Apply{_eq, Tuple{t, Quote{symbol}}}, Apply{peg_call_rule, Tuple{e, p}},
    If{Apply{_eq, Tuple{t, Quote{function}}}, Apply{e, Tuple{p}},
        Apply{Apply{table_get, Tuple{peg_handlers, Apply{head, Tuple{e}}, none}}, Tuple{e, p}}}}}}}}

A string is matched after skipping whitespace. A symbol is called as a rule. A function is called as it is. For M-expressions such as Seq and Choice, the table peg_handlers gives the handler for each head (planck/peg.pk:175–210). Tokens such as identifiers and integers are implemented as functions on the side of Defining the syntax.

At every failure, the parser records the farthest position reached in peg_far (planck/peg.pk:57–59) and reports a syntax error at that position.

Memoization and direct left recursion

The parser memoizes the result of a rule for each (position, rule) pair (packrat parsing). Backtracking does not recompute the same rule at the same position.

planck/peg.pk:219–225

" === Rules and memoization === "
" The memo of position p is the array peg_memo[p] (made when first used), which holds "
" three slots for each rule id: end position, value and left-recursion flag. "
" The end position is none before the rule runs, -1 for failure and -2 while the rule is running. "
" On left recursion (the rule is called again at the same position while it runs), "
" the inner call fails, which is the seed. Then the rule is run again "
" while it consumes more than the last result. "

The memo is an array for each position. For each rule it has three fields: the end position, the value and a left-recursion mark. peg_call_rule first looks up the memo (planck/peg.pk:234–250).

The memo also handles direct left recursion (sum ::= sum "+" term | term). While a rule runs, its memo entry is marked as running, and a recursive call at the same position fails. The parser stores the result obtained with this failure as a seed in the memo and runs the rule again. It repeats this as long as the rule reads more than before (seed growing).

planck/peg.pk:252–270

Set{peg_run_rule, Lambda{Tuple{r, p, row, b}, Do{
    Def{body, Apply{table_get, Tuple{peg_rules, r, none}}},
    Def{b1, Apply{_add, Tuple{b, 1}}},
    Apply{array_set, Tuple{row, b, -2}},
    Def{q, Apply{peg_px, Tuple{body, p}}},
    Apply{array_set, Tuple{row, b, q}},
    Apply{array_set, Tuple{row, b1, peg_pv}},
    If{Apply{_eq, Tuple{Apply{array_get, Tuple{row, Apply{_add, Tuple{b, 2}}}}, true}}, Do{
        Def{go, Apply{_ge, Tuple{q, 0}}},
        While{go, Do{
            Set{q, Apply{peg_px, Tuple{body, p}}},
            If{Apply{_gt, Tuple{q, Apply{array_get, Tuple{row, b}}}},
                Do{
                    Apply{array_set, Tuple{row, b, q}},
                    Apply{array_set, Tuple{row, b1, peg_pv}}},
                Set{go, false}}}},
        Set{peg_pv, Apply{array_get, Tuple{row, b1}}},
        Apply{array_get, Tuple{row, b}}},
    q}}}}

As a result, 1 - 2 - 3 is (1 - 2) - 3.

Defining a rule

planck/peg.pk:288–297

" _define_rule(name, e) defines or replaces the rule "
Def{_define_rule, Lambda{Tuple{name, e}, Do{
    If{Apply{_eq, Tuple{Apply{table_get, Tuple{peg_ids, name, none}}, none}}, Do{
        Apply{table_set, Tuple{peg_ids, name, peg_nrules}},
        Set{peg_nrules, Apply{peg_inc, Tuple{peg_nrules}}}}, none},
    Def{old, Apply{table_get, Tuple{peg_rules, name, Fail{}}}},
    Apply{table_set, Tuple{peg_sources, name, Apply{peg_subst_prev, Tuple{e, Apply{table_get, Tuple{peg_sources, name, Fail{}}}}}}},
    Set{peg_version, Apply{peg_inc, Tuple{peg_version}}},
    Apply{table_set, Tuple{peg_rules, name, Apply{peg_subst_prev, Tuple{Apply{peg_prepare, Tuple{e}}, old}}}},
    name}}}

_define_rule numbers the rule, evaluates f of the action Act{e, f}, and enters the rule in the table. Prev{} in an alternative is replaced by the previous definition of the rule. The ... of ::= is this Prev{}.

The form before evaluation is kept in peg_sources. Tools that read the grammar, such as unparse, use this table.

Entry point

peg_parse(rule, s) rebuilds the memo, calls the rule and returns Tuple{value, rest} (planck/peg.pk:306–322). On failure it returns SyntaxError{...} with the text from the position of peg_far to the end of the line.
