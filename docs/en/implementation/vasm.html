The vasm checker

planck/lib/vasm.pk (862 lines) is a library, written in planck, that reads and checks vasm, a low-level language close to machine instructions. use("vasm") loads it. The list of structs and functions written in vasm{| ... |} is checked for ownership and borrow violations, uses after free and reads of uninitialized registers, using type rules alone. The rules of the language are in vasm in the reference.

Entry points

planck/lib/vasm.pk:1–11

# vasm: a language with types, ownership and named regions, written in .pk files
# Copyright (C) 2026 nineties
#
# vasm{| struct ... fn ... |} reads structs and functions of the language and is Module{[Struct{...}, Fn{...}, ...]}.
# vasm_check(m) is the list of VasmErr{kind, Pos{d}, msg}, one for each struct or function with an error,
# and vasm_errors(file, m) gives the positions as Loc{file, line, column} of the file.

use("list")
use("table")
use("string")
use("error")

vasm{| ... |} is read as Module{[Struct{...}, Fn{...}, ...]}. vasm_check(m) takes it and returns a list of VasmErr{kind, Pos{d}, msg}. vasm_errors(file, m) turns the positions into Loc{file, line, column} of the file, and vasm_report(file, m) writes them as file:line:column: message. A function without an error does not appear in the result, and a function has at most one error: the first. The examples on this page write the result line by line with the report function in each file.

Syntax

The syntax of vasm is declared with ::= as rules of the packrat parser (planck/lib/vasm.pk:38–39). The keywords are collected in vasm_kw, and a name is an identifier that is not a keyword. The rule for statements lists one alternative for each head, and each result is an M-expression such as Decl{...}, IfS{...} or Assign{...}.

planck/lib/vasm.pk:123–134

vasm_stmt ::= at:vasm_here 'var x:vasm_name ":" t:vasm_type { Decl{at, x, t} }
    | at:vasm_here 'if "(" c:vasm_cond ")" a:vasm_block 'else b:vasm_block { IfS{at, c, a, b} }
    | at:vasm_here 'if "(" c:vasm_cond ")" a:vasm_block { IfS{at, c, a, []} }
    | at:vasm_here 'while "(" c:vasm_cond ")" a:vasm_block { WhileS{at, c, a} }
    | at:vasm_here 'region r:vasm_name a:vasm_block { RegionS{at, r, a} }
    | at:vasm_here 'return vasm_same a:vasm_operand { Ret{at, a} }
    | at:vasm_here 'return { Ret{at, none} }
    | at:vasm_here "*" p:vasm_name "=" a:vasm_operand { Store{at, p, a} }
    | at:vasm_here p:vasm_name "[" i:vasm_operand "]" "=" a:vasm_operand { IStore{at, p, i, a} }
    | at:vasm_here p:vasm_name "." f:vasm_name "=" a:vasm_operand { FStore{at, p, f, a} }
    | at:vasm_here x:vasm_name "=" r:vasm_rhs { Assign{at, x, r} }
    | at:vasm_here f:vasm_name "(" args:vasm_args? ")" { CallS{at, f, vasm_opt_list(args)} }

Every result carries its position at. vasm_here is a rule that reads nothing and returns, as Pos{d}, the number of characters from the next token to the end of the text (planck/lib/vasm.pk:29–34). An error of the checker holds this Pos, and vasm_errors subtracts it from the length of the text to get the line and the column.

Types and the state of the checker

Types are M-expressions too. The integers are I8{} to U64{}, a box is Own{u}, a borrow is Ref{'shr or 'mut, region, u}, an array is Arr{u} and a struct is Named{s}.

planck/lib/vasm.pk:186–198

# === Checker state ===
# vasm_info: name -> Info{type, regions open at the declaration}, for the variables in scope
# a state: name -> Vs{status, loans}, and ".dead" -> true after return
#   status: 'init, 'uninit, Moved{at}, Freed{at}, Taken{at} (an own value whose contents are moved out by x = *p)
#   or Parts{fields} (a struct value whose fields that own are moved out by x = s.f, U19); loans: [Loan{region, kind}, ...]
# vasm_regions: the regions in scope, the innermost first, ending with the regions of the function

vasm_sigs := table()
vasm_structs := table()
vasm_info := table()
vasm_regions := []
vasm_fn_regions := []
vasm_ret_type := Unit{}

For each function, the checker keeps the declarations of the variables in vasm_info (name to type) and the state of the variables in a table of Vs{status, loans}. The status is one of initialized, uninitialized, moved, freed, a box whose contents are moved out, and a struct whose fields are moved out. The loans are the borrows that currently borrow the variable. if and while copy the table, check each branch, and compare the results afterwards.

Whether a value is moved or copied depends on its type. own and a struct that owns something are linear: a use moves them, and they must be moved or freed exactly once. Integers, bool, structs that own nothing and shared borrows are copied.

planck/lib/vasm.pk:217–222

# An integer literal is Lit{n} until it meets an integer type; Lit{none} is the result of an operation on literals.
# Integers, bool and structs without own are copied. own and a struct with own are linear: they are moved
# by a use and must be moved or freed once (U6, U19). &mut is moved by a use, except for an argument of a call
# (vasm_call). & is copied.
vasm_linear(t) := head(t) == 'Own or (head(t) == 'Named and vasm_owning(t))
vasm_moves(t) := vasm_linear(t) or (head(t) == 'Ref and arg(t, 0) == 'mut)

Ownership

vasm_box.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    fn bump[r](p: &mut r i64) {
        var v: i64
        v = *p
        v = v + 1
        *p = v
    }
    fn main() -> i64 {
        var p: own i64
        var v: i64
        p = box(41)
        region r {
            var m: &mut r i64
            m = &mut r p
            bump(m)
        }
        v = *p
        free(p)
        return v
    }
|}
report(m)

Output

ok

own i64 is the single owner of an integer allocated by box. The [r] of bump is a region parameter fixed at each call. For a call that passes a &mut to a borrow parameter, vasm_reborrows treats the argument as borrowed again for the duration of the call, and does not move it (planck/lib/vasm.pk:511–517). This is why m can be used after the call.

m := vasm{|

        var p: own i64
        var v: i64
        p = box(1)
        free(p)

        return v
    }
    fn free_twice() {
        var p: own i64
        p = box(1)
        free(p)
        free(p)
    }

        free(q)
        return p
    }
|}

Output

line 15: p is used after it is freed
line 22: p is freed twice
line 27: q is used after it is moved

Before a register is read, vasm_need_init looks up its state. An uninitialized, moved or freed register is an error of kind 'uninit, 'moved or 'freed (planck/lib/vasm.pk:258–265). A freed own cannot be read or freed again, because vasm_call marks the argument of free as freed. Assigning q to p marks q as moved, and the ownership moves to p.

Automatic release

vasm_drop.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    struct Buf { data: own [u8], size: i64 }
    fn at_block_end(c: bool) {
        if (c) {
            var q: own i64
            q = box(2)
        }
    }
    fn overwrite() -> i64 {
        var p: own i64
        var v: i64
        p = box(1)
        p = box(2)
        box(3)
        v = *p
        return v
    }
    fn free_with_contents(b: own Buf) {
        free(b)
    }
|}
report(m)

Output

ok

A value that owns something is released automatically where its owner goes away, so none of the functions above is an error. Those places are the end of a block or a function, an overwrite, the result of a call that is discarded as a statement, and what is left inside a value passed to free. The release is an action at run time, and the checker counts nothing. vasm_leak_all, which would examine what is left at the end of a block or a function, is an empty function kept to mark where the release happens (planck/lib/vasm.pk:654–657). An overwrite only sets the state back to initialized in vasm_assign (planck/lib/vasm.pk:642–652). free is for releasing a value earlier.

Borrows and regions

vasm_borrow.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)

m := vasm{|
    fn two_shared() -> i64 {
        var p: own i64
        var v: i64
        p = box(1)
        region r {
            var a: &r i64
            var b: &r i64
            a = &r p
            b = &r p
            var w: i64
            v = *a
            w = *b
            v = v + w
        }
        free(p)
        return v
    }
    fn mut_and_shared() {
        var p: own i64
        p = box(1)
        region r {
            var a: &mut r i64
            var b: &r i64
            a = &mut r p
            b = &r p
        }
    }
    fn overwrite_while_borrowed() -> i64 {
        var p: own i64
        var v: i64
        p = box(1)
        region r {
            var a: &r i64
            a = &r p
            p = box(2)
            v = *a
        }
        return v
    }
|}
report(m)

Output

line 34: p is borrowed as mut and cannot be borrowed
line 44: p is borrowed and cannot be assigned

The Vs of a borrowed variable holds Loan{region, kind}. vasm_no_loans rejects a move, a free or an assignment while the variable is borrowed, and vasm_no_mut_loan rejects a read or a write while it is borrowed with &mut (planck/lib/vasm.pk:294–295). Any number of shared borrows can exist at once. A &mut is exclusive: while it lives, the original value can be neither read, written nor freed. At the end of region r { ... }, vasm_end_region removes the loans of r (planck/lib/vasm.pk:691).

line 18: a borrow of region inner is put in keep, which lives outside the region

vasm_outlives(q, r) decides which region is inside which. q outlives r if they are the same, or if r is a region opened in the function and q was opened before it. The region parameters of a function have no order among themselves.

planck/lib/vasm.pk:325–327

# q outlives r: q is r, or r is a region opened in the function and q was opened before it (U13).
# The regions of the function are not ordered.
vasm_outlives(q, r) := q == r or (not member(r, vasm_fn_regions) and index_of(q, vasm_regions) > index_of(r, vasm_regions))

planck/lib/vasm.pk:334–345

# a value of type t can be put where e is expected: an integer literal in the range of e,
# or a borrow of a region that outlives the region of e (U13)
vasm_fits(at, e, t) := if (head(t) == 'Lit and vasm_int(e)) {
    vasm_lit_range(at, arg(t, 0), e)
    true
} else if (head(e) == 'Own and head(t) == 'Own) vasm_fits(at, arg(e, 0), arg(t, 0))
else if (head(e) == 'Arr and head(t) == 'Arr) vasm_fits(at, arg(e, 0), arg(t, 0))
else if (head(e) == 'Ref and head(t) == 'Ref) arg(e, 0) == arg(t, 0) and vasm_outlives(arg(t, 1), arg(e, 1)) and vasm_fits(at, arg(e, 2), arg(t, 2))
else e == t

# a borrow that does not fit only because its region is opened inside the function and does not outlive the expected one
vasm_escapes(e, t) := head(e) == 'Ref and head(t) == 'Ref and arg(e, 0) == arg(t, 0) and arg(e, 2) == arg(t, 2) and not member(arg(t, 1), vasm_fn_regions)

vasm_fits decides whether the type of a borrow matches in an assignment or an argument. A borrow of an outer region can be used where a borrow of an inner region is expected, because the outer one lives longer, and the reverse is rejected. When the reverse puts the borrow in a register that lives outside the region opened in the function, vasm_escapes makes the error of kind 'escape.

Branches and loops

planck/lib/vasm.pk:659–684

# the state after if: both branches must agree on own values
vasm_merge(at, a, b) := if (vasm_dead(a)) b else if (vasm_dead(b)) a else {
    m := table()
    each(x -> {
        t := arg(table_get(vasm_info, x, none), 0)
        sa := vasm_status(a, x)
        sb := vasm_status(b, x)
        if (vasm_owns(t, sa) != vasm_owns(t, sb)) vasm_fail(at, 'branch, f"{symname(x)} is owned after one branch and not after the other")
        if (vasm_linear(t) and vasm_key(t, sa) != vasm_key(t, sb)) vasm_fail(at, 'branch, f"{symname(x)} has different parts moved out after the two branches")
        s := if (sb == 'init) sa else sb
        la := vasm_loans(a, x)
        table_set(m, x, Vs{s, append(la, filter(l -> not member(l, la), vasm_loans(b, x)))})
    }, vasm_vars(a))
    m
}

vasm_replace(st, m) := {
    each(x -> table_set(st, x, table_get(m, x, none)), vasm_vars(st))
    table_set(st, ".dead", vasm_dead(m))
}

# a loop must give back the own and &mut values it moves
vasm_loop_same(at, a, b) := each(x -> {
    t := arg(table_get(vasm_info, x, none), 0)
    if (vasm_moves(t) and vasm_key(t, vasm_status(a, x)) != vasm_key(t, vasm_status(b, x))) vasm_fail(at, 'loop, f"{symname(x)} is moved or freed in the loop and not given a value again")
}, vasm_vars(a))

if checks both branches on copies of the state, and vasm_merge compares them. A value moved or freed in only one branch has no definite owner afterwards, which is an error of kind 'branch. A branch that ends in return is marked with .dead and left out of the comparison. while checks the body twice, and vasm_loop_same looks at whether a value moved in the loop is given back before the next iteration ('loop).

Widths of integers

vasm_ints.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    fn mixed(flags: u8, size: u32) -> u32 {
        var w: u32
        w = size + flags
        return w
    }
    fn widened(flags: u8, size: u32) -> u32 {
        var f: u32
        var w: u32
        f = flags as u32
        w = size + f
        return w
    }
    fn magic() -> u32 {
        var m: u32
        m = 0x7F45
        m = m << 16
        m = m | 0x4C46
        return m
    }
    fn too_big() -> u32 {
        var m: u32
        m = 0x7F454C46
        return m
    }
|}
report(m)

Output

line 12: the operands are u32 and u8
line 31: 0x7F454C46 is out of the range of a literal, -32768 to 32767; make it with << and |

The integer types are listed in the table vasm_ints (type, name, bits, signedness) (planck/lib/vasm.pk:159–166). Both operands of an operator have the same type, and as changes the width or the signedness. A literal starts as Lit{n}, which has no type, and its range is checked where it meets an integer type. The range is -32768 to 32767, narrowed to start at 0 for an unsigned type and to the range of the type for 8 bits (vasm_lit_lo and vasm_lit_hi, planck/lib/vasm.pk:167–170). A larger value is built with shifts and |.

Arrays and structs

vasm_array.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    struct Section { offset: u64, size: u32 }
    fn total[r](ss: &r [Section]) -> u64 {
        var i: i64
        var n: i64
        var t: u64
        var s: Section
        var o: u64
        i = 0
        t = 0
        n = len(ss)
        while (i < n) {
            s = ss[i]
            o = s.offset
            t = t + o
            i = i + 1
        }
        return t
    }
    fn build() -> u64 {
        var a: own [Section]
        var s: Section
        var t: u64
        s = Section{offset: 64, size: 16}
        a = alloc(3, s)
        s = Section{offset: 128, size: 0}
        a[1] = s
        region r {
            var view: &r [Section]
            view = &r a
            t = total(view)
        }
        free(a)
        return t
    }
|}
report(m)

Output

ok

The built-in functions are listed in the table vasm_builtins as types Sig{regions, arguments, result} with the type variable T (planck/lib/vasm.pk:224–232). alloc(n, v) makes an own [T] of n copies of v, and len returns the length. An index is an i64. Checking its range is left to run time, and the checker looks only at types and ownership. A struct is built by giving every field once. It is copied like an integer unless it owns something, and vasm_owning decides that by following the fields (planck/lib/vasm.pk:200–212).

Exchanging values that own

vasm_swap.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)

m := vasm{|
    struct Image { header: own [u8], body: own [u8], entry: u64 }
    fn replace_body(img: Image, n: i64) -> Image {
        var b: own [u8]
        b = alloc(n, 0)
        img.body = b
        return img
    }
    fn take_header[r](parts: &mut r [own [u8]]) -> own [u8] {
        var a: own [u8]
        a = alloc(1, 9)
        a = swap(parts[0], a)
        return a
    }
    fn read_header[r](parts: &r [own [u8]]) -> own [u8] {
        var a: own [u8]
        a = parts[0]
        return a
    }
|}
report(m)

Output

line 25: the elements of parts own values and are not copied; use swap(parts[i], v)

A value that owns something cannot be copied out of an array element or the target of a pointer, because it would have two owners. swap(p[i], v) puts v in and returns the previous value. The parameter type Place{T} accepts only a place of the form *p, p[i] or p.f. Writing a field of a struct register, as in img.body = b, releases the previous value and puts the new one in.

Reporting errors

planck/lib/vasm.pk:830–848

# the errors of the module m: [VasmErr{kind, Pos{d}, msg}, ...], the first error of each struct and function
vasm_check(m) := {
    items := arg(m, 0)
    vasm_sigs = table()
    vasm_structs = table()
    each(d -> match d {
        Fn{_, f, rs, ps, ret, _} -> table_set(vasm_sigs, f, Sig{rs, map(p -> arg(p, 2), ps), ret})
      | Struct{_, s, _} -> if (table_get(vasm_structs, s, none) == none) table_set(vasm_structs, s, d)
    }, items)
    errs := []
    each(d -> {
        r := handle {
            if (head(d) == 'Struct) vasm_check_struct(d) else vasm_check_fn(d)
            none
        } with (VasmFail{at, kind, msg}, k) -> VasmErr{kind, at, msg}
        if (r != none) errs = r :: errs
    }, items)
    reverse(errs)
}

When the checker meets an error, vasm_fail performs the algebraic effect VasmFail{at, kind, msg} (Algebraic effects). For each struct and function, vasm_check receives it with handle, makes a VasmErr and abandons the check, so a function has at most one error: the first. The kinds are in the table of the reference.
