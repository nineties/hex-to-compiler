init.pk and M-expressions

planck0 reads planck/init.pk first. The reader at this point reads only M-expressions, so all 111 lines are M-expressions. The file defines the functions and tables used afterward.

Writing in M-expressions only

There are no operators and no syntax for if, so everything is written with special forms and function calls. The definition of _not, which not calls, is as follows.

planck/init.pk:12–15

" === Basic Functions === "
Def{_not, Fusion{
    Lambda{Tuple{Quote{false}}, true},
    Lambda{Tuple{_}, false}}}

A Fusion joins two Lambdas. The first is chosen when the argument is false, and the second otherwise. Quote{false} is a pattern that matches the symbol false. A top-level string " ... " does nothing when evaluated, so it serves as a comment.

The first lines bind true, false and none to the symbols of the same names (planck/init.pk:8–10).

Tables

The builtins of planck0 stop at arrays and hash. init.pk implements the hash table with arrays (planck/init.pk:18–77).

planck/init.pk:18–26

" A table is Table{a}, where a is an array | buckets | number of entries |. Each bucket is a chain of entries "
" | key | value | next entry or none | hash of the key |. Keys are compared by eq. "
" The number of buckets doubles when there are more entries than buckets. "
Def{table, Lambda{Tuple{}, Do{
    Def{t, Apply{array, Tuple{2}}},
    Apply{array_set, Tuple{t, 0, Apply{array, Tuple{16}}}},
    Apply{array_set, Tuple{t, 1, 0}},
    Table{t}}}}

A table is Table{a}, where a is an array that holds an array of buckets and the number of entries. The number of buckets doubles when the number of entries exceeds it. Keys are compared as by ==. Tables are used for the memo table of the parser, the table of rules, the record of the libraries that use has loaded, and so on.

Loading files

Like interpret_file of planck0, load evaluates a file one expression at a time with the current parse and eval.

planck/init.pk:81–99

Def{load, Lambda{Tuple{path}, Do{
    Def{s, Apply{read_file, Tuple{path}}},
    Def{r, none},
    Def{e, none},
    Def{go, true},
    While{go, Do{
        Set{r, Apply{parse, Tuple{s}}},
        Set{e, Apply{arg, Tuple{r, 0}}},
        If{Apply{_eq, Tuple{e, Eof{}}}, Set{go, false},
        If{If{Apply{_eq, Tuple{Apply{typeof, Tuple{e}}, Quote{mexpr}}}, Apply{_eq, Tuple{Apply{head, Tuple{e}}, Quote{SyntaxError}}}, false},
            Do{
                Apply{put, Tuple{path}},
                Apply{put, Tuple{": syntax error: "}},
                Apply{println, Tuple{e}},
                Apply{exit, Tuple{1}}},
            Do{
                Apply{eval, Tuple{e}},
                Set{s, Apply{arg, Tuple{r, 1}}}}}}}},
    none}}}

use is a load that records what it has loaded (planck/init.pk:103–106).

Switching to the syntax

The last lines load the packrat parser and the syntax.

planck/init.pk:108–111

" === Syntax === "
" planck/syntax.pk replaces parse. The files after it are read by the new syntax. "
Apply{load, Tuple{"planck/peg.pk"}}
Apply{load, Tuple{"planck/syntax.pk"}}

planck/peg.pk is a parser written in M-expressions (The packrat parser). planck/syntax.pk defines the syntax of planck with that parser and replaces parse (Defining the syntax). The files read afterward, both planck/lib and the programs of users, are read in the syntax of planck.
