init.pk and M-expressions

The reader of planck0 reads only M-expressions. planck/init.pk is written entirely in M-expressions, defines the functions and tables used afterward, and switches to the syntax at its end.

Writing in M-expressions only

There are no operators and no if, so everything is written with special forms and function calls. A top-level string does nothing when evaluated, so it serves as a comment. The first lines bind true, false and none to the symbols of the same names.

planck/init.pk: Basic Functions

" === Basic Functions === "
Def{_not, Fusion{
    Lambda{Tuple{Quote{false}}, true},
    Lambda{Tuple{_}, false}}}

Tables and loading files

The builtins of planck0 stop at arrays and hash, so the hash table is implemented with arrays.

planck/init.pk: A table is a Table, whose

" A table is a Table, whose field is an array | buckets | number of entries |. Each bucket is a chain of entries "
" | key | value | next entry or none | hash of the key |. Keys are compared by eq. "
" The number of buckets doubles when there are more entries than buckets. "
Def{_table_type, Apply{_record_new, Tuple{Quote{Table}, Quote{Tuple{a}}}}}

load evaluates a file one expression at a time with the current parse and eval, and records the file that defines each global variable.

planck/init.pk: load(path) parses and evaluates

" load(path) parses and evaluates the file by the current parse and eval. "
" The top-level definitions of the file are made while path is the file being loaded. "
" A syntax error is printed as file:line:column: syntax error: message, once planck/syntax.pk has replaced parse and planck/peg.pk has defined peg_file_error_text. "
Def{peg_file_error_text, none}
Def{_parse0, parse}
Def{load, Lambda{Tuple{path}, Do{
    Def{s, Apply{read_file, Tuple{path}}},
    Def{s0, s},
    Def{prev, Apply{_set_file, Tuple{path}}},
    Def{r, none},
    Def{e, none},
    Def{go, true},
    While{go, Do{
        Set{r, Apply{parse, Tuple{s}}},
        Set{e, Apply{arg, Tuple{r, 0}}},
        If{Apply{_eq, Tuple{e, Eof{}}}, Set{go, false},
        If{If{Apply{_eq, Tuple{Apply{type, Tuple{e}}, Expr}}, Apply{_eq, Tuple{Apply{head, Tuple{e}}, Quote{SyntaxError}}}, false},
            Do{
                Def{text, If{Apply{_ne, Tuple{parse, _parse0}}, Apply{peg_file_error_text, Tuple{path, s0, s}}, none}},
                If{Apply{_eq, Tuple{text, none}},
                    Do{
                        Apply{put, Tuple{path}},
                        Apply{put, Tuple{": syntax error: "}},
                        Apply{println, Tuple{e}}},
                    Do{
                        Apply{put, Tuple{text}},
                        Apply{put, Tuple{"\n"}}}},
                Apply{exit, Tuple{1}}},
            Do{
                Apply{eval, Tuple{e}},
                Set{s, Apply{arg, Tuple{r, 1}}}}}}}},
    Apply{_set_file, Tuple{prev}},
    none}}}

Switching to the syntax

planck/init.pk: Syntax

" === Syntax === "
" planck/syntax.pk replaces parse. The files after it are read by the new syntax. "
Apply{load, Tuple{"planck/peg.pk"}}
Apply{load, Tuple{"planck/syntax.pk"}}

" planck/lib/use.pk defines use(name), which loads planck/lib/<name>.pk once. It is written in the syntax above. "
Apply{load, Tuple{"planck/lib/use.pk"}}

The last lines load the packrat parser and the syntax. The files read after this are read in the syntax of planck.
