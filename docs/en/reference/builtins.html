Output

print(x) writes a value, and println(x) writes it followed by a newline. A string is written with quotes. put(s) writes the contents of a string as they are.

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

Output

42 "abc"
abc
Point{1, "a"}

Numbers and comparison

The operators + - * / % and the comparison operators are translated to calls of these functions (see Names the sugar calls). There is no function of the same name without _. The rules for their arguments and results are in Numbers. To pass an operator as a function, write a lambda such as (a, b) -> a + b.

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

M-expressions and strings

  • push(Head{a, ...}, x): Head{a, ..., x}.
  • mexpr(h, Tuple{a, ...}) builds the M-expression h{a, ...} with the head h.
  • symname(sym): the name of the symbol as a string (the inverse of intern). intern(s): the symbol named s.
  • strlen(s): the number of bytes, 0 bytes included. ord(s, i): the byte at i, or -1 when i is out of range. s[i]: the byte at i as a string of length 1.
  • substr(s, i, j): the bytes from i to j - 1, and a runtime error out of range. _strcat(a, b): a followed by b.

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

Arrays and tables

  • array(n): a new array of n elements, all none. array_get(a, i), array_set(a, i, x) (returns x) and array_len(a). An index outside 0 to n - 1 is a runtime error.
  • hash(x): a non-negative integer. Values equal by _eq have the same hash.
  • table(): a new hash table Table{a}, where a is made of arrays. table_get(t, key, default), table_set(t, key, value). Keys are compared by ==. t[key] and t[key] = value also read and write a table (see Indexing and rewriting).

Floats and complex numbers

  • itof(n): n + 0.0. fsqrt(a): the square root, NaN for a negative number. ffloor(a): the floor as a float.
  • ftoi(a): the integer truncated toward 0, and a runtime error for NaN and infinities. ftobits(a): the 64 bits as a non-negative integer. bitstof(n): the inverse, and a runtime error when n does not fit 64 bits.
  • ftos(a): the shortest decimal string that reads back to the same value, which is also what print writes for a float. stof(s): read a decimal string (an exponent is allowed), or none when it cannot be read.
  • fexp(a), flog(a), fsin(a), fcos(a), fpow(a, b), fatan2(a, b): exponential, natural logarithm, sine, cosine, power and the arctangent of two arguments. These functions also take an integer and raise it to a float. A complex number is a runtime error.
  • complex(re, im): the complex number with the real part re and the imaginary part im, each an integer or a float raised to a float. real(z), imag(z): the parts as floats, and a runtime error unless z is a complex number. conj(z): complex(real(z), imag(z) * -1).

Plain arrays

A plain array is an array of elements of one type. plain_array(kind, n) makes a plain array of n elements of the type kind, all 0 of that type (false, 0, 0.0 or complex(0, 0)). It is a runtime error when kind is not one of these types or n is negative. u8_array(n) is plain_array('u8, n), and the other types have the same form.

TypeElements
'booltrue or false
'i8 'i16 'i32 'i64Signed integers (-2^(n-1) to 2^(n-1)-1)
'u8 'u16 'u32 'u64Unsigned integers (0 to 2^n-1)
'f16 'f32 'f64Floats (IEEE 754 binary16, binary32 and binary64)
'c64 'c128Complex numbers (parts in binary32 and binary64)
  • a[i] and a[i] = x (plain_get(a, i), plain_set(a, i, x)) read and write an element. An index outside 0 to n - 1 is a runtime error.
  • Reading gives a value of the language, with 'f16, 'f32 and 'c64 widened to binary64 without changing the value.
  • plain_len(a): n. plain_kind(a): the symbol of the type. plain_copy(dst, di, src, si, n) copies n elements of src from si to dst from di. The types must be the same, and the ranges may overlap in one array.

Writing to a plain array converts the value:

  • An integer out of the range of an integer type is a runtime error and never wraps around.
  • A float written to an integer type is truncated toward 0, then the range is checked. NaN and infinities are runtime errors.
  • A complex number written to an integer type or to 'f16, 'f32 or 'f64 is a runtime error.
  • A number written to 'bool is false when it is 0 (0, 0.0, -0.0, complex(0, 0)), and otherwise true, also for NaN.
  • true and false written to 'bool stay as they are, and written to a number type are 1 and 0.
  • An integer or a float written to a complex type is the real part, and the imaginary part is 0.
  • A number written to a float or complex type is rounded to the nearest value. A value that rounds beyond the maximum of the type is an infinity of the same sign. An integer beyond the range of binary64 is a runtime error.
  • Any other value is a runtime error for every type.

Bit operations

  • bit_and(a, b), bit_or(a, b), bit_xor(a, b), bit_not(a): bit by bit on integers, as infinite-width two's complement, negative integers included.
  • bit_shl(a, k) shifts left by k bits and does not wrap around. bit_sar(a, k) is the arithmetic shift. A negative k is a runtime error.
  • bit_shr(a, k) is bit_sar(a, k) when a is not negative, and otherwise a runtime error.

b := u8_array(4)
b[0] = 72
b[1] = 0

println(plain_len(c))

println(bit_xor(5, 3))

Files and language

  • read_file(path): the contents of the file, including bytes 0. try_read_file(path): the same, or none when the file cannot be read. read_bytes(path): the same contents as a u8 array. write_file(path, x) writes all bytes of the string or u8 array x to the file, which is created or emptied; bytes 0 are written as they are. chmod(path, mode) sets the permissions (493 is 755 in octal).
  • argv(): the array of the command-line strings, as argv of C main. The first is the program file and the rest are its arguments. For the program a.pk with the arguments x y they are "a.pk", "x" and "y".
  • load(path): parse and evaluate the file. Its top-level expressions are evaluated with path as the file being loaded, and the program file given as the first argument and planck/init.pk are the files being loaded while they run (see Scope of variables).
  • _set_file(path): make path the file being loaded and return the previous one (none if there is none).
  • use(name): load("planck/lib/<name>.pk") once, or the same with the preprocessed library. used_libs is the table of the libraries already loaded.
  • parse and eval are the functions used by the top level. exit(n) ends the program with the status n.
  • _define_rule(name, e): define the rule by a parsing expression (see The packrat parser). peg_parse is in Grammar declarations.
  • parse_mexpr(s): the parser of M-expressions, with the same arguments and result as parse.
  • _to_text(x): x for a string, the decimal text for an integer, and show(x) (planck/lib/pretty.pk) otherwise, so a value other than a string or an integer in {e} needs use("pretty"). A string with embedded values is joined by _strcat from the left, and an empty piece is left out.
  • _record_declare(name, fields): set the field names of the head name (fields is Tuple{f, ...}). _record_get(t, name): the field.
  • _index_get(a, i) and _index_set(a, i, e) are the functions that a[i] and a[i] = e call, and subst(t, f) is the function that t[f] calls (see Indexing and rewriting).
  • peg_for(xs, f): call f with each element of the list or vector xs, and return none.

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

Output

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}
