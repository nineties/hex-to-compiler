Builtin functions

These functions are available without use. Most names that start with _ are functions that operators and syntax call. An error such as an index out of range or an unreadable value is a runtime error.

Output

print(x) writes a value, and println(x) writes it followed by a newline. Only put(s) writes the contents of a string as they are.

> Apply{println, Tuple{"abc"}}
"abc"
> Apply{println, Tuple{Quote{abc}}}
abc
> Apply{println, Tuple{Point{1, "a"}}}
Point{1, "a"}

Numbers and comparison

Arithmetic is _add _sub _mul _div _quo _mod, comparison is _lt _le _gt _ge _eq _ne _is, and negation is _not. The rules for their arguments and results are in Numbers.

> Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}
7
> Apply{_div, Tuple{7, 2}}
3
> Apply{_mod, Tuple{7, 2}}
1
> Apply{_div, Tuple{-7, 2}}
-3
> Apply{_add, Tuple{0x1f, 0b101}}
36

M-expressions and strings

head, arity, arg and type give the head, the number of arguments, an argument and the type of an M-expression.

> Def{s, "abc"}
> Apply{strlen, Tuple{s}}
3
> Apply{ord, Tuple{s, 1}}
98
> Apply{_index_get, Tuple{s, 1}}
"b"
> Apply{substr, Tuple{s, 1, 3}}
"bc"
> Apply{_strcat, Tuple{s, "de"}}
"abcde"
> Apply{push, Tuple{Point{1}, 2}}
Point{1, 2}
> Apply{arity, Tuple{Point{1, 2, 3}}}
3
> Apply{arg, Tuple{Point{1, 2, 3}, 2}}
3
> Apply{strlen, Tuple{"あい"}}
2
> Apply{ord, Tuple{"あ", 0}}
12354
> Apply{substr, Tuple{"あいう", 1, 2}}
"い"
> Apply{plain_len, Tuple{Apply{string_to_bytes, Tuple{"あ"}}}}
3
  • push(Head{a, ...}, x) is Head{a, ..., x}, and mexpr(h, Tuple{a, ...}) is h{a, ...}.
  • strlen(s) is the number of characters. ord(s, i) is the code point of the character at i, or -1 when out of range.
  • substr(s, i, j) is the characters from i to j - 1.
  • string_to_bytes(s) gives the UTF-8 bytes of s as a u8 plain array, and bytes_to_string(b) is its inverse. It is an error if b is not UTF-8.
  • intern(s) is the symbol named s, and symname(symbol) is its inverse.
> Apply{_eq, Tuple{Apply{intern, Tuple{"abc"}}, Quote{abc}}}
true
> Apply{symname, Tuple{Quote{abc}}}
"abc"
> Apply{ord, Tuple{"A", 0}}
65
> Apply{ord, Tuple{"A", 5}}
-1
> Apply{mexpr, Tuple{Quote{P}, Tuple{1, 2}}}
P{1, 2}

Arrays and tables

> Def{t, Apply{table_new, Tuple{}}}
> Apply{table_set, Tuple{t, "a", 1}}
> Apply{table_get, Tuple{t, "a", 0}}
1
> Apply{table_get, Tuple{t, "c", 0}}
0
> Def{a, Apply{array, Tuple{2}}}
> Apply{array_set, Tuple{a, 1, "x"}}
> Apply{array_get, Tuple{a, 1}}
"x"
  • array(n) makes an array of n elements, all none. array_get, array_set (returns none) and array_len read, write and give the length. An index out of range is an error.
  • table_new() makes a hash table. table_get(t, key, default) gives default when the key is absent, and table_set(t, key, value) (returns none) writes.
  • Keys are compared by equal. hash(x) is a non-negative integer, and values equal by _eq have the same hash (see equality).

Floats and complex numbers

  • itof, fsqrt (NaN for a negative number), ffloor (the result is a float), fexp, flog, fsin, fcos, fpow and fatan2 also take an integer and raise it to a float. A complex is an error.
  • ftoi(a) is the integer truncated toward 0, and NaN and infinities are errors.
  • ftobits(a) is the 64 bits as a non-negative integer. bitstof(n) is its inverse, an error when n does not fit 64 bits.
  • ftos(a) is the shortest decimal string that reads back to the same value, which is also what print writes.
  • stof(s) is none when s cannot be read, and _float(s) is an error.
  • complex(re, im) makes a complex. real(z) and imag(z) give the parts as floats, and conj(z) the conjugate. It is an error unless z is a complex.

Plain arrays

plain_array(kind, n) makes n elements of the type kind, all 0 of that type (false, 0, 0.0 or complex(0, 0)). u8_array(n) is plain_array(Quote{u8}, n), and the other types have the same form.

kind (a symbol)Elements
boolbooleans
i8 i16 i32 i64signed integers
u8 u16 u32 u64unsigned integers
f16 f32 f64floats (IEEE 754)
c64 c128complex (parts in binary32 and binary64)

Any other value, or a negative n, is an error.

  • plain_get(a, i) and plain_set(a, i, x) (returns none) read and write an element. Reading widens f16, f32 and c64 to binary64 without changing the value.
  • plain_len(a) is n, and plain_kind(a) is the symbol of the type.
  • plain_copy(dst, di, src, si, n) copies n elements of src from si to dst from di. The types must be the same, and the ranges may overlap in one array.

A written value is converted to the type. A value out of range or one that cannot be converted is an error, and nothing wraps around. The exceptions:

Value writtenToResult
floatinteger typetruncated toward 0, then the range is checked. NaN and infinities are errors
complexinteger or float typeerror
0 (0, 0.0, -0.0, complex(0, 0))boolfalse
anything else (NaN included)booltrue
true, falsenumber type1, 0
integer, floatfloat or complex typerounded to the nearest. Beyond the maximum of the type, an infinity of the same sign. An integer beyond the range of binary64 is an error
integer, floatcomplex typethe real part; the imaginary part is 0

Bit operations

bit_and, bit_or, bit_xor and bit_not work bit by bit on integers as infinite-width two's complement, negative integers included.

  • bit_shl(a, k) does not wrap around, and bit_sar(a, k) is the arithmetic shift. A negative k is an error.
  • bit_shr(a, k) is bit_sar when a is not negative, and an error otherwise.
> Apply{bit_and, Tuple{12, 10}}
8
> Apply{bit_or, Tuple{12, 10}}
14
> Apply{bit_xor, Tuple{12, 10}}
6
> Apply{bit_not, Tuple{5}}
-6
> Apply{bit_shl, Tuple{1, 10}}
1024
> Apply{bit_sar, Tuple{-16, 2}}
-4
> Apply{bit_shr, Tuple{16, 2}}
4
> Def{b, Apply{u8_array, Tuple{4}}}
> Apply{plain_set, Tuple{b, 0, 72}}
> Apply{plain_set, Tuple{b, 1, 0}}
> Apply{plain_set, Tuple{b, 2, 255}}
> Apply{plain_len, Tuple{b}}
4
> Apply{plain_get, Tuple{b, 2}}
255
> Apply{plain_kind, Tuple{b}}
u8
> Apply{write_file, Tuple{"tmp-plain.bin", b}}
> Def{c, Apply{read_bytes, Tuple{"tmp-plain.bin"}}}

record

_record(Quote{T}, Quote{Tuple{f, g, ...}}) makes a type by _record_new, ties the field names to the type, and returns Tuple{T, make}. _record_get(t, Quote{f}) is the field f of t, and _record_with(T, make) is a function that takes (d, Quote{f}, e) and returns the data with the field f replaced by e.

  • Different types can have fields of the same name.
  • Using _record_get on a value that has no field f, or that was not made by record, stops the program with a message.

Files and language

> Apply{write_file, Tuple{"tmp-gm.txt", "Apply{println, Tuple{Apply{_add, Tuple{1, 1}}}}\n"}}
> Apply{read_file, Tuple{"tmp-gm.txt"}}
"Apply{println, Tuple{Apply{_add, Tuple{1, 1}}}}\n"
> Apply{load, Tuple{"tmp-gm.txt"}}
2
> Tuple{Apply{try_read_file, Tuple{"no-such-file"}}}
Tuple{none}
> Apply{array_len, Tuple{Apply{argv, Tuple{}}}}
1
  • read_file(path) gives the contents as a string (an error if it is not UTF-8). try_read_file gives none when it cannot be read, and read_bytes gives a u8 plain array.
  • write_file(path, x) writes the UTF-8 bytes of the string, or all bytes of the u8 plain array x (the file is created or emptied). chmod(path, mode) sets the permissions (493 is 755 in octal).
  • argv() is the array of the command-line strings: the program file first, then its arguments. exit(n) ends the program with the status n.
  • load(path) parses the file and evaluates its top-level expressions with path as the file being loaded. _set_file(path) changes the file being loaded and returns the previous one (none if there is none).
  • use(name) runs load("planck/lib/<name>.pk") once, or the same with the preprocessed library. used_libs is the table of the libraries already loaded.
  • parse and eval are the functions used by the top level.

Functions the syntax implementation calls

  • _define_rule(name, e) defines a rule by a parsing expression (see The packrat parser). peg_parse is in Extending the grammar.
  • parse_mexpr(s) is the parser of M-expressions, with the same arguments and result as parse.
  • _to_text(x) is x for a string, the decimal text for an integer, and show(x) (planck/lib/pretty.pk) otherwise, so a value other than a string or an integer needs use("pretty"). _strcat(s, t) joins strings.
  • _index_get(a, i) and _index_set(a, i, e) read and write by index, and what they do for each kind is in Indexing and rewriting. subst(t, f) rewrites the tree t.

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
