Special forms

The special forms, and algebraic effects.

List

FormMeaning
Def{x, e}Defines the variable x. The right side sees the variables before x. true, false and none are not variables, so Def{true, e}, Set{true, e} and Declare{true} stop the program before it runs
Set{x, e}Assignment
Declare{x}Same as Def{x, none}. Does nothing if x already exists
If{cond, a, b}b only when cond is false
Fusion{f, g}Tries g if no pattern of f matches. Fusion{none, g} is g
Do{e, ...}Evaluates e, ... in order and returns the last value
While{cond, body}Evaluates body until cond is false. The value is none

bd_forms.pk

Def{x, 1}
Apply{println, Tuple{Do{Set{x, 5}, x}}}
Apply{println, Tuple{While{false, 1}}}
Def{n, 0}
While{Apply{_lt, Tuple{n, 3}}, Set{n, Apply{_add, Tuple{n, 1}}}}
Apply{println, Tuple{n}}

Output

5
none
3

Algebraic effects

Perform{Ask{}} calls the handler Lambda{Tuple{Ask{}, k}, ...} of the nearest Handle{body, h} that has a matching pattern. k is an ordinary function for the continuation, and the value passed to k becomes the value of the Perform.

t5_resume.pk

Def{ask, Lambda{Tuple{}, Perform{Ask{}}}}
Def{with_answer, Lambda{Tuple{v, f},
    Handle{Apply{f, Tuple{}}, Lambda{Tuple{Ask{}, k}, Apply{k, Tuple{v}}}}}}
Apply{println, Tuple{Apply{with_answer, Tuple{21,
    Lambda{Tuple{}, Apply{_mul, Tuple{Apply{ask, Tuple{}}, 2}}}}}}}
Apply{println, Tuple{Apply{with_answer, Tuple{5,
    Lambda{Tuple{}, Apply{_add, Tuple{Apply{ask, Tuple{}}, Apply{ask, Tuple{}}}}}}}}}

Output

42
10
  • k can be called any number of times, even after Handle has returned.
  • The handler is also active inside the resumed continuation.
  • Variables defined when the continuation is captured are shared between the resumed copies. Variables defined after the resumption are separate.

MatchingFailed (Partial functions and fusion), which a function call with no matching arm performs, can also be resumed with k. The value passed to k becomes the value of the failed call.

Def{f, Lambda{Tuple{0}, "zero"}}
Def{b, Handle{Cons{Apply{f, Tuple{7}}, Cons{1, Nil{}}}, Lambda{Tuple{MatchingFailed{_, _, _}, k}, Apply{k, Tuple{"other"}}}}}
Apply{println, Tuple{b}}
Cons{"other", Cons{1, Nil{}}}
