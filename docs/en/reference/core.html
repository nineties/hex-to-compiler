Core language

The core language consists of values, special forms, patterns and fusion, and algebraic effects.

M-expressions

An M-expression is a value written Head{a, b, ...}. It has a head (a symbol) and a sequence of arguments. A tuple has the head Tuple, and a list has Cons and Nil.

> Def{p, Point{3, 4}}
> p
Point{3, 4}
> Apply{head, Tuple{p}}
Point
> Apply{arity, Tuple{p}}
2
> Apply{arg, Tuple{p, 1}}
4
> Apply{push, Tuple{p, 5}}
Point{3, 4, 5}
> Point{Apply{_add, Tuple{1, 1}}, 2}
Point{2, 2}
> Tuple{1, 2}
Tuple{1, 2}
> Cons{1, Cons{2, Nil{}}}
Cons{1, Cons{2, Nil{}}}
> Nil{}
Nil{}
> Apply{_eq, Tuple{Point{1, 2}, Point{1, 2}}}
true
> Apply{_eq, Tuple{Point{1, 2}, Point{1, 3}}}
false
  • The type is Expr, and it is immutable.
  • The number of arguments has no limit. A mutable value and a NaN cannot be arguments. Making an M-expression with one is a runtime error.
  • head(x) works on M-expressions only.
> Apply{head, Tuple{1}}
not a m-expr

A type is a value (a type value), which type(x) returns. type(1) is Int, and type(Int) is Type.

> Def{a, Apply{array, Tuple{2}}}
> Tuple{Apply{array_get, Tuple{a, 0}}}
Tuple{none}
> Apply{array_set, Tuple{a, 0, 5}}
> Apply{array_get, Tuple{a, 0}}
5
> Def{b, a}
> Apply{array_set, Tuple{b, 1, 6}}
> Apply{array_get, Tuple{a, 1}}
6
> Def{a, Apply{array, Tuple{2}}}
> Apply{array_set, Tuple{a, 2, 1}}
array_set: out of range

An array or a plain array is changed by array_set or plain_set. Out of range is an error, and so is a value that does not fit a plain array.

Equality

_eq(a, b) tests whether a and b are equal as values.

  • Integers, floats and complex numbers are equal if the values are the same, even when the types differ. A NaN is not equal to any value.
  • M-expressions are interned, so they are equal only when identical. M-expressions with the same head and arguments that are identical one by one are one object. F{1} and F{1.0} are not equal.
  • Arrays and plain arrays are equal if identical, and otherwise are compared element by element.
  • hash(x) is an integer of 0 or more, and equal values give the same value.

Identity

_is(a, b) is true if a and b are the same thing (identical). Identical values are always equal. Values of different types are not identical: the integer 1 and the float 1.0 are equal but not identical.

Interning makes equal values into one object. For an interned type, equal values are identical, and _is is O(1) (except for arbitrary precision integers).

User data

_record_new(name, Tuple{f, ...}) returns Tuple{T, make}. T is the type value of a new type, and make is a function that takes as many arguments as there are fields and returns a data of that type.

> Def{r, Apply{_record_new, Tuple{Quote{Point}, Quote{Tuple{x, y}}}}}
> Def{Point, Apply{arg, Tuple{r, 0}}}
> Def{point, Apply{arg, Tuple{r, 1}}}
> Def{p, Apply{point, Tuple{1, 2}}}
> p
Point{1, 2}
> Apply{_eq, Tuple{Apply{type, Tuple{p}}, Point}}
true
> Apply{arity, Tuple{p}}
2
> Apply{arg, Tuple{p, 1}}
2
> Apply{_eq, Tuple{p, Apply{point, Tuple{1, 2}}}}
false
  • Each call makes a different type. name (a symbol) is only used for display.
  • type(x) is the type of the data, arity(x) is the number of fields, and arg(x, i) is the field i. head(x) cannot be used.
  • No function changes a field. A field can hold a mutable value.
  • A data is equal only when it is identical, and its hash is decided by the object.
  • A pattern matches by _TypeOf{p, T}. T is an expression that is evaluated when the function is made.

Numbers

An operation on mixed number types raises them to the highest type.

> Apply{_quo, Tuple{-7, 2}}
-4
> Apply{_div, Tuple{-7, 2}}
-3
> Apply{_mod, Tuple{-7, 2}}
1
> Apply{_mod, Tuple{7, -2}}
-1
  • _div truncates toward 0, and _quo rounds toward minus infinity. _mod(a, b) is _sub(a, _mul(b, _quo(a, b))) and has the sign of the divisor.
  • A zero divisor is a runtime error. _div with a float or a complex number gives an infinity or NaN (per component for a complex number).
  • _lt _le _gt _ge compare an integer and a float by their mathematical values. They give false when a NaN is involved and are a runtime error on a complex number.
  • An integer raised to a float becomes the nearest float, and one beyond the range of floats is a runtime error.

Literals

true, false and none are literals whose value is the symbol of the same name. They are not variables.

Special forms

Definition and assignment

Def{x, e} defines a new variable where it is written. Defining the same name again also makes a new variable, and functions made earlier keep the earlier one. Set{x, e} assigns to the existing variable, so functions made earlier see the new value.

> Def{f, Lambda{Tuple{x}, 1}}
> Def{g, Lambda{Tuple{}, Apply{f, Tuple{0}}}}
> Def{f, Lambda{Tuple{x}, 2}}
> Apply{g, Tuple{}}
1
> Def{h, Lambda{Tuple{x}, 1}}
> Def{k, Lambda{Tuple{}, Apply{h, Tuple{0}}}}
> Set{h, Lambda{Tuple{x}, 2}}
> Apply{k, Tuple{}}
2

The right side sees the earlier x; if there is none, it is undefined. A function that calls itself first creates the name with Declare{f}, and then adds the function with Set{f, Fusion{f, Lambda{...}}} (Adding a case).

> Declare{fact}
> Set{fact, Fusion{fact, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, 1,
...         Apply{_mul, Tuple{n, Apply{fact, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}}}
> Apply{fact, Tuple{5}}
120
> Def{x, Apply{_add, Tuple{x, 1}}}
undefined variable: x

UnQuote on the left of a definition or an assignment

Inside a QuasiQuote, the left side of Def and Set may be written UnQuote{x}, which is replaced by the symbol that x holds. When x holds Quote{true}, it stops the program, as Def{true, e} does.

> Def{x, Quote{i}}
> QuasiQuote{Do{Def{UnQuote{x}, 0}, Set{UnQuote{x}, Apply{_add, Tuple{UnQuote{x}, 1}}}}}
Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}}

Partial functions and fusion

A function takes its arguments by patterns, so it is a partial function: some arguments may not match. Fusion{f, g} tries f, and tries g if none of its patterns match.

> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Apply{f, Tuple{1}}
"one"
> Def{g, Fusion{f, Lambda{Tuple{_}, "other"}}}
> Apply{g, Tuple{7}}
"other"

A call that matches no arm raises MatchingFailed. With no handler, the program stops.

> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Apply{f, Tuple{7}}
matching failed

Patterns

  • Variable: matches anything and binds it. _ matches anything and binds nothing.
  • Integer, string: matches an equal value. Quote{s} matches the symbol s.
  • Head{p, ...}: matches an M-expression whose head is Head and whose arguments match p, ... in order.
  • _TypeOf{p, T}: matches a value x with type(x) equal to T and which p matches. T is an expression that is evaluated when the function is made. With Expr as T, it matches every M-expression.
> Def{describe, Fusion{
...     Lambda{Tuple{_TypeOf{n, Int}}, Apply{_strcat, Tuple{"integer ", Apply{_to_text, Tuple{n}}}}},
...     Fusion{
...         Lambda{Tuple{_TypeOf{s, String}}, Apply{_strcat, Tuple{"string ", s}}},
...         Lambda{Tuple{_}, "other"}}}}
> Apply{describe, Tuple{1}}
"integer 1"
> Apply{describe, Tuple{"abc"}}
"string abc"
> Apply{describe, Tuple{Quote{x}}}
"other"

To match a tree such as Apply{_add, Tuple{x, 1}}, write the function position as Quote{_add}. A variable there matches a call of any function.

> Def{simp, Fusion{
...     Lambda{Tuple{Apply{Quote{_add}, Tuple{_TypeOf{a, Int}, _TypeOf{b, Int}}}}, Apply{_add, Tuple{a, b}}},
...     Fusion{
...         Lambda{Tuple{Apply{Quote{_add}, Tuple{a, 0}}}, a},
...         Lambda{Tuple{e}, e}}}}
> Apply{simp, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}
3
> Apply{simp, Tuple{Quote{Apply{_add, Tuple{z, 0}}}}}
z
> Def{swap, Lambda{Tuple{Apply{Quote{_add}, Tuple{a, b}}}, QuasiQuote{Apply{_add, Tuple{UnQuote{b}, UnQuote{a}}}}}}
> Apply{swap, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}
Apply{_add, Tuple{2, 1}}
> Def{callee, Lambda{Tuple{Apply{f, Tuple{x}}}, f}}
> Apply{callee, Tuple{Quote{Apply{g, Tuple{1}}}}}
g

Rest arguments

_Rest{x} binds the remaining arguments to a Tuple (Tuple{} if none).

> Def{total, Lambda{Tuple{_Rest{xs}}, xs}}
> Apply{total, Tuple{}}
Tuple{}
> Apply{total, Tuple{1, 2, 3}}
Tuple{1, 2, 3}
> Def{count, Lambda{Tuple{first, _Rest{others}}, Apply{_add, Tuple{1, Apply{arity, Tuple{others}}}}}}
> Apply{count, Tuple{7, 8, 9}}
3
> Def{describe, Fusion{
...     Lambda{Tuple{a}, "one"},
...     Fusion{
...         Lambda{Tuple{a, b}, "two"},
...         Lambda{Tuple{a, b, _Rest{c}}, "three or more"}}}}
> Apply{describe, Tuple{1}}
"one"
> Apply{describe, Tuple{1, 2}}
"two"
> Apply{describe, Tuple{1, 2, 3, 4}}
"three or more"
> Def{args_of, Lambda{Tuple{Call{f, _Rest{rest}}}, rest}}
> Apply{args_of, Tuple{Call{1, 2, 3}}}
Tuple{2, 3}
> Apply{args_of, Tuple{Call{1}}}
Tuple{}
  • It can be written only as the last parameter of a Lambda and as the last argument of a pattern Head{p, ...}.
  • A call with fewer arguments than the preceding parameters does not match.
  • Writing it anywhere else or as an argument of a call stops the program with a message before the code runs.

Adding a case

Declare{f} followed by Set{f, Fusion{f, Lambda{Tuple{p, ...}, body}}} adds a case after the function of f when the variables at the place where it is written have f, and defines a new f otherwise.

> Declare{fib}
> Set{fib, Fusion{fib, Lambda{Tuple{0}, 0}}}
> Set{fib, Fusion{fib, Lambda{Tuple{1}, 1}}}
> Set{fib, Fusion{fib, Lambda{Tuple{n},
...     Apply{_add, Tuple{
...         Apply{fib, Tuple{Apply{_sub, Tuple{n, 1}}}},
...         Apply{fib, Tuple{Apply{_sub, Tuple{n, 2}}}}}}}}}
> Apply{fib, Tuple{20}}
6765
Written atVariables at the place
top levelglobal variables of the same file
in a functionits parameters and the variables defined earlier in it
branch of a top-level If, body of a Whilevariables defined earlier in it

Variables of an outer function, variables of another file (a library loaded by use) and builtin functions are not variables at the place. Declare{f} with such a name defines a new f that hides the outer one and does not change it. To add a case to an f of another file, Set it without Declare.

> Declare{name}
> Set{name, Fusion{name, Lambda{Tuple{x}, "outer"}}}
> Def{inner, Lambda{Tuple{}, Do{
...     Declare{name},
...     Set{name, Fusion{name, Lambda{Tuple{0}, "inner"}}},
...     Apply{name, Tuple{0}}}}}
> Tuple{Apply{inner, Tuple{}}, Apply{name, Tuple{0}}, Apply{name, Tuple{1}}}
Tuple{"inner", "outer", "outer"}
> Apply{use, Tuple{"list"}}
> Set{foldl, Fusion{foldl, Lambda{Tuple{f, acc, Tuple{a, b}},
...     Apply{f, Tuple{Apply{f, Tuple{acc, a}}, b}}}}}
> Tuple{
...     Apply{foldl, Tuple{_add, 0, Cons{1, Cons{2, Cons{3, Nil{}}}}}},
...     Apply{foldl, Tuple{_add, 0, Tuple{4, 5}}}}
Tuple{6, 9}
> Declare{reverse}
> Set{reverse, Fusion{reverse, Lambda{Tuple{xs}, "mine"}}}
> Apply{reverse, Tuple{Cons{1, Cons{2, Nil{}}}}}
"mine"

Mutual recursion

Declare the name first with Def{f, none} and fill it in later with Set{f, Fusion{f, Lambda{...}}}. Since Fusion{none, g} is g, the first Set assigns the function itself.

> Def{odd, none}
> Declare{even}
> Set{even, Fusion{even, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, true, Apply{odd, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
> Set{odd, Fusion{odd, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, false, Apply{even, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
> Tuple{Apply{even, Tuple{10}}, Apply{odd, Tuple{7}}}
Tuple{true, true}

Calling f before it is filled calls none and stops the program.

> Def{f, none}
> Apply{f, Tuple{}}
not a function

MatchingFailed

A function call or the last function of a fusion that has no matching arm performs MatchingFailed{f, args, loc} instead of stopping.

FieldContents
fthe function that was called (the whole fusion for a fusion)
argsa Tuple{...} of the arguments that did not match
locthe position of the failed call: Loc{file, line, column}
> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Def{a, Handle{Apply{f, Tuple{7}}, Lambda{Tuple{MatchingFailed{_, Tuple{n}, _}, k}, n}}}
> a
7
  • The value of the handler is the value of the Handle, not of Apply{f, Tuple{7}}.
  • With no handler, the program prints matching failed and stops. It is not unhandled effect.
  • A handler that accepts only Return{v} or Break{} is passed through. A handler Lambda{Tuple{e, k}, body} whose pattern matches anything also receives MatchingFailed.

Position of the failed call

  • loc is the position of the At that wraps the call. The loc of a call with no At is none.
  • For a failure in the callee of a tail call, loc is the position of the nearest caller left on the stack, which is outside the failed call. If the g in f(x) := g(x) fails, it is the position where f was called, not g(x).

A failure deep inside an arm

Whether to move on to the next arm is decided only by the entry patterns. A MatchingFailed raised deep in the body of an arm whose entry matched propagates outward.

> Def{g, Lambda{Tuple{0}, "zero"}}
> Def{h, Fusion{Lambda{Tuple{x}, Apply{g, Tuple{x}}}, Lambda{Tuple{x}, "second arm"}}}
> Handle{Apply{h, Tuple{5}}, Lambda{Tuple{MatchingFailed{f, _, _}, k}, "failed in g"}}
"failed in g"

Algebraic effects

Perform{Ask{}} calls the handler Lambda{Tuple{Ask{}, k}, ...} of the nearest Handle{body, h} that has a matching pattern. k is an ordinary function for the continuation, and the value passed to k becomes the value of the Perform.

> Def{ask, Lambda{Tuple{}, Perform{Ask{}}}}
> Def{with_answer, Lambda{Tuple{v, f},
...     Handle{Apply{f, Tuple{}}, Lambda{Tuple{Ask{}, k}, Apply{k, Tuple{v}}}}}}
> Apply{with_answer, Tuple{21,
...     Lambda{Tuple{}, Apply{_mul, Tuple{Apply{ask, Tuple{}}, 2}}}}}
42
> Apply{with_answer, Tuple{5,
...     Lambda{Tuple{}, Apply{_add, Tuple{Apply{ask, Tuple{}}, Apply{ask, Tuple{}}}}}}}
10
  • k can be called any number of times, even after Handle has returned.
  • The handler is also active inside the resumed continuation.
  • Variables defined when the continuation is captured are shared between the resumed copies. Variables defined after the resumption are separate.

MatchingFailed (Partial functions and fusion), which a function call with no matching arm performs, can also be resumed with k. The value passed to k becomes the value of the failed call.

> Def{f, Lambda{Tuple{0}, "zero"}}
> Handle{Cons{Apply{f, Tuple{7}}, Cons{1, Nil{}}}, Lambda{Tuple{MatchingFailed{_, _, _}, k}, Apply{k, Tuple{"other"}}}}
Cons{"other", Cons{1, Nil{}}}
