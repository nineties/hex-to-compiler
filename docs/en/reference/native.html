native

use("native/expand") defines a systems language. Its meaning is that of vasm, with a higher-level notation: expressions nest, and let, for, compound assignments, the short-circuit and and or, and large integer literals are available. native_expand expands the functions and structs written in native{| ... |} to a vasm module. Ownership and borrowing are checked on the expanded vasm.

Programs

A program is a list of structs and functions. Types, structs and function declarations are written as in vasm. The body of a function is a list of statements, separated by newlines or ;.

The value of native{| ... |} is PModule{[...]}. native_expand(m) is the vasm Module{[...]}, which vasm_check and vasm_build take as it is. native_expand_all(m) is Tuple{module, errors}. The errors are VasmErr{kind, loc, msg}, the first one of each function. native_errors(file, errors) gives the positions as Loc of the file.

Expressions

Expressions nest. The precedence grows from the top to the bottom.

Parentheses group. Arguments are computed from left to right. The a of a[i] and the s of s.f are variables. A struct value starts with a field, so it is told from the { that starts the body of an if or a for.

If the last statement of the body of a function that gives a value is an expression, its value is the result.

native_expand.pk

use("native/expand")
use("vasm/text")

m := native{|
    fn gcd(a: i64, b: i64) -> i64 {
        while b != 0 {
            let t = a % b
            a = b
            b = t
        }
        a
    }

    fn bump[r](m: &mut r [i32], n: i32) {
        for i in 0 as i32..n {
            m[i] += 1
        }
    }
|}
put(vasm_text(native_expand(m)))

Output

fn gcd(a: i64, b: i64) -> i64 {
    while (b != 0) {
        var t: i64
        t = a % b
        a = b
        b = t
    }
    return a
}

fn bump[r](m: &mut r [i32], n: i32) {
    var t0: i32
    t0 = n
    var i: i32
    i = 0
    while (i < t0) {
        var t1: i64
        t1 = i as i64
        var t2: i32
        t2 = m[t1]
        t2 = t2 + 1
        m[t1] = t2
        i = i + 1
    }
}

How types are fixed

  • The type of an expression comes from the declarations of the variables and functions and from the types of the built-in functions. Types are written only at let, var, parameters, results of functions and as.
  • An integer literal alone has no type. The type of the place it is put in, of the parameter, of the other operand or of the result of the function is its type. A literal that has nothing to fix its type, as in let x = 5, is an error. Write let x: i64 = 5 or 5 as i64.
  • The type of the variable of for i in a..b is the type of whichever of a and b is not a literal. If both are literals it is an error; give one of them a type, as in 0 as i64..10.
  • The type of a call whose result holds a borrow is inferred only when the region of the result is fixed by the arguments to one. Otherwise write let x: T = f(...).
  • The index of an array is i64. An index of another integer type gets as i64.
  • A name can be declared again. The earlier variable is hidden.

Large literals

A literal of vasm is from -32768 to 32767. native accepts an integer literal beyond it. A literal outside the range of its type is an error.

native_logic.pk

use("native/expand")
use("vasm/text")

m := native{|
    fn both(a: i64, b: i64) -> bool {
        a > 0 and b > 0
    }

    fn mask(x: i32) -> i32 {
        x & 0x3FFFFFF
    }
|}
put(vasm_text(native_expand(m)))

Output

fn both(a: i64, b: i64) -> bool {
    var t0: bool
    t0 = a > 0
    var t1: bool
    t1 = t0
    if (t1) {
        var t2: bool
        t2 = b > 0
        t1 = t2
    }
    return t1
}

fn mask(x: i32) -> i32 {
    var t0: i32
    t0 = 2047
    t0 = t0 << 15
    t0 = t0 | 32767
    var t1: i32
    t1 = x & t0
    return t1
}

The expansion makes the value from parts of 15 bits, the greatest first, joined by << and |. A negative value is subtracted from 0 at the end.

Errors

The kind of an error of the expansion is 'type (the type is not known, a literal is outside the range of its type, a statement that is an expression is not a call) or 'undefined (a variable, function or struct that is not declared). Ownership, borrowing and initialization are not checked by the expansion; vasm_check checks the expanded vasm. The positions of the errors are those of the native source.

native_errors.pk

use("native/expand")

m := native{|
    fn f(n: i64) {
        let x = 5
    }
    fn g(n: i64) {
        for i in 0..10 {
            n += 1
        }
    }
    fn h(n: i64) -> i64 {
        n + k
    }
|}
file := argv()[0]
each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), native_errors(file, arg(native_expand_all(m), 1)))

Output

line 5: the type of this value is not known; write the type, as in let x: i32 = ... or e as i32
line 8: the type of the loop variable is not known; write one bound with its type, as in 0 as i64..n
line 13: k is not declared
