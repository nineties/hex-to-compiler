Data model

A value is an M-expression or an atom.

M-expressions

An M-expression is a value written Head{a, b, ...}. It has a head (a symbol) and a sequence of arguments.

dm_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(push(p, 5))
println(Point{1 + 1, 2})
println((1, 2))
println([1, 2])
println(1 :: [2])
println([])
println(Point{1, 2} == Point{1, 2})
println(Point{1, 2} == Point{1, 3})

Output

4

Nil{}
true
false
  • The type is Expr, and it is immutable.
  • Sugar: (a, b) is Tuple, [a, b] and :: are Cons, and [] is Nil.
  • The number of arguments has no limit. A mutable value and a NaN cannot be arguments. Making an M-expression with one is a runtime error.
  • head(x) works on M-expressions only.

println(head(1))

A type is a value (a type value), which type(x) returns. type(1) is Int, and type(Int) is Type. x @ T tests whether type(x) is T, and x @ Expr matches every M-expression.

a := array(2)
println(a[0])
a[0] = 5
println(a[0])
b := a
b[1] = 6
println(a[1])

a := array(2)

An array or a plain array is changed by a[i] = e. Out of range is an error, and so is a value that does not fit a plain array.

Equality

a == b tests whether a and b are equal as values.

  • Integers, floats and complex numbers are equal if the values are the same, even when the types differ (1 == 1.0). A NaN is not equal to any value.
  • M-expressions are equal if the heads and the arguments are equal.
  • Arrays and plain arrays are equal if identical, and otherwise are compared element by element.
  • A pattern that writes the same name twice, such as f(a, a), matches only when the two values are equal.
  • hash(x) is an integer of 0 or more, and equal values give the same value.

Identity and is

a is b is true if a and b are the same thing (identical). Identical values are always equal, and values of different types are not identical (1 == 1.0 is true, 1 is 1.0 is false). is not is the negation. Its precedence is that of ==, it does not group, and it cannot be written in a pattern.

Interning makes equal values into one object. For an interned type, equal values are identical, and is is O(1) (except for arbitrary precision integers).

User data

  • Made by a builtin function. You must specify whether it is immutable or mutable.
  • Immutable user data cannot hold a mutable value. Making one that does is a runtime error.
  • Each type made is a different value. The name is only used for display, and types with the same name are told apart by is.
  • You may give a function for == and a function for hash, both together. The author must keep two rules: if a is b then a == b, and equal values have the same hash.
  • Without them, the hash is decided by the contents if immutable and by the object if mutable.

Numbers

An operation on mixed number types raises them to the highest type.

dm_int.pk

println(-7 // 2)
println(_div(-7, 2))
println(_quo(-7, 2))
println(_mod(-7, 2))
println(_mod(7, -2))

Output

-4
-3
-4
1
-1
  • _div truncates toward 0, and _quo (the operator //) rounds toward minus infinity. _mod(a, b) is a - b * (a // b) and has the sign of the divisor.
  • A zero divisor is a runtime error. _div with a float or a complex number gives an infinity or NaN (per component for a complex number).
  • _lt _le _gt _ge compare an integer and a float by their mathematical values. They give false when a NaN is involved and are a runtime error on a complex number.
  • An integer raised to a float becomes the nearest float, and one beyond the range of floats is a runtime error.

Literals

true, false and none are literals whose value is the symbol of the same name. They are not variables. A top-level string is a comment.

record

record T(f, g, ...) names the arguments of T{a, b, ...}. t.f is the argument at the position of f, and the . follows its left operand with no space. t with { f = e } is a new value with that field replaced.

t1_with.pk

record Point(x, y)

p := Point{1, 2}
q := p with { y = 5 }
println(p)
println(q)
println(p with { x = p.y, y = p.x })
println(p with { x = 7 } with { y = 8 })

Output

Point{1, 2}
Point{1, 5}
Point{2, 1}
Point{7, 8}
  • Values with different heads can have fields of the same name. Declaring the same T again replaces the names.
  • Using .f on a value whose head is not declared, or that has no field f, stops the program with a message.
  • The fields of with are replaced from the left, and a right-hand side can refer to the fields of the original t. with { ... } can follow another one.
