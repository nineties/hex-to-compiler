Libraries

The files of planck/lib are written in the syntax of planck and loaded by use("name"). The functions are the fields of the modules, called as in list.map(f, xs). Functions that are clear from their names and arguments are left out; only the rules and the exceptions are written. A list is Cons{x, xs} and Nil{}.

Some functions can also be called without the module name: panic and assert of base; foldl reverse length append map filter concat_map each find member range of list; and join of string.

list

  • map, filter and each call from the front. foldl(f, acc, xs) computes f(f(acc, x1), x2), and foldr(f, init, xs) computes f(x1, f(x2, init)).
  • nth(xs, i) counts from 0. find(p, xs) gives none when nothing is found, and index_of(x, xs) gives -1.
  • zip(xs, ys) has the length of the shorter one. range(a, b) is [a, ..., b - 1]. sort(less, xs) is a stable merge sort by less(a, b).

r_lib_list.pk

use("list")
use("pretty")
xs := [3, 1, 4, 1, 5]
put(f"{length(xs)} {list.sum(xs)} {list.nth(xs, 2)} {list.last(xs)}\n")
put(f"{reverse(xs)} {append([0], xs)} {list.concat([[1], [2, 3]])}\n")
put(f"{list.take(xs, 2)} {list.drop(xs, 2)}\n")
put(f"{find(x -> x > 3, xs)} {list.any(x -> x > 4, xs)} {list.all(x -> x > 0, xs)}\n")
put(f"{member(4, xs)} {list.index_of(4, xs)} {list.index_of(9, xs)}\n")
put(f"{list.foldr((x, acc) -> x :: acc, [], xs)}\n")
put(f"{concat_map(x -> [x, x], [1, 2])}\n")
each(x -> put(f"<{x}>"), [1, 2, 3])
put("\n")

Output

[5, 1, 4, 1, 3] [0, 3, 1, 4, 1, 5] [1, 2, 3]
[3, 1] [4, 1, 5]
4 true true
true 2 -1
[3, 1, 4, 1, 5]
[1, 1, 2, 2]
<1><2><3>

vector

A vector is a growable array Vector{a}. v[i] and v[i] = x call vector.get and vector.set, which stop the program for an index out of range. vector.push(v, x) appends and returns x, and vector.pop(v) removes and returns the last element.

string

  • The c of chr(c) is 32 to 126, 9, 10 or 13. char_at(s, i) is "" when out of range.
  • index_of_str(s, part, from) gives -1 when part is not found, and str_to_int(s) gives none when s cannot be read. str_cmp(a, b) is -1, 0 or 1 by the order of the character codes.
  • sep of split(s, sep) cannot be empty, and join(sep, xs) is its inverse. strbuf.add(b, s) adds a piece, and strbuf.str(b) gives the joined string.

r_lib_string.pk

use("string")
use("pretty")
put(f"{string.chr(65)} [{string.char_at("abc", 5)}] {string.ends_with("main.pk", ".pk")}\n")
put(f"{string.index_of_str("banana", "na", 3)} {string.str_repeat("ab", 3)}\n")
put(f"{string.str_cmp("a", "b")} {string.str_cmp("b", "b")} {string.str_less("b", "a")}\n")
put(f"{string.int_to_str(-42)} {string.str_to_int("x1")}\n")
put(f"{string.is_digit(ord("7", 0))} {string.is_alpha(ord("_", 0))} {string.is_ident_start(ord("_", 0))}\n")
b := strbuf.new()
strbuf.add(b, "plan")
strbuf.add(b, "ck")
put(strbuf.str(b)); put("\n")

-1 0 false
-42 none
true false true

getopt

Reads command-line options in the rules of GNU getopt_long. An option is Opt{short, long, takes}: short is a one-character string, long is a string (either may be ""), and takes is true when the option has a value. getopt.parse(opts, args, from) reads the array args from the index from (1 for argv(), which skips the program file).

  • The result is Parsed{table, rest}. table maps the name of each given option, long or else short, to its value: true for an option without a value, and the last one wins. rest is the array of the strings that are not options.
  • The forms are -a, -abc, -o value, -ovalue, --opt, --opt value and --opt=value. A value may begin with -. A lone - is not an option, and after -- every string is in rest.
  • Errors are values, not stops: Unknown{name} (not in opts), Missing{name} (the value is missing) and NoValue{name} (--opt=value on an option without a value). name is the string as written. A long option cannot be shortened.

r_lib_getopt.pk

use("table")
use("getopt")
spec := [Opt{"a", "all", false}, Opt{"o", "output", true}, Opt{"", "level", true}]
use("list")
args := list.list_to_array(["prog", "-ao", "out.txt", "x", "--level=3", "--", "-y"])
r := getopt.parse(spec, args, 1)
println(head(r))
opts := arg(r, 0)
println(table.get(opts, "all", false))
println(table.get(opts, "output", none))
println(table.get(opts, "level", none))
rest := arg(r, 1)
println(array_len(rest))
println(rest[0])
println(rest[1])
println(getopt.parse(spec, list.list_to_array(["prog", "-ax"]), 1))
println(getopt.parse(spec, list.list_to_array(["prog", "-o"]), 1))

table

table.get(t, key, default) and table.set(t, key, value) read and write a table. table.keys, table.values and table.items ([Tuple{key, value}, ...]) list the entries in an unspecified order. A set is a table whose values are true.

r_lib_table.pk

use("list")
use("table")
use("pretty")
t := table.new()
table.set(t, 'a, 1)
table.set(t, 'b, 2)
put(f"{table.len(t)} {table.has(t, 'a)} {table.has(t, 'z)}\n")
put(f"{list.sort((a, b) -> a < b, table.values(t))}\n")
s := set.from_list([1, 2, 2, 3])
put(f"{set.len(s)} {set.has(s, 2)} {list.sort((a, b) -> a < b, set.to_list(s))}\n")

Output

2 true false
[1, 2]
3 true [1, 2, 3]

error

  • error.line_col(src, pos) is Tuple{line, column} of the byte position pos, counted from 1, and error.line_text(src, line) is the line without the newline. error.loc_at(file, src, pos) is Loc{file, line, column}, and error.show_loc writes it as file:line:column.
  • error.at(loc, msg) performs Error{loc, msg}. error.catch(f) gives Ok{f()}, or Err{loc, msg} when f() performs Error{loc, msg}.
  • error.show(src, loc, msg) is file:line:column: msg, the line, and a ^ under the column.

r_lib_error.pk

use("error")
src := "x := 1\ny := x +\n"
r := error.catch(() -> error.at(error.loc_at("a.pk", src, 12), "expected an expression"))
println(r)
put(error.show(src, arg(r, 0), arg(r, 1))); put("\n")
println(error.catch(() -> 42))

Output

Err{Loc{"a.pk", 2, 6}, "expected an expression"}
a.pk:2:6: expected an expression
  y := x +
       ^
Ok{42}

pretty

show(x) is the string that print writes, except that a list is written as [a, b]. With use("pretty"), a value embedded in f"..." is also written by show, so a list becomes [...]. pretty.text(x, width) puts a part on one line when it fits in width columns, and otherwise puts one element on each line, indented by two spaces. pretty.print(x) writes it with the width 60.

r_lib_pretty.pk

use("pretty")
put(pretty.show(["a", 'b, F{1}])); put("\n")
put(pretty.quote_str("say \"hi\"")); put("\n")
pretty.print(Node{Node{Leaf{}, "left", Leaf{}}, "root", Node{Leaf{}, "a long right branch", Leaf{}}})

"say \"hi\""

  "root",
  Node{Leaf{}, "a long right branch", Leaf{}}
}

unparse

Makes, from a tree, a string that a rule reads as that tree. unparse.text(t) does it for the rule expr, and unparse.text_as(rule, t) for any rule, stopping the program when there is no string. unparse.try_as returns none instead of stopping. The grammar is read from peg_sources.

  • An alternative Act{Seq{e1, ...}, Lambda{Tuple{Tuple{l1, ...}}, body}} is reversed when body is a quasi-quotation whose !x are labels, Quote{c}, labels, Tuple{labels} or mexpr(h, args). The tree is matched against the quasi-quotation, the subtrees are put in the labels, and the elements are written in order (a rule by unparse_as(rule, subtree)). The label of an element that always matches the same string ("+" or Same{}) can be _.
  • Among the alternatives that match the tree, the one with the most parts of the quasi-quotation that are not !x is used.
  • When an alternative of a stronger rule is placed where a weaker rule is wanted, it is enclosed in the first "(" e ")" of the grammar. An alternative that is only a rule name connects the rule to the rules it can be, and decides which alternatives need parentheses. An alternative that ends with a weaker rule (while (c) e ends with expr) also needs parentheses, except where the same or a weaker rule is wanted.
  • unparse.custom(owner, spec, tail, f) adds an alternative to the rule owner. f(t) is a string or none, spec ranks it against the quasi-quotations, and tail is the last rule of the string or none. Do{...} (in { }, one expression per line, indented by four spaces) and If (if (c) a else b) are added this way.
  • A tree that the grammar does not write becomes a constructor call Head{a, ...}. A symbol that is not an identifier, and a value that is not an integer, a string, a symbol or an M-expression, have no string.

t6_unparse.pk

use("unparse")
t := '(if (n < 0) -n else n * (n + 1))
println(t)
put(unparse.text(t)); put("\n")

Output

If{Apply{_lt, Tuple{n, 0}}, Apply{_sub, Tuple{0, n}}, Apply{_mul, Tuple{n, Apply{_add, Tuple{n, 1}}}}}
if (n < 0) -n else n * (n + 1)

base

panic(msg) writes msg and stops with status 1. assert(c, msg) calls panic(msg) when c is not true.

Libraries written as a module

When a library is written as a module, the module is called by its name after the library is loaded. A helper function stays inside unless it is marked export. A test that calls it is written in a test in the module. If bitset is written as module bitset, it goes as follows.

use("bitset")
s := bitset.new(100)
bitset.add(s, 3)

Preprocessed libraries

Running tools/preprocess.pk with the names of libraries parses them into M-expressions in advance and writes them to planck/lib/<name>.pkm, one M-expression on each line. Nothing is evaluated in advance. use evaluates the M-expressions of the .pkm one by one, with the same behavior as parsing the .pk. Without a usable .pkm, use parses the .pk.

A .pkm is used when the text of the library and the grammar are the same as when it was written. The grammar is the same when:

  • The files planck/init.pk, planck/peg.pk and planck/syntax.pk have the same text
  • The libraries that have declared rules are the same libraries with the same text in the same order
  • No other rule has been declared (peg_version is the same).

A file that cannot be read as M-expressions, or that does not end with its last expression, is not used either. A program that replaces parse or a function that the actions of the rules call is not detected. A library with a value that has no text as an M-expression (a function, an array) in its parse result cannot be preprocessed.
