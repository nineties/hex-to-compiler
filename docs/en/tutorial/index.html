planck tutorial

planck is a language for symbolic and language processing. Expressions are read as M-expressions and evaluated, and a program can extend the syntax itself, which is a set of packrat parser rules. Each chapter runs one example to show an idea. All outputs are results of planck0, and the language is defined in the Reference.

Running

$ ./planck0 prog.pk a b

Run it at the top of the repository. There is no REPL, and the program receives its arguments from argv().
