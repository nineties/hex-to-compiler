planck tutorial

planck is a language for symbolic and language processing. Expressions are translated to M-expressions and evaluated. A program can extend the syntax itself, which is a set of packrat parser rules.

This tutorial walks through the language by example, for readers who have written a language processor. All outputs are the results of running planck0. The Reference gives the details of the rules. The definition is planck/SPEC.rst.

t3_fib.pk

fib := (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

Output

6765

A function is a chain of lambdas, one per pattern, joined by | (fusion). The syntax is a set of grammar rules, so a program can add to it.

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

Output

planck!
planck!
planck!

Running

$ ./planck0 prog.pk a b

Run it at the top of the repository. There is no REPL. The program receives its arguments from argv(): argv()[0] is prog.pk, followed by "a" and "b".

A file is read and evaluated one top-level expression at a time. The global variable parse reads and eval evaluates. Both are looked up again for every expression (chapter 8).
