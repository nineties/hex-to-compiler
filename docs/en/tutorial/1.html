1. Expressions, bindings, functions

There are no statements. if, while and blocks are expressions, so programs are built by combining expressions that return values.

t1_hello.pk

put("Hello, world!\n")

Output

Hello, world!

t1_vars.pk

x := 10
y := x * 2
println(y)
x = x + 1
println(x)

Output

20
11

t1_func.pk

square(n) := n * n
println(square(12))

add3(a, b, c) := a + b + c
println(add3(1, 2, 3))

twice := f -> x -> f(f(x))
println(twice(square)(3))

Output

144
6
81
  • := defines a variable and = assigns to an existing one. A variable defined by := in a function is not visible outside it (Scope of variables).
  • Only false is false. 0 and none are true.
  • There is no space between a function name and (.

Blocks and closures

t1_rec.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(10))

make_counter() := {
    n := 0
    () -> { n = n + 1; n }
}
c := make_counter()
c(); c()
println(c())

Output

3628800
3

{ ... } returns the value of its last expression. A function is a closure and can assign to the variables it captures.
