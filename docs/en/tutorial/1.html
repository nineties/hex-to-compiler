1. Expressions, bindings, functions

There are no statements. if, while and blocks are expressions.

Hello, world

t1_hello.pk

put("Hello, world!\n")

Output

Hello, world!

Output and integers

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

Output

7
9
3
1
-3
36

Integer / truncates toward zero. Literals are decimal, 0x, 0o or 0b. Expressions are separated by a newline or ;. # starts a comment up to the end of the line.

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

Output

42 "abc"
abc
Point{1, "a"}

print and println write a value as it is written in source. put writes only the contents of a string.

Bindings

t1_vars.pk

x := 10
y := x * 2
println(y)
x = x + 1
println(x)

Output

20
11

:= defines a variable and = assigns to an existing one. They are different operations. A variable defined by := in a function is a variable of the function and is not visible outside (Scope of variables).

Functions

t1_func.pk

square(n) := n * n
println(square(12))

add3(a, b, c) := a + b + c
println(add3(1, 2, 3))

twice := f -> x -> f(f(x))
println(twice(square)(3))

Output

144
6
81

f(p, ...) := e defines a function. x -> e, (a, b) -> e and () -> e are lambdas. There is no space between a function name and (.

t1_if.pk

abs(n) := if (n < 0) -n else n
println(abs(-5))

sign(n) := n < 0 ? -1 : n == 0 ? 0 : 1
println(sign(-3))
println(sign(0))
println(sign(8))

Output

5
-1
0
1

if (c) a else b is an expression. Without else its value is none. Only false is false: 0 and none are true. The logical operators are and, or and not.

Blocks and closures

t1_block.pk

sum_to(n) := {
    s := 0
    i := 1
    while (i <= n) {
        s = s + i
        i = i + 1
    }
    s
}
println(sum_to(100))

Output

5050

{ ... } evaluates its expressions in order and returns the value of the last one.

t1_rec.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(10))

make_counter() := {
    n := 0
    () -> { n = n + 1; n }
}
c := make_counter()
c(); c()
println(c())

Output

3628800
3

A function is a closure with lexical scope. It can assign to the variables it captures.

Scope of variables

The variables a function sees are decided by where it is written (chapter 9).
