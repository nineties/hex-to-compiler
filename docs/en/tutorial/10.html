10. Indexing and rewriting

a[i] and a[i] = v call _index_get and _index_set. These are functions joined by |, one for each kind of value, so a program can add its own kind. t[p -> e | ...] rewrites a syntax tree.

Reading and writing

t9_index.pk

record Point(x, y)
a := array(3)
a[0] = 10
a[1] = a[0] + 5
a[2] = a[1] * 2
println(a[2])
s := "planck"
println(s[1])
t := table()
t['x] = 1
t['y] = 2
println(t['x] + t['y])
println(t['z])
xs := [10, 20, 30]
println(xs[1])
p := Point{3, 4}
println(p[0] + p[1])
println(p['y])

Output

30
"l"
3
none
20
7
4

Indexing works on arrays, strings, tables, lists and M-expressions. For a string, s[i] is the i-th character, a string of length 1. A list is counted from 0. For an M-expression, an integer is a position and a symbol is a field declared by record. A missing key of a table gives none.

Arrays, plain arrays, tables and vectors can be written. Strings, lists, tuples and M-expressions are immutable: s[0] = 1 stops the program with cannot assign to an element of a string, which is immutable: .... An index out of range also stops the program.

Adding a kind

t9_kind.pk

_index_get = (Counts{t}, k) -> table_get(t, k, 0) | _index_get
_index_set = (Counts{t}, k, n) -> table_set(t, k, n) | _index_set
c := Counts{table()}
for (w in ["a", "b", "a", "a"]) c[w] = c[w] + 1
println(c["a"])
println(c["b"])
println(c["z"])

Output

3
1
0

Put your own kind at the front of the fusion and pass the rest to the original _index_get. Here an M-expression with the head Counts is a table that counts a missing key as 0. use("vector") adds vectors in the same way.

Rewriting trees

t9_rewrite.pk

use("unparse")
step(e) := e[
    Apply{'_add, Tuple{a @ int, b @ int}} -> a + b
  | Apply{'_mul, Tuple{a @ int, b @ int}} -> a * b
  | Apply{'_add, Tuple{a, 0}} -> a
  | Apply{'_mul, Tuple{a, 1}} -> a
]
simplify(e) := {
    println(unparse(e))
    n := step(e)
    while (n != e) {
        e = n
        println(unparse(e))
        n = step(e)
    }
    e
}
simplify('(x * 1 + (2 + 3) * 4 + 0))

Output

"x * 1 + (2 + 3) * 4 + 0"
"x * 1 + (2 + 3) * 4"
"x + 5 * 4"
"x + 20"

t[p -> a | q -> b] is subst(t, p -> a | q -> b). Each part of the tree t is tried from the root down. When the pattern of an arm matches, the part is replaced and its inside is not tried. When no arm matches, the arguments are tried in order. An arm can have a guard p if c -> a as in match.

A replacement leaves its inside untouched, so repeat until nothing changes. The head of an operator tree is a name with _, such as '_add. A quoted tree is written ('e)[f]; 't[f] quotes t[f].
