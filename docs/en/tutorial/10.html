10. Indexing and rewriting

a[i] and a[i] = v call _index_get and _index_set. These are functions joined by |, one for each kind of value, so a program can add its own kind.

t9_index.pk

use("table")
record Point(x, y)
a := array(3)
a[0] = 10
a[1] = a[0] + 5
a[2] = a[1] * 2
println(a[2])
s := "planck"
println(s[1])
t := table.new()
t['x] = 1
t['y] = 2
println(t['x] + t['y])
println(t['z])
xs := [10, 20, 30]
println(xs[1])
p := Point{3, 4}
println(p[0] + p[1])
println(p['y])

Output

30
"l"
3
none
20
7
4

Strings, lists, tuples and M-expressions are immutable, and writing to them stops the program.

Adding a kind

t9_kind.pk

use("table")
_index_get = (Counts{t}, k) -> table.get(t, k, 0) | _index_get
_index_set = (Counts{t}, k, n) -> table.set(t, k, n) | _index_set
c := Counts{table.new()}
for (w in ["a", "b", "a", "a"]) c[w] = c[w] + 1
println(c["a"])
println(c["b"])
println(c["z"])

Output

3
1
0

Put the new kind at the front of the fusion and pass the others to the original function.

Rewriting trees

t9_rewrite.pk

use("unparse")
step(e) := e[
    Apply{'_add, Tuple{a @ int, b @ int}} -> a + b
  | Apply{'_mul, Tuple{a @ int, b @ int}} -> a * b
  | Apply{'_add, Tuple{a, 0}} -> a
  | Apply{'_mul, Tuple{a, 1}} -> a
]
simplify(e) := {
    println(unparse.text(e))
    n := step(e)
    while (n != e) {
        e = n
        println(unparse.text(e))
        n = step(e)
    }
    e
}
simplify('(x * 1 + (2 + 3) * 4 + 0))

Output

"x * 1 + (2 + 3) * 4 + 0"
"x * 1 + (2 + 3) * 4"
"x + 5 * 4"
"x + 20"

t[p -> a | q -> b] is subst(t, ...). It tries each part of the tree from the root down, replaces a part that matches and does not try its inside. Repeat it until nothing changes.
