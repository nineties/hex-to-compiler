8. Records, local functions, escapes

record declares names for the arguments of an M-expression. return, break and continue are implemented as effects (chapter 5).

record

t8_record.pk

record Point(x, y)
p := Point{3, 4}
println(p.x * p.x + p.y * p.y)

move(p, dx) := Point{p.x + dx, p.y}
println(move(p, 10))

Output

25
Point{13, 4}

record Point(x, y) only names the 0th and 1st arguments of the head Point. The value is still Point{3, 4}. Patterns can destructure it too. There is no space before ..

Local functions

t8_local.pk

parity(n) := {
    is_even(n) := if (n == 0) true else is_odd(n - 1)
    is_odd(n) := if (n == 0) false else is_even(n - 1)
    if (is_even(n)) "even" else "odd"
}
put(parity(10)); put("\n")
put(parity(7)); put("\n")

Output

even
odd

An f(x) := ... in a block is a function definition of the same form as at the top level. It is defined where it is written, so functions that call each other first declare the name with fun f and fill it later with f(x) = .... The body of a function sees the variables of the place where it is defined, not those of the caller (Scope of variables).

return, break, continue

t8_return.pk

find_first(p, xs) := {
    for (x in xs) if (p(x)) return x
    none
}
println(find_first(x -> x > 3, [1, 5, 2, 7]))
println(find_first(x -> x > 9, [1, 5, 2, 7]))

n := 0
odd_sum := 0
while (true) {
    n = n + 1
    if (n > 10) break
    if (n % 2 == 0) continue
    odd_sum = odd_sum + n
}
println(odd_sum)

Output

5
none
25

return e leaves the enclosing function. The body of for is a function, but the return in it leaves the outer find_first. break and continue apply to the innermost while or for.
