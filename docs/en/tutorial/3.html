3. Patterns and fusion

The parameters of a lambda are patterns. f | g (fusion) is a function that tries g when no pattern of f matches. Case analysis is written with it.

t3_fib.pk

fun fib
fib = (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

The arms are tried from the left, and MatchingFailed is performed when none matches (with no handler, the program stops with matching failed). f(p, ...) = e is f = f | (p, ...) -> e. When f is already defined in the same place, := also adds a case, so each arm can be written on its own line.

t3_fib_lines.pk

fib(0) := 0
fib(1) = 1
fib(n) = fib(n - 1) + fib(n - 2)
println(fib(20))

Patterns

t3_list.pk

fun len
len = (Nil{}) -> 0 | (_ :: xs) -> 1 + len(xs)
println(len([5, 6, 7]))

fun sum
sum = ([]) -> 0 | (x :: xs) -> x + sum(xs)
println(sum([1, 2, 3, 4]))

swap2 := ([a, b]) -> [b, a] | (xs) -> xs
use("pretty")
put(f"{swap2([1, 2])} {swap2([1, 2, 3])}\n")

x :: xs, [a, b], Head{p, ...}, p @ Int, 'none and _ are patterns. They are listed in Patterns.

A fusion is a value

t3_extend.pk

greet := (_) -> "hello"
put(greet("en")); put("\n")

greet = ("fr") -> "bonjour" | greet
put(greet("fr")); put("\n")
put(greet("de")); put("\n")

A case can be put in front of an existing function, and the result assigned back.

match

t3_match.pk

classify(n) := match n {
    0 -> "zero"
  | n if n < 0 -> "negative"
  | n if n % 2 == 0 -> "even"
  | _ -> "odd"
}
put(classify(0)); put(" ")
put(classify(-4)); put(" ")
put(classify(6)); put(" ")
put(classify(7)); put("\n")

match e { f } evaluates e once and passes it to the fusion f. In a guard p if c -> a, the next arm is tried when c is false.

Symbolic differentiation

t3_deriv.pk

fun d
d = (n @ Int, x) -> 0
   | (y @ Symbol, x) -> if (y == x) 1 else 0
   | (Add{a, b}, x) -> Add{d(a, x), d(b, x)}
   | (Mul{a, b}, x) -> Add{Mul{d(a, x), b}, Mul{a, d(b, x)}}

println(d('Add{x, 3}, 'x))
println(d('Mul{x, y}, 'x))

'Add{x, 3} is a quotation that passes the M-expression without evaluating it (chapter 6). A version with simplification is planck/examples/deriv.pk.
