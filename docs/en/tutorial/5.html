5. Algebraic effects

perform v calls the nearest handler of a handle as h(v, k). k is the continuation of the perform and can be called any number of times, so exceptions, generators and nondeterminism use the same mechanism.

Exceptions

t5_exception.pk

safe_div(a, b) := if (b == 0) perform Raise{"division by zero"} else a / b

try(f) := handle Ok{f()} with (Raise{msg}, k) -> Error{msg}

println(try(() -> safe_div(10, 2)))
println(try(() -> safe_div(10, 0)))
println(try(() -> { put("before\n"); safe_div(1, 0); put("after\n") }))

Output

Ok{5}
Error{"division by zero"}
before
Error{"division by zero"}

The value of the handler is the value of the handle expression. When the handler does not call k, the rest of the computation is discarded.

Resumption and generators

t5_generator.pk

fun walk
walk = (Leaf{}) -> none
      | (Node{l, v, r}) -> { walk(l); perform Yield{v}; walk(r) }

tree := Node{Node{Leaf{}, 1, Leaf{}}, 2, Node{Leaf{}, 3, Leaf{}}}

handle walk(tree) with (Yield{v}, k) -> { put(f"yield {v}\n"); k(none) }

to_list(t) := handle { walk(t); [] } with (Yield{v}, k) -> v :: k(none)
use("pretty")
put(f"{to_list(tree)}\n")

Output

yield 1
yield 2
yield 3
[1, 2, 3]

k(x) resumes the computation as if the perform returned x. For the same walk, the handler decides how the values are used.

Multiple resumption

t5_choose.pk

use("list")
use("pretty")
choose(xs) := perform Choose{xs}

all_results(f) := handle [f()] with (Choose{xs}, k) -> concat_map(x -> k(x), xs)

put(f"{all_results(() -> (choose([1, 2]), choose(["a", "b"])))}\n")

Output

[Tuple{1, "a"}, Tuple{1, "b"}, Tuple{2, "a"}, Tuple{2, "b"}]

Here k is called for each candidate and the results are concatenated. planck/examples/queens.pk solves N-queens this way.
