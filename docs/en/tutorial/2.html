2. Values and M-expressions

Data structures and programs are both M-expressions Head{a, ...}. They need no declaration, and == compares them by structure.

t2_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(Point{1, 2} == Point{1, 2})
println(push(p, 5))

Output

Point{3, 4}
Point
2
4
true
Point{3, 4, 5}

String lengths and positions are in bytes. Lists are Cons and Nil M-expressions and tuples are Tuple. [1, 2] and (a, b) are the syntax for them.

t2_lists.pk

xs := [1, 2, 3]
println(xs)
ys := 0 :: xs
println(ys)

use("pretty")
put(f"{ys}\n")

println(())
println((1, "a"))

Output

Cons{1, Cons{2, Cons{3, Nil{}}}}
Cons{0, Cons{1, Cons{2, Cons{3, Nil{}}}}}
[0, 1, 2, 3]
Tuple{}
Tuple{1, "a"}

The kinds of values are listed in Data model.
