7. Extending the grammar

The planck syntax is a set of PEG rules, and ::= defines or replaces a rule. The top-level expressions after the declaration are read with the new rule.

t7_unless.pk

primary ::= 'unless "(" c:expr ")" a:expr { `If{!c, none, !a} } | ...

unless (1 > 2) put("1 > 2 is false\n")
unless (1 < 2) put("not printed\n")

Output

1 > 2 is false
  • The last ... is the previous definition of the rule, so the new alternative goes in front of the existing ones.
  • c:expr binds the value of the rule expr to the label c.
  • { ... } is an action, and its value is the value of the rule. Here a quasiquote builds a syntax tree.

Binary operators and blocks

t7_pipe.pk

union ::= x:union "|>" f:arrow { `Apply{!f, Tuple{!x}} } | ...

double(x) := 2 * x
3 |> double |> double |> println

Output

12

A rule may be directly left recursive, so x:union "|>" ... associates to the left.

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

Output

planck!
planck!
planck!

Another grammar

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

Output

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

An action can return any value, not only a tree. calc{| ... |} is read at parse time, and a string at run time is read by peg_parse(rule, s) (Grammar declarations).
