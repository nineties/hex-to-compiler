7. Extending the grammar

The planck syntax is a set of PEG rules, and ::= is an expression that defines or replaces a rule. The top-level expressions after the declaration are read with the new rule.

Adding syntax

t7_unless.pk

primary ::= 'unless "(" c:expr ")" a:expr { `If{!c, none, !a} } | ...

unless (1 > 2) put("1 > 2 is false\n")
unless (1 < 2) put("not printed\n")

Output

1 > 2 is false
  • The last ... in primary ::= ... | ... stands for the previous definition of the rule. The new alternative is added in front of the existing ones.
  • 'unless is a word, "(" is a string, and c:expr is an item that binds the value of the rule expr to the label c.
  • { ... } is an action. Its value is the value of the rule. Here a quasiquote builds the syntax tree If{c, none, a}.

The items and the action are on the same line as ::= or |.

Binary operators

t7_pipe.pk

union ::= x:union "|>" f:arrow { `Apply{!f, Tuple{!x}} } | ...

double(x) := 2 * x
3 |> double |> double |> println

Output

12

union is the rule of the fusion |. A rule may be directly left recursive, so x:union "|>" ... associates to the left.

Syntax that takes a block

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

Output

planck!
planck!
planck!

The inside of a quasiquote is written in the ordinary syntax. `repeat_fn(!n, () -> !body) embeds the block that was read into the tree of a call.

Another grammar

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

Output

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

An action can return any value, not only a tree. Results of rules are memoized for each position (packrat), and left recursion groups to the left.

calc{| ... |} is an expression whose text between {| and |} is read by the rule calc, at parse time. The value enters the tree as a constant. A string at run time is read by peg_parse(rule, s), and the result is Tuple{value, rest}. When nothing can be read from the start, the value is SyntaxError{...}.
