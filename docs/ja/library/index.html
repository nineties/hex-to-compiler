ライブラリ

planck/lib のファイルは planck の構文で書かれ、use("name") で読み込みます。関数はモジュールの欄で、list.map(f, xs) のように呼びます。関数の名前と引数から使い方がわかるものは省き、規則と例外だけを書きます。リストは Cons{x, xs} と Nil{} です。

モジュール名なしでも呼べる関数があります。base の panic assert、list の foldl reverse length append map filter concat_map each find member range、string の join です。

list

  • map・filter・each は先頭から順に呼びます。foldl(f, acc, xs) は f(f(acc, x1), x2)、foldr(f, init, xs) は f(x1, f(x2, init)) を計算します。
  • nth(xs, i) は0から数えます。find(p, xs) は見つからなければ none、index_of(x, xs) は -1 です。
  • zip(xs, ys) は短いほうの長さです。range(a, b) は [a, ..., b - 1] です。sort(less, xs) は less(a, b) による安定なマージソートです。

r_lib_list.pk

use("list")
use("pretty")
xs := [3, 1, 4, 1, 5]
put(f"{length(xs)} {list.sum(xs)} {list.nth(xs, 2)} {list.last(xs)}\n")
put(f"{reverse(xs)} {append([0], xs)} {list.concat([[1], [2, 3]])}\n")
put(f"{list.take(xs, 2)} {list.drop(xs, 2)}\n")
put(f"{find(x -> x > 3, xs)} {list.any(x -> x > 4, xs)} {list.all(x -> x > 0, xs)}\n")
put(f"{member(4, xs)} {list.index_of(4, xs)} {list.index_of(9, xs)}\n")
put(f"{list.foldr((x, acc) -> x :: acc, [], xs)}\n")
put(f"{concat_map(x -> [x, x], [1, 2])}\n")
each(x -> put(f"<{x}>"), [1, 2, 3])
put("\n")

出力

[5, 1, 4, 1, 3] [0, 3, 1, 4, 1, 5] [1, 2, 3]
[3, 1] [4, 1, 5]
4 true true
true 2 -1
[3, 1, 4, 1, 5]
[1, 1, 2, 2]
<1><2><3>

vector

ベクタは可変長の配列 Vector{a} です。v[i] と v[i] = x は vector.get と vector.set を呼び、範囲外の添字ではプログラムが止まります。vector.push(v, x) は後ろに足して x を返し、vector.pop(v) は最後の要素を取り除いて返します。

string

  • chr(c) の c は32から126・9・10・13のいずれかです。char_at(s, i) は範囲外なら "" です。
  • index_of_str(s, part, from) と str_to_int(s) は、見つからない・読めないとき、それぞれ -1 と none を返します。str_cmp(a, b) は文字コードの順で -1・0・1 です。
  • split(s, sep) の sep は空にできません。join(sep, xs) はその逆です。strbuf.add(b, s) で断片を足し、strbuf.str(b) で連結した文字列を得ます。

r_lib_string.pk

use("string")
use("pretty")
put(f"{string.chr(65)} [{string.char_at("abc", 5)}] {string.ends_with("main.pk", ".pk")}\n")
put(f"{string.index_of_str("banana", "na", 3)} {string.str_repeat("ab", 3)}\n")
put(f"{string.str_cmp("a", "b")} {string.str_cmp("b", "b")} {string.str_less("b", "a")}\n")
put(f"{string.int_to_str(-42)} {string.str_to_int("x1")}\n")
put(f"{string.is_digit(ord("7", 0))} {string.is_alpha(ord("_", 0))} {string.is_ident_start(ord("_", 0))}\n")
b := strbuf.new()
strbuf.add(b, "plan")
strbuf.add(b, "ck")
put(strbuf.str(b)); put("\n")

出力

A [] true
4 ababab
-1 0 false
-42 none
true false true
planck

getopt

コマンドラインのオプションを GNU の getopt_long と同じ規則で読みます。オプションは Opt{short, long, takes} で、short は1文字の文字列、long は文字列（どちらも "" にできる）、takes は値を取るなら true です。getopt.parse(opts, args, from) は配列 args を添字 from から読みます（argv() では先頭のファイルを飛ばして 1）。

  • 結果は Parsed{table, rest} です。table は指定されたオプションの名前（long、なければ short）から値への表で、値を取らないオプションは true、複数回指定すると最後が残ります。rest はオプションでない文字列の配列です。
  • 読める形は -a・-abc・-o 値・-o値・--opt・--opt 値・--opt=値 です。値は - で始まってもかまいません。- だけの文字列はオプションではなく、-- より後は全部 rest です。
  • 誤りは止まらず値として返ります。Unknown{name}（opts にない）・Missing{name}（値が抜けた）・NoValue{name}（値を取らないオプションへの --opt=値）で、name は書かれたとおりです。長いオプションの省略形は受け付けません。

r_lib_getopt.pk

use("table")
use("getopt")
spec := [Opt{"a", "all", false}, Opt{"o", "output", true}, Opt{"", "level", true}]
use("list")
args := list.list_to_array(["prog", "-ao", "out.txt", "x", "--level=3", "--", "-y"])
r := getopt.parse(spec, args, 1)
println(head(r))
opts := arg(r, 0)
println(table.get(opts, "all", false))
println(table.get(opts, "output", none))
println(table.get(opts, "level", none))
rest := arg(r, 1)
println(array_len(rest))
println(rest[0])
println(rest[1])
println(getopt.parse(spec, list.list_to_array(["prog", "-ax"]), 1))
println(getopt.parse(spec, list.list_to_array(["prog", "-o"]), 1))

true
"out.txt"
"3"
2
"x"
"-y"

table

table.get(t, key, default) と table.set(t, key, value) で読み書きします。table.keys・table.values・table.items（[Tuple{key, value}, ...]）の順序は不定です。set は値が true の表です。

r_lib_table.pk

use("list")
use("table")
use("pretty")
t := table.new()
table.set(t, 'a, 1)
table.set(t, 'b, 2)
put(f"{table.len(t)} {table.has(t, 'a)} {table.has(t, 'z)}\n")
put(f"{list.sort((a, b) -> a < b, table.values(t))}\n")
s := set.from_list([1, 2, 2, 3])
put(f"{set.len(s)} {set.has(s, 2)} {list.sort((a, b) -> a < b, set.to_list(s))}\n")

出力

2 true false
[1, 2]
3 true [1, 2, 3]

error

  • error.line_col(src, pos) はバイト位置 pos の Tuple{行, 列}（1から数える）、error.line_text(src, line) は改行を除いたその行です。error.loc_at(file, src, pos) は Loc{file, line, column}、error.show_loc は file:line:column と書きます。
  • error.at(loc, msg) は Error{loc, msg} を perform します。error.catch(f) は Ok{f()} を返し、f() が Error{loc, msg} を perform したら Err{loc, msg} を返します。
  • error.show(src, loc, msg) は file:line:column: msg・その行・列の下の ^ を並べた文字列です。

r_lib_error.pk

use("error")
src := "x := 1\ny := x +\n"
r := error.catch(() -> error.at(error.loc_at("a.pk", src, 12), "expected an expression"))
println(r)
put(error.show(src, arg(r, 0), arg(r, 1))); put("\n")
println(error.catch(() -> 42))

出力

Err{Loc{"a.pk", 2, 6}, "expected an expression"}
a.pk:2:6: expected an expression
  y := x +
       ^
Ok{42}

pretty

show(x) は print が出力する文字列で、リストだけ [a, b] と書きます。use("pretty") があると、f"..." に埋め込んだ値も show で書かれ、リストは [...] になります。pretty.text(x, width) は width 桁に収まる部分を1行にし、収まらない部分は要素を1行ずつ2つの空白で字下げして置きます。pretty.print(x) は幅60で出力します。

r_lib_pretty.pk

use("pretty")
put(pretty.show(["a", 'b, F{1}])); put("\n")
put(pretty.quote_str("say \"hi\"")); put("\n")
pretty.print(Node{Node{Leaf{}, "left", Leaf{}}, "root", Node{Leaf{}, "a long right branch", Leaf{}}})

出力

["a", b, F{1}]
"say \"hi\""
Node{
  Node{Leaf{}, "left", Leaf{}},
  "root",
  Node{Leaf{}, "a long right branch", Leaf{}}
}

unparse

木から、規則で読むとその木になる文字列を作ります。unparse.text(t) は規則 expr について、unparse.text_as(rule, t) は任意の規則について作り、文字列がなければプログラムを止めます。unparse.try_as は止まる代わりに none を返します。文法は peg_sources から読みます。

  • 選択肢 Act{Seq{e1, ...}, Lambda{Tuple{Tuple{l1, ...}}, body}} は、body が準クオートで、その !x がラベル・Quote{c}・ラベル・Tuple{labels}・mexpr(h, args) のとき逆にたどれます。木を準クオートと照合し、ラベルに部分木を入れ、要素を順に書きます（規則は unparse_as(rule, subtree)）。いつも同じ文字列に合う要素（"+" や Same{}）のラベルは _ にできます。
  • 木に合う選択肢が複数あれば、準クオートの中で !x でない節が一番多いものを使います。
  • 弱い規則が求められている所に強い規則の選択肢を置くときは、文法の最初の "(" e ")" で囲みます。規則名だけの選択肢は規則とそれがなりうる規則を結び、どれに括弧が要るかを決めます。より弱い規則で終わる選択肢（while (c) e は expr で終わる）も、同じかより弱い規則が求められている所以外では括弧が要ります。
  • unparse.custom(owner, spec, tail, f) は規則 owner に選択肢を足します。f(t) は文字列か none、spec は準クオートとの順位付け、tail は文字列の最後の規則か none です。Do{...}（{ } の中に1行1式、4つの空白で字下げ）と If（if (c) a else b）はこれで足しています。
  • 文法で書かれない木は、コンストラクタの呼び出し Head{a, ...} になります。識別子でないシンボルと、整数・文字列・シンボル・M式でない値には文字列がありません。

t6_unparse.pk

use("unparse")
t := '(if (n < 0) -n else n * (n + 1))
println(t)
put(unparse.text(t)); put("\n")

出力

If{Apply{_lt, Tuple{n, 0}}, Apply{_sub, Tuple{0, n}}, Apply{_mul, Tuple{n, Apply{_add, Tuple{n, 1}}}}}
if (n < 0) -n else n * (n + 1)

base

panic(msg) は msg を出力して終了状態1で止まります。assert(c, msg) は c が成り立たないときに panic(msg) を呼びます。

module でまとめたライブラリ

ライブラリを module でまとめて書くと、読み込んだあとに module の名前で呼べます。補助の関数は export を付けなければ外に出ません。それを呼ぶ試験は、module の中の test に書きます。bitset が module bitset で書かれていれば、次のとおりです。

use("bitset")
s := bitset.new(100)
bitset.add(s, 3)

前処理したライブラリ

tools/preprocess.pk にライブラリの名前を渡すと、そのライブラリを前もって M式へ構文解析し、planck/lib/<name>.pkm に1行1式で書きます。評価は前もってしません。use は .pkm の M式を1つずつ評価し、動作は .pk を構文解析した場合と同じです。使える .pkm がなければ .pk を構文解析します。

.pkm を使うのは、ライブラリの本文と文法が書いたときと同じ場合です。文法が同じとは、次の3つです。

  • planck/init.pk・planck/peg.pk・planck/syntax.pk の本文が同じ
  • 規則を宣言したライブラリが同じ本文で同じ順に並んでいる
  • ほかの規則が宣言されていない（peg_version が同じ）

M式として読めないファイルと、最後の式で終わっていないファイルも使われません。プログラムが parse や規則の動作が呼ぶ関数を差し替えても検出しません。解析結果に M式の文字列表現がない値（関数・配列）を含むライブラリは前処理できません。
