packrat パーサ

planck/peg.pk は、M式で書いた PEG の解釈実行器です。文法は M式のデータで、結果は（位置, 規則）ごとにメモ化します。

データとしての文法

構文解析式（規則の右辺）の形はファイルの先頭にあります。_define_rule で名前を付けると規則になります。::= もこの呼び出しに読み替えられます（構文の定義）。

planck/peg.pk: A grammar is data.

" A grammar is data. A parsing expression is one of "
"   \"text\"          the text, after blanks and comments "
"   Tight{\"text\"}   the text, without skipping blanks "
"   Key{\"word\"}     the word, not followed by a letter, a digit or _ "
"   name            the rule name (a symbol) "
"   f               a function: f(p) returns the new position or -1, and sets peg_pv "
"   Seq{e, ...}     sequence. The value is Tuple{v, ...} "
"   Choice{e, ...}  ordered choice "
"   Many{e}, Many1{e}, Option{e}  the values are Tuple{v, ...}, Option gives Tuple{} or Tuple{v} "
"   And{e}, Not{e}  lookahead "
"   Delimited{e, sep}, Delimited1{e, sep}  e separated by sep. The value is Tuple{v, ...} "
"   Same{}          succeeds when the next token is on the same line "
"   Act{e, f}       applies f to the value of e. f is an expression evaluated by _define_rule "
"   Prev{}          the previous definition of the rule (only as an alternative of _define_rule) "
"   Fail{}          never matches "
"   Any{}           any one character, after blanks and comments. The value is the character as a string "
"   OneOf{\"set\"}, NoneOf{\"set\"}  one character that is in the set, or is not in it, after blanks and comments "
"                   A set is characters, ranges of letters or digits (a-z) and escapes with a backslash. "

" Results of rules are memoized for each position. "
" Direct left recursion (sum ::= sum \"+\" term | term) is handled by growing the seed. "

i_define.pk

_define_rule('sevens, 'Act{Many1{"7"}, t -> arity(t)})
println(peg_parse('sevens, "7 7 7 rest"))
println(sevens{| 7 7 7 7 |})

出力

Tuple{3, "rest"}
4

解釈実行

peg_px(e, p) は構文解析式 e を位置 p から試し、成功すれば次の位置を返して値を peg_pv に置きます。失敗は -1 で、最も先まで進んだ位置が peg_far に残り、構文エラーの位置になります。peg_px・peg_call_rule・peg_run_rule は互いに呼び合うので、Def{名前, none} で先に宣言して Set で定義します。

planck/peg.pk: Set{peg_px,

Set{peg_px, Lambda{Tuple{e, p}, Do{
    Def{t, Apply{typeof, Tuple{e}}},
    If{Apply{_eq, Tuple{t, Quote{string}}}, Apply{peg_lit, Tuple{e, Apply{peg_skip_ws, Tuple{p}}}},
    If{Apply{_eq, Tuple{t, Quote{symbol}}}, Apply{peg_call_rule, Tuple{e, p}},
    If{Apply{_eq, Tuple{t, Quote{function}}}, Apply{e, Tuple{p}},
        Apply{Apply{table_get, Tuple{peg_handlers, Apply{head, Tuple{e}}, none}}, Tuple{e, p}}}}}}}}

メモ化と直接左再帰

バックトラックしても同じ規則を同じ位置で再計算しません。

planck/peg.pk: Rules and memoization

" === Rules and memoization === "
" The memo of position p is the array peg_memo[p] (made when first used), which holds "
" three slots for each rule id: end position, value and left-recursion flag. "
" The end position is none before the rule runs, -1 for failure and -2 while the rule is running. "
" On left recursion (the rule is called again at the same position while it runs), "
" the inner call fails, which is the seed. Then the rule is run again "
" while it consumes more than the last result. "

直接左再帰（sum ::= sum "+" term | term）もメモで扱います。実行中の規則を同じ位置で呼ぶと失敗を返し、この失敗を種にして規則を再実行します。前より長く読めた間は繰り返します。1 - 2 - 3 は (1 - 2) - 3 になります。

planck/peg.pk: Set{peg_run_rule

Set{peg_run_rule, Lambda{Tuple{r, p, row, b}, Do{
    Def{body, Apply{table_get, Tuple{peg_rules, r, none}}},
    Def{b1, Apply{_add, Tuple{b, 1}}},
    Apply{array_set, Tuple{row, b, -2}},
    Def{q, Apply{peg_px, Tuple{body, p}}},
    Apply{array_set, Tuple{row, b, q}},
    Apply{array_set, Tuple{row, b1, peg_pv}},
    If{Apply{_eq, Tuple{Apply{array_get, Tuple{row, Apply{_add, Tuple{b, 2}}}}, true}}, Do{
        Def{go, Apply{_ge, Tuple{q, 0}}},
        While{go, Do{
            Set{q, Apply{peg_px, Tuple{body, p}}},
            If{Apply{_gt, Tuple{q, Apply{array_get, Tuple{row, b}}}},
                Do{
                    Apply{array_set, Tuple{row, b, q}},
                    Apply{array_set, Tuple{row, b1, peg_pv}}},
                Set{go, false}}}},
        Set{peg_pv, Apply{array_get, Tuple{row, b1}}},
        Apply{array_get, Tuple{row, b}}},
    q}}}}

規則の定義と入口

_define_rule は動作 Act{e, f} の f を評価してから表に入れます。選択肢の Prev{}（::= の ...）は直前の定義です。

planck/peg.pk: _define_rule(name, e) defines or replaces

" _define_rule(name, e) defines or replaces the rule "
Def{_define_rule, Lambda{Tuple{name, e}, Do{
    If{Apply{_eq, Tuple{Apply{table_get, Tuple{peg_ids, name, none}}, none}}, Do{
        Apply{table_set, Tuple{peg_ids, name, peg_nrules}},
        Set{peg_nrules, Apply{peg_inc, Tuple{peg_nrules}}}}, none},
    Def{old, Apply{table_get, Tuple{peg_rules, name, Fail{}}}},
    Apply{table_set, Tuple{peg_sources, name, Apply{peg_subst_prev, Tuple{e, Apply{table_get, Tuple{peg_sources, name, Fail{}}}}}}},
    Set{peg_version, Apply{peg_inc, Tuple{peg_version}}},
    Apply{table_set, Tuple{peg_rules, name, Apply{peg_subst_prev, Tuple{Apply{peg_prepare, Tuple{e}}, old}}}},
    name}}}

peg_parse(rule, s) は成功すると Tuple{値, 残り} を、失敗すると位置から行末までを添えた SyntaxError{...} を返します。
