planckvm の命令

planckvm の命令と、planck の各機能がどの命令になるか、どの組み込み関数が命令かを書きます。機械と値はplanckvm: 実行モデルと値にあります。planckvm はこれから実装する設計です。

表記: スタックは左が底です。a b -> r は 2 個取って 1 個積みます。オペランド: k 定数表の添字、c セル（k の一種）、d i 環境の深さと添字、L 命令列の添字、n 個数、p 組み込みの命令番号。印: S 確保などで GC が走りうる安全点、W 書き込み記録、T 条件を満たさないと止まる。

呼び出し

名前オペランドスタック意味
CALLnf a1..an -> r実行モデルの「呼び出し」の規則で呼ぶ。S T
TCALLnf a1..an -> r現在のフレームを捨てて呼ぶ（末尾呼び出し）。どの場所でも使う。入口のフレームでも同じで、呼ばれた関数の RET が結果を評価器に返す。現在のフレームが境界なら CALL と同じ。S T
RETv ->フレームを捨て、呼び出し元のオペランドスタックに v を積んで続ける。入口のフレームなら実行結果として評価器に返す

プログラムは _index_get のように大域の関数を代入できるので、a + b を ADD と決め打ちできません。CALLP は組み込みの上書きを守ります。

入口の照合

関数の入口は、パターンの数だけ命令列を並べます。失敗すると L へ移り、そのときオペランドスタックを空にします。L には NEXT を置きます。引数がパターンの変数に束縛されたら、STORE 0 i と POP で環境に書きます。PARAM STORE POP を 1 つにまとめた融合命令は持ちません。

名前オペランドスタック意味

MATCHHEADk n Lv -> vv が頭が k のシンボルで引数 n 個の M式なら次へ。違えば L へ
MATCHTYPEk Lv -> vtypeof v が定数 k のシンボルなら次へ。違えば L へ。_TypeOf{p, type} のパターン
NEXT今のフレームを捨て、同じ引数で残りの選択肢を試す。尽きれば T（matching failed）。PERFORM が呼んだフレームでは外側の境界へ進む

効果

名前オペランドスタック意味
HANDLEbody h -> rbody（arity 0 の Lambda）を境界フレームで実行する。h が関数でなければ T。S
PERFORMv -> r実行モデルの「継続と handler」の規則。値は再開の引数になる。S T

HANDLE の本体の末尾の呼び出しは TCALL と書きますが、境界のフレームは捨てません。

数

引数が数でなければ T です（EQ を除く）。型の混ざり方と結果の型は、実行モデルの「数」にあります。

名前スタック意味組み込み
ADDa b -> ra + b。S_add
SUBa b -> ra - b。S_sub
MULa b -> ra * b。S_mul
DIVa b -> r整数どうしは 0 方向へ切り捨てる商で、b が 0 なら T。それ以外は割り算で、0 でも止まらない。S_div
LTa b -> ra < b を true か false で返す。複素数が絡めば T_lt
EQa b -> r実行モデルの「値」の等しさ。数に限らず全ての値。true か false_eq

整数どうしで結果が小さい整数に収まるなら、確保なしで済ませてかまいません。確保が起きるのは桁が増えたときと、浮動小数点・複素数の結果を作るときです。

ビット演算

引数は整数です。負の数を含めて、無限桁の 2 の補数として扱います。

名前スタック意味組み込み
BANDa b -> rビットごとの積bit_and
BORa b -> rビットごとの和bit_or
BXORa b -> rビットごとの排他的論理和bit_xor
BSHLa k -> ra を k ビット左へ。巻き戻らない。k が負なら T。Sbit_shl
BSARa k -> ra を k ビット右へ（符号を保つ）。k が負なら T。Sbit_sar

浮動小数点と複素数

四則と比較は「数」の命令が受け持ちます。ここは浮動小数点の関数と変換と複素数の部品です。浮動小数点を受ける命令は整数も受け、浮動小数点に揃えます。複素数を渡すと T です。組み込みの名前は命令名の小文字です。

名前スタック意味
FSQRTa -> r平方根。負なら NaN。S
FFLOORa -> r床。結果は浮動小数点。S
FTOIa -> n0 方向へ切り捨てた整数。NaN・無限大なら T。S
FTOBITSa -> n64 ビットのビット列を非負の整数で返す。S
BITSTOFn -> rFTOBITS の逆。n が 64 ビットに収まらなければ T。S
FTOSa -> s読み戻すと同じ値になる最短の 10 進の文字列。S
STOFs -> r10 進（指数付き可）の文字列を読む。読めなければ none。S
FEXP FLOG FSIN FCOSa -> r指数・自然対数・正弦・余弦。S
FPOW FATAN2a b -> rべき乗・逆正接（2 引数）。S
COMPLEXre im -> z実部 re・虚部 im の複素数。re と im は整数か浮動小数点で、浮動小数点に揃える。S
REAL IMAGz -> x複素数 z の実部・虚部（浮動小数点）。z が複素数でなければ T。S

数学関数は FEXP FLOG FSIN FCOS FPOW FATAN2 の 6 つだけです。複素数の足し算・引き算・掛け算・割り算・等しさは「数」の命令で書けます。

組み込みと命令

他の命令と planck の式だけでは書けないものを命令にします。値の表現・ヒープ・OS・数値の機械演算・制御に触れるものがそうです。書けるものは planck の関数にして、命令を増やしません。熱い関数を命令に昇格するかは、測ってから別に決めます。型で分かれる演算は、値の型を見る 1 命令にします。

命令にしない組み込み

命令を使った planck の関数として、評価器のイメージに入れます。大域変数の名前と振る舞いは、組み込みと同じです。

組み込み書き方
_ne(a, b)if (a == b) false else true

_mod(a, b)a - b * (a / b)（整数の剰余）

bit_shr(a, k)a が非負なら bit_sar(a, k)。負なら誤り

read_file(path)try_read_file が none なら失敗の文を出して exit(1)

誤りの文に出る関数名は、呼んだ組み込みと違うことがあります。たとえば _mod の引数が整数でないときの文は、_div の名前になります。

planck のコードで定義される名前

仕様の組み込み関数の表にあって、機械の組み込みでない名前は、planck のコードで定義され、命令を要しません: _define_rule _index_get _index_set _not _record_declare _record_get _to_text false load none parse_mexpr peg_for peg_parse subst table table_get table_set true use used_libs。

planckvm が仕様に足す組み込みは、plain_array、浮動小数点の関数 fsqrt ffloor ftoi ftobits bitstof ftos stof fexp flog fsin fcos fpow fatan2、複素数の complex real imag、plain 配列の型ごとの作成関数、itof conj です。

場所で規則が変わる所

命令は場所によって意味を変えません。違いは、コンパイラが選ぶ命令に出ます。

場所規則命令への影響
トップレベル（ブロックの外）の x := e大域変数。新しいセルを作るGSET c
トップレベルでも if や while のブロックの中の x := e局所変数。トップレベルのコードの環境に置くSTORE 0 i
関数の中の x := e局所変数。同じ関数の新しいスロットSTORE 0 i
Declare{x}（f(p) := e の前半）同じ場所に変数があれば何もしない。トップレベルでは「今読み込み中のファイルで定義した大域変数」だけが同じ場所。別ファイルの大域変数は同じ場所ではなく、新しく作って隠すSETFILE が示すファイルを使うコンパイル時の判定
関数の中の Declare{x}同じ関数の環境にある変数だけが同じ場所。外側の関数の変数は同じ場所ではないコンパイル時の判定
末尾の呼び出しどの場所でも TCALL。結果は同じで、スタックの深さだけが変わる命令の選択は場所で変わらない
HANDLE の本体の末尾の呼び出しTCALL と書いても境界のフレームは捨てない実行時の規則
名前が見つからないどの場所でも式の実行前にコンパイル時に止める命令は出ない
前方参照fun f で先に宣言する。関数の中とトップレベルで同じfun f は none で始まり、呼ぶと止まる（not a function: none）。GLOAD と LOAD は検査しない
