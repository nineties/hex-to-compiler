planckvm の命令

1命令は 32 ビットで、高頻度の操作だけを命令にします。他は組み込み関数です。この頁はフォーマット、命令、組み込み、planck の各機能に対応する命令を定めます。機械と値は実行モデルと値に、実装の設計は内部仕様にあります。

バイトコードのフォーマット

基本単位は 64 ビットの語で、ビットの番号は最下位を 0 とします。命令は 32 ビットで、コードの instrs（u32 の plain array）の1要素に置きます。1つの Lambda かトップレベルの式が1つのコードで、入れ子の関数のコードは外側の定数表に入ります。コードは型 Code のユーザーデータで、オブジェクトの形は内部表現にあります。

  • nregs は窓のレジスタの個数で、コードの中のレジスタ番号はすべてこれより小さい値です。
  • instrs は命令を並べた u32 の plain array、consts は定数表の array です。
  • params は引数のパターンの木の定数表の添字で、関数の表示と照合失敗のメッセージに使います（トップレベルの式では -1）。
  • locs は位置の表の u32 の plain array です。呼び出しの位置から MatchingFailed の loc を引くために使います。1項目は pc・line・column の3要素です。pc は CALL か TCALL の、命令列の先頭からの添字で（EXT が前にあれば EXT の次の命令）、項目は pc の昇順に並びます。At が包む呼び出しだけが項目を持ちます。
  • file は表の全項目に共通のファイル名の文字列の、定数表の添字です（ファイル名がなければ -1）。

定数表と正しいコード

定数表の要素は値1語です。リテラル・Quote の中身・定数だけの M式は LOADK、シンボルは MATCHHEAD、セルは GETGLOBAL SETGLOBAL、入れ子のコードは CLOSURE が指します。コードは次を満たします。満たさないコードは、作るとき（_code_new）とイメージを読み込むときに、invalid bytecode で止まります。

  • オペコードは、評価器が実行する命令のどれかです。
  • レジスタ番号は nregs より小さい値です。範囲で使う命令は、その全体が窓に入ります。CALL TCALL BUILD は R[B] から R[B+C]、TUPLE は R[B] から R[B+C-1]、LOADNONE は R[A] から R[A+B-1]、HANDLE は R[B] と R[B+1] です。
  • 定数表の添字は定数の個数より小さく、GETGLOBAL と SETGLOBAL が指す定数はセル、CLOSURE が指す定数はコードです。
  • ジャンプ先は命令列の中の命令の先頭で、命令列の最後は RET TCALL JMP HALT NEXT のいずれかです。
  • 条件の命令の次の命令は JMP、MATCH で始まる命令の次の命令は NEXT か JMP で、どちらの次にも命令があります。条件の命令の k は 0 か 1 です。
  • arity は 255 以下で nregs 以下、nregs は 65535 以下です。params と file は -1 か定数表の添字で、file の定数は文字列です。位置の表の pc は命令列の中の添字で、昇順に並びます。

次の検査は命令が実行するときに行い、満たさなければ invalid bytecode で止まります。ENVGET と ENVSET は、たどった先が環境で、スロットの番号がその範囲に入ること。FIELD は、R[B] が M式で、C がその引数の個数より小さいことです。

次は生成する側が守ります。

  • 局所変数は、一時の値より小さい番号のレジスタに置きます。CALL HANDLE の時点で生きている値は、すべて R[B] より下に置きます（HANDLE は R[B] と R[B+1] も保ちます）。
  • NEWENV は、コードの中で1回だけ、パターンの照合がすべて成功したあとに実行します。照合が終わるまで R[0] から R[arity-1] を書き換えません。

算術と比較の命令は、数でない引数で止まります。T の印のある命令は、引数の型が違うときと範囲外のときにも止まります（ORD の範囲外を除く）。

組み込みと命令

型で分かれる演算は、値の型を見る1つの命令にします。Apply{f, Tuple{...}} の f が「組み込み」の欄の名前で、局所変数でなく、引数の個数が合うとき、コンパイラはその命令を使い、大域変数の上書きの有無を区別しません。

命令にしない組み込み（組み込み関数）は機械の組み込みで、GETGLOBAL で R[B] に読み、引数をその上のレジスタに置いて CALL で呼びます。確保とエラーは、その CALL の S と T に含まれます。

  • eval(e): M式 e を現在の大域環境でコードに変換して実行します。コンパイルエラーは実行時エラーと同じく止まり、その loc は、コンパイルに失敗した式を囲む一番内側の At の位置です。At が無ければ none です。内側のフレームは通常のフレームなので、eval の中の PERFORM でも複製できます。
  • _set_file(path): 読み込み中のファイルを path にし、前の値を返します。大域変数の定義元の判定に使います。
  • システムの組み込み: _sys_open(path) は読み込み用にファイルを開き、記述子か負の数を返します。_sys_read(fd, buf, n) は u8 の plain array buf の先頭へ最大 n バイトを読み、読んだバイト数を返します（終わりでは 0）。_sys_write(fd, buf, n) は buf の先頭 n バイトを書き、書いたバイト数を返します。_sys_close(fd) は記述子を閉じます。_sys_argc() と _sys_argv(i) は機械のコマンドラインの個数と文字列で、先頭が機械、2番目がイメージです。
  • 実行中にコードを作る組み込み: _code_new(arity, nregs, instrs, consts, file, locs) は、u32 の plain array instrs と array consts から、この頁のフォーマットどおりのコードを作ります。コードは instrs・consts・locs を写して持ちます。作ったあとにこれらの配列を書き換えても、コードは変わりません。作ったコードは上の条件を検査し、満たさなければ止まります。file はファイル名の文字列の consts での添字（無ければ -1）で、u32 の plain array locs は位置の表の項 pc・line・column を並べたものです。_lambda(code) はコードの環境なしの Lambda です。_cells() は大域変数のセルすべての array です。_cell_new(symbol, g) は世代 g で値が none のセルを作ります。_cell_field(c, i) はセル c の値（i が 0）・名前の symbol（1）・世代（2）で、_cell_set(c, v) は値を書きます。
  • ビット演算は負の数も含めて無限桁の 2 の補数として扱います。

言語の機能と命令

構文の各行に対して生成するコードです。<e:d> は式 e の値を R[d] に入れる命令列で、t はその時点で空いている最小の一時レジスタです。

  • パラメータ i のパターンがレジスタの変数なら R[i] です。残りのレジスタの変数は R[arity] から順に割り当て、ブロックを抜けても再利用しません。一時の値はその次から、スタックのように使います。
  • 被演算子 <e:r> は、e がレジスタの変数で、後の被演算子の評価でその変数が書き換わらないなら、その変数のレジスタで命令は要りません。そうでなければ t に入れます。
  • 演算子・添字・for・f"..."・::= など、対応する命令のないものは planck の関数の CALL になります（_index_get _index_set _record_get peg_for _strcat _define_rule など）。
  • a <= b と a > b は、左右を入れ替えた GE と LT になります。

条件

<c, L, k> は、c の真偽が k に一致すれば L へジャンプし、一致しなければ次へ進む命令列です。

  • a == b a != b a < b a >= b: 条件の命令（TEQ など）に JMP L を続けます。b が -128 〜 127 の整数なら即値の形（TEQI TLTI TGEI）、b が定数なら TEQK TNEK を使います。
  • a and b は k = 0 なら <a, L, 0> <b, L, 0>、k = 1 なら <a, L1, 0> <b, L, 1> L1: です。or は 0 と 1 を入れ替えます。
  • 上のどれでもない c は <c:r> TEST r k JMP L です。

パターン

パターンの命令は値が R[r] にある状態から始め、照合に失敗したとき実行する命令は NEXT です。環境に置く変数は照合の間はレジスタに置き、すべて成功したあとの NEWENV に続けて ENVSET で移します。

  • _ は無し。変数は、引数の位置なら無し、M式の引数なら FIELD の行き先が x のレジスタです。
  • 整数・文字列・true false none・Quote{v} は MATCHEQ r k NEXT です。
  • Head{p1, ..., pn} は MATCHHEAD r k n NEXT のあと、_ でない各 p_j について FIELD s r j と p_j の命令を並べます。_TypeOf{p, T} は MATCHTYPE r t NEXT のあと p の命令です。T は式で、関数を作る場所で評価し、値を関数の環境に置いておきます。照合の前にその値をレジスタ t へ読みます。
