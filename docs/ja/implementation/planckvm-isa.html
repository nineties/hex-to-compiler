planckvm の命令

1命令は1語で、高頻度の操作だけを命令にします。他は組み込み関数です。コードの正しさは生成する側が守り、評価器は検査しません。この頁はフォーマット、命令、組み込み、planck の各機能に対応する命令を定めます。機械と値は実行モデルと値に、実装の設計は内部仕様にあります。

定数表と正しいコード

定数表の要素は値1語です。リテラル・Quote の中身・定数だけの M式は LOADK、シンボルは MATCHHEAD MATCHTYPE、セルは GETGLOBAL SETGLOBAL、入れ子のコードは CLOSURE が指します。生成する側は次を守ります。

  • ジャンプ先は命令の先頭で、命令列の最後は RET TCALL JMP HALT NEXT のいずれかです。
  • 条件の命令の次の語は JMP、MATCH で始まる命令の次の語は NEXT か JMP です。
  • 局所変数は、一時の値より小さい番号のレジスタに置きます。CALL HANDLE の時点で生きている値は、すべて R[B] より下に置きます（HANDLE は R[B] と R[B+1] も保ちます）。
  • NEWENV は、コードの中で1回だけ、パターンの照合がすべて成功したあとに実行します。照合が終わるまで R[0] から R[arity-1] を書き換えません。

条件の命令（TEST から TGEI まで）は値を作りません。条件が k と一致すれば（k = 1 なら真、k = 0 なら偽のとき）次の語の JMP を実行し、一致しなければ飛ばします。NaN を含むと TLT と TGE はどちらも偽です。

算術と比較の命令は、数でない引数で止まります。T の印のある命令は、引数の型が違うときと範囲外のときにも止まります（ORD の範囲外を除く）。

組み込みと命令

型で分かれる演算は、値の型を見る1つの命令にします。Apply{f, Tuple{...}} の f が「組み込み」の欄の名前のセルに解決され、引数の個数が合うとき、コンパイラはその命令を使い、上書きの有無を区別しません。

命令にしない組み込み（組み込み関数）は機械の組み込みで、GETGLOBAL で R[B] に読み、引数をその上のレジスタに置いて CALL で呼びます。確保とエラーは、その CALL の S と T に含まれます。

  • eval(e): M式 e を現在の大域環境でコードに変換して実行します。コンパイルエラーは実行時エラーと同じく止まります。内側のフレームは通常のフレームなので、eval の中の PERFORM でも複製できます。
  • _set_file(path): 読み込み中のファイルを path にし、前の値を返します。大域変数の定義元の判定に使います。
  • ビット演算は負の数も含めて無限桁の 2 の補数として扱います。

言語の機能と命令

構文の各行に対して生成するコードです。<e:d> は式 e の値を R[d] に入れる命令列で、t はその時点で空いている最小の一時レジスタです。

  • パラメータ i のパターンがレジスタの変数なら R[i] です。残りのレジスタの変数は R[arity] から順に割り当て、ブロックを抜けても再利用しません。一時の値はその次から、スタックのように使います。
  • 被演算子 <e:r> は、e がレジスタの変数で、後の被演算子の評価でその変数が書き換わらないなら、その変数のレジスタで命令は要りません。そうでなければ t に入れます。
  • 演算子・添字・for・f"..."・::= など、対応する命令のないものは planck の関数の CALL になります（_le _gt _index_get _index_set _record_get peg_for _strcat _define_rule など）。

条件

<c, L, k> は、c の真偽が k に一致すれば L へジャンプし、一致しなければ次へ進む命令列です。

  • a == b a != b a < b a >= b: 条件の命令（TEQ など）に JMP L を続けます。b が -128 〜 127 の整数なら即値の形（TEQI TLTI TGEI）、b が定数なら TEQK TNEK を使います。
  • a and b は k = 0 なら <a, L, 0> <b, L, 0>、k = 1 なら <a, L1, 0> <b, L, 1> L1: です。or は 0 と 1 を入れ替えます。
  • 上のどれでもない c は <c:r> TEST r k JMP L です。

パターン

パターンの命令は値が R[r] にある状態から始め、照合に失敗したとき実行する語は NEXT です。環境に置く変数は照合の間はレジスタに置き、すべて成功したあとの NEWENV に続けて ENVSET で移します。

  • _ は無し。変数は、引数の位置なら無し、M式の引数なら FIELD の行き先が x のレジスタです。
  • 整数・文字列・true false none・Quote{v} は MATCHEQ r k NEXT です。
  • Head{p1, ..., pn} は MATCHHEAD r k n NEXT のあと、_ でない各 p_j について FIELD s r j と p_j の命令を並べます。_TypeOf{p, type} は MATCHTYPE r k NEXT のあと p の命令です。
