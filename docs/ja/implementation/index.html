処理系の実装

各ステージは前のステージの成果物だけで作ります。手書きの機械語から planck の構文まで、ソースを引用して説明します。全体は概要にあります。

ビルドの順序

pforth:  xxd -r -c 8 bootstrap/pforth.xxd > pforth
plisp2:  ./pforth < bootstrap/plisp.fs bootstrap/sasm.lisp bootstrap/plisp2.sv tmp-plisp2
planck0: ./plisp2 bootstrap/sasm.lisp bootstrap/planck0.sv planck0

plisp には実行ファイルがありません。pforth が起動のたびに bootstrap/plisp.fs を読んで組み立てます。

プログラムの実行

$ ./planck0 prog.pk a b

リポジトリの最上位で実行します。引数は argv() で受け取ります。

処理系ごとの実装範囲

planck0 は sasm で書いた最小の処理系です。planck1 は planckvm から float と complex を除いたもの、planck は planckvm の全部です。planck1 は表に書いた所以外 planck と同じです。仕様はリファレンスにあります。
