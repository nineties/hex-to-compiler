planckvm の内部表現

ヒープ上の値の word、ヘッダ、種類ごとの中身、GC から見た扱い。

word

ヒープ・レジスタ・フレームの word はすべて 32 ビットで、ビットの番号は最下位を 0 とします。word の下位 1 ビットが値の種別を分けます。

オブジェクトの中身

以降の表の「word」は、ヘッダの次の word を 0 とした位置です。「値」と書いた欄には値の word（即値か参照）を置きます。「生」と書いた欄は、値でなく word そのものの数です。64 ビットの量を 2 word に分けるときは、下位の word を先に置きます。

多倍長整数

word中身
0符号（生。0 は 0 以上、1 は負）
1桁数 n（生。1 以上）
2〜3桁 0（64 ビット。下位の word が先）
4〜5桁 1
…桁 n-1
  • 値は符号と絶対値で表します。絶対値の桁は底 264 で、下位の桁から並べます。
  • size は 2 + 2n です。桁数は size 欄に収まる範囲に限られます。
  • 最上位の桁は 0 ではありません。値が即値の範囲に収まる整数は、多倍長整数にしません。0 は即値です。

文字列

word中身
0バイト数 n（生）
1〜バイト列。word 1 + i/4 の下位から i mod 4 番目のバイトに、i 番目のバイトを置く。word 数は n を 4 で割って切り上げた値。最後の word の使わないバイトは 0

バイト列は 0 バイトを含められます。size は 1 + ceil(n/4) です。

同じ名前の symbol は 1 つのオブジェクトで、名前ごとに一意です。名前の文字列は変わりません。

  • 作った直後の要素は全ビットが 0 で、false・0・0.0・complex(0, 0) を表します。

identity の番号

array・plain array・Lambda・Fusion・組み込み・継続は、word 0 に identity の番号を持ちます。作った直後は 0 で、番号を割り当てるまで 0 のままです。最初の HASH が 1 以上の番号を割り当て、以降は変わりません。同じ機械で割り当てる番号は互いに異なります。
