planckvm のデータ型

値の種類、head、equality、ハッシュ。

値の種類

整数は 1 種類で、大きさに上限がありません。word に何ビット入るかは言語の値の仕様に現れません。

head

すべての値が head（head）を持ちます。M式の head は自分の head の symbol で、それ以外の値の head は型名の symbol です。

  • true・false・none は symbol なので、head は Symbol です。

バイトコードの中の整数

整数は次のどちらかで書きます。

  • 命令の欄に収まる整数は、欄に符号つき（2 の補数）で書きます。欄の幅は命令の形式で決まります（ABC 形式の C は 8 ビット、AD 形式の D は 16 ビット、J 形式の sJ は 24 ビット）。
  • 収まらない整数は、定数表に整数の定数として置き、命令は定数表の添字を持ちます。定数表の整数は、符号の word（0 は 0 以上、1 は負）、桁数の word、64 ビットの桁（下位の桁から、下位の word が先）の順に並べます。

同じ値を定数表と命令の欄の両方で書けるときは、命令の欄に書きます。

ハッシュ

HASH は 0 以上 230-1 以下の整数を返します。EQ で等しい値は同じ値になります。

  • 整数は値だけで決まります。値の符号を 0（0 以上）か 1（負）の acc とし、絶対値を下位から 16 ビットずつ取った各 d について acc = (acc * 31 + d + 7) mod 230 を繰り返した結果です。0 のハッシュは 0 です。桁の幅には依りません。
  • 整数に等しい float と、虚部が 0 で実部が整数に等しい complex は、その整数と同じ値です。
  • それ以外の float・complex・文字列・symbol・M式は中身で決まります。中身が等しければ値が同じで、具体的な値は定めません。
  • array・plain array・関数は、オブジェクトごとに決まり、そのオブジェクトの間は変わらない値です。
