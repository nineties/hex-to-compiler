init.pk と M式

planck0 のリーダは M式しか読めません。planck/init.pk は全体を M式で書き、以降で使う関数と表を定義して、末尾で構文に切り替えます。

M式だけの記述

演算子も if もないので、特殊形式と関数呼び出しだけで書きます。トップレベルの文字列は何も起きず、コメントになります。冒頭で true・false・none を同名のシンボルに束縛します。

planck/init.pk: Basic Functions

" === Basic Functions === "
Def{_not, Fusion{
    Lambda{Tuple{Quote{false}}, true},
    Lambda{Tuple{_}, false}}}

表とファイルの読み込み

planck0 の組み込みは配列と hash までなので、ハッシュ表は配列で実装します。

planck/init.pk: A table is Table{a}

" A table is Table{a}, where a is an array | buckets | number of entries |. Each bucket is a chain of entries "
" | key | value | next entry or none | hash of the key |. Keys are compared by eq. "
" The number of buckets doubles when there are more entries than buckets. "
Def{table_new, Lambda{Tuple{}, Do{
    Def{t, Apply{array, Tuple{2}}},
    Apply{array_set, Tuple{t, 0, Apply{array, Tuple{16}}}},
    Apply{array_set, Tuple{t, 1, 0}},
    Table{t}}}}

load はその時点の parse と eval でファイルを1式ずつ評価し、大域変数に定義したファイルを記録します（変数の範囲）。

planck/init.pk: load(path) parses and evaluates

" load(path) parses and evaluates the file by the current parse and eval. "
" The top-level definitions of the file are made while path is the file being loaded. "
Def{load, Lambda{Tuple{path}, Do{
    Def{s, Apply{read_file, Tuple{path}}},
    Def{prev, Apply{_set_file, Tuple{path}}},
    Def{r, none},
    Def{e, none},
    Def{go, true},
    While{go, Do{
        Set{r, Apply{parse, Tuple{s}}},
        Set{e, Apply{arg, Tuple{r, 0}}},
        If{Apply{_eq, Tuple{e, Eof{}}}, Set{go, false},
        If{If{Apply{_eq, Tuple{Apply{typeof, Tuple{e}}, Quote{mexpr}}}, Apply{_eq, Tuple{Apply{head, Tuple{e}}, Quote{SyntaxError}}}, false},
            Do{
                Apply{put, Tuple{path}},
                Apply{put, Tuple{": syntax error: "}},
                Apply{println, Tuple{e}},
                Apply{exit, Tuple{1}}},
            Do{
                Apply{eval, Tuple{e}},
                Set{s, Apply{arg, Tuple{r, 1}}}}}}}},
    Apply{_set_file, Tuple{prev}},
    none}}}

構文への切り替え

planck/init.pk: Syntax

" === Syntax === "
" planck/syntax.pk replaces parse. The files after it are read by the new syntax. "
Apply{load, Tuple{"planck/peg.pk"}}
Apply{load, Tuple{"planck/syntax.pk"}}

" planck/lib/use.pk defines use(name), which loads planck/lib/<name>.pk once. It is written in the syntax above. "
Apply{load, Tuple{"planck/lib/use.pk"}}
