部分関数と融合

関数はパターンで引数を取ります。パターンは引数の形を式と同じ書き方で書いたもので、合えば変数を束縛します。f | g（融合）で場合分けを書きます。

部分関数と融合

関数はパターンで引数を取るので、合わない引数があり得る部分関数です。f | g（Fusion{f, g}）は f を試し、どのパターンも合わなければ g を試します。

fn_fusion.pk

f := (0) -> "zero" | (1) -> "one"
println(f(1))

sign(x) if x > 0 := "positive"
sign(0) := "zero"
sign(_) := "negative"
println(sign(5))
println(sign(0))
println(sign(-5))

出力

"one"
"positive"
"zero"
"negative"
  • ガード if c が偽のときも、合わなかったものとして扱います。
  • 同じ場所に続けて書いた f(0) := ... の定義は、書いた順に試す1つの関数です。
  • どの腕にも合わない呼び出しは、MatchingFailed を起こします。受け手がなければプログラムが止まります。

e_fn_nomatch.pk

f := (0) -> "zero" | (1) -> "one"
println(f(7))

出力

matching failed: <lambda:(0)>|<lambda:(1)> <-> (7)

パターン

  • _：何にでも合い、何も束縛しません。
  • Head{p, ..., _Rest{x}}：引数が _Rest の前の数以上ある M式に合い、残りの Tuple を x に束縛します。
  • _TypeOf{p, type}：type(x) が type で p が合う値に合います。

t3_type.pk

describe := (n @ int) -> f"integer {n}"
          | (s @ string) -> f"string {s}"
          | (_) -> "other"
put(describe(1)); put("\n")
put(describe("abc")); put("\n")
put(describe('x)); put("\n")

出力

integer 1
string abc
other

引数に書く形

引数 p と for のパターンは、or の階層までの式として書き、表の M式にして照合します。式と同じ書き方で、識別子が変数になります。例外は次のとおりです。

  • 演算子と呼ばれる関数の名前は symbol です。x + 1 は Apply{Quote{_add}, Tuple{x, 1}}、f(p, ...) は Apply{Quote{f}, Tuple{p, ...}} の木に合います。呼ばれる関数を変数にするには (f)(p, ...) と書きます。
  • 'e は Quote{e}、p @ type は型の検査、x... は最後の引数の残りです。
  • 同じ名前を2回書く f(a, a) は、2つの値が == で等しいときだけ合います。
  • p or q はどちらかに合います。変数を書けるのは、どの枝も同じ変数を束縛するときだけです（f((x, 0) or (0, x)) := x）。式の or の M式 If{a, true, b} に合わせるには If{a, 'true, b} と書きます。
  • 書ける形：演算子（or and not == != <= >= < > :: + - * / %、単項の - と '）・f(p, ...)・Head{p, ...}・識別子・true false none・整数・文字列・組・リスト。

r_pattern.pk

simp(e) := match e {
    a @ int + b @ int -> a + b
  | a + 0 -> a
  | x * y if x == y -> `sq(!x)
  | _ -> e
}
println(simp('(1 + 2)))
println(simp('(z + 0)))
println(simp('(z * z)))
swap(a + b) := `(!b + !a)
println(swap('(1 + 2)))
callee((f)(x)) := f
println(callee('g(1)))

出力

3
z
Apply{sq, Tuple{z}}
Apply{_add, Tuple{2, 1}}
g

残りの引数

x... は残りの引数を Tuple（なければ Tuple{}）に束縛します。

r_rest.pk

# A rest parameter x... takes the remaining arguments as a Tuple

sum_tuple(t) := {
    s := 0
    i := 0
    while (i < arity(t)) {
        s = s + arg(t, i)
        i = i + 1
    }
    s
}

# the last parameter of a function
total(xs...) := sum_tuple(xs)
println(total())
println(total(1, 2, 3))

# after the fixed parameters
scale(k, xs...) := k * sum_tuple(xs)
println(scale(10, 1, 2, 3))

# in a function written with ->
count := (first, others...) -> 1 + arity(others)
println(count(7, 8, 9))

# arms with fewer parameters are chosen by the number of arguments
describe(a) := "one"
describe(a, b) := "two"
describe(a, b, c...) := "three or more"
println(describe(1))
println(describe(1, 2))
println(describe(1, 2, 3, 4))

# in the pattern of an M-expression, the arguments after the fixed ones
args_of(Call{f, rest...}) := rest
println(args_of(Call{1, 2, 3}))
println(args_of(Call{1}))

# in match
println(match Call{1, 2, 3} { Call{x, ys...} -> ys })

出力

0
6
60
3
"one"
"two"
"three or more"
Tuple{2, 3}
Tuple{}
Tuple{2, 3}
  • 書けるのは、関数 f(p, x...) := e・(p, x...) -> e とパターン Head{p, x...} の最後の引数だけです。
  • 前の引数の数より少ない呼び出しは合いません。
  • 最後以外・呼び出しの引数・ガード付きの関数に書くと、実行前にメッセージを出して止まります。

定義で場合を足す

f(p, ...) := e は、書いた場所の変数に f があれば f(p, ...) = e（f の関数の後ろに足す）と同じで、なければ新しい f を定義します。

r_scope_same.pk

fib(0) := 0
fib(1) := 1
fib(n) := fib(n - 1) + fib(n - 2)
println(fib(20))

x := 1
x := x + 1
println(x)

出力

6765
2
書いた場所場所の変数
トップレベル同じファイルの大域変数
関数の中その関数の引数と、それより前に定義した変数
トップレベルの if の枝・while の本体その中でそれより前に定義した変数

外側の関数・別のファイル（use で読んだライブラリ）の変数と組み込み関数は場所の変数ではありません。同じ名前の f(p, ...) := e は外の f を変えず、隠す新しい f を定義します。別のファイルの f に足すには f(p, ...) = e と書きます。

t8_place.pk

fib(0) := 0
fib(1) := 1
fib(n) := fib(n - 1) + fib(n - 2)
println(fib(10))

name(x) := "outer"
inner() := {
    name(0) := "inner"
    name(0)
}
println(Tuple{inner(), name(0), name(1)})

出力

55
Tuple{"inner", "outer", "outer"}

t8_library.pk

use("list")
foldl(f, acc, Tuple{a, b}) = f(f(acc, a), b)
println(Tuple{foldl(_add, 0, [1, 2, 3]), foldl(_add, 0, Tuple{4, 5})})
reverse(xs) := "mine"
println(reverse([1, 2]))

出力

Tuple{6, 9}
"mine"
  • ガードは定義にも付けられます。f(p, ...) if c := e は、引数が合って c が真のときだけ e を返します。偽のときと合わないときは、続けて書いた次の定義を試します（間に別の式があると続きません）。
  • export を付けた定義と f(p, ...) = e にはガードを付けられません。

相互再帰

先に fun f で名前だけを宣言し（値は none）、あとで f(p, ...) = e で埋めます。f(p, ...) = e は f = f | (p, ...) -> e です。none | g は g なので、最初の f(p, ...) = e は関数そのものを代入します。

r_scope_fun.pk

fun odd
even(n) := if (n == 0) true else odd(n - 1)
odd(n) = if (n == 0) false else even(n - 1)
println(Tuple{even(10), odd(7)})

fun fact
fact(0) = 1
fact(n) = n * fact(n - 1)
println(fact(5))

出力

Tuple{true, true}
120

埋める前に呼ぶと none を呼ぶことになって止まります。

e_call_before_fill.pk

fun f
println("run")
f()
f() = 1

出力

"run"
not a function: none

値がガード付きの関数なら、ガードが偽でも f(p, ...) = e で足した関数は呼ばれません。変数で渡したガード付きの関数に | g をつないでも、g は呼ばれないのと同じです。

e_fn_guard_chain.pk

fun f
f = (n) if n > 0 -> "positive"
f(n) = "other"
println(f(5))
println(f(-1))

出力

"positive"
matching failed: <lambda:(_TypeOf{_, nomatch})> <-> (-1)

MatchingFailed

どの腕にも合わなかった関数呼び出し・match・融合の最後のつなぎ先は、止まる代わりに MatchingFailed{f, args, loc} を Perform します。match e { f } は f(e) と同じ呼び出しです。

フィールド中身
f呼ばれた関数（融合なら融合全体）
args合わなかった引数の Tuple{...}
loc失敗した呼び出しや match の位置 Loc{file, line, column}
f := (0) -> "zero" | (1) -> "one"
a := handle f(7) with (MatchingFailed{_, Tuple{n}, _}, k) -> n
println(a)
7
  • ハンドラの値が Handle の値になります。f(7) を呼んだ式の値にはなりません。
  • 受け手のハンドラが無ければ、matching failed を出して止まります。unhandled effect にはなりません。
  • Return{v} や Break{} だけを受けるハンドラは通り抜けます。どのパターンにも合う (e, k) -> ... のハンドラは MatchingFailed も受けます。

腕の奥で起きた失敗

次の腕へ移るかどうかは、入口のパターンとガードだけで決まります。入口が合った腕の本体の奥で起きた MatchingFailed は、外側へ伝わります。

g(0) := "zero"
h := (x) -> g(x) | (x) -> "second arm"

r := handle h(5) with (MatchingFailed{f, _, _}, k) -> "failed in g"
println(r)
"failed in g"
