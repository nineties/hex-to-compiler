部分関数と融合

関数はパターンで引数を取ります。パターンは引数の形を M式で書いたもので、合えば変数を束縛します。Fusion{f, g}（融合）で場合分けを書きます。

部分関数と融合

関数はパターンで引数を取るので、合わない引数があり得る部分関数です。Fusion{f, g} は f を試し、どのパターンも合わなければ g を試します。

fn_fusion.pk

Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
Apply{println, Tuple{Apply{f, Tuple{1}}}}
Def{g, Fusion{f, Lambda{Tuple{_}, "other"}}}
Apply{println, Tuple{Apply{g, Tuple{7}}}}

出力

"one"
"other"

どの腕にも合わない呼び出しは、MatchingFailed を起こします。受け手がなければプログラムが止まります。

e_fn_nomatch.pk

Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
Apply{println, Tuple{Apply{f, Tuple{7}}}}

出力

matching failed: <lambda:(0)>|<lambda:(1)> <-> (7)

パターン

  • 変数：何にでも合い、値を束縛します。_ は何にでも合い、何も束縛しません。
  • 整数・文字列：equal な値に合います。Quote{s} は symbol s に合います。
  • Head{p, ...}：head が Head で、引数が順に p, ... に合う M式に合います。
  • _TypeOf{p, type}：type(x) が type で p が合う値に合います。type が Expr なら M式すべてに合います。

t3_type.pk

Def{describe, Fusion{
    Lambda{Tuple{_TypeOf{n, int}}, Apply{_strcat, Tuple{"integer ", Apply{_to_text, Tuple{n}}}}},
    Fusion{
        Lambda{Tuple{_TypeOf{s, string}}, Apply{_strcat, Tuple{"string ", s}}},
        Lambda{Tuple{_}, "other"}}}}
Apply{println, Tuple{Apply{describe, Tuple{1}}}}
Apply{println, Tuple{Apply{describe, Tuple{"abc"}}}}
Apply{println, Tuple{Apply{describe, Tuple{Quote{x}}}}}

出力

"integer 1"
"string abc"
"other"

Apply{_add, Tuple{x, 1}} のような木に合わせるには、関数の位置を Quote{_add} と書きます。変数にすると、任意の関数の呼び出しに合います。

r_pattern.pk

Def{simp, Fusion{
    Lambda{Tuple{Apply{Quote{_add}, Tuple{_TypeOf{a, int}, _TypeOf{b, int}}}}, Apply{_add, Tuple{a, b}}},
    Fusion{
        Lambda{Tuple{Apply{Quote{_add}, Tuple{a, 0}}}, a},
        Lambda{Tuple{e}, e}}}}
Apply{println, Tuple{Apply{simp, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}}}
Apply{println, Tuple{Apply{simp, Tuple{Quote{Apply{_add, Tuple{z, 0}}}}}}}
Def{swap, Lambda{Tuple{Apply{Quote{_add}, Tuple{a, b}}}, QuasiQuote{Apply{_add, Tuple{UnQuote{b}, UnQuote{a}}}}}}
Apply{println, Tuple{Apply{swap, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}}}
Def{callee, Lambda{Tuple{Apply{f, Tuple{x}}}, f}}
Apply{println, Tuple{Apply{callee, Tuple{Quote{Apply{g, Tuple{1}}}}}}}

出力

3
z
Apply{_add, Tuple{2, 1}}
g

残りの引数

_Rest{x} は残りの引数を Tuple（なければ Tuple{}）に束縛します。

r_rest.pk

Def{total, Lambda{Tuple{_Rest{xs}}, xs}}
Apply{println, Tuple{Apply{total, Tuple{}}}}
Apply{println, Tuple{Apply{total, Tuple{1, 2, 3}}}}
Def{count, Lambda{Tuple{first, _Rest{others}}, Apply{_add, Tuple{1, Apply{arity, Tuple{others}}}}}}
Apply{println, Tuple{Apply{count, Tuple{7, 8, 9}}}}
Def{describe, Fusion{
    Lambda{Tuple{a}, "one"},
    Fusion{
        Lambda{Tuple{a, b}, "two"},
        Lambda{Tuple{a, b, _Rest{c}}, "three or more"}}}}
Apply{println, Tuple{Apply{describe, Tuple{1}}}}
Apply{println, Tuple{Apply{describe, Tuple{1, 2}}}}
Apply{println, Tuple{Apply{describe, Tuple{1, 2, 3, 4}}}}
Def{args_of, Lambda{Tuple{Call{f, _Rest{rest}}}, rest}}
Apply{println, Tuple{Apply{args_of, Tuple{Call{1, 2, 3}}}}}
Apply{println, Tuple{Apply{args_of, Tuple{Call{1}}}}}

出力

Tuple{}
Tuple{1, 2, 3}
3
"one"
"two"
"three or more"
Tuple{2, 3}
Tuple{}
  • 書けるのは、Lambda の引数の最後と、パターン Head{p, ...} の最後の引数だけです。
  • 前の引数の数より少ない呼び出しは合いません。
  • 最後以外や呼び出しの引数に書くと、実行前にメッセージを出して止まります。

場合を足す

Declare{f} のあとに Set{f, Fusion{f, Lambda{Tuple{p, ...}, body}}} と書くと、書いた場所の変数に f があればその関数の後ろに場合を足し、なければ新しい f を定義します。

r_scope_same.pk

Declare{fib}
Set{fib, Fusion{fib, Lambda{Tuple{0}, 0}}}
Set{fib, Fusion{fib, Lambda{Tuple{1}, 1}}}
Set{fib, Fusion{fib, Lambda{Tuple{n},
    Apply{_add, Tuple{
        Apply{fib, Tuple{Apply{_sub, Tuple{n, 1}}}},
        Apply{fib, Tuple{Apply{_sub, Tuple{n, 2}}}}}}}}}
Apply{println, Tuple{Apply{fib, Tuple{20}}}}

出力

6765
書いた場所場所の変数
トップレベル同じファイルの大域変数
関数の中その関数の引数と、それより前に定義した変数
トップレベルの If の枝・While の本体その中でそれより前に定義した変数

外側の関数・別のファイル（use で読んだライブラリ）の変数と組み込み関数は場所の変数ではありません。同じ名前の Declare{f} は外の f を変えず、隠す新しい f を定義します。別のファイルの f に足すには、Declare を付けずに Set します。

t8_place.pk

Declare{name}
Set{name, Fusion{name, Lambda{Tuple{x}, "outer"}}}
Def{inner, Lambda{Tuple{}, Do{
    Declare{name},
    Set{name, Fusion{name, Lambda{Tuple{0}, "inner"}}},
    Apply{name, Tuple{0}}}}}
Apply{println, Tuple{Tuple{Apply{inner, Tuple{}}, Apply{name, Tuple{0}}, Apply{name, Tuple{1}}}}}

出力

Tuple{"inner", "outer", "outer"}

t8_library.pk

Apply{use, Tuple{"list"}}
Set{foldl, Fusion{foldl, Lambda{Tuple{f, acc, Tuple{a, b}},
    Apply{f, Tuple{Apply{f, Tuple{acc, a}}, b}}}}}
Apply{println, Tuple{Tuple{
    Apply{foldl, Tuple{_add, 0, Cons{1, Cons{2, Cons{3, Nil{}}}}}},
    Apply{foldl, Tuple{_add, 0, Tuple{4, 5}}}}}}
Declare{reverse}
Set{reverse, Fusion{reverse, Lambda{Tuple{xs}, "mine"}}}
Apply{println, Tuple{Apply{reverse, Tuple{Cons{1, Cons{2, Nil{}}}}}}}

出力

Tuple{6, 9}
"mine"

相互再帰

先に Def{f, none} で名前だけを宣言し、あとで Set{f, Fusion{f, Lambda{...}}} で埋めます。Fusion{none, g} は g なので、最初の Set は関数そのものを代入します。

r_scope_fun.pk

Def{odd, none}
Declare{even}
Set{even, Fusion{even, Lambda{Tuple{n},
    If{Apply{_eq, Tuple{n, 0}}, true, Apply{odd, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
Set{odd, Fusion{odd, Lambda{Tuple{n},
    If{Apply{_eq, Tuple{n, 0}}, false, Apply{even, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
Apply{println, Tuple{Tuple{Apply{even, Tuple{10}}, Apply{odd, Tuple{7}}}}}

出力

Tuple{true, true}

埋める前に呼ぶと none を呼ぶことになって止まります。

e_call_before_fill.pk

Def{f, none}
Apply{println, Tuple{"run"}}
Apply{f, Tuple{}}
Set{f, Fusion{f, Lambda{Tuple{}, 1}}}

出力

"run"
not a function: none

MatchingFailed

どの腕にも合わなかった関数呼び出しと、融合の最後のつなぎ先は、止まる代わりに MatchingFailed{f, args, loc} を Perform します。

フィールド中身
f呼ばれた関数（融合なら融合全体）
args合わなかった引数の Tuple{...}
loc失敗した呼び出しの位置 Loc{file, line, column}
Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
Def{a, Handle{Apply{f, Tuple{7}}, Lambda{Tuple{MatchingFailed{_, Tuple{n}, _}, k}, n}}}
Apply{println, Tuple{a}}
7
  • ハンドラの値が Handle の値になります。Apply{f, Tuple{7}} の値にはなりません。
  • 受け手のハンドラが無ければ、matching failed を出して止まります。unhandled effect にはなりません。
  • Return{v} や Break{} だけを受けるハンドラは通り抜けます。どのパターンにも合う Lambda{Tuple{e, k}, body} のハンドラは MatchingFailed も受けます。

腕の奥で起きた失敗

次の腕へ移るかどうかは、入口のパターンだけで決まります。入口が合った腕の本体の奥で起きた MatchingFailed は、外側へ伝わります。

Def{g, Lambda{Tuple{0}, "zero"}}
Def{h, Fusion{Lambda{Tuple{x}, Apply{g, Tuple{x}}}, Lambda{Tuple{x}, "second arm"}}}
Def{r, Handle{Apply{h, Tuple{5}}, Lambda{Tuple{MatchingFailed{f, _, _}, k}, "failed in g"}}}
Apply{println, Tuple{r}}
"failed in g"
