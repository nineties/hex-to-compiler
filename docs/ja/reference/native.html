native

use("native/compile") が定義するシステム言語です。意味は vasm と同じで、書き方が高級です。native{| ... |} に書いた関数と構造体を、native_compile.compile が vasm のモジュールに展開します。所有と借用の検査は展開した vasm に対して行います。

プログラム

プログラムは構造体と関数の並びで、その前に import を置けます。import lib は単位 lib を指し、ほかの単位の構造体と関数は、こう書いた単位のものだけ使えます（vasmc）。import はファイルの先頭に1行に1つ書きます。型・構造体・関数の宣言は vasm と同じ書き方です。関数の本体は文の並びで、文は改行か ; で区切ります。

native{| ... |} の値は PModule{[...]} で、リストの先頭に import ごとの PImport{at, name} が並びます。native_compile の関数は、これを次のように扱います。

関数返す値
native_compile.compile(m)vasm の Module{[...]}。vasm_check と vasm_build がそのまま受け取る
native_compile.compile_all(m)Tuple{モジュール, 誤りのリスト}。誤りは VasmErr{kind, loc, msg} で、関数ごとに最初の1件
native_compile.errors(file, 誤り)位置をファイルの Loc にした誤り

式

式は入れ子にでき、優先順位は上から下へ強くなります。

形意味
a or ba が真なら b を計算しない
a and ba が偽なら b を計算しない
== != < <= > >=比較。結果は bool
|ビットの or
^ビットの xor
&ビットの and。比較より強い
<< >>シフト
+ -加減算
* / %乗除算。* は左の項と同じ行に書く
e as T整数の型を変える
-e not e *p &r y &mut r y符号の反転・否定・箱の中身・借用
a[i] s.f f(a, ...) S{f: a, ...}要素・フィールド・呼び出し・構造体の値
'name "text" val H(a, ...) fn f(a, ...) true falseval の値と文字列と真偽

括弧でまとめられます。引数は左から順に計算します。a[i] と s.f の a と s は変数です。構造体の値は、先頭にフィールドを書くので、if や for の本体の { と区別できます。

文

形意味
let x = e let x: T = e変数を宣言して初期化する。型は e の型で、: T で指定もできる
var x: T未初期化の変数を宣言する
x = e *p = e a[i] = e s.f = e代入。右辺を先に計算する
x += e など複合代入。+= -= *= /= %= &= |= ^= <<= >>=。左辺の場所は1回だけ読む
f(a, ...)呼び出しの文
if c {...} else {...} else if条件に括弧は要らない
while c {...}条件は周のたびに計算し直す
for i in a..b {...}i は a から b の手前まで。b は始めに1回だけ計算する。i は本体の中だけで見える
region r {...} return return evasm と同じ

値を返す関数の本体は、最後の文が式なら、その値を返します。

native_compile.pk

use("native/compile")
use("vasm/text")

m := native{|
    fn gcd(a: i64, b: i64) -> i64 {
        while b != 0 {
            let t = a % b
            a = b
            b = t
        }
        a
    }

    fn bump[r](m: &mut r [i32], n: i32) {
        for i in 0 as i32..n {
            m[i] += 1
        }
    }
|}
put(vasm_text.text(native_compile.compile(m)))

出力

fn gcd(a: i64, b: i64) -> i64 {
    while (b != 0) {
        var t: i64
        t = a % b
        a = b
        b = t
    }
    return a
}

fn bump[r](m: &mut r [i32], n: i32) {
    var t0: i32
    t0 = n
    var i: i32
    i = 0
    while (i < t0) {
        var t1: i64
        t1 = i as i64
        var t2: i32
        t2 = m[t1]
        t2 = t2 + 1
        m[t1] = t2
        i = i + 1
    }
}

型の決まり方

  • 式の型は、変数と関数の宣言と組み込みの型から決まります。型を書く場所は let・var・パラメータ・関数の結果・as だけです。
  • 整数のリテラルは、それだけでは型がありません。代入先・引数・相手の項・関数の結果の型が、リテラルの型になります。let x = 5 のように型を決める手がかりのないリテラルは誤りです。let x: i64 = 5 か 5 as i64 が正しい書き方です。
  • for i in a..b の変数の型は、a と b のうちリテラルでない方の型です。両方リテラルなら誤りで、0 as i64..10 のように一方に型を付けます。
  • 借用を結果に持つ関数の呼び出しは、結果の領域が引数から1つに決まるときだけ、型を推論します。決まらないときは let x: T = f(...) のように型を書きます。
  • 配列の添字は i64 です。ほかの整数型の添字には as i64 が必要です。
  • 同じ名前を宣言し直せます。前の変数は見えなくなります。

大きなリテラル

vasm のリテラルは -32768 から 32767 までです。native はそれを超える整数のリテラルを書けます。リテラルは型の範囲に入らなければ誤りです。

native_logic.pk

use("native/compile")
use("vasm/text")

m := native{|
    fn both(a: i64, b: i64) -> bool {
        a > 0 and b > 0
    }

    fn mask(x: i32) -> i32 {
        x & 0x3FFFFFF
    }
|}
put(vasm_text.text(native_compile.compile(m)))

出力

fn both(a: i64, b: i64) -> bool {
    var t0: bool
    t0 = a > 0
    var t1: bool
    t1 = t0
    if (t1) {
        var t2: bool
        t2 = b > 0
        t1 = t2
    }
    return t1
}

fn mask(x: i32) -> i32 {
    var t0: i32
    t0 = 2047
    t0 = t0 << 15
    t0 = t0 | 32767
    var t1: i32
    t1 = x & t0
    return t1
}

誤り

展開の誤りの kind は 'type（型が決まらない・リテラルが型の範囲にない・式の文が呼び出しでない）と 'undefined（宣言のない変数・関数・構造体）です。所有・借用・初期化の誤りは展開では調べず、展開した vasm を vasm_check.check が調べます。誤りの位置は native のソースの位置です。

native_errors.pk

use("native/compile")

m := native{|
    fn f(n: i64) {
        let x = 5
    }
    fn g(n: i64) {
        for i in 0..10 {
            n += 1
        }
    }
    fn h(n: i64) -> i64 {
        n + k
    }
|}
file := argv()[0]
each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), native_compile.errors(file, arg(native_compile.compile_all(m), 1)))

出力

line 5: the type of this value is not known; write the type, as in let x: i32 = ... or e as i32
line 8: the type of the loop variable is not known; write one bound with its type, as in 0 as i64..n
line 13: k is not declared
