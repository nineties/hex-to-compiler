リファレンス

planck は記号処理と言語処理のための言語です。この節が言語の定義です。

プログラムの読み込み

最初に planck/init.pk を読み、続いて最初の引数のプログラムファイルを実行します。トップレベルの式は1つずつ読んで評価します。

planck/init.pk・planck/peg.pk は M式で書かれています。planck/syntax.pk は planck/peg.pk の packrat パーサで構文を定義します。::= の文法と動作用の最小の構文までを M式で書いてそこで parse を差し替え、残りの構文を ::= で宣言するので、引数のファイルはこの構文で読まれます。
