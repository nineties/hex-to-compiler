planck は記号処理と言語処理のための言語です。この節で言語を定義します。

プログラムの読み込み

処理系は planck/init.pk を読み込んでから、第1引数のプログラムファイルのトップレベルの式を1つずつ読んで評価します。planck/syntax.pk は planck/peg.pk の packrat パーサで構文を定義します。まず M式で ::= の文法と動作の最小の構文までを書き、そこで parse を差し替え、残りを ::= で宣言します。引数のファイルはこの構文で読みます。
