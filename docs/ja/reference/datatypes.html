データ型

planck の値の型、immutability、equality と identity を定めます。式・パターン・特殊形式は値・パターン・M式にあります。

値の型

組み込みの型は次の8つです。これに加えて、利用者が新しい型（ユーザーデータ）を作れます。

型値リテラルhead

floatIEEE 754 の binary641.5Float

symbol名前ごとに一意x。英字・_・% で始まる名前。true false none は同名の symbol を値とするリテラルSymbol
M式head の symbol と任意の個数の引数。引数に mutable な値は入れられないHead{a, b}。糖衣は (a, b)（Tuple）・[a, b] と ::（Cons）・[]（Nil）M式ごとの head

complex は組み込みの型ではなく、ユーザーデータです。標準のライブラリが定めます。Table・Vector は array を包む M式ではなくなります。

値の型は head で調べます。パターンの x @ Int は head が Int の値に合います。型名の symbol は M式の head にできません。M式の引数の個数に上限はありません。

immutability

値は immutable か mutable のどちらかです。array と plain array は mutable です。整数・float・文字列・symbol・M式・function は immutable です。ユーザーデータは、作るときに immutable か mutable かを指定できます。

型mutable かa[i] = e
整数・floatimmutable止まる
文字列immutable止まる。a[i] は読める（長さ1の文字列）
symbolimmutable止まる
M式（Cons・Tuple・Nil を含む）immutable止まる。a[i] は読める
arraymutable通る。範囲外はエラー
plain arraymutable通る。範囲外と変換できない値はエラー
ユーザーデータ作るときに指定するこの頁に定めがない

M式の引数に mutable な値は入れられません。入れようとするとエラーになります。

添字の規則は添字と置き換えにあります。

equality と identity

equality は a == b（_eq）で調べます。a != b（_ne）はその逆です。

identity は、2つの値が同じオブジェクトであることです。array・plain array・function は identity が同じときだけ equal です。ユーザーデータの equality はこの頁に定めがありません。identity だけを調べる組み込み関数はありません。

数の型をまたぐ equality

整数と float は、型が違っても値が同じなら equal です。1 == 1.0 は true です。complex との equality はこの頁に定めがありません。

NaN は自分自身とも equal ではありません。x == x は x が NaN のとき false です。

順序の比較 < <= > >= は equality ではありません。整数と float を数学的な値で比べます。NaN を含むと false です。数を参照してください。

equality を使う所

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が == で equal なときだけ合います。
  • 組み込みの table（table_get・table_set・t[key]）は key を == で比べます。
  • hash(x) は 0 以上の整数です。== で equal な値は同じ値になります。
