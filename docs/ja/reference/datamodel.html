データモデル

すべての値が型を持ち、値は M式か atom のどちらかです。評価の対象は M式で、特殊形式の頭を持たない M式は構築子で、引数を評価した同じ頭の M式になります。== は値として等しいか（equal）、is は同じ物か（identical）を調べます。identical な値は必ず equal で、intern する型では equal な値は identical です。数は型が混ざると高いほうに揃え、誤りは実行時エラーです。以下は型ごとの違いと、原則から外れる所です。

M式と atom

atom は M式でない値です。整数・float・complex・文字列・symbol・function・array・plain array・型の値・ユーザーデータがあります。

  • M式の head は symbol です。head は登録しないので、2つのライブラリが同じ head を使えます。head(x) は M式だけに使い、atom ならエラーです。
  • 型そのものが値（型の値）で、type(x) が返します。type(1) は Int、type(Int) は Type です。
  • Int・String・Expr などの名前は、型の値を持つ変数です。x @ T は変数 T を type(x) と比べるので、x @ Expr はすべての M式に合います。

M式の Set{1} と、名前が Set の型は別物で、名前が head とぶつかることはありません。

M式

  • 型は Expr で、immutable です。リテラルは Head{a, b} で、糖衣に (a, b)（Tuple）・[a, b] と ::（Cons）・[]（Nil）があります。
  • intern します。f{1} と f{1.0} は equal ではありません。
  • mutable な値、mutable な値を持つ immutable なユーザーデータ、NaN は引数に入れられず、作るときに実行時エラーになります。

型ごとの補足

  • 整数は多倍長で、範囲に制限がなく、ラップアラウンドも切り詰めも起きません。
  • complex は虚数リテラル（2i）か complex(re, im) で作ります。値が同じ整数・float と equal です。
  • float は IEEE 754 の binary64 です。NaN は自分自身を含むどの値とも equal でも identical でもなく（x == x も x is x も false）、table の key にするとエラーです。
  • 文字列は 0 のバイトを含むバイト列で、65535バイトまでです。a[i] は長さ1の文字列を返します。
  • symbol の名前は英字・_・% で始まります。true false none は字句にあります。
  • function は Lambda・Fusion・組み込み関数・継続で、equal になるのは identical なときだけです。
  • array は固定長で、array(n) で作り、全要素は初め none です。plain array は要素の型が1つで、'bool・'i8 から 'u64・'f16 から 'f64・'c64・'c128 のどれかです。どちらも a[i] = e で書き換えられ、範囲外はエラーです（plain array は変換できない値もエラー）。
  • array と plain array は、中身が同じ別の物なら equal ですが identical ではありません。== は identical なら先に true を返すので、NaN を持つ a は a == a が true です。同じ NaN を持つ別の array b との a == b は false です。
  • 型の値は、表示では型の名前で出ます。同じ名前の別の型は is で区別します。

ユーザーデータ

  • 組み込み関数で作り、immutable か mutable かを必ず指定します。既定はありません。
  • 型は作るたびに一意の値で、名前は表示にしか使いません。別の所で作った同じ名前の型は別の型です。
  • 作るときに == の関数と hash の関数を、両方まとめて渡せます。渡した型は intern せず、is は object の比較になります。a is b なら a == b であること、equal なら hash が同じであることは、型を作る人が守ります。
  • 渡さない型は == が identity で、hash は immutable なら中身、mutable ならオブジェクトで決まります。

equality

a == b（_eq）で調べ、a != b（_ne）はその逆です。整数・float・complex は、型が違っても値が同じなら equal で、hash も同じです（1 == 1.0、1 == complex(1, 0)）。

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が equal なときだけ合います。
  • table（table_get・table_set・t[key]）は、key が identical か equal なら同じ key とします。array・plain array・NaN を key にするとエラーです。
  • hash(x) は 0 以上の整数で、equal な値は同じ値になります。具体的な値は定めません。

identity と is

a is b は a と b が identical なら true です。否定は a is not b で、優先順位は == と同じ比較演算子の段です。結合しないので a is b is c はエラーで、パターンの中に is は書けません。

  • intern は、同じ値を1つの object にまとめることです。整数・文字列・symbol・M式・== を渡していない immutable なユーザーデータは intern するので、== と is は同じ判定で、O(1) です（多倍長整数を除く）。
  • float・function・array・plain array・mutable なユーザーデータ・== を渡したユーザーデータは object です。equal でも identical とは限りません。
  • 型が違う値は identical ではありません。1 == 1.0 は true で、1 is 1.0 は false です。

リテラル

true・false・none は、同じ名前のシンボルを値とするリテラルです。変数ではないので、Def{true, e}・Set{true, e}・Declare{true} は実行前にプログラムを止めます。トップレベルの文字列は効果を持たず、コメントになります。

数

  • 整数どうしの割り算は3つあります。_div は0方向へ切り捨て、_quo（//）は負の無限大方向へ丸めます（-7 // 2 は -4）。_mod(a, b) は a - b * (a // b) で、符号は除数と同じです。
  • 除数が0なら実行時エラーです。ただし浮動小数点数か複素数を含む _div は止まらず、無限大か NaN（複素数は成分ごと）になります。
  • _lt _le _gt _ge は整数と浮動小数点数を、型を揃えず数学的な値で比べます。NaN を含むと false で、複素数は実行時エラーです。
  • _eq は型が違っても値が同じ数を等しいとします（1 == 1.0）。複素数は両成分が等しいときに等しく、NaN は自分自身とも等しくありません。
  • 整数は最も近い浮動小数点数に丸めて揃え、範囲外は実行時エラーです。

特殊形式

  • Def{x, e}：右辺から x より前の変数が見えます。Set{x, e} は代入です。
  • Declare{x}：Def{x, none} と同じです。ただし Def{x, e} が x を定義する場所に x がすでにあれば何もしません。
  • If{c, a, b}：c が false のときだけ b です。
  • Fusion{f, g}：f のどのパターンも合わなければ g を試します。Fusion{none, g} は g です。

record

record T(f, g, ...) は、値 T{a, b, ...} の引数に欄の名前を付けます。値の作り方は変わりません。t.f は t の頭の宣言で f の位置にある引数で、. は左の式に空白なしで続けます。

  • 頭が違えば同じ名前の欄を持てます。同じ T をもう一度宣言すると名前が置き換わります。
  • 頭が宣言されていない値や、欄 f がない値に .f を使うと、メッセージを出してプログラムが止まります。
  • t with { f = e, g = e2 } は欄を替えた新しい値です（t は変わりません）。欄は左から順に替えるので、e は元の t の欄も参照できます。with { ... } は続けて書けます。

t1_with.pk

record Point(x, y)

p := Point{1, 2}
q := p with { y = 5 }
println(p)
println(q)
println(p with { x = p.y, y = p.x })
println(p with { x = 7 } with { y = 8 })

出力

Point{1, 2}
Point{1, 5}
Point{2, 1}
Point{7, 8}
