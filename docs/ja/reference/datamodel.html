データモデル

値は M式か atom のどちらかです。

M式

M式は Head{a, b, ...} と書く値で、head（symbol）と引数の列を持ちます。

dm_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(push(p, 5))
println(Point{1 + 1, 2})
println((1, 2))
println([1, 2])
println(1 :: [2])
println([])
println(Point{1, 2} == Point{1, 2})
println(Point{1, 2} == Point{1, 3})

  • 型は Expr で、immutable です。
  • 糖衣：(a, b) は Tuple、[a, b] と :: は Cons、[] は Nil です。
  • 引数の数に限度はありません。mutable な値と NaN は引数に入れられず、作るときに実行時エラーです。
  • head(x) は M式だけに使えます。

equality

a == b は値として等しい（equal）かを調べます。

  • 整数・float・complex は、型が違っても値が同じなら equal です（1 == 1.0）。NaN はどの値とも equal ではありません。
  • M式は head と引数が equal なら equal です。
  • array と plain array は、identical なら equal で、そうでなければ要素ごとに比べます。
  • 同じ名前を2回書いたパターン f(a, a) は、2つの値が equal なときだけ合います。
  • hash(x) は 0 以上の整数で、equal な値は同じ値です。

identity と is

a is b は同じ物（identical）なら true です。identical な値は必ず equal で、型が違う値は identical ではありません（1 == 1.0 は true、1 is 1.0 は false）。否定は is not です。優先順位は == と同じで、結合せず、パターンには書けません。

intern は、equal な値を1つの object にまとめることです。intern する型では equal な値が identical で、is は O(1) です（多倍長整数を除く）。

ユーザーデータ

  • 組み込み関数で作り、immutable か mutable かを必ず指定します。
  • immutable なユーザーデータは mutable な値を中身に持てず、作るときに実行時エラーです。
  • 型は作るたびに別の値です。名前は表示にしか使わず、同じ名前の型は is で区別します。
  • 作るときに == と hash の関数をまとめて渡せます。a is b なら a == b、equal なら hash が同じであることは、作る人が守ります。
  • 渡さない型の hash は、immutable なら中身、mutable なら object で決まります。

数

型が混ざる演算は、高い型に揃えます。

dm_int.pk

println(-7 // 2)
println(_div(-7, 2))
println(_quo(-7, 2))
println(_mod(-7, 2))
println(_mod(7, -2))

出力

-4
-3
-4
1
-1
  • _div は0方向へ切り捨て、_quo（//）は負の無限大方向へ丸めます。_mod(a, b) は a - b * (a // b) で、符号は除数と同じです。
  • 除数が0なら実行時エラーです。float か complex を含む _div は無限大か NaN（complex は成分ごと）になります。
  • _lt _le _gt _ge は整数と float を数学的な値で比べます。NaN があれば false、complex は実行時エラーです。
  • 整数を float に揃えると最も近い float になり、範囲外は実行時エラーです。

リテラル

true・false・none は同じ名前の symbol を値とするリテラルで、変数ではありません。トップレベルの文字列はコメントです。

record

record T(f, g, ...) は T{a, b, ...} の引数に欄の名前を付けます。t.f は f の位置の引数で、. は左の式に空白なしで続けます。t with { f = e } は欄を替えた新しい値です。

t1_with.pk

record Point(x, y)

p := Point{1, 2}
q := p with { y = 5 }
println(p)
println(q)
println(p with { x = p.y, y = p.x })
println(p with { x = 7 } with { y = 8 })

出力

Point{1, 2}
Point{1, 5}
Point{2, 1}
Point{7, 8}
  • head が違えば同じ名前の欄を持てます。同じ T を宣言し直すと名前が置き換わります。
  • 宣言のない head や、欄がない値に .f を使うと、メッセージを出して止まります。
  • with の欄は左から順に替わり、右辺は元の t の欄を参照できます。with { ... } は続けて書けます。
