文法

標準の構文は糖衣で、下の表のコア言語の M式に展開されて評価されます。

字句

  • 識別子は [A-Za-z_][A-Za-z0-9_]*[?!]? で、予約語とリテラル true false none は除きます。予約語は if else while and or handle with perform match record for in return break continue fun macro module export import is です。
  • 整数は10進・0x1f・0o17・0b101、float は 1.5e-3、complex は 2i です。
  • 文字列は1行の "..." で、エスケープは \0 \a \b \t \n \v \f \r \" \' \\ です。f"...{e}..." は e の値を埋め込み、{{ と }} は波括弧1つです。
  • # から行末まではコメントです。トップレベルの文字列もコメントです。
  • f(a)・a[i]・Head{a} は、(・[・{ の前に空白を入れません。
  • ブロックの式は ; か改行で区切ります。二項の - は左の式と同じ行に書き、-1 で始まる行は新しい式です。ほかの二項演算子は行頭に書けます。

結合

  • 右結合：|・->・::。左結合：+ - * / %。比較と is は結合せず、a < b < c は構文エラーです。is の優先順位は == と同じで、パターンには書けません。
  • :: は比較より強く + - より弱く、.. はさらに + - より弱いだけで結合しません。
  • if と while の条件 cond は括弧で囲み、枝と body は | を含まない式です。複数の式は { ... } にします。else は、まだ else のない最も近い if に付きます。
> '(a - b - c)
Apply{_sub, Tuple{Apply{_sub, Tuple{a, b}}, c}}
> '(a :: b :: c)
Cons{a, Cons{b, c}}
> '(f | g | h)
Fusion{f, Fusion{g, h}}
> '(a + 1 :: b == c)
Apply{_eq, Tuple{Cons{Apply{_add, Tuple{a, 1}}, b}, c}}
> '(a + 1..b * 2)
Range{Apply{_add, Tuple{a, 1}}, Apply{_mul, Tuple{b, 2}}}
> '(if (c) a else b | g)
Fusion{If{c, a, b}, g}
> '(if (a) if (b) x else y)
If{a, If{b, x, y}, none}

構文ごとの規則

引数に書くパターン

引数 p と for のパターンは、or の階層までの式として書き、コア言語のパターンにして照合します。式と同じ書き方で、識別子が変数になります。例外は次のとおりです。

  • 演算子と呼ばれる関数の名前は symbol です。x + 1 は Apply{Quote{_add}, Tuple{x, 1}}、f(p, ...) は Apply{Quote{f}, Tuple{p, ...}} の木に合います。呼ばれる関数を変数にするには (f)(p, ...) と書きます。
  • 'e は Quote{e}、p @ type は _TypeOf{p, type}、x... は最後の引数の残り _Rest{x} です。
  • 同じ名前を2回書く f(a, a) は、2つの値が equal なときだけ合います。
  • p or q はどちらかに合います。変数を書けるのは、どの枝も同じ変数を束縛するときだけです（f((x, 0) or (0, x)) := x）。式の or の M式 If{a, true, b} に合わせるには If{a, 'true, b} と書きます。
  • 書ける形：演算子（or and not == != <= >= < > :: + - * / %、単項の - と '）・f(p, ...)・Head{p, ...}・識別子・true false none・整数・文字列・組・リスト。
> size(0 or 1) := "small"
... size(_) := "big"
> size(1)
"small"
> size(2)
"big"
> kind(F{1 or 2, x}) := "small first"
... kind(_) := "other"
> kind(F{2, 0})
"small first"
> sign(x) if x > 0 := "positive"
... sign(0) := "zero"
... sign(_) := "negative"
> sign(5)
"positive"
> sign(0)
"zero"
> sign(-5)
"negative"
> same(a, a) := "same"
... same(_, _) := "differ"
> same([1], [1])
"same"
> same([1], [2])
"differ"
> origin((x, 0) or (0, x)) := x
... origin(_) := "none"
> origin((0, 4))
4
> origin((1, 2))
"none"
  • ガード付きの関数に x... を書くと、実行前にメッセージを出して止まります。
  • 値がガード付きの関数なら、ガードが偽でも f(p, ...) = body で足した関数は呼ばれません。変数で渡したガード付きの関数に | g をつないでも、g は呼ばれないのと同じです。
> fun f
> f = (n) if n > 0 -> "positive"
> f(n) = "other"
> f(5)
"positive"
> f(-1)
matching failed: <lambda:(_TypeOf{_, nomatch})> <-> (-1)

定義の続き

  • 同じ場所に続けて書いた f(0) := ... の定義は、書いた順に試す1つの関数です。
  • f(p, ...) if cond := body は、引数が合って cond が真のときだけ body を返します。偽のときと合わないときは、続けて書いた次の定義を試します（間に別の式があると続きません）。
  • export を付けた定義と f(p, ...) = body にはガードを付けられません。

x += e は x = x + e と同じで、-=・*=・/=・%= も同じ形です。a[i] += e は a と i を1回だけ評価します。左辺は変数か a[i] で、t.f += e は書けません。

組の分割

(a, b) := e は組 e の要素で変数を定義し、(a, b) = e は定義済みの変数に代入します。右辺を先にすべて評価するので、(a, b) = (b, a) は入れ替えです。

> (a, b) := (1, 2)
> a + b
3
> (a, b) = (b, a)
> Tuple{a, b}
Tuple{2, 1}
> divmod(x, y) := (x / y, x % y)
> (q, r) := divmod(17, 5)
> Tuple{q, r}
Tuple{3, 2}
> fib(n) := {
...     (x, y) := (0, 1)
...     i := 0
...     while (i < n) {
...         (x, y) = (y, x + y)
...         i = i + 1
...     }
...     x
... }
> fib(10)
55

要素の数が名前の数と違う組と、組でない値はエラーです。

> (a, b) := (1, 2, 3)
cannot assign Tuple{1, 2, 3} to 2 names
> (a, b) := 5
cannot assign 5 to 2 names

record と with

record T(f, ...) = make は型 T と、データを作る関数 make を別々に定義します。make(a, ...) で作り、x.f で欄を読みます。x @ T は型を調べるパターンで、module の型は x @ m.T と書きます。

. は左の式に空白なしで続けます。t with { f = e, ... } は欄を替えたコピーで、欄は左から順に替わり、右辺は元の t の欄を参照できます。with { ... } は続けて書けます。

欄の名前は変数名と同じ扱いで、none・true・false は欄の名前にできません。t.none は構文エラーです。

  • with は record を書いた場所（module の中ならその module の中）だけで使えます。外で使うと _with が未定義でエラーです。
  • module の中の export record は型 T だけを export します。make は module の外から使えません。
> record Point(x, y) = point
> p := point(1, 2)
> q := p with { y = 5 }
> p
Point{1, 2}
> q
Point{1, 5}
> p with { x = p.y, y = p.x }
Point{2, 1}
> p with { x = 7 } with { y = 8 }
Point{7, 8}

for と return・break・continue

return e は含む関数の呼び出しを値 e で終え（e がなければ none）、break は最も内側の while か for を終え、continue は次の回に進めます。

> first_even(xs) := {
...     for (x in xs) {
...         if (x % 2 == 0) return x
...     }
...     none
... }
> first_even([3, 5, 6, 8])
6
> Tuple{first_even([3, 5])}
Tuple{none}
> for (i in [1, 2, 3, 4, 5, 6]) {
...     if (i % 2 == 1) continue
...     if (i == 6) break
...     println(i)
... }
2
4
  • e は return と同じ行で始めます。
  • for の本体や match の腕の中の return は、それらを囲む関数を終えます。中に書いた関数の中の return は、その関数を終えます。
  • ループの外の continue は unhandled effect: Continue{} で止まります。
> continue
unhandled effect: Continue{}

match

match e { f } は e を1回だけ評価し、その値を引数に関数 f を呼びます。f はふつう1引数の関数を | でつないだもので、各関数が腕です。e に合うパターンを持つ最初の腕が選ばれ、どれにも合わなければ MatchingFailed を Perform します。| は行頭に書けます。

> sign(n) := match n {
...     (x) if x > 0 -> "positive"
...   | (0) -> "zero"
...   | (_) -> "negative"
... }
> sign(5)
"positive"
> sign(0)
"zero"
> sign(-3)
"negative"
> swap(p) := match p {
...     ((a, b)) -> (b, a)
... }
> swap((1, 2))
Tuple{2, 1}
  • 腕の引数は1つです。組を取るのは ((a, b)) -> x です。
  • ガード (p, ...) if cond -> body | g の cond は、引数が合ったあとにその変数を使って評価されます。偽のとき、または引数が合わないときは、同じ引数で g を呼びます。g は、ソース上で | によってその関数の後ろにつないだ式です（括弧の中にあっても同じ）。
  • ガードと body は or の階層までの式なので、無名関数は括弧で囲みます。

module

module m { body } は、本体の定義を名前 m の下にまとめます。本体が返す値が module の値で、export を付けた定義が欄になります。欄にない名前を . で読むとエラーです。

> module counter {
...     n := 0
...     export start := n
...     export next() := {
...         n = n + 1
...         n
...     }
...     export current() := n
... }
> counter.next()
1
> counter.next()
2
> counter.start
0
> counter.current()
2
> module outer {
...     module hidden {
...         export f(x) := x + 1
...     }
...     export module inner {
...         export g(x) := hidden.f(x) * 2
...     }
... }
> outer.inner.g(3)
8
> module m {
...     helper(i) := i / 30
...     export f(i) := helper(i)
... }
> m.f(65)
2
> m.helper(65)
no field helper in Module{}
  • 本体の変数の範囲は引数のない関数の本体と同じです。あとで定義するものを前から呼ぶには fun f と f(p, ...) = body を使います（相互再帰）。
  • 本体の定義は本体の変数で、大域変数になりません。外から書き換えられず、外に同じ名前があっても隠しません。外から場合を足せるようにするには、足す関数を export します（m.f(p, ...) = body は書けません）。
  • m は本体を評価したあとに定義されるので、本体から m は見えません。
  • 本体の中で parse を差し替えても残りには反映されません。文法を差し替えるときは module の外に書きます。

export

  • 書けるのは、module の本体の直下にある f(p, ...) := body・x := e・module n { ... } の前だけです。ほかは構文エラーです。
  • export x := e の欄は、本体が値を返した時点の x の値です。あとで代入しても変わらないので、今の値を見せるには x を読む関数を export します（上の start と current）。
  • 内側の module n { ... } は本体の変数 n を定義し、外からは見えません。外に見せるには export module n { ... } と書きます。内側の本体からは、外側の本体でそれより前に定義した変数が見えます。

test

module の本体の直下に test { ... } を書けます。ふだんは何も実行されません。tools/test.pk <ライブラリ> ... を実行すると、使うライブラリの test も含めて実行されます。

module bitset {
    export new(n) := i32_array(n / 30 + 1)
    helper(i) := i / 30
    export add(s, i) := {
        w := helper(i)
        s[w] = bit_or(s[w], bit_shl(1, i % 30))
    }
    test {
        assert(helper(65) == 2, "helper")
        s := new(100)
        add(s, 3)
        assert(s[0] == 8, "add")
    }
}
  • 変数の範囲は module の本体と同じで、export のない関数も呼べます。
  • test は本体の評価の途中で実行されるので、その前に定義した変数が見え、m はまだ定義されていません。
  • assert(c, msg) は c が真でなければ msg を書いてステータス 1 で止まります。
  • 1つのブロックに書ける式は 64 個までです。

import

import a::b は use("a/b") と同じ読み込みで、同じファイルは1度だけ読まれます。最後の名前が、そのファイルが定義する module の名前です。取り込み方はパスのあとに続けます。M は Apply{_import_module, Tuple{"a/b", Quote{b}}} です。

書き方展開先
import mDo{M, none}
import m as nDo{Def{n, M}, none}
import m (x, y)Do{M, Def{x, Apply{_record_get, Tuple{M, Quote{x}}}}, Def{y, ...}, none}
import m (*)Do{M, Apply{eval, Tuple{Apply{_import_defs, Tuple{M, Quote{Tuple{}}}}}}, none}
import m hiding (x, y)Do{M, Apply{eval, Tuple{Apply{_import_defs, Tuple{M, Quote{Tuple{x, y}}}}}}, none}

import m は読み込むだけで、欄は m.f で読みます。as n は n := m を足します。(x, y) は指定した欄を、(*) はすべての欄を、hiding (x, y) は x と y 以外のすべての欄を、同じ名前の変数に定義します。

> import bitset as bs
> s := bs.new(100)
> for (i in [3, 42]) bs.add(s, i)
> bs.to_list(s)
Cons{3, Cons{42, Nil{}}}
> import bitset (has, count)
> has(s, 42)
true
> count(s)
2
> import bitset hiding (new, add)
> to_list(s)
Cons{3, Cons{42, Nil{}}}
  • as n は (x, y)・(*)・hiding (...) の前に置けます。as・(...)・hiding は m と同じ行に書きます。
  • m にない欄を (x, y) に書くと、. で読むときと同じエラーです。
  • 関数の中に書くと、(*) と hiding は大域変数を、(x, y) と as は局所変数を定義します。

添字と置き換え

a[i] は _index_get(a, i)、a[i] = e は _index_set(a, i, e) を呼び、値は e です。[ は a に空白なしで続けます。

> a := array(2)
> a[1] = 7
7
> a[1]
7
> "abc"[1]
"b"
> [10, 20, 30][2]
30
> (Point{3, 4})[0]
3
> t := table_new()
> t[5] = "five"
"five"
> t[5]
"five"
> Tuple{t[6]}
Tuple{none}

種類ごとの関数が次の順に試されます。

aia[i]a[i] = e
array整数array_get(a, i)array_set(a, i, e)
plain array整数plain_get(a, i)plain_set(a, i, e)
文字列整数i 番目の文字（長さ1の文字列）止まる
table任意の値table_get(a, i, none)。ないキーは nonetable_set(a, i, e)
vector（use("vector") が先頭に足す）整数vector.get(a, i)vector.set(a, i, e)
任意の値関数subst(a, i)
リスト整数0から数えた要素止まる
M式整数arg(a, i)（位置）止まる

immutable な値（文字列・リスト・組・M式）への代入、範囲外の添字、どの種類にも合わない a[i] は止まります。

> s := "abc"
> s[0] = "x"
cannot assign to an element of a string, which is immutable: "abc" at 0
> a := array(2)
> a[5]
array index out of range: 5

_index_get と _index_set に代入して、独自の種類を先頭に足せます。

> _index_get = (Matrix{w, _, d}, (i, j)) -> d[i * w + j] | _index_get
> _index_set = (Matrix{w, _, d}, (i, j), e) -> { d[i * w + j] = e } | _index_set
> m := Matrix{2, 2, array(4)}
> m[(1, 0)] = 5
5
> m[(0, 1)] = 7
7
> m[(1, 0)] + m[(0, 1)]
12
> Tuple{m[(1, 1)]}
Tuple{none}

subst

t[f] は subst(t, f) で、木 t を根から順に見て、f のパターンが合う部分を f の値に置き換えます。置き換えた部分の内側は見ません。合わなければ引数を順に見ます。f の腕はガードを付けられ（t[p if c -> a | q -> b]）、本体は -> の階層までの式なので、中の | は括弧で囲みます。クオートした木を書き換えるには ('e)[f] と書きます。

> use("unparse")
> t := '(x * 1 + 0 * y)
> unparse.text(t[Apply{'_mul, Tuple{a, 1}} -> a | Apply{'_mul, Tuple{0, _}} -> 0])
"x + 0"
> u := '(1 * 2 + 3 * 4)
> unparse.text(u[Apply{'_mul, Tuple{a @ Int, b @ Int}} if a > 1 -> a * b])
"1 * 2 + 12"

糖衣が呼ぶ名前

読み替え先の関数は名前が _ で始まります。プログラムで add を定義しても a + b は変わりません。演算子を関数として渡すには無名関数を使います（sort((a, b) -> a < b, xs)）。

文法の拡張

::= で文法の規則を定義します。planck の構文も同じ規則で定義されているので、規則を足すと、後に続く式の構文を拡張できます。

::=

次の例は、unless の構文を足します。

> primary ::= 'unless c:expr a:block 'else b:block { `If{!c, !b, !a} } | ...
> unless (1 > 2) { "then" } else { "else" }
"then"
> unless (1 < 2) { "then" } else { "else" }
"else"
  • name ::= alternative | ... は規則 name を定義し、すでにあれば置き換えます。選択肢の ... は、その規則のそれまでの定義です。
  • 選択肢は項目の列で、末尾に動作 { ... } を付けられます。項目と動作は ::= や | と同じ行に書きます。
  • 選択肢は順に試し、規則の結果は位置ごとにメモ化します（packrat）。
  • 選択肢の値は、動作があれば動作の値、項目が1つならその項目の値、それ以外は項目の値の Tuple{v, ...} です。

項目

項目合うもの
"text"・'wordその文字列・その単語（後ろに [A-Za-z0-9_] が続かないもの）
nospace("text")直前に空白やコメントを置かない、その文字列
.・[set]・[^set]任意の1文字・set にある1文字・ない1文字（文字クラス）。値はその文字の文字列

文字列・単語・.・[set] は、空白とコメントを読み飛ばしてから合わせます。規則には直接の左再帰を書けて、左結合になります。

文字クラス

  • 英字・数字・_ のあとに - と1文字を続けると範囲です（a-z）。それ以外の - は文字そのものです。
  • \n・\t・\a・\b・\f・\r・\v・\0 は制御文字で、ほかの \x は文字 x です。
  • 空の set・逆順の範囲（[9-0]）・終わりが欠けた範囲（[a-]）は構文エラーです。
  • 入力の終わりには、. も [set] も [^set] も合いません。
> use("string")
> join(cs) := {
...     r := ""
...     i := 0
...     while (i < arity(cs)) {
...         r = _strcat(r, arg(cs, i))
...         i = i + 1
...     }
...     r
... }
> word ::= cs:[a-z_]+ { join(cs) }
> number ::= cs:[0-9]+ { string.str_to_int(join(cs)) }
> quoted ::= "\"" cs:[^"]* "\"" { join(cs) }
> pair ::= k:word "=" v:(number | quoted) { Tuple{k, v} }
> first ::= c:. { c }
> arg(peg_parse('pair, "a=12"), 0)
Tuple{"a", 12}
> arg(peg_parse('pair, "name=\"koichi\""), 0)
Tuple{"name", "koichi"}
> arg(peg_parse('first, "  xyz"), 0)
"x"

規則で読む

peg_parse

peg_parse(rule, s) は s の先頭を規則で読み、Tuple{値, 残り} を返します。空白しか残っていなければ Tuple{Eof{}, ""}、読めなければ Tuple{SyntaxError{...}, ""} です。peg_parse_at(rule, s, loc) は同じ読み方で、各 At の位置を s の先頭の Loc{file, line, column} である loc から数えます。loc が none のときは位置がなく、木に At は付きません。peg_parse(rule, s) は peg_parse_at(rule, s, none) です。

loc があるとき、SyntaxError の最後の引数に、エラーの位置の Loc{file, line, column} が付きます。位置は読むのをやめた字句の先頭で、loc から数えます。loc が none のときは付きません。load と REPL は、構文エラーを file:line:column: syntax error: message の形で表示します。REPL の file は <repl> です。

name{| text |}

パーサがその式を読む時点で、text を規則 name で読みます。値は規則の値（定数）です。

> calc ::= a:calc "+" b:num { a + b } | num
> num ::= integer
> calc{| 1 + 2 + 3 |}
6
  • name と {| の間に空白は入れません。
  • 規則は、この式を含む式を読むより前に評価される式で定義しておきます。
  • text の終わりは規則が読み終えた位置で、そのあと空白をはさんで |} が続きます。
  • 規則が失敗したときや |} がないときは構文エラーで、位置は規則が text の中で最も先まで読んだ位置です。

peg_sources と peg_version

peg_sources は、規則の名前から _define_rule に渡された構文解析式への表です。動作は評価する前の形で、... はそれまでの定義に置き換えてあります。peg_version は _define_rule を呼ぶたびに増えます。

> use("table")
> use("pretty")
> pretty.print(table.get(peg_sources, 'add_expr, none))
Choice{
  Act{
    Seq{add_expr, "+", mul_expr},
    Lambda{

        }
      }
    }
  },
  Act{
    Seq{add_expr, minus, mul_expr},
    Lambda{
      Tuple{Tuple{a, _, b}},
      Do{
        QuasiQuote{
          Apply{_sub, Tuple{UnQuote{a}, UnQuote{b}}}
        }

  mul_expr
}

macro

macro p := e は、評価の前に木を書き換える規則を足します。p は引数のパターンと同じ書き方で木の形を表し、e は p の変数を使って評価されて新しい木になります。

> macro Twice{x} := `(!x + !x)
> macro unless(c, e) := `if (not !c) !e
> Twice{21}
42
> unless(1 > 2, "shown")
"shown"
> Tuple{unless(1 < 2, "not shown")}
Tuple{none}
> '(Twice{1})
Twice{1}
  • 式を評価する前（eval に渡した木も同じ）に、根から順に各部分を書き換えます。規則は後に足したものから試し、合わなければそのままです。
  • f(a, ...) が作る At{loc, Apply{...}} では、Apply を書き換えます。書き換えたあとも At は残ります。
  • 書き換えた部分は、変わらなくなるまで規則を当ててから、その中を書き換えます。1つの式で 1000 回より多く当てるとエラーで止まります。
  • クオート 'e の中は書き換えません。準クオート `e は !e の中だけを書き換えます。
  • 関数の引数のパターンと、Def・Set・Declare が定義する名前も書き換えません。
  • 規則が有効なのは、macro の位置から、それを囲む一番内側の関数か module の本体の終わりまでです。何も囲んでいなければ以降のすべての式です。
  • module の中の export macro は、その module の定義のあとから module の外でも有効です。
> module shapes {
...     macro Inside{x} := `(!x + 100)
...     export macro Double{x} := `(!x * 2)
...     export f() := Inside{1}
... }
> shapes.f()
101
> Double{21}
42
> '(Inside{1})
Inside{1}

トップレベル

式を読むたびに大域変数 parse と eval を引き直すので、差し替えると次の式から新しい定義で処理されます。Apply{eval, ...} も差し替えた eval を呼びます。

  • parse：文字列 -> Tuple{M式, 文字列の残り}。空白しか残っていなければ Tuple{Eof{}, ""} を返し、差し替える parse は Eof{} をそのまま通します。読んだ木に At は付かず、f(a, ...) は Apply{f, Tuple{a, ...}} になります。
  • parse_at：文字列, Loc -> Tuple{M式, 文字列の残り}。parse と同じに読み、f(a, ...) を At で包みます。Loc{file, line, column} は文字列の先頭の位置で、各 At の loc はこの位置から数えます。
  • eval：M式 -> 値。
  • ファイルを読むループは parse を呼ぶので、このループで読み込んだファイルの呼び出しに At は付きません。REPL と PlanckVM のコンパイラは parse_at でテキストを読み、読み終えた文字を数えて進めた位置を、次の式を読むときの Loc にします。REPL は Loc{"<repl>", 行, 列} を渡します。

t6_eval.pk

old_eval := eval
eval = e -> {
    v := old_eval(e)
    put("=> ")
    println(v)
    v
}

'(a + b)
Point{1, 2}
