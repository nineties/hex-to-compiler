結合

  • |・->・:: は右結合です。+ - * / % は左結合です。比較は結合しません（a < b < c とは書けません）。
  • :: は比較より強く + - より弱く結合します。a + 1 :: b == c は Cons{a + 1, b} == c です。
  • () で式をまとめます。

定義と代入の左辺の !x

x := e と x = e の x は !x とも書けます。それぞれ Def{!x, e} と Set{!x, e} です。準クオートの中の !x は x の値のシンボルに置き換わります。x の値が 'i のとき、`{ !x := 0; !x = !x + 1 } は Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}} です。

if と while

if と while の条件は括弧で囲みます。while の本体 e は任意の式です。if の枝 a・b は括弧の外に | を含まない式なので、if (c) a else b | g は (if (c) a else b) | g です。複数の式はブロック { ... } にします。

else はまだ else のない最も近い if に対応します。if (a) if (b) x else y は if (a) { if (b) x else y } です。else if (c) ... は else のあとに if の式が続いたものです。if は式なので y = if (c) 1 else 2 と書けます。

record

record T(f, g, ...) は値 T{a, b, ...} の引数の名前を宣言します。名前を付けた引数を欄と呼びます。値の作り方は変わりません。t.f は t の頭の宣言で f の位置にある引数です。

頭が違えば同じ名前の欄を持てます。同じ T をもう一度宣言すると名前が置き換わります。. は左の式に空白なしで続けます。頭が宣言されていない値や欄 f がない値に .f を使うと、メッセージを出してプログラムが止まります。

変数の範囲

true・false・none はリテラルで識別子ではないので、変数の名前にできません。true := e・true = e・fun true・true(p) := e は構文エラーです。引数に書いた true は、値 true に合って何も束縛しないパターンです。x の値が 'true のとき、!x := e と !x = e は Def{true, e}・Set{true, e} と同じくプログラムを止めます。

変数の範囲は静的（字句的）で、名前がどの変数を指すかは式を実行する前に決まります。関数の本体の変数は、その関数か外側の関数の引数、またはそれらの関数でそれより前に定義した変数です。どれでもなければ、トップレベルでそれより前に定義した変数（大域変数）です。呼んだ側の変数は見えません。どの変数も指さない名前があると、その式を実行する前にメッセージを出してプログラムが止まります。関数は作られた場所の変数を参照します。変数は共有されるので、関数を作ったあとの代入も関数から見えます。

定義と代入

トップレベルの定義は書いた順に処理されます。後ろに書いた定義はそれより前の式から見えません。関数の定義 f(p, ...) := e の本体からは f 自身が見えます。

同じ名前を x := e か fun f でもう一度定義すると新しい変数になります。前に作った関数は前の変数を指したままで、新しい変数が見えるのは定義より後ろの式だけです。今ある変数を上書きするときは x = e と書きます。これは同じ変数への代入なので、前に作った関数からも新しい値が見えます。次の例の前半は f := (x) -> 2 で新しい f を作るので g() は 1 です。後半は h = (x) -> 2 で代入するので k() は 2 です。

r_scope_redefine.pk

f(x) := 1
g() := f(0)
f := (x) -> 2
println(g())

h(x) := 1
k() := h(0)
h = (x) -> 2
println(k())

出力

1
2

x := e（x := (p) -> e も含む）は書いた場所で変数を定義するので、それより前の式からは外側の x が見えます。右辺 e から見えるのも前の x です。新しい x は右辺を評価したあとに作るので、前の x がなければ右辺の x は未定義です。x := 1 のあとの x := x + 1 で x は2になります。自分を呼ぶ関数は f(p, ...) := e と書きます。トップレベルでもブロックの中でも同じです。ブロックの変数は、ブロックを含む関数かプログラムの変数です。

関数に定義が加わるとき

関数の定義 f(p, ...) := e は、書いた場所の変数に f がすでにあれば f(p, ...) = e と同じで、なければ fun f と f(p, ...) = e を続けて書いたのと同じです。後者は書いた場所で新しい f を定義します。同じ場所に書いた f の定義は1つの関数になり、書いた順に試されます。

書いた場所の変数は、トップレベルでは同じファイルで定義した大域変数で、関数の中ではその関数の引数とその関数でそれより前に定義した変数です。トップレベルの if の枝や while の本体では、その枝や本体でそれより前に定義した変数です。外側の関数の変数や関数の中から見た大域変数は、書いた場所の変数ではありません。したがって、これらと同じ名前の f(p, ...) := e は新しい f を定義し、外の f を変えません。

println(fib(20))

x := 1
x := x + 1
println(x)

互いに呼び合う関数

互いに呼び合う関数は、先に fun f で名前だけを宣言します。fun f は値が none の変数 f を書いた場所で定義します。この変数はあとで f(p, ...) = e で埋めます。f(p, ...) = e は代入 f = f | (p, ...) -> e で、f の関数の後ろに関数を足します。関数は書いた順に試されます。none | g は g なので、fun f のあとの最初の f(p, ...) = e は関数 (p, ...) -> e そのものを代入します。引数の数が違う関数も足せます。宣言のあとに書いた関数からは f が見えます。

fun odd

odd(n) = if (n == 0) false else even(n - 1)
println(Tuple{even(10), odd(7)})

fun fact
fact(0) = 1
fact(n) = n * fact(n - 1)
println(fact(5))

出力

module

module m { ... } は定義をまとめて名前 m の下に置く式です。m := (() -> { ... })() の糖衣として読めます。ただし本体が返す値は module の値で、export を付けた定義を欄に持ちます。

module bitset {
    export new(n) := i32_array(n / 30 + 1)
    helper(i) := i / 30
    export add(s, i) := {
        w := helper(i)
        s[w] = bit_or(s[w], bit_shl(1, i % 30))
    }
}

この bitset の値は欄 new と add を持ちます。使う側は bitset.new(100) のように . で呼びます。

module の値はどれも同じ頭 Module を持ち、欄の名前と値は module の値ごとの表に持ちます。したがって module ごとに欄が違います。. の読み方は他の record の欄と同じで、欄にない名前（export を付けていない helper など）を読むとメッセージを出してプログラムが止まります。

  • 本体の変数の範囲は引数のない関数の本体と同じです。本体の変数は、それより前に本体で定義した変数と外側の変数です。あとで定義するものを前から呼ぶには fun f で宣言し、f(p, ...) = e で場合を足します。
  • 本体の定義は本体の変数で、大域変数になりません。同じ名前が外にあっても隠さず、外から書き換えることもできません。本体の中の f(p, ...) := e は外に f があっても本体の新しい f を定義します。
  • m は m := e と同じく本体を評価したあとに定義されます。本体から m は見えず、本体の中の関数どうしは名前でそのまま呼び合います。module m { ... } を同じ名前でもう一度書くと、x := e と同じく新しい変数になります。
  • 本体は丸ごと読まれます。本体の中で parse を差し替えてもその本体の残りには効きません。文法を差し替えるときは module の外に書きます。
  • module はトップレベルの1つの式です。大域変数の表はファイルごとに分けず、ファイルは今までどおり1式ずつ読まれます。

export

export を書けるのは、module の本体の直下にある f(p, ...) := e と x := e と module n { ... } の前だけです。関数の中・if の枝・ブロックの中・トップレベルなど、ほかの場所に書くと構文エラーです。export を付けた定義の名前が module の値の欄になり、付けない定義は外から見えません。

export x := e の欄の値は、本体が値を返した時点の x の値です。あとで本体の関数が x に代入しても欄は変わりません。今の値を見せるには、x を読む関数を export します。次の counter では counter.start が 0 のままで、counter.current() が今の値を返します。

module counter {
    n := 0
    export start := n
    export next() := {
        n = n + 1
        n
    }
    export current() := n
}

module の入れ子

module の本体の中に module を書けます。内側の module n { ... } は本体の変数 n を定義し、外からは見えません。内側を外に見せるには export module n { ... } と書きます。このとき n は外側の module の欄で、その値も module の値です。内側の本体からは外側の本体でそれより前に定義した変数が見えます。

module outer {
    module hidden {
        export f(x) := x + 1
    }
    export module inner {
        export g(x) := hidden.f(x) * 2
    }
}
outer.inner.g(3)

module の外からの定義の追加

m.f(p, ...) = e と書いて module の外から関数に場合を足すことはできません。外から場合を足せるようにするには、足す関数を module の中で export します。

test

module の本体の直下に test { ... } を書けます。test { e } は if (_testing) { e } の糖衣で、変数 _testing は初めは false です。ふだんの読み込みでは何も実行されません。planck0 tools/test.pk <ライブラリ> ... は _testing を true にしてからライブラリを読み込み、test の中の式を実行します。読み込まれるライブラリが使うライブラリの test も実行されます。

test の中は module の本体と同じ範囲で、export を付けていない関数も呼べます。test は本体を評価する途中で実行されるので、その前に定義した変数が見え、m はまだ定義されていません。assert(c, msg) は c が真でなければ msg を書いてステータス 1 で止まります。test の { ... } は普通のブロックなので、1つに書ける式は 64 個までです。それより多いときは test を分けます。test は module の本体の直下だけに書けて、その外では普通の名前です。

module bitset {
    export new(n) := i32_array(n / 30 + 1)
    helper(i) := i / 30
    export add(s, i) := {
        w := helper(i)
        s[w] = bit_or(s[w], bit_shl(1, i % 30))
    }
    test {
        assert(helper(65) == 2, "helper")
        s := new(100)
        add(s, 3)
        assert(s[0] == 8, "add")
    }
}

糖衣が呼ぶ名前

糖衣の読み替え先の関数は名前が _ で始まり、_ のない同名の関数はありません。したがってプログラムで add や index_get という変数を定義しても、a + b や a[i] の意味は変わりません。

演算子を引数に取る関数には、糖衣を使った無名関数を渡します（sort((a, b) -> a < b, xs)）。糖衣が作る木にはこれらの名前が入ります。a + b は Apply{_add, Tuple{a, b}} です。

添字と置き換え

a[i] は _index_get(a, i)、a[i] = e は _index_set(a, i, e) で、値は e の値です。[ は a に空白なしで続けます。空白や改行をはさんだ [1, 2] は別の式です。a は x・f(x)・t.f・b[j] のような後置式で、a[i][j] = e は Apply{_index_set, Tuple{a[i], j, e}} です。

_index_get と _index_set は、a の種類ごとの関数を | でつないだもので、次の順に試されます。

文字列・リスト・組・M式は不変です。これらへの a[i] = e は cannot assign to an element of a string, which is immutable: ... のようなメッセージを出してプログラムを止めます。書き換えられるのは配列・平らな配列・表・ベクタと、利用者が足した種類です。文字列・リスト・M式の範囲外の添字と、どの種類にも合わない a[i]・a[i] = e もメッセージを出して止まります。

利用者は _index_get と _index_set に代入して、独自の種類を先頭に足します。

m := Matrix{2, 2, array(4)}

subst(t, f) は木 t を関数 f で書き換えます。t の各部分を根から順に試し、f のパターンが合えばその部分を f の値に置き換え、その内側は試しません。合わなければ引数を順に試して頭は残します。M式でない部分はそれ以上分解しません。

t[p -> a | q -> b] は、p -> a | q -> b を括弧に入れた式なので、腕は順に試されます。match と同じくガードを付けられます。t[p if c -> a | q -> b] は p が合って c が成り立つときにその腕を使い、そうでなければ次の腕を試します。どの腕も合わない部分はその内側を試します。腕の本体は -> の階層までの式なので、本体の中の | は括弧で囲みます。't[f] は t[f] のクオートです。クオートした木を書き換えるには ('e)[f] と書きます。

r_rewrite.pk

use("unparse")
t := '(x * 1 + 0 * y)
println(unparse.text(t[Apply{'_mul, Tuple{a, 1}} -> a | Apply{'_mul, Tuple{0, _}} -> 0]))
# with a guard: 1 * 2 is skipped and its parts are tried

println(unparse.text(u[Apply{'_mul, Tuple{a @ int, b @ int}} if a > 1 -> a * b]))

"1 * 2 + 12"

for

for (p in e) a は、リストかベクタ e の要素ごとに要素をパターン p と照合して a を評価します。値は none です。a から見えるループの外の変数は共有され、a から書き換えられます。

return・break・continue

return e はそれを含む関数の呼び出しを値 e で終えます。e がなければ none です。e は return と同じ行で始め、-> の階層までの式で、括弧の外に |・:=・= を含みません。break はそれを含む最も内側の while か for を終えます。

これらはエフェクトです。本体に return がある関数は Handle{body, (Return{v}, k) -> v} に、本体に break があるループは Handle{loop, (Break{}, k) -> none} に読み替えられます。continue はそれを含む最も内側の while か for の次の回に進みます。本体に continue があるループでは、本体が Handle{body, (Continue{}, k) -> none} に読み替えられます。ループの外の continue は unhandled effect: Continue{} でプログラムを止めます。

for の本体や match の腕の中の return は、それらを囲む関数の呼び出しを終えます。中に書いた関数の中の return は、その関数の呼び出しを終えます。

match

match e { f } は e を1回だけ評価し、その値を引数に関数 f を呼びます。f は | の階層までの式で、ふつうは1引数の関数を | でつないだものです。つないだ各関数を腕と呼びます。e に合うパターンを持つ最初の腕が選ばれます。腕の引数は1つです。(a, b) -> x は2引数で、((a, b)) -> x が組を取ります。| は行頭に書けます。2つ目以降の腕はふつう次のように書きます。

match e {
    p -> a
  | q -> b
}

(p, ...) if c -> e | g のガード if c は、引数が合ったあとにその変数を使って評価されます。偽のとき、または引数が合わないときは、同じ引数で g を呼びます。g はそのあとの腕です。| g がなければ、パターンの合わない関数を呼んだときと同じく失敗します。g は、ソース上で | によってその関数の後ろにつないだ式です。関数が括弧の中にあっても同じです（(p if c -> a) | g）。h := p if c -> a のあとの h | g のように変数で渡したガード付きの関数は、g を呼びません。match のガードと e は ?: の階層までの式なので、無名関数は括弧で囲みます。関数は % で始まる名前の変数を束縛します。これらはどの識別子とも重なりません。

残りの引数

関数の最後の引数は x... と書けます。x は、前の引数を除いた残りの引数を並べた Tuple に束縛されます。残りがなければ Tuple{} です。x... は _Rest{x} という木になります。

  • 書ける位置は、関数 f(p, x...) := e・(p, x...) -> e の最後の引数と、パターン Head{p, x...} の最後の引数です。
  • 前の引数の数より引数が少ない呼び出しは合いません。
  • x... を最後以外に書くと、x... を呼び出しの引数に書くと、ガード付きの関数に書くと、いずれも式を実行する前にメッセージを出してプログラムが止まります。

r_rest.pk

# A rest parameter x... takes the remaining arguments as a Tuple

sum_tuple(t) := {
    s := 0
    i := 0
    while (i < arity(t)) {
        s = s + arg(t, i)
        i = i + 1
    }
    s
}

# the last parameter of a function
total(xs...) := sum_tuple(xs)
println(total())
println(total(1, 2, 3))

# after the fixed parameters
scale(k, xs...) := k * sum_tuple(xs)
println(scale(10, 1, 2, 3))

# in a function written with ->
count := (first, others...) -> 1 + arity(others)
println(count(7, 8, 9))

# arms with fewer parameters are chosen by the number of arguments
describe(a) := "one"
describe(a, b) := "two"
describe(a, b, c...) := "three or more"
println(describe(1))
println(describe(1, 2))
println(describe(1, 2, 3, 4))

# in the pattern of an M-expression, the arguments after the fixed ones
args_of(Call{f, rest...}) := rest
println(args_of(Call{1, 2, 3}))
println(args_of(Call{1}))

# in match
println(match Call{1, 2, 3} { Call{x, ys...} -> ys })

"two"

引数のパターン

引数 p と for のパターンは or の階層までの式として書きます。これを上の表の M式にしたうえで、値・パターン・M式のパターンとして照合します。次の規則があります。

  • 演算子や呼ばれる関数の名前はシンボルです。a + b は Apply{Quote{_add}, Tuple{a, b}}、-a は Apply{Quote{_sub}, Tuple{0, a}}、f(p, ...) は Apply{Quote{f}, Tuple{p, ...}} なので、x + 1・-x・f(1) の木に合います。
  • ほかの識別子は変数です。Head{p, ...} の引数はパターンなので、Apply{f, Tuple{x}} は引数1つの任意の関数の呼び出しに合い、f を束縛します。
  • (f)(p, ...) は Apply{f, Tuple{p, ...}} です。括弧の中の名前はシンボルでなく変数なので、(f)(x) は引数1つの任意の関数の呼び出しに合い、f を束縛します。
  • 'e は式 e の Quote{e} です。
  • x... は最後の引数にだけ書けます（残りの引数）。
  • 書ける形は、演算子 or and not == != <= >= < > :: + - * / %、単項の - と '、f(p, ...)、p @ type、Head{p, ...}、(f)(p, ...)、識別子・true・false・none・整数・文字列、()・(p)・(p, q, ...)・[p, ...] です。結合は式と同じで、a @ int + b @ int は (a @ int) + (b @ int) です。

r_pattern.pk

simp(e) := match e {
    a @ int + b @ int -> a + b
  | a + 0 -> a
  | x * y if x == y -> `sq(!x)
  | _ -> e
}
println(simp('(1 + 2)))
println(simp('(z + 0)))
println(simp('(z * z)))
swap(a + b) := `(!b + !a)
println(swap('(1 + 2)))
callee((f)(x)) := f
println(callee('g(1)))

出力

3
z
Apply{sq, Tuple{z}}
Apply{_add, Tuple{2, 1}}
g

macro

macro p := e は、評価の前に木を書き換える規則を足します。p は引数のパターンと同じ書き方で、木の形を表します。e は p の変数を使って評価され、その値が新しい木です。macro は M式を別の M式に直すもので、文字列を M式にする構文には触れません。

r_macro.pk

macro Twice{x} := `(!x + !x)
macro unless(c, e) := `if (not !c) !e

println(Twice{21})
unless(1 > 2, println("shown"))
unless(1 < 2, println("not shown"))

# a quote is not rewritten
println('(Twice{1}))

出力

42
"shown"
Twice{1}

書き換えは、読み終わった式を評価する前に行います。eval に渡した木も同じです。次の順に進みます。

  • 木の根から順に、各部分を規則で書き換えます。規則は後に足したものから試し、どれにも合わなければその部分はそのままです。
  • 書き換えた部分に、変わらなくなるまで規則を当てます。そのあとで、結果の中の部分を書き換えます。
  • クオート 'e の中は書き換えません。準クオート `e の中は、アンクオート !e の中だけを書き換えます。
  • 関数の引数のパターンと、Def・Set・Declare が定義する名前は書き換えません。関数の本体は書き換えます。

1つの式を書き換える間に規則を 1000 回より多く当てると、書き換えはエラーで止まります。macro A{x} := `A{!x + 1}` のように終わらない規則が止まらずに動き続けることはありません。

規則は読み終わった式の中の macro の位置から足され、macro を囲む一番内側の関数か module の本体の終わりまで、その中の部分も含めて効きます。何も囲んでいなければ、以降のすべての式に効きます。module の中の export macro は、module の外でも、その module の定義のあとから効きます。macro は予約語です。

r_macro_module.pk

module shapes {
    macro Inside{x} := `(!x + 100)
    export macro Double{x} := `(!x * 2)
    export f() := Inside{1}
}
println(shapes.f())
println(Double{21})
println('(Inside{1}))

出力

101
42
Inside{1}

字句

  • 識別子は [A-Za-z_][A-Za-z0-9_]* です。ただし次の予約語は除きます。
    if else while and or handle with perform match record for in return break continue fun macro module export
    リテラル true false none も除きます。
  • 整数は10進（10・-3）・0x1f・0o17・0b101 です。
  • 浮動小数点数は小数点のある10進（1.5）です。
  • 文字列は1行の "..." で、エスケープ \0 \a \b \t \n \v \f \r \" \' \\ が使えます。f"...{e}..." は式 e の値を埋め込みます。e の中に文字列や f 文字列を書けます。{{ と }} は波括弧1つを表します。f の付かない文字列には何も埋め込みません。
  • # から行の終わりまではコメントです。
  • f(a) の f と ( の間、a[i] の a と [ の間、Head{a} の Head と { の間には空白を入れません。

put("tab:[\t] quote:[\"] backslash:[\\]\n")

式の区切り

ブロックの中の式は ; か改行で区切ります。トップレベルの式は ;・改行・次の式の始まりのどれかで終わります。

二項の - は左の式と同じ行に書きます。したがって -1 で始まる行は新しい式です。ほかの二項演算子は行頭に書けます。
