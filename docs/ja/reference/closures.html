クロージャー

変数の範囲は静的（字句的）で、名前がどの変数を指すかは式を実行する前に決まります。関数は作られた場所の変数を参照し、変数は共有されるので、作ったあとの代入も関数から見えます。呼んだ側の変数は見えません。どの変数も指さない名前があると、その式を実行する前にメッセージを出してプログラムが止まります。

変数の範囲

  • 関数の本体から見えるのは、その関数か外側の関数の引数と、それらの関数でそれより前に定義した変数、トップレベルでそれより前に定義した変数（大域変数）です。
  • true・false・none はリテラルで変数の名前にできません。true := e・fun true・true(p) := e は構文エラーです。引数に書いた true は、値 true に合って何も束縛しないパターンです。

t1_scope.pk

n := 5
read_n() := n
caller() := {
    n := 100
    read_n()
}
println(caller())

x := 1
get() := x
x := x + 1
println(Tuple{x, get()})
x = 10
println(Tuple{x, get()})

出力

5
Tuple{2, 1}
Tuple{10, 1}

e_undefined.pk

println("start")
println(later)
later := 2

出力

"start"
undefined variable: later
