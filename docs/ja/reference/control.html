特殊形式

特殊形式の一覧と、代数的エフェクト・for・match です。

一覧

形式意味
Def{x, e}変数 x を定義する。右辺から x より前の変数が見える
Set{x, e}代入
Declare{x}Def{x, none} と同じ。x がすでにあれば何もしない
If{c, a, b}c が false のときだけ b
Fusion{f, g}f のどのパターンも合わなければ g を試す。Fusion{none, g} は g

true・false・none は変数ではないので、Def{true, e}・Set{true, e}・Declare{true} は実行前にプログラムを止めます。

代数的エフェクト

perform Ask{}（Perform{Ask{}}）は、合うパターンを持つ一番近い handle のハンドラ (Ask{}, k) -> ... を呼びます。k は継続を表す通常の関数で、k(v) の v が perform の値になります。

t5_resume.pk

ask() := perform Ask{}

with_answer(v, f) := handle f() with (Ask{}, k) -> k(v)

println(with_answer(21, () -> ask() * 2))
println(with_answer(5, () -> ask() + ask()))

出力

42
10
  • k は handle が値を返したあとでも、何度でも呼べます。
  • ハンドラは、再開した継続の中でも有効です。
  • 継続を捕捉した時点で定義済みの変数は、再開した計算のあいだで共有されます。再開のあとに定義した変数は別です。

どの腕にも合わなかった関数呼び出しと match が perform する MatchingFailed（部分関数と融合）も k で再開できます。k(x) の x が、失敗した呼び出しや match の値になります。

f(0) := "zero"
b := handle [f(7), 1] with (MatchingFailed{_, _, _}, k) -> k("other")
println(b)
Cons{"other", Cons{1, Nil{}}}

for と return・break・continue

for (p in e) body は、リスト・ベクタ・範囲 e の要素ごとに、要素をパターン p と照合して body を評価します。値は none です。return e は含む関数の呼び出しを値 e で終え（e がなければ none）、break は最も内側の while か for を終え、continue は次の回に進めます。

bd_loop.pk

first_even(xs) := {
    for (x in xs) {
        if (x % 2 == 0) return x
    }
    none
}
println(first_even([3, 5, 6, 8]))
println(first_even([3, 5]))

for (i in [1, 2, 3, 4, 5, 6]) {
    if (i % 2 == 1) continue
    if (i == 6) break
    println(i)
}

出力

6
none
2
4
  • e は return と同じ行で始めます。
  • 本体に return がある関数は Handle{body, (Return{v}, k) -> v}、break があるループは Handle{loop, (Break{}, k) -> none}、continue があるループは本体が Handle{body, (Continue{}, k) -> none} になります。
  • for の本体や match の腕の中の return は、それらを囲む関数を終えます。中に書いた関数の中の return は、その関数を終えます。
  • ループの外の continue は unhandled effect: Continue{} で止まります。

e_bd_continue_outside.pk

continue

出力

unhandled effect: Continue{}

match

match e { f } は e を1回だけ評価し、その値を引数に関数 f を呼びます。f はふつう1引数の関数を | でつないだもので、各関数が腕です。e に合うパターンを持つ最初の腕が選ばれ、どれにも合わなければ MatchingFailed を perform します。| は行頭に書けます。

bd_match.pk

sign(n) := match n {
    (x) if x > 0 -> "positive"
  | (0) -> "zero"
  | (_) -> "negative"
}
println(sign(5))
println(sign(0))
println(sign(-3))
swap(p) := match p {
    ((a, b)) -> (b, a)
}
println(swap((1, 2)))

出力

"positive"
"zero"
"negative"
Tuple{2, 1}
  • 腕の引数は1つです。組を取るのは ((a, b)) -> x です。
  • ガード (p, ...) if c -> e | g の c は、引数が合ったあとにその変数を使って評価されます。偽のとき、または引数が合わないときは、同じ引数で g を呼びます。g は、ソース上で | によってその関数の後ろにつないだ式です（括弧の中にあっても同じ）。
  • h := p if c -> a のあとの h | g のように変数で渡したガード付きの関数は、g を呼びません。
  • ガードと e は or の階層までの式なので、無名関数は括弧で囲みます。
