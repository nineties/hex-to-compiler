コア言語

コア言語は、値・特殊形式・パターンと融合・代数的エフェクトでできています。

M式

M式は Head{a, b, ...} と書く値で、head（symbol）と引数の列を持ちます。組は Tuple、リストは Cons と Nil を head とします。

> Def{p, Point{3, 4}}
> p
Point{3, 4}
> Apply{head, Tuple{p}}
Point
> Apply{arity, Tuple{p}}
2
> Apply{arg, Tuple{p, 1}}
4
> Apply{push, Tuple{p, 5}}
Point{3, 4, 5}
> Point{Apply{_add, Tuple{1, 1}}, 2}
Point{2, 2}
> Tuple{1, 2}
Tuple{1, 2}
> Cons{1, Cons{2, Nil{}}}
Cons{1, Cons{2, Nil{}}}
> Nil{}
Nil{}
> Apply{_eq, Tuple{Point{1, 2}, Point{1, 2}}}
true
> Apply{_eq, Tuple{Point{1, 2}, Point{1, 3}}}
false
  • 型は Expr で、immutable です。
  • 引数の数に限度はありません。mutable な値と NaN は引数に入れられず、作るときに実行時エラーです。
  • head(x) は M式だけに使えます。
> Apply{head, Tuple{1}}
Mexpr is expected: 1

型は値（型の値）で、type(x) が返します。type(1) は Int、type(Int) は Type です。

> Def{a, Apply{array, Tuple{2}}}
> Tuple{Apply{array_get, Tuple{a, 0}}}

array と plain array は array_set・plain_set で書き換えます。範囲外と、plain array に入らない値はエラーです。

equality

_eq(a, b) は値として等しい（equal）かを調べます。

  • 整数・float・complex は、型が違っても値が同じなら equal です。NaN はどの値とも equal ではありません。
  • M式は intern されるので、identical のときだけ equal です。head が同じで引数が1つずつ identical な M式は、1つの object です。F{1} と F{1.0} は equal ではありません。
  • array と plain array は、identical なら equal で、そうでなければ要素ごとに比べます。
  • hash(x) は 0 以上の整数で、equal な値は同じ値です。

identity

_is(a, b) は同じ物（identical）なら true です。identical な値は必ず equal です。型が違う値は identical ではなく、整数 1 と float 1.0 は equal でも identical ではありません。

intern は、equal な値を1つの object にまとめることです。intern する型では equal な値が identical で、_is は O(1) です（多倍長整数を除く）。

table（table_get・table_set）は、key が identical か equal なら同じ key とします。

ユーザーデータ

_record_new(name, Tuple{f, ...}) は Tuple{T, make} を返します。T は新しい型の値、make は f, ... の数だけ引数を取り、その型のデータを返す関数です。

> Def{r, Apply{_record_new, Tuple{Quote{Point}, Quote{Tuple{x, y}}}}}
> Def{Point, Apply{arg, Tuple{r, 0}}}
> Def{point, Apply{arg, Tuple{r, 1}}}
> Def{p, Apply{point, Tuple{1, 2}}}
> p
Point{1, 2}
> Apply{_eq, Tuple{Apply{type, Tuple{p}}, Point}}
true
> Apply{arity, Tuple{p}}
2
> Apply{arg, Tuple{p, 1}}
2
> Apply{_eq, Tuple{p, Apply{point, Tuple{1, 2}}}}
false
  • 型は呼ぶたびに別の値です。name（symbol）は表示にだけ使います。
  • type(x) はデータの型、arity(x) はフィールドの数、arg(x, i) は i 番目のフィールドです。head(x) は使えません。
  • フィールドを書き換える関数はありません。フィールドには mutable な値も入れられます。
  • データは identical のときだけ equal で、hash は object で決まります。
  • パターンは _TypeOf{p, T} で合わせます。T は式で、関数を作るときに評価します。

数

型が混ざる演算は、高い型に揃えます。

> Apply{_quo, Tuple{-7, 2}}
-4
> Apply{_div, Tuple{-7, 2}}
-3
> Apply{_mod, Tuple{-7, 2}}
1
> Apply{_mod, Tuple{7, -2}}
-1
  • _div は0方向へ切り捨て、_quo は負の無限大方向へ丸めます。_mod(a, b) は _sub(a, _mul(b, _quo(a, b))) で、符号は除数と同じです。
  • 除数が0なら実行時エラーです。float か complex を含む _div は無限大か NaN（complex は成分ごと）になります。
  • _lt _le _gt _ge は整数と float を数学的な値で比べます。NaN があれば false、complex は実行時エラーです。
  • 整数を float に揃えると最も近い float になり、範囲外は実行時エラーです。

リテラル

true・false・none は同じ名前の symbol を値とするリテラルで、変数ではありません。

特殊形式

形式意味

Set{x, e}代入

> Do{Set{x, 5}, x}
5
> Tuple{While{false, 1}}
Tuple{none}
> Def{n, 0}
> While{Apply{_lt, Tuple{n, 3}}, Set{n, Apply{_add, Tuple{n, 1}}}}
> n
3

定義と代入

Def{x, e} は書いた場所で新しい変数を定義します。同じ名前をもう一度定義しても新しい変数で、前に作った関数は前の変数を指したままです。Set{x, e} は今ある変数への代入なので、前に作った関数からも新しい値が見えます。

> Def{f, Lambda{Tuple{x}, 1}}
> Def{g, Lambda{Tuple{}, Apply{f, Tuple{0}}}}
> Def{f, Lambda{Tuple{x}, 2}}
> Apply{g, Tuple{}}
1
> Def{h, Lambda{Tuple{x}, 1}}
> Def{k, Lambda{Tuple{}, Apply{h, Tuple{0}}}}
> Set{h, Lambda{Tuple{x}, 2}}
> Apply{k, Tuple{}}
2

右辺から見えるのは前の x で、なければ未定義です。自分を呼ぶ関数は、先に Declare{f} で名前を作り、Set{f, Fusion{f, Lambda{...}}} で関数を足します（場合を足す）。

> Declare{fact}
> Set{fact, Fusion{fact, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, 1,
...         Apply{_mul, Tuple{n, Apply{fact, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}}}
> Apply{fact, Tuple{5}}
120
> Def{x, Apply{_add, Tuple{x, 1}}}
undefined variable: x

定義と代入の左辺の UnQuote

QuasiQuote の中では、Def と Set の左辺を UnQuote{x} と書くと、x の値のシンボルに置き換わります。x の値が Quote{true} なら、Def{true, e} と同じくプログラムを止めます。

> Def{x, Quote{i}}
> QuasiQuote{Do{Def{UnQuote{x}, 0}, Set{UnQuote{x}, Apply{_add, Tuple{UnQuote{x}, 1}}}}}
Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}}

部分関数と融合

関数はパターンで引数を取るので、合わない引数があり得る部分関数です。Fusion{f, g} は f を試し、どのパターンも合わなければ g を試します。

> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Apply{f, Tuple{1}}
"one"
> Def{g, Fusion{f, Lambda{Tuple{_}, "other"}}}
> Apply{g, Tuple{7}}
"other"

どの腕にも合わない呼び出しは、MatchingFailed を起こします。受け手がなければプログラムが止まります。

> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Apply{f, Tuple{7}}
matching failed: <lambda:(0)>|<lambda:(1)> <-> (7)

パターン

  • 変数：何にでも合い、値を束縛します。_ は何にでも合い、何も束縛しません。
  • 整数・文字列：equal な値に合います。Quote{s} は symbol s に合います。
  • Head{p, ...}：head が Head で、引数が順に p, ... に合う M式に合います。
  • _TypeOf{p, T}：type(x) が T で p が合う値に合います。T は式で、関数を作るときに評価します。T が Expr なら M式すべてに合います。
> Def{describe, Fusion{
...     Lambda{Tuple{_TypeOf{n, Int}}, Apply{_strcat, Tuple{"integer ", Apply{_to_text, Tuple{n}}}}},
...     Fusion{
...         Lambda{Tuple{_TypeOf{s, String}}, Apply{_strcat, Tuple{"string ", s}}},
...         Lambda{Tuple{_}, "other"}}}}
> Apply{describe, Tuple{1}}
"integer 1"
> Apply{describe, Tuple{"abc"}}
"string abc"
> Apply{describe, Tuple{Quote{x}}}
"other"

Apply{_add, Tuple{x, 1}} のような木に合わせるには、関数の位置を Quote{_add} と書きます。変数にすると、任意の関数の呼び出しに合います。

> Def{simp, Fusion{
...     Lambda{Tuple{Apply{Quote{_add}, Tuple{_TypeOf{a, Int}, _TypeOf{b, Int}}}}, Apply{_add, Tuple{a, b}}},
...     Fusion{
...         Lambda{Tuple{Apply{Quote{_add}, Tuple{a, 0}}}, a},
...         Lambda{Tuple{e}, e}}}}
> Apply{simp, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}
3
> Apply{simp, Tuple{Quote{Apply{_add, Tuple{z, 0}}}}}
z
> Def{swap, Lambda{Tuple{Apply{Quote{_add}, Tuple{a, b}}}, QuasiQuote{Apply{_add, Tuple{UnQuote{b}, UnQuote{a}}}}}}
> Apply{swap, Tuple{Quote{Apply{_add, Tuple{1, 2}}}}}
Apply{_add, Tuple{2, 1}}
> Def{callee, Lambda{Tuple{Apply{f, Tuple{x}}}, f}}
> Apply{callee, Tuple{Quote{Apply{g, Tuple{1}}}}}
g

残りの引数

_Rest{x} は残りの引数を Tuple（なければ Tuple{}）に束縛します。

> Def{total, Lambda{Tuple{_Rest{xs}}, xs}}
> Apply{total, Tuple{}}
Tuple{}
> Apply{total, Tuple{1, 2, 3}}
Tuple{1, 2, 3}
> Def{count, Lambda{Tuple{first, _Rest{others}}, Apply{_add, Tuple{1, Apply{arity, Tuple{others}}}}}}
> Apply{count, Tuple{7, 8, 9}}
3
> Def{describe, Fusion{
...     Lambda{Tuple{a}, "one"},
...     Fusion{
...         Lambda{Tuple{a, b}, "two"},
...         Lambda{Tuple{a, b, _Rest{c}}, "three or more"}}}}
> Apply{describe, Tuple{1}}
"one"
> Apply{describe, Tuple{1, 2}}
"two"
> Apply{describe, Tuple{1, 2, 3, 4}}
"three or more"
> Def{args_of, Lambda{Tuple{Call{f, _Rest{rest}}}, rest}}
> Apply{args_of, Tuple{Call{1, 2, 3}}}
Tuple{2, 3}
> Apply{args_of, Tuple{Call{1}}}
Tuple{}
  • 書けるのは、Lambda の引数の最後と、パターン Head{p, ...} の最後の引数だけです。
  • 前の引数の数より少ない呼び出しは合いません。
  • 最後以外や呼び出しの引数に書くと、実行前にメッセージを出して止まります。

場合を足す

Declare{f} のあとに Set{f, Fusion{f, Lambda{Tuple{p, ...}, body}}} と書くと、書いた場所の変数に f があればその関数の後ろに場合を足し、なければ新しい f を定義します。

> Declare{fib}
> Set{fib, Fusion{fib, Lambda{Tuple{0}, 0}}}
> Set{fib, Fusion{fib, Lambda{Tuple{1}, 1}}}
> Set{fib, Fusion{fib, Lambda{Tuple{n},
...     Apply{_add, Tuple{
...         Apply{fib, Tuple{Apply{_sub, Tuple{n, 1}}}},
...         Apply{fib, Tuple{Apply{_sub, Tuple{n, 2}}}}}}}}}
> Apply{fib, Tuple{20}}
6765
書いた場所場所の変数
トップレベル同じファイルの大域変数
関数の中その関数の引数と、それより前に定義した変数
トップレベルの If の枝・While の本体その中でそれより前に定義した変数

外側の関数・別のファイル（use で読んだライブラリ）の変数と組み込み関数は場所の変数ではありません。同じ名前の Declare{f} は外の f を変えず、隠す新しい f を定義します。別のファイルの f に足すには、Declare を付けずに Set します。

> Declare{name}
> Set{name, Fusion{name, Lambda{Tuple{x}, "outer"}}}
> Def{inner, Lambda{Tuple{}, Do{
...     Declare{name},
...     Set{name, Fusion{name, Lambda{Tuple{0}, "inner"}}},
...     Apply{name, Tuple{0}}}}}
> Tuple{Apply{inner, Tuple{}}, Apply{name, Tuple{0}}, Apply{name, Tuple{1}}}
Tuple{"inner", "outer", "outer"}
> Apply{use, Tuple{"list"}}
> Set{foldl, Fusion{foldl, Lambda{Tuple{f, acc, Tuple{a, b}},
...     Apply{f, Tuple{Apply{f, Tuple{acc, a}}, b}}}}}
> Tuple{
...     Apply{foldl, Tuple{_add, 0, Cons{1, Cons{2, Cons{3, Nil{}}}}}},
...     Apply{foldl, Tuple{_add, 0, Tuple{4, 5}}}}
Tuple{6, 9}
> Declare{reverse}
> Set{reverse, Fusion{reverse, Lambda{Tuple{xs}, "mine"}}}
> Apply{reverse, Tuple{Cons{1, Cons{2, Nil{}}}}}
"mine"

相互再帰

先に Def{f, none} で名前だけを宣言し、あとで Set{f, Fusion{f, Lambda{...}}} で埋めます。Fusion{none, g} は g なので、最初の Set は関数そのものを代入します。

> Def{odd, none}
> Declare{even}
> Set{even, Fusion{even, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, true, Apply{odd, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
> Set{odd, Fusion{odd, Lambda{Tuple{n},
...     If{Apply{_eq, Tuple{n, 0}}, false, Apply{even, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}
> Tuple{Apply{even, Tuple{10}}, Apply{odd, Tuple{7}}}
Tuple{true, true}

埋める前に呼ぶと none を呼ぶことになって止まります。

> Def{f, none}
> Apply{f, Tuple{}}
not a function: none

MatchingFailed

どの腕にも合わなかった関数呼び出しと、融合の最後のつなぎ先は、止まる代わりに MatchingFailed{f, args, loc} を Perform します。

フィールド中身
f呼ばれた関数（融合なら融合全体）
args合わなかった引数の Tuple{...}
loc失敗した呼び出しの位置 Loc{file, line, column}
> Def{f, Fusion{Lambda{Tuple{0}, "zero"}, Lambda{Tuple{1}, "one"}}}
> Def{a, Handle{Apply{f, Tuple{7}}, Lambda{Tuple{MatchingFailed{_, Tuple{n}, _}, k}, n}}}
> a
7
  • ハンドラの値が Handle の値になります。Apply{f, Tuple{7}} の値にはなりません。
  • 受け手のハンドラが無ければ、matching failed を出して止まります。unhandled effect にはなりません。
  • Return{v} や Break{} だけを受けるハンドラは通り抜けます。どのパターンにも合う Lambda{Tuple{e, k}, body} のハンドラは MatchingFailed も受けます。

失敗した呼び出しの位置

  • loc は、呼び出しを包む At の位置です。At のない呼び出しの loc は none です。
  • 末尾呼び出しの先で失敗したときの loc は、失敗した呼び出しより外側の、スタックに残る一番近い呼び出し元の位置です。f(x) := g(x) の g が失敗すれば、g(x) ではなく f を呼んだ位置です。

腕の奥で起きた失敗

次の腕へ移るかどうかは、入口のパターンだけで決まります。入口が合った腕の本体の奥で起きた MatchingFailed は、外側へ伝わります。

> Def{g, Lambda{Tuple{0}, "zero"}}
> Def{h, Fusion{Lambda{Tuple{x}, Apply{g, Tuple{x}}}, Lambda{Tuple{x}, "second arm"}}}
> Handle{Apply{h, Tuple{5}}, Lambda{Tuple{MatchingFailed{f, _, _}, k}, "failed in g"}}
"failed in g"

代数的エフェクト

Perform{Ask{}} は、合うパターンを持つ一番近い Handle{body, h} のハンドラ Lambda{Tuple{Ask{}, k}, ...} を呼びます。k は継続を表す通常の関数で、k に渡した値が Perform の値になります。

> Def{ask, Lambda{Tuple{}, Perform{Ask{}}}}
> Def{with_answer, Lambda{Tuple{v, f},
...     Handle{Apply{f, Tuple{}}, Lambda{Tuple{Ask{}, k}, Apply{k, Tuple{v}}}}}}
> Apply{with_answer, Tuple{21,
...     Lambda{Tuple{}, Apply{_mul, Tuple{Apply{ask, Tuple{}}, 2}}}}}
42
> Apply{with_answer, Tuple{5,
...     Lambda{Tuple{}, Apply{_add, Tuple{Apply{ask, Tuple{}}, Apply{ask, Tuple{}}}}}}}
10
  • k は Handle が値を返したあとでも、何度でも呼べます。
  • ハンドラは、再開した継続の中でも有効です。
  • 継続を捕捉した時点で定義済みの変数は、再開した計算のあいだで共有されます。再開のあとに定義した変数は別です。

どの腕にも合わなかった関数呼び出しが Perform する MatchingFailed（部分関数と融合）も k で再開できます。k に渡した値が、失敗した呼び出しの値になります。

> Def{f, Lambda{Tuple{0}, "zero"}}
> Handle{Cons{Apply{f, Tuple{7}}, Cons{1, Nil{}}}, Lambda{Tuple{MatchingFailed{_, _, _}, k}, Apply{k, Tuple{"other"}}}}
Cons{"other", Cons{1, Nil{}}}
