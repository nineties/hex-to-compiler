文法の宣言

::= は文法の規則を定義するか置き換えます。planck の構文も同じ規則で定義されているので、宣言によって後続の式の構文を拡張できます。

::=

name ::= alternative | ... は文法の規則 name を定義するか置き換えます。構文の規則（expr・primary・block・add_expr ...・ident・integer・string）も同じ文法の規則です。選択肢の ... はその規則のそれまでの定義を表します。

r_unless.pk

primary ::= 'unless c:expr a:block 'else b:block { `If{!c, !b, !a} } | ...

unless (1 > 2) { put("then\n") } else { put("else\n") }
unless (1 < 2) { put("then\n") } else { put("else\n") }

出力

then
else

選択肢は項目の列で、末尾に動作 { ... } を付けられます。項目と動作は ::= や | と同じ行に書きます。

項目

項目合うもの
"text"空白とコメントを読み飛ばしたあとの、その文字列
'wordその単語。後ろに [A-Za-z0-9_] が続かないもの
nospace("text")直前に空白やコメントを置かない、その文字列
nameその規則
same次の字句が現在の位置と同じ行にあるときに合う。入力を消費しない
delimited(e, sep)・delimited1(e, sep)sep で区切った e。0個以上・1個以上。値は Tuple{v, ...}
(a | b ...)選択
e*・e+・e?0回以上・1回以上・省略可能
&e・!e肯定・否定の先読み。入力を消費しない
label:ee。その値は動作の中で変数 label の値になる

選択肢の順序と値

選択肢は順に試されます（PEG）。選択肢の値は、動作があれば動作の値、項目が1つならその項目の値、それ以外は項目の値の Tuple{v, ...} です。e* と e+ の値は Tuple{v, ...}、e? の値は Tuple{} か Tuple{v} です。

規則の結果は位置ごとにメモ化します（packrat 構文解析）。規則には直接の左再帰を書けます（sum ::= a:sum "+" b:term { ... } | term）。左再帰の規則は左結合です。

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

出力

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

peg_parse

peg_parse(rule, s) は s の先頭を規則で読み、Tuple{値, 残り} を返します。空白しか残っていなければ Tuple{Eof{}, ""} を返し、読めなければ Tuple{SyntaxError{...}, ""} を返します。

規則で読む文字列

name{| text |} は、パーサがその式を読む時点で text を規則 name で読む式です。name と {| の間に空白は入れません。

text を読むのはその規則だけです（規則の文字列・単語・規則と、それらの空白とコメント）。まわりの式の字句では読みません。text の終わりは規則が読み終えた位置で、そのあと空白をはさんで |} が続きます。したがって規則が読む |} や }（規則の文字列や括弧の中のもの）は text の一部です。規則が失敗したときや |} がないときは、その式の構文エラーです。エラーの位置は規則が text の中で最も先まで読んだ位置です。

式の値は規則の値で、定数として扱います。

r_calc.pk

calc ::= a:calc "+" b:num { a + b } | num
num ::= integer
println(calc{| 1 + 2 + 3 |})        # 6, computed when this line is read

出力

6

その文字列を含む式を読むより前に評価される式で、規則を定義しておきます。

peg_sources と peg_version

peg_sources は規則の名前から _define_rule に渡された構文解析式への表です。動作は評価する前の形で、... はそれまでの定義に置き換えてあります。peg_version は _define_rule を呼ぶたびに増えます。

i_sources.pk

use("pretty")
pprint(table_get(peg_sources, 'add_expr, none))

出力

Choice{
  Act{
    Seq{add_expr, "+", mul_expr},
    Lambda{
      Tuple{Tuple{a, _, b}},
      Do{
        QuasiQuote{
          Apply{_add, Tuple{UnQuote{a}, UnQuote{b}}}
        }
      }
    }
  },
  Act{
    Seq{add_expr, minus, mul_expr},
    Lambda{
      Tuple{Tuple{a, _, b}},
      Do{
        QuasiQuote{
          Apply{_sub, Tuple{UnQuote{a}, UnQuote{b}}}
        }
      }
    }
  },
  mul_expr
}
