文法の拡張

::= は PEG の規則を定義するか置き換えます。planck の構文も同じ規則で定義されているので、宣言すると後続の式の構文を拡張できます。選択肢は順に試し、規則の結果は位置ごとにメモ化します（packrat）。

::=

name ::= alternative | ... は規則 name を定義し、すでにあれば置き換えます。選択肢の ... は、その規則のそれまでの定義です。選択肢は項目の列で、末尾に動作 { ... } を付けられます。項目と動作は ::= や | と同じ行に書きます。

r_unless.pk

primary ::= 'unless c:expr a:block 'else b:block { `If{!c, !b, !a} } | ...

unless (1 > 2) { put("then\n") } else { put("else\n") }
unless (1 < 2) { put("then\n") } else { put("else\n") }

出力

then
else

項目

項目合うもの
"text"・'wordその文字列・その単語（後ろに [A-Za-z0-9_] が続かないもの）
nospace("text")直前に空白やコメントを置かない、その文字列
.・[set]・[^set]任意の1文字・set にある1文字・ない1文字（文字クラス）。値はその文字の文字列
nameその規則
same次の字句が現在の位置と同じ行にあるときに合う。入力を消費しない
delimited(e, sep)・delimited1(e, sep)sep で区切った e（0個以上・1個以上）。値は Tuple{v, ...}
(a | b ...)・e*・e+・e?選択・0回以上・1回以上・省略可能
&e・!e肯定・否定の先読み。入力を消費しない
label:ee。その値は動作の中で変数 label の値になる

文字列・単語・.・[set] は、空白とコメントを読み飛ばしてから合わせます。選択肢の値は、動作があれば動作の値、項目が1つならその項目の値、それ以外は項目の値の Tuple{v, ...} です。e* と e+ は Tuple{v, ...}、e? は Tuple{} か Tuple{v} になります。

規則には直接の左再帰を書けます（sum ::= a:sum "+" b:term { ... } | term）。左結合になります。

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

出力

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

文字クラス

  • a-z のように、英字・数字・_ のあとに - と1文字を続けると範囲です。それ以外の - は文字そのものです。
  • \n・\t・\a・\b・\f・\r・\v・\0 は制御文字で、ほかの \x は文字 x です。
  • set の両端の空白は含めません。空の set・逆順の範囲（[9-0]）・終わりが欠けた範囲（[a-]）は構文エラーです。
  • 入力の終わりには、. も [set] も [^set] も合いません。

r_charset.pk

use("string")

join(cs) := {
    r := ""
    i := 0
    while (i < arity(cs)) {
        r = _strcat(r, arg(cs, i))
        i = i + 1
    }
    r
}

word ::= cs:[a-z_]+ { join(cs) }
number ::= cs:[0-9]+ { string.str_to_int(join(cs)) }
quoted ::= "\"" cs:[^"]* "\"" { join(cs) }
pair ::= k:word "=" v:(number | quoted) { Tuple{k, v} }
first ::= c:. { c }

println(arg(peg_parse('pair, "a=12"), 0))
println(arg(peg_parse('pair, "name=\"koichi\""), 0))
println(arg(peg_parse('first, "  xyz"), 0))

出力

Tuple{"a", 12}
Tuple{"name", "koichi"}
"x"

peg_parse

peg_parse(rule, s) は s の先頭を規則で読み、Tuple{値, 残り} を返します。空白しか残っていなければ Tuple{Eof{}, ""}、読めなければ Tuple{SyntaxError{...}, ""} です。

規則で読む文字列

name{| text |} は、パーサがその式を読む時点で text を規則 name で読む式で、値は規則の値（定数）です。name と {| の間に空白は入れません。規則は、この式を含む式を読むより前に評価される式で定義しておきます。

  • text を読むのはその規則だけで、まわりの式の字句では読みません。
  • text の終わりは規則が読み終えた位置で、そのあと空白をはさんで |} が続きます。規則が読む |} や } は text の一部です。
  • 規則が失敗したときや |} がないときは構文エラーで、位置は規則が text の中で最も先まで読んだ位置です。

r_calc.pk

calc ::= a:calc "+" b:num { a + b } | num
num ::= integer
println(calc{| 1 + 2 + 3 |})        # 6, computed when this line is read

出力

6

peg_sources と peg_version

peg_sources は規則の名前から _define_rule に渡された構文解析式への表です。動作は評価する前の形で、... はそれまでの定義に置き換えてあります。peg_version は _define_rule を呼ぶたびに増えます。

i_sources.pk

use("table")
use("pretty")
pretty.print(table.get(peg_sources, 'add_expr, none))

出力

Choice{
  Act{
    Seq{add_expr, "+", mul_expr},
    Lambda{
      Tuple{Tuple{a, _, b}},
      Do{
        QuasiQuote{
          Apply{_add, Tuple{UnQuote{a}, UnQuote{b}}}
        }
      }
    }
  },
  Act{
    Seq{add_expr, minus, mul_expr},
    Lambda{
      Tuple{Tuple{a, _, b}},
      Do{
        QuasiQuote{
          Apply{_sub, Tuple{UnQuote{a}, UnQuote{b}}}
        }
      }
    }
  },
  mul_expr
}

macro

macro p := e は、評価の前に木を書き換える規則を足します。p は引数のパターンと同じ書き方で木の形を表し、e は p の変数を使って評価されて新しい木になります。文字列を M式にする構文には触れません。

r_macro.pk

macro Twice{x} := `(!x + !x)
macro unless(c, e) := `if (not !c) !e

println(Twice{21})
unless(1 > 2, println("shown"))
unless(1 < 2, println("not shown"))

# a quote is not rewritten
println('(Twice{1}))

出力

42
"shown"
Twice{1}
  • 読み終わった式を評価する前（eval に渡した木も同じ）に、根から順に各部分を書き換えます。規則は後に足したものから試し、合わなければそのままです。書き換えた部分は、変わらなくなるまで規則を当ててから、その中を書き換えます。
  • クオート 'e の中は書き換えません。準クオート `e の中は !e の中だけを書き換えます。関数の引数のパターンと、Def・Set・Declare が定義する名前も書き換えません。
  • 1つの式の書き換えで規則を 1000 回より多く当てるとエラーで止まります（終わらない規則も止まります）。
  • 規則が有効なのは、macro の位置から、それを囲む一番内側の関数か module の本体の終わりまでです。何も囲んでいなければ以降のすべての式です。module の中の export macro は、その module の定義のあとから module の外でも有効です。

r_macro_module.pk

module shapes {
    macro Inside{x} := `(!x + 100)
    export macro Double{x} := `(!x * 2)
    export f() := Inside{1}
}
println(shapes.f())
println(Double{21})
println('(Inside{1}))

出力

101
42
Inside{1}

トップレベル

式を読むたびに大域変数 parse と eval を引き直すので、差し替えると次の式から新しい定義で処理されます。Apply{eval, ...} も差し替えた eval を呼びます。

  • parse：文字列 -> Tuple{M式, 文字列の残り}。空白しか残っていなければ Tuple{Eof{}, ""} を返し、差し替える parse は Eof{} をそのまま通します。
  • eval：M式 -> 値。

t6_eval.pk

old_eval := eval
eval = e -> {
    v := old_eval(e)
    put("=> ")
    println(v)
    v
}
1 + 2
'(a + b)
Point{1, 2}

出力

=> 3
=> Apply{_add, Tuple{a, b}}
=> Point{1, 2}
