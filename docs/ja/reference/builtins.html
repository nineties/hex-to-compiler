組み込み関数

use なしで使える関数です。名前が _ で始まるものの多くは、演算子や構文が呼ぶ関数です。誤り（範囲外の添字・読めない値など）は実行時エラーです。個々の関数は名前から使い方がわかるものが多いので、ここには規則と例外だけを書きます。

出力

print(x) は値を、println(x) は値と改行を出力します。文字列は引用符つきで、put(s) だけが中身をそのまま出力します。M式は M式の形で出て、リストは Cons{a, Cons{1, Nil{}}} です。

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

出力

42 "abc"
abc
Point{1, "a"}

数と比較

演算子 + - * / % と比較演算子は、_add _sub _mul _div _quo _mod と _lt _le _gt _ge _eq _ne _is の呼び出しに読み替えられます（糖衣が呼ぶ名前）。引数と結果の規則は数にあります。演算子を関数として渡すには (a, b) -> a + b のように書きます。

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

出力

7
9
3
1
-3
36

M式と文字列

  • head・arity・arg・type は M式の頭・引数の数・引数・型を返します。push(Head{a, ...}, x) は Head{a, ..., x}、mexpr(h, Tuple{a, ...}) は h{a, ...} です。
  • 文字列はバイトの列です。strlen(s) は0のバイトも含むバイト数、ord(s, i) は i 番目のバイトで範囲外なら -1、s[i] はそれを長さ1の文字列にしたものです。
  • substr(s, i, j) は i から j - 1 番目まで、_strcat(a, b) は連結です。intern(s) は名前が s の symbol、symname(sym) はその逆です。

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

出力

true
"abc"
65
-1
P{1, 2}
"x"
none
3
true

配列と表

  • array(n) は全要素が none の配列を作ります。array_get(a, i)・array_set(a, i, x)（x を返す）・array_len(a) で読み書きします。範囲外の添字はエラーです。
  • table_new() は新しいハッシュ表を作ります。table_get(t, key, default)・table_set(t, key, value) か t[key]・t[key] = value で読み書きします（添字と置き換え）。key は == で比べます。hash(x) は0以上の整数で、_eq で等しい値は同じ値です。

浮動小数点数と複素数

  • itof・fsqrt（負の数は NaN）・ffloor（結果は浮動小数点数）・fexp・flog・fsin・fcos・fpow・fatan2 は整数も取り、浮動小数点数に揃えます。複素数はエラーです。
  • ftoi(a) は0方向へ切り捨てた整数で、NaN と無限大はエラーです。ftobits(a) は64ビットを0以上の整数で返し、bitstof(n) はその逆で、64ビットに収まらなければエラーです。
  • ftos(a) は読み戻すと同じ値になる最短の10進文字列で、print の出力でもあります。stof(s) は読めなければ none、_float(s) は読めなければエラーです。浮動小数点数のリテラル（1.5）は _float の呼び出しに読み替えられます。
  • complex(re, im) は複素数を作ります。real(z)・imag(z) は成分を浮動小数点数で返し、conj(z) は共役です。z が複素数でなければエラーです。

平らな配列

plain array は要素の型が1つの配列です。plain_array(kind, n) は型 kind の要素 n 個を、その型の0（false・0・0.0・complex(0, 0)）で作ります。kind は 'bool、符号付き 'i8 'i16 'i32 'i64、符号なし 'u8 'u16 'u32 'u64、浮動小数点数 'f16 'f32 'f64（IEEE 754）、複素数 'c64 'c128（成分が binary32・binary64）で、ほかの値と負の n はエラーです。u8_array(n) は plain_array('u8, n) で、ほかの型も同じ形です。

  • a[i]・a[i] = x（plain_get・plain_set）で読み書きします。読み出すと 'f16・'f32・'c64 は値を変えずに binary64 に広がります。
  • plain_len(a) は n、plain_kind(a) は型の symbol です。plain_copy(dst, di, src, si, n) は src の si から n 個を dst の di 以降へコピーします。型は同じで、同じ配列の中で範囲が重なってもかまいません。

書き込む値は型に変換され、範囲外と変換できない値は実行時エラーです（ラップアラウンドしません）。例外は次のとおりです。

  • 浮動小数点数を整数型へは、0方向へ切り捨ててから範囲を調べます。NaN と無限大はエラーです。複素数を整数型・浮動小数点型へはエラーです。
  • 'bool へは、0（0・0.0・-0.0・complex(0, 0)）なら false、それ以外は NaN も含めて true です。true と false は数の型へ1と0で入ります。
  • 浮動小数点型・複素数型へは、最も近い値に丸めます。型の最大値を超えると同じ符号の無限大で、binary64 の範囲を超える整数はエラーです。整数・浮動小数点数を複素数型へ書くと、実部になり虚部は0です。

ビット演算

bit_and・bit_or・bit_xor・bit_not は、整数を無限桁の2の補数として扱うビットごとの演算で、負の数も扱えます。bit_shl(a, k) はラップアラウンドせず、bit_sar(a, k) は算術シフトです。k が負ならエラーです。bit_shr(a, k) は a が負でなければ bit_sar と同じで、負ならエラーです。

r_plain.pk

b := u8_array(4)
b[0] = 72
b[1] = 0
b[2] = 255
println(plain_len(b))
println(b[2])
println(plain_kind(b))
write_file("tmp-plain.bin", b)
c := read_bytes("tmp-plain.bin")
println(c[1])
println(plain_len(c))
println(bit_and(0xff0, 0x3c))
println(bit_xor(5, 3))
println(bit_shl(1, 20))
println(bit_shr(256, 4))
println(bit_sar(-256, 4))
s := "ab"
println(s[1])

ファイルと言語

  • read_file(path) は0のバイトも含む中身を返し、try_read_file は読めなければ none、read_bytes は u8 配列で返します。write_file(path, x) は文字列か u8 配列 x の全バイトを書き（なければ作り、あれば空にする）、chmod(path, mode) は権限を設定します（493 が8進の755）。
  • argv() はコマンドラインの文字列の配列で、先頭がプログラムのファイル、残りが引数です。exit(n) は終了状態 n で終了します。
  • load(path) はファイルを読み、トップレベルの式を path を読み込み中のファイルとして評価します。第1引数のプログラムと planck/init.pk も、実行中はそれぞれが読み込み中のファイルです（変数の範囲）。_set_file(path) は読み込み中のファイルを替え、前のファイルを返します（なければ none）。
  • use(name) は load("planck/lib/<name>.pk") を1回だけ実行します。前処理したライブラリがあれば、同じことをその M式で行います。used_libs は読み込み済みの表です。
  • parse と eval はトップレベルで使われる関数です。

構文の実装が呼ぶ関数

  • _define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の宣言にあります。parse_mexpr(s) は M式のパーサで、parse と同じ引数と結果です。
  • _to_text(x) は、文字列ならそのまま、整数なら10進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。文字列と整数以外を {e} に入れるには use("pretty") が必要です。値を埋め込んだ文字列は左から _strcat でつなぎ、空の部分は省きます。
  • _record_declare(name, fields) は頭 name の欄の名前を決め、_record_get(t, name) は欄の値、_record_with(t, name, v) は欄を v に替えた新しい値を返します。_destructure(t, i, n) は n 個の要素の組 t の i 番目を返し、そうでなければ止まります。
  • _index_get・_index_set は a[i]・a[i] = e が、subst(t, f) は t[f] が呼ぶ関数です。peg_for(xs, f) はリスト・ベクタ・範囲 xs の要素ごとに f を呼び、none を返します。Range{a, b} は b を含みます。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}

実行時エラーのメッセージに出る関数の名前は、呼んだ組み込み関数の名前と異なることがあります。
