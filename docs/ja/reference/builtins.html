組み込み関数

出力

print(x) は値を出力し、println(x) はそのあと改行します。文字列は引用符つきで出力します。put(s) は文字列の中身をそのまま出力します。

println("abc")
println('abc)
println(Point{1, "a"})

Point{1, "a"}

数と比較

演算子 + - * / % と比較演算子はこれらの関数の呼び出しに読み替えられます（糖衣が呼ぶ名前）。_ のない名前の関数はありません。引数と結果の規則は数にあります。演算子を関数として渡すには (a, b) -> a + b のように無名関数で書きます。

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

M式と文字列

  • push(Head{a, ...}, x) は Head{a, ..., x} です。
  • mexpr(h, Tuple{a, ...}) は頭 h の M式 h{a, ...} を作ります。
  • symname(sym) はシンボルの名前を文字列で返します（intern の逆）。intern(s) は名前が s のシンボルを返します。
  • strlen(s) は0のバイトも含むバイト数です。ord(s, i) は i 番目のバイトで、i が範囲外なら -1 です。s[i] は i 番目のバイトを長さ1の文字列で返します。
  • substr(s, i, j) は i から j - 1 番目までのバイトで、範囲外は実行時エラーです。_strcat(a, b) は a のあとに b を続けた文字列です。

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

配列と表

  • array(n) は要素が n 個で全要素が none の新しい配列を作ります。array_get(a, i)・array_set(a, i, x)（x を返す）・array_len(a) で要素の読み書きと長さの取得をします。0 から n - 1 の外の添字は実行時エラーです。
  • hash(x) は0以上の整数です。_eq で等しい値は同じハッシュになります。
  • table_new() は新しいハッシュ表 Table{a} を作ります。a は配列で構成します。table_get(t, key, default)・table_set(t, key, value) で読み書きします。キーは == で比べます。t[key] と t[key] = value でも読み書きできます（添字と置き換え）。

浮動小数点数と複素数

  • itof(n) は n + 0.0 です。fsqrt(a) は平方根で、負の数なら NaN です。ffloor(a) は床関数で、結果は浮動小数点数です。
  • ftoi(a) は0方向へ切り捨てた整数で、NaN と無限大は実行時エラーです。ftobits(a) は64ビットを0以上の整数で返し、bitstof(n) はその逆です。n が64ビットに収まらなければ実行時エラーです。
  • ftos(a) は読み戻すと同じ値になる最短の10進文字列で、print が浮動小数点数に対して出力する文字列でもあります。stof(s) は10進の文字列（指数も可）を読み、読めなければ none を返します。_float(s) は10進の文字列 s の浮動小数点数で、読めなければ実行時エラーです。浮動小数点数のリテラル（1.5）はこの関数の呼び出しに読み替えられます。
  • fexp(a)・flog(a)・fsin(a)・fcos(a)・fpow(a, b)・fatan2(a, b) は指数関数・自然対数・正弦・余弦・べき乗・2引数の逆正接です。これらの関数は整数も取り、浮動小数点数に揃えます。複素数は実行時エラーです。
  • complex(re, im) は実部 re・虚部 im の複素数です。どちらも整数か浮動小数点数で、浮動小数点数に揃えます。real(z)・imag(z) は実部と虚部を浮動小数点数で返し、z が複素数でなければ実行時エラーです。conj(z) は complex(real(z), imag(z) * -1) です。

平らな配列

平らな配列は要素の型が1つの配列です。plain_array(kind, n) は型 kind の要素 n 個の配列を作り、要素はすべてその型の0（false・0・0.0・complex(0, 0)）です。kind が次の型のどれでもないときと n が負のときは実行時エラーです。u8_array(n) は plain_array('u8, n) で、ほかの型にも同じ形の関数があります。

型要素
'booltrue か false
'i8 'i16 'i32 'i64符号付き整数（-2^(n-1) から 2^(n-1)-1）
'u8 'u16 'u32 'u64符号なし整数（0 から 2^n-1）
'f16 'f32 'f64浮動小数点数（IEEE 754 の binary16・binary32・binary64）
'c64 'c128複素数（実部と虚部が binary32・binary64）
  • a[i] と a[i] = x（plain_get(a, i)・plain_set(a, i, x)）で要素を読み書きします。0 から n - 1 の外の添字は実行時エラーです。
  • 読み出した要素は言語の値です。'f16・'f32・'c64 は値を変えずに binary64 へ広げます。
  • plain_len(a) は n、plain_kind(a) は型のシンボルです。plain_copy(dst, di, src, si, n) は src の si から n 個を dst の di 以降にコピーします。型は同じでなければならず、同じ配列の中で範囲が重なってもかまいません。

書き込む値は次のように変換します。

  • 整数型の範囲の外にある整数は実行時エラーで、ラップアラウンドしません。
  • 整数型に書く浮動小数点数は0方向へ切り捨ててから範囲を調べます。NaN と無限大は実行時エラーです。
  • 整数型と 'f16・'f32・'f64 に書く複素数は実行時エラーです。
  • 'bool に書く数は、0（0・0.0・-0.0・complex(0, 0)）なら false、それ以外なら NaN も含めて true です。
  • 'bool に書く true と false はそのままで、数の型に書くと1と0です。
  • 複素数型に書く整数と浮動小数点数は実部になり、虚部は0です。
  • 浮動小数点型と複素数型に書く数は最も近い値に丸めます。丸めた値が型の最大値を超えると、同じ符号の無限大になります。binary64 の範囲を超える整数は実行時エラーです。
  • これ以外の値はどの型でも実行時エラーです。

ビット演算

  • bit_and(a, b)・bit_or(a, b)・bit_xor(a, b)・bit_not(a) は、負の数も含めて整数を無限桁の2の補数として扱うビットごとの演算です。
  • bit_shl(a, k) は左に k ビットシフトします。ラップアラウンドはしません。bit_sar(a, k) は算術シフトです。k が負なら実行時エラーです。
  • bit_shr(a, k) は、a が負でなければ bit_sar(a, k) で、負なら実行時エラーです。

ファイルと言語

  • read_file(path) はファイルの中身を0のバイトも含めて返します。try_read_file(path) も同じですが、読めなければ none を返します。read_bytes(path) は同じ中身を u8 配列で返します。write_file(path, x) は文字列か u8 配列 x の全バイトをファイルに書きます（なければ作り、あれば空にします。0のバイトもそのまま書きます）。chmod(path, mode) はファイルの権限を mode にします（493 が8進の755）。
  • argv() はコマンドラインの文字列の配列を返します。C の main の argv と同じです。先頭は実行するプログラムのファイルで、残りがそのプログラムの引数です。プログラムが a.pk で引数が x y なら "a.pk"・"x"・"y" の3要素です。
  • load(path) はファイルを読んで評価します。トップレベルの式は path を読み込み中のファイルとして評価します。第1引数のプログラムのファイルと planck/init.pk も、実行中はそれぞれが読み込み中のファイルです（変数の範囲）。
  • _set_file(path) は path を読み込み中のファイルにし、前のファイルを返します（なければ none）。
  • use(name) は load("planck/lib/<name>.pk") を1回だけ実行します。前処理したライブラリがあれば、同じことをその M式で行います。used_libs は読み込み済みのライブラリの表です。
  • parse と eval はトップレベルで使われる関数です。exit(n) は終了状態 n でプログラムを終了します。
  • _define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の宣言にあります。
  • parse_mexpr(s) は M式のパーサで、引数と結果は parse と同じです。
  • _to_text(x) は、文字列ならそのまま、整数なら10進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。このため文字列と整数以外を {e} に入れるには use("pretty") が必要です。値を埋め込んだ文字列は左から _strcat でつなぎ、空の部分は省きます。
  • _record_declare(name, fields) は頭 name の欄の名前を決めます（fields は Tuple{f, ...}）。_record_get(t, name) はその欄の値を返します。_record_with(t, name, v) はその欄を v に替えた新しい値を返します。_destructure(t, i, n) は n 個の要素の組 t の i 番目を返し、そうでなければ止まります。
  • _index_get(a, i) と _index_set(a, i, e) は a[i] と a[i] = e が呼ぶ関数で、subst(t, f) は t[f] が呼ぶ関数です（添字と置き換え）。
  • peg_for(xs, f) はリスト・ベクタ・範囲 xs の要素ごとに f を呼び、none を返します。範囲 Range{a, b} では a から b まで（b を含む）の整数を順に渡します。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}

実行時エラーのメッセージに出る関数の名前は、呼んだ組み込み関数の名前と異なることがあります。
