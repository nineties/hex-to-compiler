組み込み関数

use なしで使える関数です。名前が _ で始まるものの多くは、演算子や構文が呼ぶ関数です。誤り（範囲外の添字・読めない値など）は実行時エラーです。

出力

print(x) は値を、println(x) は値と改行を出力します。put(s) だけは文字列の中身をそのまま出力します。

> Apply{println, Tuple{"abc"}}
"abc"
> Apply{println, Tuple{Quote{abc}}}
abc
> Apply{println, Tuple{Point{1, "a"}}}
Point{1, "a"}

数と比較

算術は _add _sub _mul _div _quo _mod、比較は _lt _le _gt _ge _eq _ne _is、否定は _not です。引数と結果の規則は数にあります。

> Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}
7
> Apply{_div, Tuple{7, 2}}
3
> Apply{_mod, Tuple{7, 2}}
1
> Apply{_div, Tuple{-7, 2}}
-3
> Apply{_add, Tuple{0x1f, 0b101}}
36

M式と文字列

head・arity・arg・type は M式の head・引数の数・引数・型を返します。

> Def{s, "abc"}
> Apply{strlen, Tuple{s}}
3
> Apply{ord, Tuple{s, 1}}
98
> Apply{_index_get, Tuple{s, 1}}
"b"
> Apply{substr, Tuple{s, 1, 3}}
"bc"
> Apply{_strcat, Tuple{s, "de"}}
"abcde"
> Apply{push, Tuple{Point{1}, 2}}
Point{1, 2}
> Apply{arity, Tuple{Point{1, 2, 3}}}
3
> Apply{arg, Tuple{Point{1, 2, 3}, 2}}
3
> Apply{strlen, Tuple{"あい"}}
2
> Apply{ord, Tuple{"あ", 0}}
12354
> Apply{substr, Tuple{"あいう", 1, 2}}
"い"
> Apply{plain_len, Tuple{Apply{string_to_bytes, Tuple{"あ"}}}}
3
  • push(Head{a, ...}, x) は Head{a, ..., x}、mexpr(h, Tuple{a, ...}) は h{a, ...} です。
  • strlen(s) は文字数です。ord(s, i) は i 番目の文字のコードポイントで、範囲外なら -1 です。
  • substr(s, i, j) は i から j - 1 番目の文字までです。
  • string_to_bytes(s) は s の UTF-8 のバイト列を u8 の plain array で返し、bytes_to_string(b) はその逆です。b が UTF-8 でなければエラーです。
  • intern(s) は名前が s の symbol、symname(symbol) はその逆です。
> Apply{_eq, Tuple{Apply{intern, Tuple{"abc"}}, Quote{abc}}}
true
> Apply{symname, Tuple{Quote{abc}}}
"abc"
> Apply{ord, Tuple{"A", 0}}
65
> Apply{ord, Tuple{"A", 5}}
-1
> Apply{mexpr, Tuple{Quote{P}, Tuple{1, 2}}}
P{1, 2}
> Def{a, Apply{array, Tuple{3}}}
> Apply{array_set, Tuple{a, 0, "x"}}
> Apply{array_get, Tuple{a, 0}}
"x"
> Tuple{Apply{array_get, Tuple{a, 1}}}
Tuple{none}
> Apply{array_len, Tuple{a}}
3
> Apply{_eq, Tuple{Apply{hash, Tuple{"abc"}}, Apply{hash, Tuple{"abc"}}}}
true

配列と表

> Def{t, Apply{table_new, Tuple{}}}
> Apply{table_set, Tuple{t, "a", 1}}
1
> Apply{table_get, Tuple{t, "a", 0}}
1
> Apply{table_get, Tuple{t, "c", 0}}
0
> Def{a, Apply{array, Tuple{2}}}
> Apply{array_set, Tuple{a, 1, "x"}}
> Apply{array_get, Tuple{a, 1}}
"x"
  • array(n) は全要素が none の array を作ります。array_get・array_set（none を返す）・array_len で読み書きし、範囲外の添字はエラーです。
  • table_new() は新しいハッシュ表を作ります。table_get(t, key, default) は key がなければ default を返し、table_set(t, key, value) は書き込みます。
  • key は equal で比べます。hash(x) は0以上の整数で、_eq で等しい値は同じ値です（equality）。

浮動小数点数と複素数

  • itof・fsqrt（負の数は NaN）・ffloor（結果は float）・fexp・flog・fsin・fcos・fpow・fatan2 は整数も取り、float に揃えます。complex はエラーです。
  • ftoi(a) は0方向へ切り捨てた整数で、NaN と無限大はエラーです。
  • ftobits(a) は64ビットを0以上の整数で返します。bitstof(n) はその逆で、64ビットに収まらなければエラーです。
  • ftos(a) は読み戻すと同じ値になる最短の10進文字列で、print の出力でもあります。
  • stof(s) は読めなければ none、_float(s) は読めなければエラーです。
  • complex(re, im) は complex を作ります。real(z)・imag(z) は成分を float で、conj(z) は共役を返します。z が complex でなければエラーです。

plain array

plain_array(kind, n) は型 kind の要素 n 個を、その型の0（false・0・0.0・complex(0, 0)）で作ります。u8_array(n) は plain_array(Quote{u8}, n) で、ほかの型も同じ形です。

kind（symbol）要素
bool真偽値
i8 i16 i32 i64符号付き整数
u8 u16 u32 u64符号なし整数
f16 f32 f64float（IEEE 754）
c64 c128complex（成分が binary32・binary64）

ほかの値と負の n はエラーです。

  • plain_get(a, i)・plain_set(a, i, x)（none を返す）で読み書きします。f16・f32・c64 は、読み出すと値を変えずに binary64 に広がります。
  • plain_len(a) は n、plain_kind(a) は型の symbol です。
  • plain_copy(dst, di, src, si, n) は src の si から n 個を dst の di 以降へコピーします。型は同じで、同じ array の中で範囲が重なってもかまいません。

書き込む値は型に変換され、範囲外と変換できない値はエラーです（ラップアラウンドしません）。例外があります。

書き込む値書き込み先結果
float整数型0方向へ切り捨ててから範囲を調べる。NaN と無限大はエラー
complex整数型・float 型エラー
0（0・0.0・-0.0・complex(0, 0)）boolfalse
それ以外（NaN を含む）booltrue
true・false数の型1・0
整数・floatfloat 型・complex 型最も近い値に丸める。型の最大値を超えると同じ符号の無限大。binary64 の範囲を超える整数はエラー
整数・floatcomplex 型実部になり、虚部は0

ビット演算

bit_and・bit_or・bit_xor・bit_not は、整数を無限桁の2の補数として扱うビットごとの演算で、負の数も扱えます。

  • bit_shl(a, k) はラップアラウンドしません。bit_sar(a, k) は算術シフトです。k が負ならエラーです。
  • bit_shr(a, k) は a が負でなければ bit_sar と同じで、負ならエラーです。
> Apply{bit_and, Tuple{12, 10}}
8
> Apply{bit_or, Tuple{12, 10}}
14
> Apply{bit_xor, Tuple{12, 10}}
6
> Apply{bit_not, Tuple{5}}
-6
> Apply{bit_shl, Tuple{1, 10}}
1024
> Apply{bit_sar, Tuple{-16, 2}}
-4
> Apply{bit_shr, Tuple{16, 2}}
4
> Def{b, Apply{u8_array, Tuple{4}}}
> Apply{plain_set, Tuple{b, 0, 72}}
> Apply{plain_set, Tuple{b, 1, 0}}
> Apply{plain_set, Tuple{b, 2, 255}}
> Apply{plain_len, Tuple{b}}
4
> Apply{plain_get, Tuple{b, 2}}
255
> Apply{plain_kind, Tuple{b}}
u8
> Apply{write_file, Tuple{"tmp-plain.bin", b}}
> Def{c, Apply{read_bytes, Tuple{"tmp-plain.bin"}}}
> Apply{plain_get, Tuple{c, 1}}
0
> Apply{plain_len, Tuple{c}}
4

record

_record(Quote{T}, Quote{Tuple{f, g, ...}}) は _record_new で型を作り、欄の名前を型に結び付けて Tuple{T, make} を返します。_record_get(t, Quote{f}) は t の欄 f を返し、_record_with(T, make) は (d, Quote{f}, e) を取って欄 f を e に替えたデータを返す関数を返します。

  • 型ごとに同じ名前の欄を持てます。
  • 欄がない値や、record で作っていない値に _record_get を使うと、メッセージを出して止まります。

ファイルと言語

> Apply{write_file, Tuple{"tmp-gm.txt", "Apply{println, Tuple{Apply{_add, Tuple{1, 1}}}}\n"}}
> Apply{read_file, Tuple{"tmp-gm.txt"}}
"Apply{println, Tuple{Apply{_add, Tuple{1, 1}}}}\n"
> Apply{load, Tuple{"tmp-gm.txt"}}
2
> Tuple{Apply{try_read_file, Tuple{"no-such-file"}}}
Tuple{none}
> Apply{array_len, Tuple{Apply{argv, Tuple{}}}}
1
  • read_file(path) は中身を文字列で返します（UTF-8 でなければエラー）。try_read_file は読めなければ none、read_bytes は u8 の plain array で返します。
  • write_file(path, x) は文字列 x なら UTF-8 のバイトを、u8 の plain array なら全バイトを書きます（なければ作り、あれば空にする）。chmod(path, mode) は権限を設定します（493 が8進の755）。
  • argv() はコマンドラインの文字列の array で、先頭がプログラムのファイル、残りが引数です。exit(n) は終了状態 n で終了します。
  • load(path) はファイルを読み、トップレベルの式を path を読み込み中のファイルとして評価します。_set_file(path) は読み込み中のファイルを替え、前のファイルを返します（なければ none）。
  • use(name) は load("planck/lib/<name>.pk") を1回だけ実行します。前処理したライブラリがあれば、同じことをその M式で行います。used_libs は読み込み済みの表です。
  • parse と eval はトップレベルで使われる関数です。

構文の実装が呼ぶ関数

  • _define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の拡張にあります。
  • parse_mexpr(s) は M式のパーサで、parse と同じ引数と結果です。
  • _to_text(x) は、文字列ならそのまま、整数なら10進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。文字列と整数以外には use("pretty") が必要です。_strcat(s, t) は文字列をつなぎます。
  • _index_get(a, i)・_index_set(a, i, e) は添字の読み書きで、種類ごとの動きは添字と置き換えにあります。subst(t, f) は木 t の置き換えです。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}
