変数束縛

束縛は定義（Def）と代入（Set）の2つです。

定義と代入

Def{x, e} は書いた場所で新しい変数を定義します。同じ名前をもう一度定義しても新しい変数で、前に作った関数は前の変数を指したままです。Set{x, e} は今ある変数への代入なので、前に作った関数からも新しい値が見えます。

r_scope_redefine.pk

Def{f, Lambda{Tuple{x}, 1}}
Def{g, Lambda{Tuple{}, Apply{f, Tuple{0}}}}
Def{f, Lambda{Tuple{x}, 2}}
Apply{println, Tuple{Apply{g, Tuple{}}}}

Def{h, Lambda{Tuple{x}, 1}}
Def{k, Lambda{Tuple{}, Apply{h, Tuple{0}}}}
Set{h, Lambda{Tuple{x}, 2}}
Apply{println, Tuple{Apply{k, Tuple{}}}}

出力

1
2

右辺から見えるのは前の x で、なければ未定義です。自分を呼ぶ関数は、先に Declare{f} で名前を作り、Set{f, Fusion{f, Lambda{...}}} で関数を足します（場合を足す）。

bd_recursion.pk

Declare{fact}
Set{fact, Fusion{fact, Lambda{Tuple{n},
    If{Apply{_eq, Tuple{n, 0}}, 1,
        Apply{_mul, Tuple{n, Apply{fact, Tuple{Apply{_sub, Tuple{n, 1}}}}}}}}}}
Apply{println, Tuple{Apply{fact, Tuple{5}}}}

出力

120

e_bd_define_self.pk

Def{x, Apply{_add, Tuple{x, 1}}}

出力

undefined variable: x

定義と代入の左辺の UnQuote

QuasiQuote の中では、Def と Set の左辺を UnQuote{x} と書くと、x の値のシンボルに置き換わります。x の値が Quote{true} なら、Def{true, e} と同じくプログラムを止めます。

bd_quasi.pk

Def{x, Quote{i}}
Apply{println, Tuple{QuasiQuote{Do{Def{UnQuote{x}, 0}, Set{UnQuote{x}, Apply{_add, Tuple{UnQuote{x}, 1}}}}}}}

出力

Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}}
