変数束縛

束縛は定義（:=）と代入（=）の2つです。名前をまとめる module と import もここに書きます。

定義と代入

x := e は書いた場所で新しい変数を定義します。同じ名前をもう一度定義しても新しい変数で、前に作った関数は前の変数を指したままです。x = e は今ある変数への代入なので、前に作った関数からも新しい値が見えます。

r_scope_redefine.pk

f(x) := 1
g() := f(0)
f := (x) -> 2
println(g())

h(x) := 1
k() := h(0)
h = (x) -> 2
println(k())

出力

1
2

右辺から見えるのは前の x で、なければ未定義です。自分を呼ぶ関数は f(p, ...) := e と書きます。

bd_recursion.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(5))

出力

120

e_bd_define_self.pk

x := x + 1

出力

undefined variable: x

複合代入と組の分割

x += e は x = x + e と同じで、-=・*=・/=・%= も同じ形です。a[i] += e は a と i を1回だけ評価します。左辺は変数か a[i] で、t.f += e は書けません。

t1_compound.pk

# x += e is x = x + e. The same goes for -=, *=, /= and %=.

x := 10
x += 5
println(x)
x -= 3
println(x)
x *= 2
println(x)
x /= 4
println(x)
x %= 4
println(x)

# the element of an array
a := array(3)
a[0] = 1
a[1] = 2
a[2] = 3
a[1] *= 10
a[2] += a[1]
println(Tuple{a[0], a[1], a[2]})

# the index is evaluated once
n := 0
next() := {
    n += 1
    n - 1
}
a[next()] += 100
println(Tuple{a[0], a[1], n})

# in a loop
sum := 0
i := 1
while (i <= 10) {
    sum += i
    i += 1
}
println(sum)

出力

15
12
24
6
2
Tuple{1, 20, 23}
Tuple{101, 20, 1}

組の分割

(a, b) := e は組 e の要素で変数を定義し、(a, b) = e は定義済みの変数に代入します。右辺を先にすべて評価するので、(a, b) = (b, a) は入れ替えです。

t1_destructure.pk

# (a, b) := e defines several variables from the elements of a tuple

(a, b) := (1, 2)
println(a + b)

# swap
(a, b) = (b, a)
println(Tuple{a, b})

# a function that returns two values
divmod(x, y) := (x / y, x % y)
(q, r) := divmod(17, 5)
println(Tuple{q, r})

# in a function and in a loop
fib(n) := {
    (x, y) := (0, 1)
    i := 0
    while (i < n) {
        (x, y) = (y, x + y)
        i = i + 1
    }
    x
}
println(fib(10))

出力

3
Tuple{2, 1}
Tuple{3, 2}
55

要素の数が名前の数と違う組と、組でない値はエラーです。

出力

module

module m { ... } は、本体の定義を名前 m の下にまとめます。本体が返す値が module の値で、export を付けた定義が欄になります。欄にない名前を . で読むとエラーです。

bd_module.pk

module counter {
    n := 0
    export start := n
    export next() := {
        n = n + 1
        n
    }
    export current() := n
}
counter.next()
counter.next()
println(counter.start)
println(counter.current())

module outer {
    module hidden {
        export f(x) := x + 1
    }
    export module inner {
        export g(x) := hidden.f(x) * 2
    }
}
println(outer.inner.g(3))

出力

0
2
8

e_bd_module_private.pk

module m {
    helper(i) := i / 30
    export f(i) := helper(i)
}
println(m.f(65))
println(m.helper(65))

出力

2
no field helper in Module{}
  • 本体の変数の範囲は引数のない関数の本体と同じです。あとで定義するものを前から呼ぶには fun f と f(p, ...) = e を使います（部分関数と融合）。
  • 本体の定義は本体の変数で、大域変数になりません。外から書き換えられず、外に同じ名前があっても隠しません。外から場合を足せるようにするには、足す関数を export します（m.f(p, ...) = e は書けません）。
  • m は本体を評価したあとに定義されるので、本体から m は見えません。
  • 本体の中で parse を差し替えても残りには反映されません。文法を差し替えるときは module の外に書きます。

export

  • 書けるのは、module の本体の直下にある f(p, ...) := e・x := e・module n { ... } の前だけです。ほかは構文エラーです。
  • export x := e の欄は、本体が値を返した時点の x の値です。あとで代入しても変わらないので、今の値を見せるには x を読む関数を export します（上の start と current）。
  • 内側の module n { ... } は本体の変数 n を定義し、外からは見えません。外に見せるには export module n { ... } と書きます。内側の本体からは、外側の本体でそれより前に定義した変数が見えます。

test

module の本体の直下に test { ... } を書けます。ふだんは何も実行されません。planck0 tools/test.pk <ライブラリ> ... が、使うライブラリの test も含めて実行します。

module bitset {
    export new(n) := i32_array(n / 30 + 1)
    helper(i) := i / 30
    export add(s, i) := {
        w := helper(i)
        s[w] = bit_or(s[w], bit_shl(1, i % 30))
    }
    test {
        assert(helper(65) == 2, "helper")
        s := new(100)
        add(s, 3)
        assert(s[0] == 8, "add")
    }
}
  • 変数の範囲は module の本体と同じで、export のない関数も呼べます。
  • test は本体の評価の途中で実行されるので、その前に定義した変数が見え、m はまだ定義されていません。
  • assert(c, msg) は c が真でなければ msg を書いてステータス 1 で止まります。
  • 1つのブロックに書ける式は 64 個までです。

import

import a::b は use("a/b") と同じ読み込みで、同じファイルは1度だけ読まれます。最後の名前が、そのファイルが定義する module の名前です。取り込み方はパスのあとに続けます。

書き方意味
import m読み込むだけ。欄は m.f で読む
import m as nn := m を足す
import m (x, y)x := m.x・y := m.y を定義する
import m (*)すべての欄を同じ名前で定義する
import m hiding (x, y)x と y 以外のすべての欄を同じ名前で定義する

i_import.pk

# import: the module of a library under the names that are chosen

import bitset as bs
s := bs.new(100)
bs.add(s, 3)
bs.add(s, 42)
println(bs.to_list(s))

# only the listed fields are defined
import bitset (has, count)
println(has(s, 42))
println(count(s))

# all the fields but the hidden ones
import bitset hiding (new, add)
println(to_list(s))

出力

Cons{3, Cons{42, Nil{}}}
true
2
Cons{3, Cons{42, Nil{}}}
  • as n は (x, y)・(*)・hiding (...) の前に置けます。as・(...)・hiding は m と同じ行に書きます。
  • m にない欄を (x, y) に書くと、. で読むときと同じエラーです。
  • 関数の中に書くと、(*) と hiding は大域変数を、(x, y) と as は局所変数を定義します。

定義と代入の左辺の !x

準クオートの中では、x := e と x = e の左辺を !x と書くと、x の値のシンボルに置き換わります（それぞれ Def{!x, e} と Set{!x, e}）。x の値が 'i のとき、`{ !x := 0; !x = !x + 1 } は Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}} です。x の値が 'true なら、Def{true, e} と同じくプログラムを止めます。
