3. パターンと融合

無名関数の引数はパターンです。f | g（融合）は、f のパターンが合わなければ g を試す関数で、場合分けはこれで書きます。

t3_fib.pk

fun fib
fib = (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

左から試して最初に合った腕を呼び、どれも合わなければ MatchingFailed を perform します（受け手がなければ matching failed で止まります）。f(p, ...) = e は f = f | (p, ...) -> e と同じです。同じ場所に f があれば := でも定義が加わるので、腕は1行ずつ書けます。

t3_fib_lines.pk

fib(0) := 0
fib(1) = 1
fib(n) = fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

パターン

t3_list.pk

fun len
len = (Nil{}) -> 0 | (_ :: xs) -> 1 + len(xs)
println(len([5, 6, 7]))

fun sum
sum = ([]) -> 0 | (x :: xs) -> x + sum(xs)
println(sum([1, 2, 3, 4]))

swap2 := ([a, b]) -> [b, a] | (xs) -> xs
use("pretty")
put(f"{swap2([1, 2])} {swap2([1, 2, 3])}\n")

出力

3
10
[2, 1] [1, 2, 3]

x :: xs・[a, b]・Head{p, ...}・p @ Int・'none・_ が書けます。一覧はパターンにあります。

融合は値

t3_extend.pk

greet := (_) -> "hello"
put(greet("en")); put("\n")

greet = ("fr") -> "bonjour" | greet
put(greet("fr")); put("\n")
put(greet("de")); put("\n")

出力

hello
bonjour
hello

既存の関数の前に腕を足して代入し直せます。

match

t3_match.pk

classify(n) := match n {
    0 -> "zero"
  | n if n < 0 -> "negative"
  | n if n % 2 == 0 -> "even"
  | _ -> "odd"
}
put(classify(0)); put(" ")
put(classify(-4)); put(" ")
put(classify(6)); put(" ")
put(classify(7)); put("\n")

出力

zero negative even odd

match e { f } は e を1回評価して融合 f に渡します。ガード p if c -> a は c が偽なら次の腕へ進みます。

記号微分

t3_deriv.pk

fun d
d = (n @ Int, x) -> 0
   | (y @ Symbol, x) -> if (y == x) 1 else 0
   | (Add{a, b}, x) -> Add{d(a, x), d(b, x)}
   | (Mul{a, b}, x) -> Add{Mul{d(a, x), b}, Mul{a, d(b, x)}}

println(d('Add{x, 3}, 'x))
println(d('Mul{x, y}, 'x))

出力

Add{1, 0}
Add{Mul{1, y}, Mul{x, 0}}

'Add{x, 3} は評価せずに M式のまま渡すクオートです（6章）。簡約まで入れた版は planck/examples/deriv.pk です。
