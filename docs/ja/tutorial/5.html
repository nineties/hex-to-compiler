5. 代数的エフェクト

handle e with h と perform v は深いハンドラの代数的エフェクトです。継続を何度でも呼べるので、例外・生成器・非決定計算を同じ仕組みで書けます。

例外

t5_exception.pk

safe_div(a, b) := if (b == 0) perform Raise{"division by zero"} else a / b

try(f) := handle Ok{f()} with (Raise{msg}, k) -> Error{msg}

println(try(() -> safe_div(10, 2)))
println(try(() -> safe_div(10, 0)))
println(try(() -> { put("before\n"); safe_div(1, 0); put("after\n") }))

出力

Ok{5}
Error{"division by zero"}
before
Error{"division by zero"}

perform v は、v に合うパターンを持つ一番近いハンドラを h(v, k) で呼びます。k は perform の継続です。

  • ハンドラの値が handle 式の値になります。
  • k を呼ばなければ、残りの計算は捨てられます。
  • 内側のハンドラに合うパターンがなければ、外側のハンドラを試します。

再開

t5_resume.pk

ask() := perform Ask{}

with_answer(v, f) := handle f() with (Ask{}, k) -> k(v)

println(with_answer(21, () -> ask() * 2))
println(with_answer(5, () -> ask() + ask()))

出力

42
10

k(x) は、perform が x を返したものとして計算を再開します。ハンドラは深いので、再開した先の perform も同じハンドラが受けます。

生成器

t5_generator.pk

fun walk
walk = (Leaf{}) -> none
      | (Node{l, v, r}) -> { walk(l); perform Yield{v}; walk(r) }

tree := Node{Node{Leaf{}, 1, Leaf{}}, 2, Node{Leaf{}, 3, Leaf{}}}

handle walk(tree) with (Yield{v}, k) -> { put(f"yield {v}\n"); k(none) }

to_list(t) := handle { walk(t); [] } with (Yield{v}, k) -> v :: k(none)
use("pretty")
put(f"{to_list(tree)}\n")

出力

yield 1
yield 2
yield 3
[1, 2, 3]

同じ walk に対してハンドラが値の使い方を決めます。2つ目は v :: k(none) で結果をリストに集めています。

多重再開

t5_choose.pk

use("list")
use("pretty")
choose(xs) := perform Choose{xs}

all_results(f) := handle [f()] with (Choose{xs}, k) -> concat_map(x -> k(x), xs)

put(f"{all_results(() -> (choose([1, 2]), choose(["a", "b"])))}\n")

出力

[Tuple{1, "a"}, Tuple{1, "b"}, Tuple{2, "a"}, Tuple{2, "b"}]

k は通常の関数で、handle が値を返したあとでも何度でも呼べます。ここでは候補ごとに k を呼んで結果を連結しています。N クイーンを同じ方法で解いたサンプルが planck/examples/queens.pk です。
