9. 変数の範囲

名前がどの変数を指すかは、書かれた位置から式の実行前に決まります。呼んだ側の変数は見えません。

t1_scope.pk

n := 5
read_n() := n
caller() := {
    n := 100
    read_n()
}
println(caller())

x := 1
get() := x
x := x + 1
println(Tuple{x, get()})
x = 10
println(Tuple{x, get()})

出力

5
Tuple{2, 1}
Tuple{10, 1}

read_n() は caller の中の n ではなく、トップレベルの n を読みます。同じ名前を := でもう一度定義すると新しい変数ができ、前に作った関数は前の変数を指したままです。

どの変数も指さない名前

e_undefined.pk

println("start")
println(later)
later := 2

出力

"start"
undefined variable: later

その式を実行する前にプログラムが止まります。later は3行目で定義されていて、2行目からは見えません。

関数に定義を足すか隠すかは3章。
