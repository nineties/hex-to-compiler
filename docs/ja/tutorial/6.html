6. クオートと評価器

ソースは M式に読まれてから評価されます。構文木は通常の値なので、組み立て・検査・評価・文字列への逆変換ができます。

クオート

t6_quote.pk

e := '(1 + 2 * x)
println(e)
x := 10
println(eval(e))

n := 5
println(`(n + !n))

出力

Apply{_add, Tuple{1, Apply{_mul, Tuple{2, x}}}}
21
Apply{_add, Tuple{n, 5}}

'e は Quote{e} で、e の構文木を値にします。演算子は組み込み関数の Apply になります。`e は準クオートで、!e（UnQuote）の所だけ評価して埋めます。eval は木をトップレベルの式としてその場でコンパイルし、実行します。

M式の直接の記述

t6_mexpr.pk

Def{y, 3}
Apply{println, Tuple{Apply{_mul, Tuple{y, y}}}}
println('Def{y, 3} == '(y := 3))

出力

9
true

M式はそのまま式として書けます。

parse と eval の差し替え

t6_eval.pk

old_eval := eval
eval = e -> {
    v := old_eval(e)
    put("=> ")
    println(v)
    v
}
1 + 2
'(a + b)
Point{1, 2}

出力

=> 3
=> Apply{_add, Tuple{a, b}}
=> Point{1, 2}

トップレベルは式ごとに大域変数 parse（文字列 -> Tuple{M式, 残り}）と eval（M式 -> 値）を引き直します。差し替えた関数は次の式から使われます。planck/syntax.pk も途中で parse を差し替えて、planck の構文を読めるようにしています。

unparse

t6_unparse.pk

use("unparse")
t := '(if (n < 0) -n else n * (n + 1))
println(t)
put(unparse.text(t)); put("\n")

出力

If{Apply{_lt, Tuple{n, 0}}, Apply{_sub, Tuple{0, n}}, Apply{_mul, Tuple{n, Apply{_add, Tuple{n, 1}}}}}
if (n < 0) -n else n * (n + 1)

unparse は文法の規則を逆にたどって木を文字列に戻します。::=（7章）で足した規則で読める木も、その規則で文字列に戻ります。

長めのサンプルは planck/examples にあります。
