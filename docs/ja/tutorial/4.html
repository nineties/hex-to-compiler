4. ライブラリ

planck/lib のライブラリも planck の構文で書かれていて、use("name") で読み込みます。一覧はライブラリにあります。

t4_list.pk

use("list")
use("pretty")
xs := range(1, 11)
put(f"{xs}\n")
put(f"{map(x -> x * x, xs)}\n")
put(f"{filter(x -> x % 2 == 0, xs)}\n")
println(foldl((a, b) -> a + b, 0, xs))
put(f"{list.sort((a, b) -> a < b, [5, 3, 9, 1])}\n")
put(f"{list.zip([1, 2, 3], ["a", "b", "c"])}\n")

演算子は関数として渡せないので、(a, b) -> a + b のように無名関数で書きます。

t4_for.pk

use("list")
for (x in range(1, 4)) println(x * 10)

total := 0
for ((name, n) in [("apple", 3), ("pear", 5)]) {
    put(f"{name}: {n}\n")
    total = total + n
}
println(total)

for (p in xs) body はリストかベクタの要素をパターン p に当てます。

t4_table.pk

use("list")
use("string")
use("table")
count := table.new()
for (w in string.split("the cat and the hat", " "))
    table.set(count, w, table.get(count, w, 0) + 1)
for (k in list.sort(string.string_less, table.keys(count)))
    put(f"{k} {table.get(count, k, 0)}\n")

use("vector")
v := vector.new()
vector.push(v, "a")
vector.push(v, "b")
println(vector.len(v))
println(vector.get(v, 1))

表とベクタは t[key]・v[i] でも読み書きできます（10章）。
