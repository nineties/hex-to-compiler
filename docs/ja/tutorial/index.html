planck チュートリアル

planck は記号処理と言語処理のための言語です。式は M式に読み替えて評価され、構文も packrat パーサの規則としてプログラムから拡張できます。各章は例を1つ動かして考え方を見せます。定義はリファレンスにあります。

実行

各章の例の「実行」ボタンは、ブラウザの中で PlanckVM を動かして出力を表示します。Playground は、式を1つずつ入力して値を確かめる REPL です。
