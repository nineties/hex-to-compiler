10. 添字と置き換え

a[i] と a[i] = v は _index_get と _index_set の呼び出しです。種類ごとの関数を | でつないだものなので、利用者が自分の種類を足せます。

t9_index.pk

use("table")
a := array(3)
a[0] = 10
a[1] = a[0] + 5
a[2] = a[1] * 2
println(a[2])
s := "planck"
println(s[1])
t := table.new()
t['x] = 1
t['y] = 2
println(t['x] + t['y])
println(t['z])
xs := [10, 20, 30]
println(xs[1])

文字列・リスト・組・M式は不変で、書き込むとプログラムが止まります。

種類の追加

t9_kind.pk

use("table")
_index_get = (Counts{t}, k) -> table.get(t, k, 0) | _index_get
_index_set = (Counts{t}, k, n) -> table.set(t, k, n) | _index_set
c := Counts{table.new()}
for (w in ["a", "b", "a", "a"]) c[w] = c[w] + 1
println(c["a"])
println(c["b"])
println(c["z"])

融合の先頭に自分の種類を置き、残りは元の関数に回します。

木の書き換え

t9_rewrite.pk

use("unparse")
step(e) := e[
    Apply{'_add, Tuple{a @ Int, b @ Int}} -> a + b
  | Apply{'_mul, Tuple{a @ Int, b @ Int}} -> a * b
  | Apply{'_add, Tuple{a, 0}} -> a
  | Apply{'_mul, Tuple{a, 1}} -> a
]
simplify(e) := {
    println(unparse.text(e))
    n := step(e)
    while (n != e) {
        e = n
        println(unparse.text(e))
        n = step(e)
    }
    e
}
simplify('(x * 1 + (2 + 3) * 4 + 0))

t[p -> a | q -> b] は subst(t, ...) で、木の各部分を根から順に試し、合えば置き換えて内側は試しません。変わらなくなるまで繰り返します。
