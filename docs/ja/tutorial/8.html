8. レコード・局所関数・脱出

record は新しい型と、そのデータを作る関数を定義する宣言です。return・break・continue は5章のエフェクトとして実装されています。

t8_record.pk

record Point(x, y) = point
p := point(3, 4)
println(p.x * p.x + p.y * p.y)

move(p, dx) := p with { x = p.x + dx }
println(move(p, 10))

出力

25
Point{13, 4}

型 Point と作る関数 point は別の名前です。x @ Point のパターンで型を調べ、with で欄を替えたコピーを作ります。

局所関数と脱出

t8_local.pk

parity(n) := {
    fun is_odd
    is_even(n) := if (n == 0) true else is_odd(n - 1)
    is_odd(n) = if (n == 0) false else is_even(n - 1)
    if (is_even(n)) "even" else "odd"
}
put(parity(10)); put("\n")
put(parity(7)); put("\n")

出力

even
odd

互いに呼び合う関数は、先に fun f で名前を宣言し、あとで f(x) = ... で埋めます。

t8_return.pk

find_first(p, xs) := {
    for (x in xs) if (p(x)) return x
    none
}
println(find_first(x -> x > 3, [1, 5, 2, 7]))
println(find_first(x -> x > 9, [1, 5, 2, 7]))

n := 0
odd_sum := 0
while (true) {
    n = n + 1
    if (n > 10) break
    if (n % 2 == 0) continue
    odd_sum = odd_sum + n
}
println(odd_sum)

出力

5
none
25

for の本体は関数ですが、その中の return は外の関数から抜けます。break・continue の対象は一番内側の while か for です。
