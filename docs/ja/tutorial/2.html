2. 値と M式

データ構造もプログラムも M式 Head{a, ...} で表します。宣言なしに作れ、== は構造で比べます。

t2_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(Point{1, 2} == Point{1, 2})
println(push(p, 5))

文字列の長さと位置は UTF-8 の文字単位で、strlen("あい") は 2 です。リストは Cons と Nil、組は Tuple の M式で、[1, 2] や (a, b) はその書き方です。

t2_lists.pk

xs := [1, 2, 3]
println(xs)
ys := 0 :: xs
println(ys)

use("pretty")
put(f"{ys}\n")

println(())
println((1, "a"))

値の種類はデータモデルにあります。
