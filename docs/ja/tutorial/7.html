7. 文法の拡張

planck の構文は PEG の規則の集まりで、::= は規則を定義または置き換えます。宣言の次のトップレベルの式から、新しい規則で読まれます。

t7_unless.pk

primary ::= 'unless "(" c:expr ")" a:expr { `If{!c, none, !a} } | ...

unless (1 > 2) put("1 > 2 is false\n")
unless (1 < 2) put("not printed\n")

出力

1 > 2 is false
  • 末尾の ... はその規則の直前の定義で、新しい選択肢は既存の前に入ります。
  • c:expr は規則 expr の値をラベル c に束縛します。
  • { ... } は動作で、その値が規則の値です。ここでは準クオートで構文木を作っています。

二項演算子とブロック

t7_pipe.pk

union ::= x:union "|>" f:arrow { `Apply{!f, Tuple{!x}} } | ...

double(x) := 2 * x
3 |> double |> double |> println

出力

12

直接の左再帰が書けるので、x:union "|>" ... は左結合です。

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

出力

planck!
planck!
planck!

別の文法

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

出力

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

動作は木でなく任意の値を返せます。calc{| ... |} は構文解析の時点で読み、実行時の文字列は peg_parse(rule, s) で読みます（文法の拡張）。
