1. 式・束縛・関数

文はなく、if・while・ブロックも式です。値を返す式を組み合わせて書きます。

t1_hello.pk

put("Hello, world!\n")

出力

Hello, world!

t1_vars.pk

x := 10
y := x * 2
println(y)
x = x + 1
println(x)

出力

20
11

t1_func.pk

square(n) := n * n
println(square(12))

add3(a, b, c) := a + b + c
println(add3(1, 2, 3))

twice := f -> x -> f(f(x))
println(twice(square)(3))

出力

144
6
81
  • := は定義、= は既存の変数への代入です。関数の中で := した変数は外から見えません（変数の範囲）。
  • 偽は false だけです。0 も none も真です。
  • 関数名と ( の間に空白は置けません。

ブロックと閉包

t1_rec.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(10))

make_counter() := {
    n := 0
    () -> { n = n + 1; n }
}
c := make_counter()
c(); c()
println(c())

出力

3628800
3

{ ... } は最後の式の値を返します。関数は閉包で、捕らえた変数を書き換えられます。
