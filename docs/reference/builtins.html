組み込み関数

use なしで使える関数です。planck0 の組み込みと、init.pk・peg.pk・syntax.pk が定義するものがあります。

出力

print(x) は値を書き、println(x) はそのあと改行します。文字列は引用符つきで書かれます。put(s) は文字列の中身をそのまま書きます。

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

出力

42 "abc"
abc
Point{1, "a"}

整数と比較

演算子 + - * / % と比較演算子はこれらの関数の呼び出しに読み替えられます（糖衣が呼ぶ名前）。_ のない名前の関数はありません。演算子を関数として渡すには (a, b) -> a + b のように無名関数に書きます。

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

出力

7
9
3
1
-3
36

M式と文字列

  • push(Head{a, ...}, x) は Head{a, ..., x} です。
  • mexpr(h, Tuple{a, ...}) は頭 h の M式 h{a, ...} を作ります。
  • symname(sym) はシンボルの名前を文字列で返します（intern の逆）。intern(s) は名前が s のシンボルです。
  • strlen(s) はバイト数です。ord(s, i) は i 番目のバイトで、i が範囲の外なら -1 です。
  • substr(s, i, j) は i から j - 1 までのバイトです。_strcat(a, b) は a のあとに b を続けたものです。

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

出力

true
"abc"
65
-1
P{1, 2}
"x"
none
3
true

配列と表

  • array(n) は要素が n 個で、全部 none の新しい配列です。array_get(a, i)・array_set(a, i, x)（x を返す）・array_len(a)。0 から n - 1 の外の位置は実行時エラーです。
  • hash(x) は0以上の整数です。== で等しい値は同じハッシュになります。
  • table() は新しいハッシュ表 Table{a} です。a は配列でできています。table_get(t, key, default)・table_set(t, key, value)。キーは == で比べます。t[key] と t[key] = value でも読み書きできます（添字と置き換え）。

ファイルと言語

  • read_file(path) はファイルの中身です。load(path) はファイルを読んで評価します。
  • use(name) は load("planck/lib/<name>.pk") を1回だけします。
  • parse と eval はトップレベルで使われる関数です。exit(n) は状態 n で終わります。
  • _define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の宣言にあります。
  • parse_mexpr(s) は M式のパーサで、引数と結果は parse と同じです。
  • _to_text(x) は、文字列ならそのまま、整数なら10進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。このため文字列と整数以外を {e} に入れるには use("pretty") が必要です。値を埋め込んだ文字列は左から _strcat でつなぎ、空の部分は省きます。
  • _record_declare(name, fields) は頭 name の欄の名前を決めます（fields は Tuple{f, ...}）。_record_get(t, name) はその欄です。
  • _index_get(a, i) と _index_set(a, i, e) は a[i] と a[i] = e が呼ぶ関数で、subst(t, f) は t[f] が呼ぶ関数です（添字と置き換え）。
  • peg_for(xs, f) はリストかベクタ xs の要素ごとに f を呼び、none を返します。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}
