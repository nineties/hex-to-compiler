出力

print(x) は値を書き、println(x) はそのあと改行します。文字列は引用符つきで書かれます。put(s) は文字列の中身をそのまま書きます。

t1_print.pk

print(42)
put(" と ")
println("文字列")
put("put は文字列をそのまま書きます\n")

出力

42 と "文字列"
put は文字列をそのまま書きます

整数と比較

演算子 + - * / % と比較演算子は、これらの関数の呼び出しになります（構文）。関数として渡すこともできます。

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

9
3
1
-3

M式と文字列

  • push(Head{a, ...}, x) は Head{a, ..., x} です。
  • mexpr(h, Tuple{a, ...}) は頭 h の M式 h{a, ...} を作ります。
  • symname(sym) はシンボルの名前を文字列で返します（intern の逆）。intern(s) は名前が s のシンボルです。
  • strlen(s) はバイト数です。ord(s, i) は i 番目のバイトで、i が範囲の外なら -1 です。
  • substr(s, i, j) は i から j - 1 までのバイトです。strcat(a, b) は a のあとに b を続けたものです。

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

出力

true
"abc"
65
-1
P{1, 2}
"x"
none
3
true

配列と表

  • array(n) は要素が n 個で、全部 none の新しい配列です。array_get(a, i)・array_set(a, i, x)（x を返す）・array_len(a)。0 から n - 1 の外の位置は実行時エラーです。
  • hash(x) は 0 以上の整数です。eq で等しい値は同じハッシュになります。
  • table() は配列でできた新しいハッシュ表です。table_get(t, key, default)・table_set(t, key, value)。キーは eq で比べます。

ファイルと言語

  • read_file(path) はファイルの中身です。load(path) はファイルを読んで評価します。
  • use(name) は load("planck/lib/<name>.pk") を 1 回だけします。
  • parse と eval はトップレベルで使われる関数です。exit(n) は状態 n で終わります。
  • define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の宣言にあります。
  • parse_mexpr(s) は M式のパーサで、引数と結果は parse と同じです。
  • to_text(x) は、文字列ならそのまま、整数なら 10 進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。だから文字列と整数以外を {e} に入れるときは use("pretty") が要ります。値を埋め込んだ文字列は左から strcat でつなぎ、空の部分は省きます。
  • record_declare(name, fields) は頭 name の欄の名前を決めます（fields は Tuple{f, ...}）。record_get(t, name) はその欄です。
  • peg_for(xs, f) はリストかベクタ xs の要素ごとに f を呼び、none を返します。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{add, Tuple{1, Apply{mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}
