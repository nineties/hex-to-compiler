組み込み関数

use なしで使える関数です。planck0 の組み込みと、init.pk・peg.pk・syntax.pk が定義するものがあります。

出力

print(x) は値を書き、println(x) はそのあと改行します。文字列は引用符つきで書かれます。put(s) は文字列の中身をそのまま書きます。

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

出力

42 "abc"
abc
Point{1, "a"}

整数と比較

演算子 + - * / % と比較演算子はこれらの関数の呼び出しに読み替えられます（糖衣が呼ぶ名前）。_ のない名前の関数はありません。演算子を関数として渡すには (a, b) -> a + b のように無名関数に書きます。

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

出力

7

3
1
-3

M式と文字列

  • push(Head{a, ...}, x) は Head{a, ..., x} です。
  • mexpr(h, Tuple{a, ...}) は頭 h の M式 h{a, ...} を作ります。
  • symname(sym) はシンボルの名前を文字列で返します（intern の逆）。intern(s) は名前が s のシンボルです。
  • strlen(s) は文字数です。ord(s, i) は i 番目の文字の番号で、i が範囲の外なら -1 です。s[i] は i 番目の文字を長さ1の文字列で返します。
  • substr(s, i, j) は i から j - 1 番目までの文字です。_strcat(a, b) は a のあとに b を続けたものです。

r_builtins.pk

println(intern("abc") == 'abc)
println(symname('abc))
println(ord("A", 0))
println(ord("A", 5))
println(mexpr('P, (1, 2)))
a := array(3)
array_set(a, 0, "x")
println(array_get(a, 0))
println(array_get(a, 1))
println(array_len(a))
println(hash("abc") == hash("abc"))

配列と表

  • array(n) は要素が n 個で、全部 none の新しい配列です。array_get(a, i)・array_set(a, i, x)（x を返す）・array_len(a)。0 から n - 1 の外の位置は実行時エラーです。
  • hash(x) は0以上の整数です。== で等しい値は同じハッシュになります。
  • table() は新しいハッシュ表 Table{a} です。a は配列でできています。table_get(t, key, default)・table_set(t, key, value)。キーは == で比べます。t[key] と t[key] = value でも読み書きできます（添字と置き換え）。

平らな配列とビット演算

平らな配列は、タグのない整数を並べた配列です。要素の型は u8（0から255）・u16（0から65535）・i32（整数）で、作った直後は全部0です。

  • u8_array(n)・u16_array(n)・i32_array(n) は要素が n 個の新しい配列です。a[i] と a[i] = x で読み書きでき、plain_get(a, i)・plain_set(a, i, x)（x を返す）も同じです。型に収まらない値と範囲の外の位置は実行時エラーです。
  • plain_len(a) は要素数、plain_kind(a) は 'u8・'u16・'i32 です。plain_copy(dst, di, src, si, n) は src の si から n 個を dst の di 以降に写します。型は同じでなければならず、同じ配列の中で重なってもかまいません。
  • bit_and(a, b)・bit_or(a, b)・bit_xor(a, b)・bit_not(a) は、31ビットの2の補数の整数に対するビットごとの演算です。
  • bit_shl(a, k) は左に k（0から31）ビットずらし、あふれたビットを捨てて31ビットに収めます。bit_shr(a, k) は a を31ビットの符号なしとして右にずらす論理シフト、bit_sar(a, k) は符号を保つ算術シフトです。

b := u8_array(4)
b[0] = 72

println(bit_xor(5, 3))
println(bit_shl(1, 20))

ファイルと言語

  • read_file(path) はファイルの中身で、0のバイトも含みます。read_bytes(path) は同じ中身の u8 配列です。write_file(path, x) は文字列か u8 配列 x の全バイトをファイルに書きます（なければ作り、あれば空にします。0のバイトもそのまま書きます）。chmod(path, mode) はファイルの権限を mode にします（493 が8進の755）。
  • argv() は、C の main の argv と同じ、コマンドラインの文字列の配列です。先頭は実行するプログラムのファイルで、残りがそのプログラムの引数です。planck0 a.pk x y なら "a.pk"・"x"・"y" の3要素です。
  • load(path) はファイルを読んで評価します。トップレベルの式は path を読み込み中のファイルとして評価します。第1引数のプログラムのファイルと planck/init.pk も、実行中はそれぞれが読み込み中のファイルです（変数の範囲）。
  • _set_file(path) は path を読み込み中のファイルにし、前のファイルを返します（なければ none）。
  • use(name) は load("planck/lib/<name>.pk") を1回だけします。
  • parse と eval はトップレベルで使われる関数です。exit(n) は状態 n で終わります。
  • _define_rule(name, e) は構文解析式で規則を定義します（packrat パーサ）。peg_parse は文法の宣言にあります。
  • parse_mexpr(s) は M式のパーサで、引数と結果は parse と同じです。
  • _to_text(x) は、文字列ならそのまま、整数なら10進の文字列、それ以外は show(x)（planck/lib/pretty.pk）です。このため文字列と整数以外を {e} に入れるには use("pretty") が必要です。値を埋め込んだ文字列は左から _strcat でつなぎ、空の部分は省きます。
  • _record_declare(name, fields) は頭 name の欄の名前を決めます（fields は Tuple{f, ...}）。_record_get(t, name) はその欄です。
  • _index_get(a, i) と _index_set(a, i, e) は a[i] と a[i] = e が呼ぶ関数で、subst(t, f) は t[f] が呼ぶ関数です（添字と置き換え）。
  • peg_for(xs, f) はリストかベクタ xs の要素ごとに f を呼び、none を返します。

i_parse.pk

println(parse("1 + 2 * 3\nx := 4"))
println(parse_mexpr("Apply{_add, Tuple{1, 2}} rest"))
println(parse("   "))

出力

Tuple{Apply{_add, Tuple{1, Apply{_mul, Tuple{2, 3}}}}, "x := 4"}
Tuple{Apply{_add, Tuple{1, 2}}, "rest"}
Tuple{Eof{}, ""}
