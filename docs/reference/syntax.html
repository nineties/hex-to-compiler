結合

  • |・->・:: は右から結合します。+ - * / % は左から結合します。比較は結合しません（a < b < c とは書けません）。
  • :: は比較より強く、+ - より弱く結合します。a + 1 :: b == c は Cons{a + 1, b} == c です。
  • () で式をまとめます。

if と while

if と while の条件は括弧で囲みます。while の本体 e は任意の式です。if の枝 a・b は、括弧の外に | を含まない式なので、if (c) a else b | g は (if (c) a else b) | g です。複数の式はブロック { ... } にします。

else は、else をまだ持たない一番近い if に付きます。if (a) if (b) x else y は if (a) { if (b) x else y } です。else if (c) ... は else のあとに if の式が続いたものです。if は式なので y = if (c) 1 else 2 と書けます。

record

record T(f, g, ...) は、値 T{a, b, ...} の引数の名前を宣言します。値の作り方は変わりません。t.f は、t の頭について宣言した中で f の位置にある引数です。

頭が違えば同じ名前の欄を持てます。同じ T をもう一度宣言すると名前が置き換わります。. は左の式に空白なしで続けます。頭が宣言されていない値や、欄 f がない値に .f を使うと、メッセージを出してプログラムが止まります。

fun

fun f(p, ...) e はブロックの中で関数を宣言します。f(p, ...) := e と違い、ブロックの fun はすべてブロックの先頭で宣言されるので、後に書いた関数も呼べます。

関数が入るのは fun を書いた場所です。そのためブロックの中でそれより前に宣言した変数が見え、その場所よりあとで呼べます。fun はブロックの中の式としてだけ書けます。x := e と同じく、ブロックを含む関数かプログラムの変数になります。

糖衣が呼ぶ名前

糖衣が読み替える先の関数は名前が _ で始まり、_ のない同名の関数はありません。したがってプログラムの add や index_get という変数は、a + b や a[i] の意味を変えません。

添字と置き換え

a[i] は _index_get(a, i)、a[i] = e は _index_set(a, i, e) で、値は e の値です。[ は a に空白なしで続けます。空白や改行をはさんだ [1, 2] は別の式です。a は x・f(x)・t.f・b[j] のような後置式で、a[i][j] = e は Apply{_index_set, Tuple{a[i], j, e}} です。

_index_get と _index_set は、a の種類ごとの関数を | でつないだもので、次の順に試されます。

文字列・リスト・組・M式は不変です。これらへの a[i] = e は cannot assign to an element of a string, which is immutable: ... のようなメッセージを出してプログラムを止めます。書き換えられるのは配列・平らな配列・表・ベクタと、利用者が足した種類です。文字列・リスト・M式の範囲外の添字と、どの種類にも合わない a[i]・a[i] = e もメッセージを出して止まります。

利用者は _index_get と _index_set に代入して、自分の種類を先頭に足します。

subst(t, f) は木 t を関数 f で書き換えます。t の各部分を根から順に試し、f のパターンが合えばその部分を f の値に置き換え、その内側は試しません。合わなければ引数を順に試して頭は残します。M式でない部分に部分はありません。

t[p -> a | q -> b] は、p -> a | q -> b を括弧に入れた式なので、腕は順に試されます。match と同じくガードを付けられます。t[p if c -> a | q -> b] は p が合って c が成り立つときにその腕を使い、そうでなければ次の腕を試します。どの腕も当てはまらない部分は、中に入って試します。腕の本体は -> までの式なので、本体の中の | は括弧で囲みます。't[f] は t[f] のクオートです。クオートした木を書き換えるには ('e)[f] と書きます。

r_rewrite.pk

use("unparse")
t := '(x * 1 + 0 * y)
println(unparse(t[Apply{'_mul, Tuple{a, 1}} -> a | Apply{'_mul, Tuple{0, _}} -> 0]))
# with a guard: 1 * 2 is skipped and its parts are tried
u := '(1 * 2 + 3 * 4)
println(unparse(u[Apply{'_mul, Tuple{a @ int, b @ int}} if a > 1 -> a * b]))

出力

"x + 0"
"1 * 2 + 12"

for

for (p in e) a は、リストかベクタ e の要素ごとに、要素をパターン p に当てて a を評価します。値は none です。a から見えるループの外の変数は共有され、a から書き換えられます。

return・break・continue

return e は、それを含む関数の呼び出しを値 e で終えます。e がなければ none です。e は return と同じ行で始め、-> までの式で、括弧の外に |・:=・= を含みません。break は、それを含む一番内側の while か for を終えます。

これらはエフェクトです。本体に return がある関数は Handle{body, (Return{v}, k) -> v} に、本体に break があるループは Handle{loop, (Break{}, k) -> none} に読み替えられます。continue は、それを含む一番内側の while か for の次の回に進みます。本体に continue があるループでは、本体が Handle{body, (Continue{}, k) -> none} に読み替えられます。ループの外の continue は unhandled effect: Continue{} でプログラムを止めます。

for の本体や match の場合の中の return は、それらを囲む関数のものです。中に書いた関数の中の return は、その関数のものです。

match

match e { f } は e を1回だけ評価し、関数 f に渡して呼びます。f は | までの式で、ふつうは1引数の関数を | でつないだものです。つないだ各関数を腕と呼ぶので、e に合うパターンを持つ最初の腕が選ばれます。腕の引数は1つです。(a, b) -> x は2引数で、((a, b)) -> x が組を取ります。| は行頭に書けます。2つ目以降の腕は、ふつう次のように書きます。

match e {
    p -> a
  | q -> b
}

(p, ...) if c -> e | g のガード if c は、引数が合ったあとに、その変数を使って評価されます。偽のとき、または引数が合わないときは、同じ引数で g を呼びます。g はそのあとの腕です。| g がなければ、パターンの合わない関数を呼んだときと同じく失敗します。g は、関数が括弧の中にあっても、文面で | によりその関数の後ろにつながるものです（(p if c -> a) | g）。h := p if c -> a のあとの h | g のように変数で渡したガード付きの関数は、g を呼びません。match のガードと e は ?: の階層までの式なので、無名関数は括弧で囲みます。関数は % で始まる名前の変数を束縛します。これらはどの識別子とも重なりません。

引数のパターン

引数 p と for のパターンは or までの式として書き、上の表の M式で、値・パターン・M式のパターンとして照合されます。次の規則があります。

  • 演算子や呼ばれる関数の名前はシンボルです。a + b は Apply{Quote{_add}, Tuple{a, b}}、-a は Apply{Quote{_sub}, Tuple{0, a}}、f(p, ...) は Apply{Quote{f}, Tuple{p, ...}} なので、x + 1・-x・f(1) の木に合います。a and b・a or b は If{a, b, Quote{false}}・If{a, Quote{true}, b} です。
  • ほかの識別子は変数です。Head{p, ...} の引数はパターンなので、Apply{f, Tuple{x}} は引数1つの任意の関数の呼び出しに合い、f を束縛します。
  • 'e は式 e の Quote{e} です。
  • 書ける形は、演算子 or and not == != <= >= < > :: + - * / %、単項の - と '、f(p, ...)、p @ type、Head{p, ...}、識別子・整数・文字列、()・(p)・(p, q, ...)・[p, ...] です。結合は式と同じで、a @ int + b @ int は (a @ int) + (b @ int) です。

字句

  • 識別子は [A-Za-z_][A-Za-z0-9_]* です。ただし次の予約語は除きます。
    if else while and or handle with perform match record for in return break continue fun
  • 整数は10進（10・-3）・0x1f・0o17・0b101 です。
  • 文字列は1行の "..." で、エスケープ \a \b \t \n \v \f \r \" \' \\ が使えます。f"...{e}..." は式 e の値を埋め込みます。e の中に文字列や f 文字列を書けます。{{ と }} は波括弧そのものです。f の付かない文字列は何も埋め込みません。
  • # から行の終わりまではコメントです。
  • f(a) の f と ( の間、a[i] の a と [ の間、Head{a} の Head と { の間には空白を入れません。

式の区切り

ブロックの中の式は ; か改行で区切ります。トップレベルの式は ;・改行・次の式の始まりのどれかで終わります。

2項の - は左の式と同じ行に書きます。したがって -1 で始まる行は新しい式です。ほかの二項演算子は行頭に書けます。
