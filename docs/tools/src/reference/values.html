値・パターン・M式

評価されるのは M式です。ここでは値の種類、M式の評価のされ方、パターン、エフェクト、トップレベルの決まりをまとめます。

M式

M式の書き方はシンボル（x）・整数（42・-1）・文字列（"abc"）と Head{a, b, ...} です。トップレベルの式として置いた文字列は何もしないので、コメントとして使えます。

これ以外の頭を持つ M式、たとえば Cons{x, y} はコンストラクタです。引数を評価し、同じ頭の M式を作ります。

パターン

引数のパターンは次のどれかです。

  • 変数 x。_ は何にでも合い、何も束縛しません
  • 整数か文字列。等しい値に合います
  • Quote{v}。等しい値に合います（例 Quote{false}）
  • Head{p, ...}。頭と引数の数が同じ M式に合います
  • _TypeOf{p, type}。p が合い、値の種類が typeof の示す type のときに合います

構文では 'none が Quote{none}、x @ int が _TypeOf{x, int}、x :: xs と [a, b] が Cons のパターンになります。

代数的エフェクト

Handle{body, handler} は body を評価します。Perform{v} は、合うパターンを持つ一番近い handler(v, k) を呼びます。k は Perform の継続です。ハンドラは深く、継続の中でも有効なままです。どのパターンにも合わなければ、エフェクトは外側のハンドラに回ります。

k はふつうの関数で、何度でも呼べます。Handle が値を返したあとでも呼べます。再開した複数の計算の間で変数は共有されます。

トップレベル

トップレベルの式を読むたびに、大域変数 parse と eval を引き直します。だからプログラムがこれらを差し替えると、次の式から新しい定義で処理されます。プログラムの中の Apply{eval, ...} も、差し替えた eval を呼びます。

  • parse：文字列 -> Tuple{M式, 文字列の残り}。空白は自分で読み飛ばし、空白しか残っていなければ Tuple{Eof{}, ""} を返します。差し替える parse は Eof{} をそのまま通します。
  • eval：M式 -> 値。
