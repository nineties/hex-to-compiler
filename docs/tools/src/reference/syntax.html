構文

式は M式に読み替えられ、その M式がいつもどおり評価されます。M式もそのままこの構文の式として書けます。

式と M式

実際に木を出してみると次のようになります。

結合

  • |・->・:: は右から結合します。+ - * / % は左から結合します。比較は結合しません（a < b < c とは書けません）。
  • :: は比較より強く、+ - より弱く結合します。a + 1 :: b == c は Cons{a + 1, b} == c です。
  • () で式をまとめます。

if と while

if と while の条件はかっこで囲みます。本体 a・b・e はどんな式でもかまいません。式を何個も書くときはブロック { ... } にします。

else は、else をまだ持たない一番近い if に付きます。if (a) if (b) x else y は if (a) { if (b) x else y } です。else if (c) ... は else のあとに if の式が続いたものです。if は式なので y = if (c) 1 else 2 と書けます。

record

record T(f, g, ...) は、値 T{a, b, ...} の引数の名前を宣言します。値の作り方は変わりません。t.f は、t の頭について宣言した中で f の位置にある引数です。

頭が違えば同じ名前の欄を持てます。同じ T をもう一度宣言すると名前が置き換わります。. は左の式に空白なしで続けます。頭が宣言されていない値や、欄 f がない値に .f を使うと、メッセージを出してプログラムが止まります。

fun

fun f(p, ...) e はブロックの中で関数を宣言します。f(p, ...) := e と同じですが、ブロックの fun は全部ブロックの先頭で宣言されます。だからどの関数も、あとに宣言した関数を呼べます。

関数が入るのは fun を書いた場所です。そのためブロックの中でそれより前に宣言した変数が見え、その場所よりあとで呼べます。fun はブロックの中の式としてだけ書けます。x := e と同じく、ブロックを含む関数かプログラムの変数になります。

for

for (p in e) a は、リストかベクタ e の要素ごとに、要素をパターン p に当てて a を評価します。値は none です。a の中から見えるループの外の変数は共有されるので、a から書き換えられます。

return・break・continue

return e は、それを含む関数の呼び出しを値 e で終えます。e がなければ none です。e は return と同じ行で始めます。break は、それを含む一番内側の while か for を終えます。

これらはエフェクトです。本体に return がある関数は Handle{body, (Return{v}, k) -> v} に、本体に break があるループは Handle{loop, (Break{}, k) -> none} に読み替えられます。continue は、それを含む一番内側の while か for の次の回に進みます。本体に continue があるループでは、本体が Handle{body, (Continue{}, k) -> none} に読み替えられます。ループの外の continue は unhandled effect: Continue{} でプログラムを止めます。

for の本体や match の場合の中の return は、それらを囲む関数のものです。中に書いた関数の中の return は、その関数のものです。

match

match は e を 1 回だけ評価し、パターン p が合う最初の場合を選びます。場合は ; か改行で区切ります。本体 a はどんな式でもかまいません。

ガード if c は p が合ったあとに、p の変数を使って評価されます。成り立たなければ、その場合より後ろが試されます。e と c は ?: までの式なので、無名関数を書くときはかっこが要ります。どの場合も当てはまらないと、パターンの合わない関数を呼んだときと同じく失敗します。

match はガードのある場合の中で %v と %r0・%r1 ... を使います。これらはどの識別子とも重なりません。

引数のパターン

引数 p はパターンです。x・1・'none・Cons{x, xs}・x @ int のような単項の式と、Cons{p, q} を表す p :: q が書けます。たとえば (x :: xs) -> ... や f(x :: y :: rest) := ... です。パターンの意味は値・パターン・M式にあります。

字句

  • 識別子は [A-Za-z_][A-Za-z0-9_]* です。ただし次の予約語は除きます。
    if else while and or handle with perform match record for in return break continue fun
  • 整数は 10 進（10・-3）・0x1f・0o17・0b101 です。
  • 文字列は 1 行の "..." で、エスケープ \a \b \t \n \v \f \r \" \' \\ が使えます。f"...{e}..." は式 e の値を埋め込みます。e の中に文字列や f 文字列を書いてもかまいません。{{ と }} は波かっこそのものです。f の付かない文字列は何も埋め込みません。
  • # から行の終わりまではコメントです。
  • f(a) の f と ( の間、Head{a} の Head と { の間には空白を入れません。

式の区切り

ブロックの中の式は ; か改行で区切ります。トップレベルの式は ;・改行・次の式の始まりのどれかで終わります。

2 項の - は左の式と同じ行に書きます。だから -1 で始まる行は新しい式です。ほかの 2 項演算子は行の頭に書いてもかまいません。
