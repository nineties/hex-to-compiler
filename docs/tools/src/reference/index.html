リファレンス

planck の決まりを引くためのページです。言語の正式な定義は planck/SPEC.rst で、このリファレンスはその内容を例つきで日本語にしたものです。食い違いがあれば SPEC が正しいとします。

目次

  • 構文 — 式と M式の対応・結合の強さ・字句・if・for・return・match・fun・record
  • 値・パターン・M式 — 値の種類・特殊形式・パターン・エフェクト・トップレベル
  • 文法の宣言 — ::=・項目・name{| text |}・peg_parse
  • 組み込み関数 — 出力・整数・M式・文字列・配列・ファイル・言語
  • ライブラリ — list・vector・string・table・symbol・error・pretty・unparse・base

プログラムの読まれ方

最初に planck/init.pk が読まれ、そのあと渡されたファイルが順に動きます。ファイルの中のトップレベルの式は、1 つ読んでは評価する、をくり返します。

planck/init.pk・planck/peg.pk・planck/syntax.pk は M式で書かれています。planck/syntax.pk は planck/peg.pk の packrat パーサで構文を定義し、parse を差し替えます。だから渡されたファイルはこの構文で読まれます。
