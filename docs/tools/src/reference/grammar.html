文法の宣言

::= は文法の規則を定義または置き換えます。planck の構文自体が同じ規則でできているので、宣言で後続の式の構文を拡張できます。

::=

name ::= alternative | ... は文法の規則 name を定義するか置き換えます。構文の規則（expr・primary・block・add_expr ...・ident・integer・string）も同じ文法の規則です。選択肢に ... と書くと、その規則のそれまでの定義を表します。

選択肢は項目の列で、末尾に動作 { ... } を付けられます。項目と動作は ::= や | と同じ行に書きます。

項目

項目合うもの
"text"空白とコメントを読み飛ばしたあとの、その文字列
'wordその単語。後ろに [A-Za-z0-9_] が続かないもの
nameその規則
(a | b ...)選択
e*・e+・e?0回以上・1回以上・省略可能
&e・!e肯定・否定の先読み。入力を消費しない
label:ee。その値が動作の中で変数 label になる

値と試す順番

選択肢は順に試されます（PEG）。選択肢の値は、動作があれば動作の値、項目が1つならその項目の値、それ以外は項目の値の Tuple{v, ...} です。e* と e+ の値は Tuple{v, ...}、e? の値は Tuple{} か Tuple{v} です。

規則の結果は位置ごとに覚えておきます（packrat 構文解析）。規則は直接の左再帰を書けます（sum ::= a:sum "+" b:term { ... } | term）。左再帰は左から結合します。

peg_parse

peg_parse(rule, s) は s の先頭を規則で読み、Tuple{値, 残り} を返します。空白しか残っていなければ Tuple{Eof{}, ""}、読めなければ Tuple{SyntaxError{...}, ""} です。

規則で読む文字列

name{| text |} は、式を読むときに規則 name で text を読む式です。name と {| の間に空白は入れません。

text を読むのはその規則だけです（規則の文字列・単語・規則と、それらの空白とコメント）。まわりの式の字句では読みません。どこで終わるかは規則が決め、そのあと空白をはさんで |} が続きます。したがって規則が読む |} や }（規則の文字列や括弧の中のもの）は text の一部です。規則が失敗したときや |} がないときは、その式の構文エラーです。位置は規則が text の中で一番先まで進んだ所です。

式の値は規則の値で、定数として入ります。

規則は、その文字列を含む式が読まれるより前に評価される式で定義しておきます。

文法を読む

peg_sources は規則の名前から、define_rule に渡された構文解析式への表です。動作は評価する前の形で、... はそれまでの定義に置き換えてあります。peg_version は define_rule のたびに増えます。
