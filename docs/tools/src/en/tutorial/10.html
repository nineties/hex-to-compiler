10. Indexing and rewriting

a[i] and a[i] = v call _index_get and _index_set. These are functions joined by |, one for each kind of value, so a program can add its own kind. t[p -> e | ...] rewrites a syntax tree.

Reading and writing

Indexing works on arrays, strings, tables, lists and M-expressions. For an M-expression, an integer index is a position and a symbol index is a field declared by record. A missing key of a table gives none.

Arrays, plain arrays, tables and vectors can be written. Strings, lists, tuples and M-expressions are immutable: s[0] = 1 stops the program with cannot assign to an element of a string, which is immutable: .... An index out of range stops the program in the same way.

Adding a kind

Put the new kind at the front of the fusion, and pass the other kinds to the original _index_get. Here an M-expression with the head Counts is a table that counts a missing key as 0.

Rewriting trees

t[p -> a | q -> b] is subst(t, p -> a | q -> b). Each part of the tree t is tried from the root down. When the pattern of an arm matches, the part is replaced and its inside is not tried. When no arm matches, the arguments are tried in order. An arm can have a guard p if c -> a, as in match.

A replacement does not try its inside, so repeat the rewrite until nothing changes. The head of an operator tree is a name with _, such as '_add. To rewrite a quoted tree, write ('e)[f]. 't[f] is the quotation of t[f].
