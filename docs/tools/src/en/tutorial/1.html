1. Expressions, bindings, functions

There are no statements. if, while and blocks are expressions, so programs are built by combining expressions that return values.

  • := defines a variable and = assigns to an existing one. A variable defined by := in a function is not visible outside it.
  • Only false is false. 0 and none are true.
  • There is no space between a function name and (.

Blocks and closures

{ ... } returns the value of its last expression. A function is a closure and can assign to the variables it captures.
