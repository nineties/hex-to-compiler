1. Expressions, bindings, functions

There are no statements. if, while and blocks are expressions.

Hello, world

Output and integers

Integer / truncates toward zero. Literals are decimal, 0x, 0o or 0b. Expressions are separated by a newline or ;. # starts a comment up to the end of the line.

print and println write a value as it is written in source. put writes only the contents of a string.

Bindings

:= defines a variable and = assigns to an existing one. They are different operations. A variable defined by := in a block is local to the block.

Functions

f(p, ...) := e defines a function. x -> e, (a, b) -> e and () -> e are lambdas. There is no space between a function name and (.

if (c) a else b is an expression. Without else its value is none. Only false is false: 0 and none are true. The logical operators are and, or and not.

Blocks and closures

{ ... } evaluates its expressions in order and returns the value of the last one.

A function is a closure with lexical scope. It can assign to the variables it captures.
