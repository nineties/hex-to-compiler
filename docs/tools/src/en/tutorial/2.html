2. Values and M-expressions

Data structures and programs are both M-expressions.

typeValue
IntInteger: 42, -1, 0x1f
FloatFloat: 1.5
ComplexComplex number, made by complex(1, 2)
StringA string as a sequence of bytes: "abc"
Symbol'apple. true, false and none are symbol literals
ExprHead{a, ...}
FunctionLambda, fusion, builtin function or continuation
ArrayMutable array of fixed length, made by array(n)
PlainMutable array of elements of one type, made by plain_array(kind, n)

Strings

Lengths and positions are in bytes, counted from 0. substr(s, i, j) takes the half-open range [i, j). f"..." embeds the value of each {expression}.

M-expressions

Head{a, ...} is a tree made of a head symbol and a sequence of arguments. It needs no declaration. == compares by structure. There is no space between the head and {.

Lists and tuples

[1, 2, 3] is Cons{1, Cons{2, Cons{3, Nil{}}}}, and x :: xs is the syntax of Cons{x, xs}. (a, b) is Tuple{a, b}. println writes an M-expression in the M-expression form. After use("pretty"), f"..." writes a list as [...].
