2. Values and M-expressions

There are nine kinds of values: integers, floats, complex numbers, strings, symbols, M-expressions, functions, arrays and plain arrays. Data structures and programs are both M-expressions.

typeValue
IntInteger: 42, -1, 0x1f
FloatFloat: 1.5
ComplexComplex number, made by complex(1, 2)
StringA string as a sequence of bytes: "abc"
Symbol'apple. true, false and none are symbols too

Strings

Lengths and positions are in bytes, counted from 0. substr(s, i, j) is the half-open range [i, j). f"..." embeds the value of {expression}.

M-expressions

Head{a, ...} is a tree made of a head symbol and a sequence of arguments. It needs no declaration. == compares by structure. planck0 interns M-expressions that contain no string, so the comparison is a pointer comparison. There is no space between the head and {.

Lists and tuples

[1, 2, 3] is Cons{1, Cons{2, Cons{3, Nil{}}}}, and x :: xs is the syntax of Cons{x, xs}. (a, b) is Tuple{a, b}. println writes an M-expression in its own form. After use("pretty"), f"..." writes a list as [...].
