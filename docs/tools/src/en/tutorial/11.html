11. vasm: checking ownership and borrows

use("vasm") lets you write vasm, a low-level language close to machine instructions, inside vasm{| ... |}. A vasm program is a list of functions and structs. The checker rejects ownership and borrow violations, uses after free and reads of uninitialized registers using type rules alone.

The result of the check is the list of VasmErr{kind, loc, msg} that vasm_errors(file, m) returns. A function without an error does not appear in it, and a function has at most one error: the first. The examples in this chapter write the result line by line with the report function in each file.

Ownership and borrows

own i64 is the single owner of an integer allocated by box. region r { ... } names the extent in which a borrow is valid, and &mut r p borrows p for writing inside it. The [r] of bump is a region parameter fixed at each call. A &mut passed to a call is borrowed again for the duration of the call, so m can be used after it.

Use after free

An own that has been freed cannot be read or freed again. Assigning q to p moves the ownership to p, so q cannot be used afterwards.

Automatic release

A value that owns something is released automatically where its owner goes away: at the end of a block or a function, when it is overwritten, when the result of a call is discarded as a statement, and for what is left inside a value that is passed to free. None of the functions above is an error. free is for releasing a value earlier.

Rules for borrows

Any number of shared borrows &r can exist at once. A &mut r is exclusive: while it lives, the original value can be neither read, written nor freed.

Inside and outside of regions

A borrow of an inner region put in an outer register would outlive its region. A borrow of an outer region can be used where a borrow of an inner region is expected, because the outer one lives longer.

Widths of integers

The integer types are i8 to i64 and u8 to u64, and both operands of an operator have the same type. Use as to change the width or the signedness. A literal ranges from -32768 to 32767, so a larger value is built with shifts and |.

Arrays and structs

alloc(n, v) makes an own [T] of n copies of v, and len returns the length. An index is an i64, and checking its range is left to run time. A struct is built by giving every field once. It is copied like an integer unless it owns something.

Exchanging values that own

A value that owns something cannot be copied out of an array element or the target of a pointer, because it would have two owners. swap(p[i], v) puts v in and returns the previous value. Writing a field of a struct register, as in img.body = b, releases the previous value and puts the new one in.

All the rules are in vasm in the reference.
