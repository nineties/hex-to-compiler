6. Quotation and the evaluator

The source is read into M-expressions and then evaluated. A syntax tree is an ordinary value, so it can be built, inspected, evaluated and turned back into a string.

  • 'e makes the syntax tree of e a value. `e is a quasiquote, and only the !e parts are evaluated and filled in.
  • eval compiles a tree on the spot and runs it.

Replacing parse and eval

The top level looks up the global variables parse and eval again for each expression, so a replacement is used from the next one (Extending the grammar).

unparse

unparse follows the grammar rules backwards to turn a tree back into a string. Longer samples are in planck/examples.
