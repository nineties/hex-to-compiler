6. Quotation and the evaluator

The source is read into M-expressions and then evaluated. A syntax tree is an ordinary value, so it can be built, inspected, evaluated and turned back into a string.

Quotation

'e is Quote{e}. Its value is the syntax tree of e. An operator becomes an Apply of a builtin function. `e is a quasiquote: only the !e (UnQuote) parts are evaluated and filled in. eval compiles a tree as a top-level expression on the spot and runs it.

Writing M-expressions

An M-expression can be written directly as an expression.

Replacing parse and eval

For each expression, the top level looks up the global variables parse (string -> Tuple{M-expression, rest}) and eval (M-expression -> value) again. A replacement takes effect from the next expression. planck/syntax.pk also replaces parse at its end to install the planck syntax.

unparse

unparse follows the grammar rules backwards to turn a tree into a string. A tree that a rule added by ::= (chapter 7) can read is turned back by that rule.

Longer samples are in planck/examples.
