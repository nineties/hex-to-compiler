9. Scope of variables

Which variable a name refers to is decided from where it is written, before the expression runs. The variables of the caller are not visible.

read_n() reads the top-level n, not the n inside caller. Defining the same name again with := makes a new variable, and the functions made before keep referring to the old one.

A name that refers to no variable

The program stops before the expression runs. later is defined on the third line and is not visible to the second.

Whether a definition adds a case to a function or hides it is in chapter 3, and the full rules are in the Reference.
