4. Libraries

The libraries in planck/lib are written in the planck syntax and loaded by use("name"). A second use of the same name does nothing.

Lists

An operator cannot be passed as a function. Write a lambda such as (a, b) -> a + b instead. sort is a stable merge sort.

for

for (p in xs) body matches the elements of a list or a vector against the pattern p in order. Its value is none. The body can assign to outer variables.

Strings

Tables and vectors

table(), table_get and table_set are in init.pk and need no use. Keys are compared by ==. The order of table_keys is unspecified. A vector is an array that grows at the end. Tables and vectors can also be read and written by t[key] and v[i] (chapter 9).
