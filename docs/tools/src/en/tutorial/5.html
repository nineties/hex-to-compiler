5. Algebraic effects

perform v calls the nearest handler of a handle as h(v, k). k is the continuation of the perform and can be called any number of times, so exceptions, generators and nondeterminism use the same mechanism.

Exceptions

The value of the handler is the value of the handle expression. When the handler does not call k, the rest of the computation is discarded.

Resumption and generators

k(x) resumes the computation as if the perform returned x. For the same walk, the handler decides how the values are used.

Multiple resumption

Here k is called for each candidate and the results are concatenated. planck/examples/queens.pk solves N-queens this way.
