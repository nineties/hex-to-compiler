planck tutorial

planck is a language for symbolic and language processing. Expressions are read as M-expressions and evaluated, and a program can extend the syntax itself, which is a set of packrat parser rules. Each chapter runs one example to show an idea. The language is defined in the Reference.

Running

The Run button of an example in a chapter runs PlanckVM in the browser and shows the output. The Playground is a REPL: enter an expression and see its value.
