8. Records, local functions, escapes

record defines a new type and the function that makes its data. return, break and continue are implemented as effects (chapter 5).

The type Point and the function point that makes the data are separate names. A pattern x @ Point tests the type, and with makes a copy with fields replaced.

Local functions and escapes

Functions that call each other first declare the name with fun f and fill it in later with f(x) = ....

The body of for is a function, but a return in it leaves the outer function. break and continue apply to the innermost while or for.
