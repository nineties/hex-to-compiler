3. Patterns and fusion

The parameters of a lambda are patterns. f | g (fusion) is a function that tries g when no pattern of f matches. Case analysis is written with it.

Fusion tries the lambdas from the left and calls the first one that matches. When none matches, the program stops with matching failed. | associates to the right.

f(p, ...) = e is f = f | (p, ...) -> e, which adds a case after f. The same function can be written in a line for each case, and the lines are tried in the order they are written.

f(p, ...) := e also adds a case when f is already defined in the same place, so the lines may all be written with :=. At the top level the same place is the same file: a function of a library or a builtin function of the same name is hidden, not added to. In a function, an f outside the function is not changed: the first f(p, ...) := e there defines a new f (Scope of variables).

Adding cases

A fusion is a value, so a case can be put in front of an existing function and assigned back.

Adding to a function and hiding it

f(p, ...) := e adds a case when f is already defined in the same place, and otherwise defines a new f. The place is the same file at the top level, and in a function the parameters of the function and the variables defined before it in the function. The outer name is not a variable of the place inside inner, so name(0) := "inner" in inner defines a new name and does not change the outer one.

A function defined by another file and a builtin function are not variables of the same place at the top level of a program either. sum(xs) := ... defines a new sum that hides the sum of use("list"). To add a case to a library function, write it with = as in last(Tuple{a, b}) = b. The added case is tried after the original cases. Which variable a name refers to is described in chapter 9.

match

match e { f } evaluates e once and calls the function f with it. f is the arms joined by |, tried from the top. p if c -> a is a guard: when c is false, the next arm is tried.

Symbolic differentiation

'Add{x, 3} is a quotation. It passes the M-expression without evaluating it (chapter 6). A version with simplification is planck/examples/deriv.pk.
