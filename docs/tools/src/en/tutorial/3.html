3. Patterns and fusion

The parameters of a lambda are patterns. f | g (fusion) is a function that tries g when no pattern of f matches. Case analysis is written with it.

Fusion tries the lambdas from the left and calls the first one that matches. When none matches, the program stops with matching failed. | associates to the right.

Patterns

p @ intA value that matches p and whose typeof is int

Adding cases

A fusion is a value, so a case can be put in front of an existing function and assigned back.

match

match e { p -> a ... } evaluates e once and tries the cases from the top. p if c is a guard: when c is false, the next case is tried.

Symbolic differentiation

'Add{x, 3} is a quotation. It passes the M-expression without evaluating it (chapter 8). An if ... else ... in the middle of a fusion is put in parentheses. The right side of else reads a whole expression, so without parentheses it would take in the following | .... A version with simplification is planck/examples/deriv.pk.
