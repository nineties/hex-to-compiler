init.pk and M-expressions

planck0 reads planck/init.pk first. The reader at this point reads only M-expressions, so the whole file is written in M-expressions. The file defines the functions and tables used afterward.

Writing in M-expressions only

There are no operators and no syntax for if, so everything is written with special forms and function calls. The definition of _not, which not calls, is as follows.

A Fusion joins two Lambdas. The first is chosen when the argument is false, and the second otherwise. Quote{false} is a pattern that matches the symbol false. A top-level string " ... " does nothing when evaluated, so it serves as a comment.

The first lines bind true, false and none to the symbols of the same names ([[planck/init.pk Def{true, Quote{true}}]]).

Tables

The builtins of planck0 stop at arrays and hash. init.pk implements the hash table with arrays ([[planck/init.pk " A table is Table{a} .. " === Loading files === "]]).

A table is Table{a}, where a is an array that holds an array of buckets and the number of entries. The number of buckets doubles when the number of entries exceeds it. Keys are compared as by ==. Tables are used for the table of rules, the record of the libraries that use has loaded, and so on.

Loading files

Like interpret_file of planck0, load evaluates a file one expression at a time with the current parse and eval. While it does so, _set_file makes the file the file being loaded, so a global variable defined at the top level of the file is known as defined by that file (Scope of variables).

use is a function that loads a library only once and records what it has loaded. planck/lib/use.pk defines it after the switch to the syntax ([[planck/lib/use.pk use(name) :=]]). After loading, it makes the file value from the global variables of the file that _file_globals returns, and returns it ([[planck/lib/use.pk file_value(name, path) :=]]).

Switching to the syntax

The last lines load the packrat parser, the syntax and use.

planck/peg.pk is a parser written in M-expressions (The packrat parser). planck/syntax.pk defines the syntax of planck with that parser and replaces parse (Defining the syntax). planck/lib/use.pk is written in the syntax. The files read afterward, both planck/lib and the programs of users, are read in the syntax of planck.
