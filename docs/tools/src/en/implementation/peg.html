The packrat parser

planck/peg.pk is an interpreter of PEG written in M-expressions. A grammar is data in M-expressions, and results are memoized per (position, rule).

The grammar as data

The forms of parsing expressions (the right-hand sides of rules) are at the top of the file. Giving one a name with _define_rule makes a rule, and ::= is translated into a call of it (Defining the syntax).

Interpretation

peg_px(e, p) tries the parsing expression e at position p. On success it returns the next position and puts the value in peg_pv. A failure is -1, and the furthest position reached stays in peg_far and gives the position of a syntax error. peg_px, peg_call_rule and peg_run_rule call each other, so they are declared first with Def{name, none} and defined with Set.

Memoization and direct left recursion

Backtracking never recomputes a rule at the same position.

Direct left recursion (sum ::= sum "+" term | term) is also handled with the memo. A call of the running rule at the same position fails, and this failure is the seed to run the rule again. This repeats while the match gets longer. 1 - 2 - 3 becomes (1 - 2) - 3.

Defining a rule and the entry point

_define_rule evaluates f of the action Act{e, f} before it stores the rule. Prev{} in an alternative (... in ::=) is the previous definition of the rule.

peg_parse(rule, s) returns Tuple{value, rest} on success. On failure it returns SyntaxError{...} with the text from the position to the end of the line. peg_parse_at adds the Loc{file, line, column} of the error as the last argument. The position is counted from the start of the text up to peg_far, the farthest failure, after skipping blanks.
