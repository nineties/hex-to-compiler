The vasm checker

planck/lib/vasm.pk (862 lines) is a library, written in planck, that reads and checks vasm, a low-level language close to machine instructions. use("vasm") loads it. The list of structs and functions written in vasm{| ... |} is checked for ownership and borrow violations, uses after free and reads of uninitialized registers, using type rules alone. The rules of the language are in vasm in the reference.

Entry points

vasm{| ... |} is read as Module{[Struct{...}, Fn{...}, ...]}. vasm_check(m) takes it and returns a list of VasmErr{kind, Pos{d}, msg}. vasm_errors(file, m) turns the positions into Loc{file, line, column} of the file, and vasm_report(file, m) writes them as file:line:column: message. A function without an error does not appear in the result, and a function has at most one error: the first. The examples on this page write the result line by line with the report function in each file.

Syntax

The syntax of vasm is declared with ::= as rules of the packrat parser ([[planck/lib/vasm.pk#38-39]]). The keywords are collected in vasm_kw, and a name is an identifier that is not a keyword. The rule for statements lists one alternative for each head, and each result is an M-expression such as Decl{...}, IfS{...} or Assign{...}.

Every result carries its position at. vasm_here is a rule that reads nothing and returns, as Pos{d}, the number of characters from the next token to the end of the text ([[planck/lib/vasm.pk#29-34]]). An error of the checker holds this Pos, and vasm_errors subtracts it from the length of the text to get the line and the column.

Types and the state of the checker

Types are M-expressions too. The integers are I8{} to U64{}, a box is Own{u}, a borrow is Ref{'shr or 'mut, region, u}, an array is Arr{u} and a struct is Named{s}.

For each function, the checker keeps the declarations of the variables in vasm_info (name to type) and the state of the variables in a table of Vs{status, loans}. The status is one of initialized, uninitialized, moved, freed, a box whose contents are moved out, and a struct whose fields are moved out. The loans are the borrows that currently borrow the variable. if and while copy the table, check each branch, and compare the results afterwards.

Whether a value is moved or copied depends on its type. own and a struct that owns something are linear: a use moves them, and they must be moved or freed exactly once. Integers, bool, structs that own nothing and shared borrows are copied.

Ownership

own i64 is the single owner of an integer allocated by box. The [r] of bump is a region parameter fixed at each call. For a call that passes a &mut to a borrow parameter, vasm_reborrows treats the argument as borrowed again for the duration of the call, and does not move it ([[planck/lib/vasm.pk#511-517]]). This is why m can be used after the call.

Before a register is read, vasm_need_init looks up its state. An uninitialized, moved or freed register is an error of kind 'uninit, 'moved or 'freed ([[planck/lib/vasm.pk#258-265]]). A freed own cannot be read or freed again, because vasm_call marks the argument of free as freed. Assigning q to p marks q as moved, and the ownership moves to p.

Automatic release

A value that owns something is released automatically where its owner goes away, so none of the functions above is an error. Those places are the end of a block or a function, an overwrite, the result of a call that is discarded as a statement, and what is left inside a value passed to free. The release is an action at run time, and the checker counts nothing. vasm_leak_all, which would examine what is left at the end of a block or a function, is an empty function kept to mark where the release happens ([[planck/lib/vasm.pk#654-657]]). An overwrite only sets the state back to initialized in vasm_assign ([[planck/lib/vasm.pk#642-652]]). free is for releasing a value earlier.

Borrows and regions

The Vs of a borrowed variable holds Loan{region, kind}. vasm_no_loans rejects a move, a free or an assignment while the variable is borrowed, and vasm_no_mut_loan rejects a read or a write while it is borrowed with &mut ([[planck/lib/vasm.pk#294-295]]). Any number of shared borrows can exist at once. A &mut is exclusive: while it lives, the original value can be neither read, written nor freed. At the end of region r { ... }, vasm_end_region removes the loans of r ([[planck/lib/vasm.pk#691]]).

vasm_outlives(q, r) decides which region is inside which. q outlives r if they are the same, or if r is a region opened in the function and q was opened before it. The region parameters of a function have no order among themselves.

vasm_fits decides whether the type of a borrow matches in an assignment or an argument. A borrow of an outer region can be used where a borrow of an inner region is expected, because the outer one lives longer, and the reverse is rejected. When the reverse puts the borrow in a register that lives outside the region opened in the function, vasm_escapes makes the error of kind 'escape.

Branches and loops

if checks both branches on copies of the state, and vasm_merge compares them. A value moved or freed in only one branch has no definite owner afterwards, which is an error of kind 'branch. A branch that ends in return is marked with .dead and left out of the comparison. while checks the body twice, and vasm_loop_same looks at whether a value moved in the loop is given back before the next iteration ('loop).

Widths of integers

The integer types are listed in the table vasm_ints (type, name, bits, signedness) ([[planck/lib/vasm.pk#159-166]]). Both operands of an operator have the same type, and as changes the width or the signedness. A literal starts as Lit{n}, which has no type, and its range is checked where it meets an integer type. The range is -32768 to 32767, narrowed to start at 0 for an unsigned type and to the range of the type for 8 bits (vasm_lit_lo and vasm_lit_hi, [[planck/lib/vasm.pk#167-170]]). A larger value is built with shifts and |.

Arrays and structs

The built-in functions are listed in the table vasm_builtins as types Sig{regions, arguments, result} with the type variable T ([[planck/lib/vasm.pk#224-232]]). alloc(n, v) makes an own [T] of n copies of v, and len returns the length. An index is an i64. Checking its range is left to run time, and the checker looks only at types and ownership. A struct is built by giving every field once. It is copied like an integer unless it owns something, and vasm_owning decides that by following the fields ([[planck/lib/vasm.pk#200-212]]).

Exchanging values that own

A value that owns something cannot be copied out of an array element or the target of a pointer, because it would have two owners. swap(p[i], v) puts v in and returns the previous value. The parameter type Place{T} accepts only a place of the form *p, p[i] or p.f. Writing a field of a struct register, as in img.body = b, releases the previous value and puts the new one in.

Reporting errors

When the checker meets an error, vasm_fail performs the algebraic effect VasmFail{at, kind, msg} (Algebraic effects). For each struct and function, vasm_check receives it with handle, makes a VasmErr and abandons the check, so a function has at most one error: the first. The kinds are in the table of the reference.
