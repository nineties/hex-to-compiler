The vasm checker

planck/lib/vasm/check.pk is a library written in planck that reads and checks vasm, a low-level language (use("vasm/check")). The rules of the language are in vasm in the reference. By type rules alone it detects violations of ownership and borrowing, use after release and reads of uninitialized values. A value is either moved or copied, and a value that has own can be moved or freed at most once in total. A borrow is valid only inside its region.

Entry points and syntax

vasm{| ... |} is read as Module{[Struct{...}, Fun{...}, ...]}. The syntax is declared with ::= as rules of the packrat parser, and statements become M-expressions such as Decl{...} and IfS{...}. Every result carries a position Pos{d}, the number of characters from the next token to the end of the text.

  • vasm_check.check(m) returns a list of VasmError{kind, Pos{d}, msg}. A function reports only its first error.
  • errors(file, m) turns positions into lines and columns, and report(file, m) writes file:line:column: message.

Types and the state of the checker

Types are also M-expressions: integers are I8{} to U64{}, a box is Own{u}, a borrow is Ref{'shr or 'mutable, region, u}, an array is Array{u} and a struct is Named{s}. static is a region that outlives every region.

For each function the checker keeps the state of each variable (initialized, uninitialized, moved, freed and so on) and its list of borrows in Vs{status, loans}.

The type decides between move and copy. An own, and a struct that has own, is linear and is moved on use. Integers, bool and shared borrows are copied.

Ownership

Before a register is read, need_init looks at its state and reports an error for uninitialized, moved or freed. An own that has been freed cannot be read because call marks the argument of free as freed. A call that passes &mutable to a borrow parameter is treated as borrowing again for the duration of the call, and does not move.

A value that has own is released automatically where it loses its owner: at the end of a block or function, on overwrite, or as a discarded result. The release is a runtime action and is not checked.

Borrows and regions

A borrowed variable gets a Loan{region, kind}. While it is borrowed, a move, a release or an assignment is an error from no_loans. Any number of shared borrows can coexist, but only one &mutable, and reads and writes during it are also errors. At the end of region r { ... } the loans of r disappear.

outlives(q, r) decides which region is outside. q outlives r when it is the same as r or static, or when r is a region opened in the function and q was opened before it. A borrow of an outer region can be used as a borrow of an inner one, but not the reverse.

Branches and loops

An if checks both branches on copies of the state, and merge joins them. A value moved or released in only one branch is an error, because it is not decided afterward who owns it. A while checks the body twice and verifies that a value moved in the loop is put back before the next round.

Integers, arrays and structs

Both sides of an operation have the same integer type, and as changes the width or the sign. A literal starts as an untyped Literal{n}, and its range is checked when it meets an integer type.

The types of the builtin functions are in the table vasm_check.builtins. The checker checks only types and ownership, and the range of an index is checked at run time. A struct is made by writing every field once, and when it has no own it is copied like an integer.

A value that has own cannot be copied out of an array element or from what a pointer points to. swap(p[i], v) puts v in and takes the previous value out.

Reporting errors

When the checker finds an error, fail raises the algebraic effect VasmFail{at, kind, msg} (Algebraic effects). check catches it per struct and function with handle, makes it a VasmError and stops checking. The kinds of kind are in the table of the reference.
