Implementation

This section reads the implementation of planck from the hand-written machine code up to the syntax of planck, with links to the source lines. The overview shows the stages as a whole.

Build order

plisp has no executable. At every start, pforth reads bootstrap/plisp.fs and assembles the Lisp, and that Lisp compiles bootstrap/plisp2.sv with bootstrap/sasm.lisp. planck0 is compiled by the same bootstrap/sasm.lisp on top of plisp2. After planck0, the rest is assembled at run time. planck0 reads init.pk, peg.pk and the first half of syntax.pk as M-expressions, and the syntax of planck takes effect when syntax.pk replaces parse.
