planckvm internal representation

The low bit of a word tells an immediate from a reference, and the kind in the header tells the kind of an object. A field marked raw is a number as it is, and every other field is a word of a value. The GC follows only the value fields.

Words and headers

Every word in the heap, the registers and the frames is 32 bits, and bits are numbered from 0 at the least significant bit.

  • An immediate integer is 2n+1, where n is 31 bits in two's complement. An integer that fits is always an immediate, and only one that does not fit is a big-integer object. Floats, complex numbers, strings and symbols are all objects.
  • A reference is twice the index of the header of the object, in words from the start of the heap.
  • The first word of an object is its header, not a value. size is the number of words after the header. r becomes 1 only when the GC moves the object. The old header of a moved object has r 1 and, in its upper 30 bits, the index of the new header.

Contents of objects

"Word" is the position counted from 0 at the word after the header. A 64-bit quantity puts the lower word first. Environments, cells and codes are never passed to a program as values.

The head of an immediate integer is also Int. The identity number of an array, a plain array, a lambda, a Fusion, a builtin, a continuation and a user data is 0 until the first HASH assigns a number of 1 or more, and it never changes after that.

Elements of a plain array

The type numbers are 0 for 'bool, 1 to 4 for 'i8 to 'i64, 5 to 8 for 'u8 to 'u64, 9 to 11 for 'f16, 'f32 and 'f64, and 12 and 13 for 'c64 and 'c128. The size of an element is 1 byte for 'bool and the number of bits in the name for the others.

  • Elements are untagged bits packed without gaps in little endian. Element i starts at byte position i * (bytes per element), and byte position b is the b mod 4-th byte from the low end of word 3 + b/4.
  • Integer types are in two's complement, 'bool is 1 for true, float types are IEEE 754 bits, and a complex type is the real part and then the imaginary part. The unused bytes of the last word are 0, and a new array has all bits 0.
