planckvm internal representation

Words, headers, the contents of each kind, and how the GC treats them on the heap. The lowest bit of a word tells an immediate from a reference, and the kind of an object is read from its header. The GC follows only the fields of values.

Words

The words of the heap, the registers and the frames are all 32 bits, and the bits are numbered from 0 at the least significant bit.

WordLowest bitValue of the word
immediate integer12n+1. n is 31 bits in two's complement, from -230 to 230-1
reference to an object0twice the index, in words from the start of the heap, of the header of the object
  • The integer of the language is one kind. An integer that fits an immediate is always an immediate, and only an integer that does not fit is a big integer object.
  • Only integers are immediates. Floats, complex numbers, strings and symbols are all objects.

Headers

The first word of an object is the header. An object is the header and the words after it.

FieldMeaning
sizeThe number of words after the header. The object is size + 1 words with the header
kindThe kind of the object, as in the table below
mA mark that the GC uses. 0 in an image
lowest bit1 in a header

kind uses 0 to 14 and does not use 15.

A header is not a value, and it is not put in a register or in a field of an object. A word with the lowest bit 0 at the place of a header is the reference to the place that the GC moved the object to. An image has none.

Contents of objects

In the tables below, a word is the position counted with the word after the header as 0. A field marked "value" holds a word of a value (an immediate or a reference). A field marked "raw" holds the number itself and not a value. When a 64-bit quantity is split into 2 words, the low word comes first.

Big integers

  • A value is the sign and the absolute value. The digits of the absolute value are in base 264, from the lowest digit.
  • size is 2 + 2n. The number of digits is limited to what fits the size field.
  • The top digit is not 0. 0 is an immediate.

Strings

WordContents

The bytes may include the 0 byte. size is 1 + ceil(n/4).

The number of arguments is size - 1. An m-expr is immutable.

Arrays

WordContents

The number of elements is size - 1 and does not change after the array is made.

  • An element is a bit string with no tag, and the elements are packed in little endian with no gap. Element i starts at the byte position i * (bytes of an element), and the byte position b is the byte number b mod 4 from the low end of word 3 + b/4.
  • Integer types are in two's complement. For 'bool, true is 1 and false is 0. Float types are the bit strings of IEEE 754, and complex types are the real part and then the imaginary part.
  • size is 2 + ceil(n * bytes of an element / 4). The unused bytes of the last word are 0.
  • The elements just after the array is made are all 0 bits, which stand for false, 0, 0.0 and complex(0, 0).

Identity numbers

Arrays, plain arrays, Lambdas, Fusions, builtins and continuations hold an identity number in word 0. It is 0 until the first HASH assigns a number of 1 or more, and it does not change afterwards. The numbers assigned in one machine are all different.

How the GC treats objects

The GC reads kind in the header and does not follow raw fields.

The GC moves objects, so the word of a reference changes while the identity of the object stays.
