Data types

This page defines the types of values of planck, immutability, and equality and identity. Expressions, patterns and special forms are in Values, patterns and M-expressions.

Table, Vector and the types that a user adds (for example Matrix{w, h, d}) are not types. They are M-expressions that wrap an array.

The type of a value is told by head. The pattern x @ Int matches a value whose head is Int. The symbol of a type name cannot be the head of an M-expression.

Equality and identity

Equality is tested by a == b (_eq). a != b (_ne) is its opposite.

Identity means that two values are the same object. Arrays, plain arrays and functions are equal only when their identity is the same. There is no builtin function that tests only identity.

Equality across number types

Integers, floats and complex numbers are equal if the values are the same, even when the types differ. 1 == 1.0 and 1 == complex(1, 0) are true.

NaN is not equal even to itself. x == x is false when x is NaN.

The ordering comparisons < <= > >= are not equality. They compare integers and floats by their mathematical values. They are false if NaN is involved. See Numbers.

Where equality is used

  • A pattern that writes the same name twice (f(a, a)) matches only when the two values are equal by ==.
  • The builtin table (table_get, table_set and t[key]) compares keys by ==.
  • hash(x) is an integer of 0 or more. Values that are equal by == give the same value.
