Reference

This is planck/SPEC.rst, the definition of the language, with examples. SPEC.rst is authoritative where the two differ.

Contents

  • Syntax: expressions and M-expressions, associativity, lexical rules, if, for, return, match, fun, record, the names the sugar calls, a[i] and t[p -> e | ...]
  • Values, patterns, M-expressions: kinds of values, special forms, patterns, effects, the top level
  • Grammar declarations: ::=, items, name{| text |}, peg_parse
  • Builtin functions: output, integers, M-expressions, strings, arrays, files, language
  • Libraries: list, vector, string, table, symbol, error, pretty, unparse, base

Loading a program

planck0 reads planck/init.pk first, then runs the files given as arguments in order. It reads and evaluates the top-level expressions one at a time.

planck/init.pk, planck/peg.pk and planck/syntax.pk are written in M-expressions. planck/syntax.pk defines the syntax with the packrat parser of planck/peg.pk and replaces parse, so the files given as arguments are read with this syntax.
