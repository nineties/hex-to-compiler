Reference

Planck is a language for symbolic and language processing. This section is the definition of the language.

Loading a program

The interpreter loads planck/init.pk, then reads and evaluates the top-level expressions of the program file given as the first argument one by one. planck/syntax.pk defines the syntax with the packrat parser of planck/peg.pk. It first writes in M-expressions the grammar of ::= and the smallest syntax for actions, replaces parse there, and declares the rest with ::=. The program file is read with this syntax.
