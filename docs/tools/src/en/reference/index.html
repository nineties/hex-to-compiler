Reference

Planck is a language for symbolic and language processing. This section is the definition of the language.

Loading a program

planck/init.pk is loaded first, then the program file given as the first argument is run. Each top-level expression is parsed and evaluated one by one.

planck/init.pk and planck/peg.pk are written in M-expressions. planck/syntax.pk defines the syntax with the packrat parser of planck/peg.pk. It is written in M-expressions up to the grammar of ::= and the smallest syntax for actions, replaces parse there, and declares the rest of the syntax with ::=, so the program file is read with this syntax.
