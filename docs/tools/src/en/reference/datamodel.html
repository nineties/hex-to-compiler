Data model

A value is an M-expression or an atom.

M-expressions

An M-expression is a value written Head{a, b, ...}. It has a head (a symbol) and a sequence of arguments. A tuple has the head Tuple, and a list has Cons and Nil.

  • The type is Expr, and it is immutable.
  • The number of arguments has no limit. A mutable value and a NaN cannot be arguments. Making an M-expression with one is a runtime error.
  • head(x) works on M-expressions only.

A value that is not an M-expression is an atom. User data makes new types.

A type is a value (a type value), which type(x) returns. type(1) is Int, and type(Int) is Type.

An array or a plain array is changed by array_set or plain_set. Out of range is an error, and so is a value that does not fit a plain array.

Equality

_eq(a, b) tests whether a and b are equal as values.

  • Integers, floats and complex numbers are equal if the values are the same, even when the types differ. A NaN is not equal to any value.
  • M-expressions are equal if the heads and the arguments are equal.
  • Arrays and plain arrays are equal if identical, and otherwise are compared element by element.
  • hash(x) is an integer of 0 or more, and equal values give the same value.

Identity

_is(a, b) is true if a and b are the same thing (identical). Identical values are always equal. Values of different types are not identical: the integer 1 and the float 1.0 are equal but not identical.

Interning makes equal values into one object. For an interned type, equal values are identical, and _is is O(1) (except for arbitrary precision integers).

A table (table_get and table_set) treats two keys as the same if they are identical or equal.

User data

  • Made by a builtin function. You must specify whether it is immutable or mutable.
  • Immutable user data cannot hold a mutable value. Making one that does is a runtime error.
  • Each type made is a different value. The name is only used for display, and types with the same name are told apart by _is.
  • You may give a function for equal and a function for hash, both together. The author must keep two rules: if _is(a, b) then _eq(a, b), and equal values have the same hash.
  • Without them, the hash is decided by the contents if immutable and by the object if mutable.

Numbers

An operation on mixed number types raises them to the highest type.

  • _div truncates toward 0, and _quo rounds toward minus infinity. _mod(a, b) is _sub(a, _mul(b, _quo(a, b))) and has the sign of the divisor.
  • A zero divisor is a runtime error. _div with a float or a complex number gives an infinity or NaN (per component for a complex number).
  • _lt _le _gt _ge compare an integer and a float by their mathematical values. They give false when a NaN is involved and are a runtime error on a complex number.
  • An integer raised to a float becomes the nearest float, and one beyond the range of floats is a runtime error.

Literals

true, false and none are literals whose value is the symbol of the same name. They are not variables.

record

_record_declare(Quote{T}, Quote{Tuple{f, g, ...}}) names the arguments of T{a, b, ...}. _record_get(t, Quote{f}) is the argument at the position of f, and _record_with(t, Quote{f}, e) is a new value with that field replaced.

  • Values with different heads can have fields of the same name. Declaring the same T again replaces the names.
  • Using _record_get on a value whose head is not declared, or that has no field f, stops the program with a message.
