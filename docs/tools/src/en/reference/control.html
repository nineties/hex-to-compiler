Special forms

The special forms, algebraic effects, for and match.

List

FormMeaning
Def{x, e}Defines the variable x. The right side sees the variables before x
Set{x, e}Assignment
Declare{x}Same as Def{x, none}. Does nothing if x already exists
If{c, a, b}b only when c is false
Fusion{f, g}Tries g if no pattern of f matches. Fusion{none, g} is g

true, false and none are not variables, so Def{true, e}, Set{true, e} and Declare{true} stop the program before it runs.

Algebraic effects

perform Ask{} (Perform{Ask{}}) calls the nearest handle handler with a matching pattern, such as (Ask{}, k) -> .... k is an ordinary function for the continuation, and the v of k(v) becomes the value of the perform.

  • k can be called any number of times, even after handle has returned.
  • The handler is also active inside the resumed continuation.
  • Variables defined when the continuation is captured are shared between the resumed copies. Variables defined after the resumption are separate.

MatchingFailed (Partial functions and fusion), which a function call or match with no matching arm performs, can also be resumed with k. The x of k(x) becomes the value of the failed call or match.

f(0) := "zero"
b := handle [f(7), 1] with (MatchingFailed{_, _, _}, k) -> k("other")
println(b)
Cons{"other", Cons{1, Nil{}}}

for, and return, break and continue

for (p in e) body matches each element of the list, vector or range e against the pattern p and evaluates body. The value is none. return e ends the call of the enclosing function with the value e (none without e), break ends the innermost while or for, and continue goes to its next round.

  • e starts on the same line as return.
  • A function whose body has return becomes Handle{body, (Return{v}, k) -> v}, a loop with break becomes Handle{loop, (Break{}, k) -> none}, and a loop with continue has the body Handle{body, (Continue{}, k) -> none}.
  • A return in the body of a for or in an arm of a match ends the function around them. A return in a function written inside ends that function.
  • A continue outside a loop stops with unhandled effect: Continue{}.

match

match e { f } evaluates e once and calls the function f with the value. f is usually one-argument functions joined by |, and each is an arm. The first arm with a pattern that matches e is chosen; if none matches, MatchingFailed is performed. A | can start a line.

  • An arm has one argument. To take a tuple, write ((a, b)) -> x.
  • The guard c of (p, ...) if c -> e | g is evaluated after the arguments match, with their variables. When it is false, or the arguments do not match, g is called with the same arguments. g is the expression joined after the function by | in the source, even inside parentheses.
  • A guarded function passed through a variable, as in h | g after h := p if c -> a, does not call g.
  • The guard and e are expressions up to the level of or, so put an anonymous function in parentheses.
