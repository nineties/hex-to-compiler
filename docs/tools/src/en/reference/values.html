Values, patterns, M-expressions

The evaluator works on M-expressions. This page defines the kinds of values, the special forms, patterns, effects and the top level. An M-expression whose head is not a special form is a constructor: its arguments are evaluated and an M-expression with the same head is built. When number types are mixed they are raised to the highest of integer, float, complex; an out-of-range value or a division of integers by 0 is a runtime error.

M-expressions

An M-expression is a symbol (x), an integer (42, -1), a float (1.5), a string ("abc") or Head{a, b, ...}. A symbol is a letter, _ or % followed by letters, digits and _. A string is up to 65535 bytes and Head{...} has no limit on the number of arguments. A string at the top level has no effect, so it can be used as a comment.

true, false and none are literals. Each is the symbol of the same name, and its value is that symbol, so true and Quote{true} have the same value. They are not variables: Def{true, e}, Set{true, e} and Declare{true} stop the program with a message before the expression runs.

Numbers

  • _add _sub _mul _div take integers, floats and complex numbers only, and stop the program on any other value.
  • No integer is out of range, and nothing wraps around or is truncated. Floats round to nearest even, and floating-point exceptions do not stop the program. A complex number is made by complex(re, im) or an imaginary literal (2i).

Division of two integers:

FunctionResult
_divThe quotient truncated toward 0
_quo (the operator //)The quotient rounded toward minus infinity, so -7 // 2 is -4
_mod(a, b)a - b * (a // b), which has the sign of the divisor

A zero divisor is a runtime error, except for _div with a float or a complex number. A float gives an infinity or NaN, and a complex number gives the same rule applied to its components.

FunctionRule
_lt _le _gt _geCompare an integer and a float by their mathematical values, without raising the type. They give false when NaN is involved, and stop the program on a value that is not a number and on a complex number
_eq _neNumbers of different types are equal when their values are the same (1 == 1.0). NaN is not equal to itself. Complex numbers are equal when both components are equal. _ne is the opposite

An integer raised to a float is rounded to the nearest value, and an integer beyond the range of floats is a runtime error.

Patterns

A parameter pattern is one of:

  • a variable x. _ matches anything and binds nothing
  • an integer, a string, true, false or none. It matches an equal value and binds nothing
  • Quote{v}. It matches an equal value
  • Head{p, ...}. It matches an M-expression with the same head and arity
  • Head{p, ..., _Rest{x}}. It matches an M-expression with the same head and at least as many arguments as the patterns before _Rest, and binds x to a Tuple of the remaining arguments. written Head{p, ..., x...}
  • _TypeOf{p, type}. It matches when type is the type of the value and p matches

In the syntax, 'none is Quote{none}, x @ Int is _TypeOf{x, Int}, where Int is a variable, and x :: xs and [a, b] are patterns of Cons.

Algebraic effects

Handle{body, handler} evaluates body. Perform{v} calls the nearest handler(v, k) that has a matching pattern, where k is the continuation of the Perform. Handlers are deep: they stay installed in the continuation. When no pattern matches, the effect goes to the outer handler.

k is an ordinary function and can be called any number of times, even after Handle has returned. Variables that are defined when the continuation is captured are shared between the resumed copies. A variable defined by x := e after the resumption is defined separately in each copy, unless a function written inside refers to it.

Top level

The loop looks up the global variables parse and eval for every expression, so a program can replace them and the next expression is handled by the new definitions. Apply{eval, ...} in a program also calls the replaced eval.

  • parse: String -> Tuple{M-expression, rest String}. It skips blanks itself and returns Tuple{Eof{}, ""} when only blanks are left. A replacement parse passes Eof{} through.
  • eval: M-expression -> value.
