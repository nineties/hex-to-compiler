Grammar declarations

::= defines or replaces a rule of the grammar. The syntax of planck is made of the same rules, so a declaration extends the syntax of the following expressions.

::=

name ::= alternative | ... defines the rule name, and replaces it if it already exists. The rules of the syntax are rules of the same grammar. The alternative ... stands for the previous definition of the rule.

An alternative is a sequence of items followed by an optional action { ... }. The items and the action are on the same line as ::= or |.

Character classes

The set of [set] is a sequence of characters and ranges.

  • Range: a letter, a digit or _ followed by - and a character, as in a-z. Any other - is itself.
  • Escape: \n, \t, \a, \b, \f, \r, \v and \0 are those control characters. Any other \x is the character x (\], \-, \\, \ ).
  • Blanks at both ends are not in the set.
  • Syntax errors: an empty set, a reversed range ([9-0]) and a range without its end ([a-]).

[^set] is a character that is not in the set. At the end of the input none of ., [set] and [^set] matches.

The value of cs:[0-9]+ is a Tuple{v, ...} of one-character strings.

Order and values of alternatives

Alternatives are tried in order (PEG). The value of an alternative is the value of its action, the value of the item when there is one item, or Tuple{v, ...} of the items. e* and e+ give Tuple{v, ...}, e? gives Tuple{} or Tuple{v}.

The result of a rule is memoized for each position (packrat parsing). A rule may be directly left recursive (sum ::= a:sum "+" b:term { ... } | term), which groups to the left.

peg_parse

peg_parse(rule, s) parses a prefix of s by the rule and returns Tuple{value, rest}, Tuple{Eof{}, ""} when only blanks are left, or Tuple{SyntaxError{...}, ""}.

Text read by a rule

name{| text |} is an expression whose text is read by the rule name when the expression is parsed. There is no space between name and {|.

Only the rule reads text (its strings, words and rules, with their blanks and comments). Not the tokens of the surrounding expressions.

The rule decides where text ends, and |} must follow, after blanks. So a |} or } that the rule reads, for example in its strings or brackets, is a part of text.

A failure of the rule or a missing |} is a syntax error of the expression, at the farthest position the rule reached in text.

The value of the expression is the value of the rule, as a constant.

Define the rule in an expression that is evaluated before the expression with text is parsed.

peg_sources and peg_version

peg_sources is a table from a rule name to the parsing expression given to _define_rule. The actions are not evaluated (... is replaced by the previous definition). peg_version increases at every _define_rule.
