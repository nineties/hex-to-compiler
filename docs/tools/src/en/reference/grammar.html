Grammar declarations

::= defines or replaces a PEG rule. The syntax of planck is made of the same rules, so a declaration extends the syntax of the following expressions. Alternatives are tried in order, and the result of a rule is memoized for each position (packrat).

::=

name ::= alternative | ... defines the rule name, and replaces it if it already exists. The alternative ... stands for the previous definition of the rule. An alternative is a sequence of items followed by an optional action { ... }. The items and the action are on the same line as ::= or |.

Texts, words, . and [set] skip blanks and comments first. The value of an alternative is the value of its action, the value of the item when there is one item, or Tuple{v, ...} of the items. e* and e+ give Tuple{v, ...}, and e? gives Tuple{} or Tuple{v}.

A rule may be directly left recursive (sum ::= a:sum "+" b:term { ... } | term), which groups to the left.

Character classes

  • A letter, a digit or _ followed by - and a character is a range, as in a-z. Any other - is itself.
  • \n, \t, \a, \b, \f, \r, \v and \0 are control characters. Any other \x is the character x.
  • Blanks at both ends of the set are not in it. An empty set, a reversed range ([9-0]) and a range without its end ([a-]) are syntax errors.
  • At the end of the input none of ., [set] and [^set] matches.

peg_parse

peg_parse(rule, s) parses a prefix of s by the rule and returns Tuple{value, rest}, Tuple{Eof{}, ""} when only blanks are left, or Tuple{SyntaxError{...}, ""}.

Text read by a rule

name{| text |} is an expression whose text is read by the rule name when the expression is parsed. Its value is the value of the rule, as a constant. There is no space between name and {|. Define the rule in an expression that is evaluated before the expression with text is parsed.

  • Only the rule reads text, not the tokens of the surrounding expressions.
  • The rule decides where text ends, and |} must follow, after blanks. A |} or } that the rule reads is a part of text.
  • A failure of the rule or a missing |} is a syntax error, at the farthest position the rule reached in text.

peg_sources and peg_version

peg_sources is a table from a rule name to the parsing expression given to _define_rule. The actions are not evaluated (... is replaced by the previous definition). peg_version increases at every _define_rule.
