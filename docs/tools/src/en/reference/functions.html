Partial functions and fusion

A function takes its arguments by patterns. A pattern describes the shape of an argument in the same notation as an expression, and binds variables when it matches. f | g (fusion) writes cases.

Partial functions and fusion

A function takes its arguments by patterns, so it is a partial function: some arguments may not match. f | g (Fusion{f, g}) tries f, and tries g if none of its patterns match.

  • A false guard if c counts as no match.
  • Definitions f(0) := ... written one after another in the same place form one function, tried in the order written.
  • A call that matches no arm raises MatchingFailed. With no handler, the program stops.

Patterns

  • _: matches anything and binds nothing.
  • Head{p, ..., _Rest{x}}: matches an M-expression with at least as many arguments as the patterns before _Rest, and binds x to a Tuple of the rest.
  • _TypeOf{p, type}: matches a value x with type(x) equal to type and which p matches.

Notation in parameters

A parameter p and the pattern of for are written as expressions up to the level of or, turned into an M-expression, and matched. They are written like expressions, with identifiers as variables. The exceptions are:

  • The names of operators and called functions are symbols. x + 1 matches the tree Apply{Quote{_add}, Tuple{x, 1}} and f(p, ...) matches Apply{Quote{f}, Tuple{p, ...}}. To make the called function a variable, write (f)(p, ...).
  • 'e is Quote{e}, p @ type checks a type, and x... is the rest of the last parameter.
  • Writing the same name twice, as in f(a, a), matches only when the two values are equal by ==.
  • p or q matches either. Variables are allowed only when every branch binds the same variables (f((x, 0) or (0, x)) := x). To match the M-expression If{a, true, b} of an expression or, write If{a, 'true, b}.
  • Allowed forms: operators (or and not == != <= >= < > :: + - * / %, unary - and '), f(p, ...), Head{p, ...}, identifiers, true false none, integers, strings, tuples and lists.

Rest arguments

x... binds the remaining arguments to a Tuple (Tuple{} if none).

  • It can be written only as the last parameter of a function f(p, x...) := e or (p, x...) -> e and of a pattern Head{p, x...}.
  • A call with fewer arguments than the preceding parameters does not match.
  • Writing it anywhere else, as an argument of a call, or in a guarded function stops the program with a message before the code runs.

Adding a case with a definition

f(p, ...) := e is the same as f(p, ...) = e (add after the function of f) when the variables at the place where it is written have f, and defines a new f otherwise.

top levelglobal variables of the same file
in a functionits parameters and the variables defined earlier in it
branch of a top-level if, body of a whilevariables defined earlier in it

Variables of an outer function, variables of another file (a library loaded by use) and builtin functions are not variables at the place. f(p, ...) := e with such a name defines a new f that hides the outer one and does not change it. To add a case to an f of another file, write f(p, ...) = e.

  • A definition can have a guard. f(p, ...) if c := e returns e only when the arguments match and c is true. Otherwise the next definition written right after it is tried (a different expression in between breaks the chain).
  • A definition with export and f(p, ...) = e cannot have a guard.

Mutual recursion

Declare the name first with fun f (its value is none) and fill it in later with f(p, ...) = e, which is f = f | (p, ...) -> e. Since none | g is g, the first f(p, ...) = e assigns the function itself.

Calling f before it is filled calls none and stops the program.

When the value of f is a guarded function, a function added by f(p, ...) = e is not called even if the guard is false, just as a following | g is not called for a guarded function passed through a variable.

MatchingFailed

A function call, a match or the last function of a fusion that has no matching arm performs MatchingFailed{f, args, loc} instead of stopping. match e { f } is the same call as f(e).

FieldContents
fthe function that was called (the whole fusion for a fusion)
argsa Tuple{...} of the arguments that did not match
locthe position of the failed call or match: Loc{file, line, column}
f := (0) -> "zero" | (1) -> "one"
a := handle f(7) with (MatchingFailed{_, Tuple{n}, _}, k) -> n
println(a)
7
  • The value of the handler is the value of the Handle, not of the expression that called f(7).
  • With no handler, the program prints matching failed and stops. It is not unhandled effect.
  • A handler that accepts only Return{v} or Break{} is passed through. A handler (e, k) -> ... whose pattern matches anything also receives MatchingFailed.

A failure deep inside an arm

Whether to move on to the next arm is decided only by the entry patterns and guards. A MatchingFailed raised deep in the body of an arm whose entry matched propagates outward.

g(0) := "zero"
h := (x) -> g(x) | (x) -> "second arm"

r := handle h(5) with (MatchingFailed{f, _, _}, k) -> "failed in g"
println(r)
"failed in g"
