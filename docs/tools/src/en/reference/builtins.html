Output

print(x) writes a value, and println(x) writes it followed by a newline. A string is written with quotes. put(s) writes the contents of a string as they are.

Integers and comparison

The operators + - * / % and the comparison operators are translated to calls of these functions (see Names the sugar calls). There is no function of the same name without _. To pass an operator as a function, write a lambda such as (a, b) -> a + b.

M-expressions and strings

  • push(Head{a, ...}, x): Head{a, ..., x}.
  • mexpr(h, Tuple{a, ...}) builds the M-expression h{a, ...} with the head h.
  • symname(sym): the name of the symbol as a string (the inverse of intern). intern(s): the symbol named s.
  • strlen(s): the number of characters. ord(s, i): the code of the character at i, or -1 when i is out of range. s[i]: the character at i as a string of length 1.
  • substr(s, i, j): the characters from i to j - 1. _strcat(a, b): a followed by b.

Arrays and tables

  • array(n): a new array of n elements, all none. array_get(a, i), array_set(a, i, x) (returns x) and array_len(a). An index outside 0 to n - 1 is a runtime error.
  • hash(x): a non-negative integer. Values equal by == have the same hash.
  • table(): a new hash table Table{a}, where a is made of arrays. table_get(t, key, default), table_set(t, key, value). Keys are compared by ==. t[key] and t[key] = value also read and write a table (see Indexing and rewriting).

Plain arrays and bit operations

A plain array is an array of untagged integers. The element type is u8 (0 to 255), u16 (0 to 65535) or i32 (an integer), and all elements are 0 when the array is made.

  • u8_array(n), u16_array(n) and i32_array(n): a new array of n elements. a[i] and a[i] = x read and write an element, as do plain_get(a, i) and plain_set(a, i, x) (returns x). A value that does not fit the type and an index out of range are runtime errors.
  • plain_len(a): the number of elements. plain_kind(a): 'u8, 'u16 or 'i32. plain_copy(dst, di, src, si, n) copies n elements of src from si to dst from di. The types must be the same, and the ranges may overlap in one array.
  • bit_and(a, b), bit_or(a, b), bit_xor(a, b) and bit_not(a) work bit by bit on 31-bit two's complement integers.
  • bit_shl(a, k) shifts left by k bits (0 to 31), drops the bits shifted out, and keeps the result in 31 bits. bit_shr(a, k) is the logical shift to the right, taking a as a 31-bit unsigned integer. bit_sar(a, k) is the arithmetic shift, which keeps the sign.

Files and language

  • read_file(path): the contents of the file, including bytes 0. read_bytes(path): the same contents as a u8 array. write_file(path, x) writes all bytes of the string or u8 array x to the file, which is created or emptied; bytes 0 are written as they are. chmod(path, mode) sets the permissions (493 is 755 in octal).
  • argv(): the array of the command-line strings, as argv of C main. The first is the program file and the rest are its arguments. For planck0 a.pk x y they are "a.pk", "x" and "y".
  • load(path): parse and evaluate the file.
  • use(name): load("planck/lib/<name>.pk") once.
  • parse and eval are the functions used by the top level. exit(n) ends the program with the status n.
  • _define_rule(name, e): define the rule by a parsing expression (see The packrat parser). peg_parse is in Grammar declarations.
  • parse_mexpr(s): the parser of M-expressions, with the same arguments and result as parse.
  • _to_text(x): x for a string, the decimal text for an integer, and show(x) (planck/lib/pretty.pk) otherwise, so a value other than a string or an integer in {e} needs use("pretty"). A string with embedded values is joined by _strcat from the left, and an empty piece is left out.
  • _record_declare(name, fields): set the field names of the head name (fields is Tuple{f, ...}). _record_get(t, name): the field.
  • _index_get(a, i) and _index_set(a, i, e) are the functions that a[i] and a[i] = e call, and subst(t, f) is the function that t[f] calls (see Indexing and rewriting).
  • peg_for(xs, f): call f with each element of the list or vector xs, and return none.
