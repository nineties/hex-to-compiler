Builtin functions

These functions are available without use. Most names that start with _ are functions that operators and syntax call. An error such as an index out of range or an unreadable value is a runtime error. Most functions are clear from their names, so only the rules and the exceptions are written here.

Output

print(x) writes a value, and println(x) writes it followed by a newline. A string is written with quotes; only put(s) writes its contents as they are. An M-expression is written in the form of an M-expression, so a list is Cons{a, Cons{1, Nil{}}}.

Numbers and comparison

The operators + - * / % and the comparison operators are translated to calls of _add _sub _mul _div _quo _mod and _lt _le _gt _ge _eq _ne _is (see Names the sugar calls). The rules for their arguments and results are in Numbers. To pass an operator as a function, write a lambda such as (a, b) -> a + b.

M-expressions and strings

  • head, arity, arg and type give the head, the number of arguments, an argument and the type. push(Head{a, ...}, x) is Head{a, ..., x}, and mexpr(h, Tuple{a, ...}) is h{a, ...}.
  • A string is a sequence of bytes. strlen(s) is the number of bytes, 0 bytes included. ord(s, i) is the byte at i, or -1 when out of range. s[i] is that byte as a string of length 1.
  • substr(s, i, j) is the bytes from i to j - 1, and _strcat(a, b) joins two strings. intern(s) is the symbol named s, and symname(sym) is its inverse.

Arrays and tables

  • array(n) makes an array of n elements, all none. array_get(a, i), array_set(a, i, x) (returns x) and array_len(a) read, write and give the length. An index out of range is an error.
  • table_new() makes a hash table. table_get(t, key, default) and table_set(t, key, value), or t[key] and t[key] = value, read and write it (see Indexing and rewriting). Keys are compared by ==. hash(x) is a non-negative integer, and values equal by _eq have the same hash.

Floats and complex numbers

  • itof, fsqrt (NaN for a negative number), ffloor (the result is a float), fexp, flog, fsin, fcos, fpow and fatan2 also take an integer and raise it to a float. A complex number is an error.
  • ftoi(a) is the integer truncated toward 0, and NaN and infinities are errors. ftobits(a) is the 64 bits as a non-negative integer, and bitstof(n) is its inverse, an error when n does not fit 64 bits.
  • ftos(a) is the shortest decimal string that reads back to the same value, which is also what print writes. stof(s) is none when s cannot be read, and _float(s) is an error. A float literal (1.5) is read as a call of _float.
  • complex(re, im) makes a complex number. real(z) and imag(z) give the parts as floats, and conj(z) the conjugate. It is an error unless z is a complex number.

Plain arrays

A plain array is an array of elements of one type. plain_array(kind, n) makes n elements of the type kind, all 0 of that type (false, 0, 0.0 or complex(0, 0)). kind is 'bool; signed 'i8 'i16 'i32 'i64; unsigned 'u8 'u16 'u32 'u64; floats 'f16 'f32 'f64 (IEEE 754); complex numbers 'c64 'c128 (parts in binary32 and binary64). Any other value, or a negative n, is an error. u8_array(n) is plain_array('u8, n), and the other types have the same form.

  • a[i] and a[i] = x (plain_get, plain_set) read and write an element. Reading widens 'f16, 'f32 and 'c64 to binary64 without changing the value.
  • plain_len(a) is n, and plain_kind(a) is the symbol of the type. plain_copy(dst, di, src, si, n) copies n elements of src from si to dst from di. The types must be the same, and the ranges may overlap in one array.

A written value is converted to the type. A value out of range or one that cannot be converted is a runtime error, and nothing wraps around. The exceptions are:

  • A float to an integer type is truncated toward 0, then the range is checked. NaN and infinities are errors. A complex number to an integer or float type is an error.
  • To 'bool, a number is false when it is 0 (0, 0.0, -0.0, complex(0, 0)) and true otherwise, NaN included. true and false go to a number type as 1 and 0.
  • To a float or complex type, the value is rounded to the nearest. A value beyond the maximum of the type is an infinity of the same sign, and an integer beyond the range of binary64 is an error. An integer or a float written to a complex type is the real part, with the imaginary part 0.

Bit operations

bit_and, bit_or, bit_xor and bit_not work bit by bit on integers as infinite-width two's complement, negative integers included. bit_shl(a, k) does not wrap around, and bit_sar(a, k) is the arithmetic shift. A negative k is an error. bit_shr(a, k) is bit_sar when a is not negative, and an error otherwise.

Files and language

  • read_file(path) gives the contents, 0 bytes included. try_read_file gives none when it cannot be read, and read_bytes gives a u8 array. write_file(path, x) writes all bytes of the string or u8 array x (the file is created or emptied), and chmod(path, mode) sets the permissions (493 is 755 in octal).
  • argv() is the array of the command-line strings: the program file first, then its arguments. exit(n) ends the program with the status n.
  • load(path) parses the file and evaluates its top-level expressions with path as the file being loaded. The program file given as the first argument and planck/init.pk are the files being loaded while they run (see Scope of variables). _set_file(path) changes the file being loaded and returns the previous one (none if there is none).
  • use(name) runs load("planck/lib/<name>.pk") once, or the same with the preprocessed library. used_libs is the table of the libraries already loaded.
  • parse and eval are the functions used by the top level.

Functions the syntax implementation calls

  • _define_rule(name, e) defines a rule by a parsing expression (see The packrat parser). peg_parse is in Extending the grammar. parse_mexpr(s) is the parser of M-expressions, with the same arguments and result as parse.
  • _to_text(x) is x for a string, the decimal text for an integer, and show(x) (planck/lib/pretty.pk) otherwise, so a value other than a string or an integer in {e} needs use("pretty"). A string with embedded values is joined by _strcat from the left, and an empty piece is left out.
  • _record_declare(name, fields) sets the field names of the head name. _record_get(t, name) gives a field, and _record_with(t, name, v) a new value in which the field is v. _destructure(t, i, n) gives element i of the tuple t of n elements, and stops the program otherwise.
  • _index_get and _index_set are called by a[i] and a[i] = e, and subst(t, f) by t[f]. peg_for(xs, f) calls f with each element of the list, vector or range xs and returns none. Range{a, b} includes b.

The name of a function in a runtime error message can differ from the builtin function that was called.
