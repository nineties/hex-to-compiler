init.pk と M式

planck0 が最初に読むのが planck/init.pk です。まだ M式しか読めないので、全部 M式で書かれています。111 行で、この先で使う関数と表を用意します。

M式で書くということ

M式は「頭{引数, ...}」だけでできた書き方です。x + 1 のような演算子も if もないので、全部を特殊形式と関数の呼び出しで書きます。たとえば not はこうです。

Fusion で 2 つの Lambda をつないでいます。引数が false なら 1 つめ、それ以外は 2 つめが選ばれます。パターンの Quote{false} は値 false そのものに合うパターンです。トップレベルに置いた文字列 " ... " は何もしないので、コメントとして使っています。

最初の 3 行は true・false・none を、同じ名前のシンボルとして定義します（[[planck/init.pk#8-10]]）。

表

次は表（ハッシュ表）です。planck0 の組み込みにあるのは配列とハッシュ値までです。表そのものは init.pk が配列で組み立てます（[[planck/init.pk#18-77]]）。

表は「バケツの配列」と「項目の数」の 2 つを持つ配列です。項目が増えてバケツの数を超えると、バケツを倍にします。キーは eq で比べます。パーサのメモや規則の表、ライブラリの読み込み済みの印など、この先のあちこちで使います。

ファイルを読む

load はファイルを読んで 1 つずつ評価します。やっていることは planck0 の interpret_file と同じで、そのときの parse と eval を使います。

use は load に読み込み済みの印を付けたものです（[[planck/init.pk#103-106]]）。

構文に切り替える

最後の 2 行で packrat パーサと構文を読み込みます。

planck/peg.pk は M式で書いたパーサです（次のページ）。planck/syntax.pk はそのパーサで planck の構文を定義し、最後に parse を差し替えます（その次のページ）。syntax.pk を読み終えると、そのあとに読むファイルはすべて planck の構文で読まれます。planck/lib のライブラリも、利用者のプログラムもそうです。
