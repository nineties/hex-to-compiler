planck0 の中身

planck0 は M式だけを読む小さな処理系です。M式を 1 つ読むたびにバイトコードにして、自前の仮想機械で動かします。ファイルは planck0.sv の 1 本です。

全体の流れ

main は準備をしてから planck/init.pk を読み、続いてコマンドラインのファイルを順に読みます。

ファイルを読むのは interpret_file です（[[planck0.sv#2269-2298]]）。大事なのは、1 つの式ごとに大域変数 parse と eval を呼び直している点です。call_global は「Apply{名前, Tuple{引数}} という M式を作ってコンパイルし、動かす」だけの関数です（[[planck0.sv#2264-2267]]）。だからプログラムが parse を差し替えると、次の式からは新しい parse で読まれます。planck の構文はこの仕組みの上に乗っています。

値の表し方

値は 32 ビットの 1 語です。最下位ビットが 1 なら小さな整数で、値を 1 つずらして入れます。0 ならヒープ上の物を指します。ヒープの物は先頭に 1 語のヘッダを持ち、そこに種類と長さが入っています。

シンボルと M式は intern されます。同じ中身の M式はメモリ上でも 1 つなので、比較がポインタの比較ですみます（[[planck0.sv#327-336]]）。

ヒープは起動時に 1GB を確保し、前から順に切り出します。GC はありません（[[planck0.sv#36-67]]）。

M式のリーダ

組み込みの parse は M式だけを読みます。シンボル・整数・文字列と、シンボルのあとに { が続く Head{...} の 4 つです（[[planck0.sv#766-856]]）。M式の引数は 16 個までです。

この parse は、planck の構文が入ったあとも parse_mexpr という名前で残ります。

コンパイラ

M式はバイトコードにコンパイルしてから動かします。compile は整数と文字列を定数に、シンボルを変数の読み出しに、M式を compile_mexpr に回します（[[planck0.sv#1427-1442]]）。

compile_mexpr は頭を見て分かれます（[[planck0.sv#1252-1425]]）。Apply・Def・Set・Do・If・While・Lambda・Fusion・Quote・QuasiQuote・Handle・Perform が特殊形式で、それ以外の頭は引数を評価して同じ頭の M式を作るコンストラクタになります。

変数はコンパイルの時に「何段外の環境の何番目か」に解決します。Def でトップレベルに作った変数と、どこにも束縛されていない名前は大域変数で、実行時に表を引きます。関数がトップレベルの自分自身を呼べるのはこのためです。

仮想機械

仮想機械の命令は 18 個です。設計はファイルの中の長い注釈にまとまっています。

要点は、フレームを機械のスタックではなくヒープに置いていることです。仮想機械は自分自身を再帰で呼びません。今の計算の状態は「今のフレームからトップレベルのフレームまでの鎖」だけで表せます。継続はこの鎖へのポインタなので、作るのも呼ぶのも軽くすみます。

呼び出しとパターン照合

関数を呼ぶと、select が引数に合う関数を選びます（[[planck0.sv#1598-1626]]）。Fusion なら左を試し、だめなら右を試します。Lambda なら引数の数を比べてから、パターンを 1 つずつ照合します。

match_pat は、変数なら新しい環境の次の場所に値を書き、Quote なら等しさを比べ、_TypeOf なら種類を見てから中のパターンを照合します。M式のパターンは頭と引数の数を比べ、引数ごとに再帰します。合う関数がなければ matching failed を出して止まります（[[planck0.sv#1679-1691]]）。

eval も組み込み関数の 1 つです。呼ばれると M式をその場でコンパイルし、新しいフレームで動かします（[[planck0.sv#1657-1661]]）。

エフェクト

Handle は、本体を新しいフレームで動かし、そのフレームにハンドラの印を付けます（[[planck0.sv#1806-1813]]）。Perform は、今のフレームから呼び出し元へ鎖をたどり、印の付いたフレームを探します。

見つけたら、継続 k（今のフレームと境目のフレームの組）を作り、ハンドラを (v, k) で照合します。合わなければさらに外の印を探します。ハンドラの値は境目のフレームの呼び出し元に返るので、Handle 式の値になります。

k を呼ぶと、今のフレームから境目までのフレームを写し、写したほうを動かします（resume、[[planck0.sv#1628-1645]]）。元のフレームは一度も動かさないので、同じ k を何度でも呼べます。
