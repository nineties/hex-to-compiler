処理系の実装

planck の処理系は、手で書いた機械語から始めて 1 段ずつ積み上げて作ります。どの段も、前の段が作ったものだけを使います。外のアセンブラやコンパイラは使いません。

積み上げの全体

  1. pforth — 16 進で手書きした機械語の Forth。pforth.xxd を xxd -r で実行ファイルに戻します。
  2. plisp — pforth の上で Forth を育て、その Forth で書いた Lisp。plisp.fs
  3. asm・sasm — plisp で書いた x86 のアセンブラと、C に似た構造化アセンブリ言語。asm/core.lisp・sasm/core.lisp
  4. plisp2 — sasm で書き直した速い Lisp。plisp2.sv
  5. planck0 — sasm で書いた planck の核。M式を読み、バイトコードにして仮想機械で動かします。planck0.sv
  6. planck — planck0 の上に M式で書いた起動の手順・packrat パーサ・構文。init.pk・peg.pk・syntax.pk

make はこの順に作ります。Makefile の該当する行は次のとおりです。

pforth:  xxd -r -c 8 pforth.xxd > pforth
plisp2:  ./pforth < plisp.fs sasm.lisp plisp2.sv tmp-plisp2
planck0: ./plisp2 sasm.lisp planck0.sv planck0

plisp は実行ファイルになりません。pforth が起動するたびに plisp.fs を読んで Lisp を組み立てます。その Lisp が sasm.lisp を動かし、plisp2.sv を機械語にします。できた plisp2 で、今度は planck0.sv を機械語にします。

各ページ

  • 機械語から planck0 まで — pforth・plisp・asm・sasm・plisp2 のつくり
  • planck0 の中身 — 値の表し方・M式のリーダ・コンパイラ・仮想機械・パターン照合・エフェクト
  • init.pk と M式 — 核の上に最初に積むもの
  • packrat パーサ — データとしての文法・メモ化・左再帰
  • 構文を planck で書く — planck の構文を規則で定義し、parse を差し替える
