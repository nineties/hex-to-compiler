構文の定義

planck/syntax.pk は、planck の構文を packrat パーサの規則として定義し、最後に parse を差し替えます。構文は処理系に組み込まれておらず、planck のプログラムの一部です。

字句

識別子・整数・文字列などの字句は、構文解析式でなく関数で書きます。読めたら次の位置を返す関数です。

予約語の表 peg_reserved の単語と f" の f は識別子になりません（[[planck/syntax.pk#10-26]]）。関数は define_rule にそのまま渡せば規則になります（[[planck/syntax.pk#123-126]]）。

式

規則は結合の弱い順に expr・union・arrow・ternary・or_expr と続き、primary で終わります（[[planck/syntax.pk#145-290]]）。加減算の規則は次のとおりです。

add_expr は直接左再帰なので左結合です。動作 peg_binop は（左, 演算子, 右）を Apply{add, Tuple{a, b}} にします（[[planck/syntax.pk#130-132]]）。二項の - の前の Same{} は次の字句が同じ行にあるときだけ成功するので、行頭の -1 は新しい式になります。

動作が返すのは評価器が受け取る M式そのものです。1 + 2 は Apply{add, Tuple{1, 2}} になり、M式で直接書いた場合と同じ木です。

primary の最後の選択肢 sugar_primary が match・return・break・continue・for を持ちます（[[planck/syntax.pk#1100-1122]]）。

文法の宣言

::= も規則 syntax_decl が読み、define_rule を呼ぶ木にします。

選択肢の項目と動作は g_alt が Act{Seq{...}, Lambda{Tuple{Tuple{ラベル, ...}}, 動作}} に組み替えます（[[planck/syntax.pk#309-319]]）。ラベルは動作の無名関数の引数パターンになります。

syntax_decl は expr の最初の選択肢なので、::= は式を書ける所ならどこにでも書けます。新しい規則は次のトップレベルの式から効きます。

return と break の読み替え

return・break・continue はエフェクトに読み替えます。return を読むたびに数を数え、関数の木を作るときに数が増えていれば本体を Handle で包みます（[[planck/syntax.pk#927-950]]）。

for の本体の return x は Perform{Return{x}} になり、関数の本体全体が Handle{..., (Return{v}, k) -> v} で包まれます。for は peg_for の呼び出しです。

規則で読む文字列

name{| text |} は関数で書いた規則 embed が読みます（[[planck/syntax.pk#1124-1149]]）。name と {| のあと規則 name をその位置から呼び、続く |} を求めます。規則の値は Quote{v} として木に入ります。

parse の差し替え

末尾の2行で切り替えます。

M式のリーダを parse_mexpr として残し、parse を規則 toplevel で1式読む関数にします。planck0 は式ごとに parse を引き直すので（planck0）、syntax.pk の次の式から planck の構文で読まれます。toplevel は expr を1つ読み、;・改行・次の式の始まりのどれかを確かめます（[[planck/syntax.pk#149-151]]）。

primary に ident{expr, ...} の選択肢があるので、M式もそのまま式として読めます。
