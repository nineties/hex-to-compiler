9. 変数の範囲

名前がどの変数を指すかは、プログラムの書かれた位置から、式を実行する前に決まります。関数に定義を追加するか隠すかは3章にあります。

名前の解決

変数の範囲は字句的で、名前がどの変数を指すかは、式を実行する前に、プログラムの書かれた位置から決まります。関数の本体から見えるのは、その関数と外側の関数の引数と変数、およびトップレベルでそれより前に定義した変数です。呼んだ側の変数は見えません。read_n() は caller の中の n ではなく、トップレベルの n を読みます。

同じ名前を := でもう一度定義すると新しい変数ができ、前に作った関数は前の変数を指したままです。get は最初の x を指すので、x = 10 が代入する新しい x は見えません。

どの変数も指さない名前があると、その式を実行する前にメッセージを出してプログラムが止まります。later は3行目で定義されていて、2行目からは見えません。1行目は先に実行されるので "start" は出ます。

規則の全体はリファレンスの変数の範囲にあります。
