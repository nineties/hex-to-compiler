8. クオートと評価器

ソースは M式に読まれてから評価されます。構文木は通常の値なので、組み立て・検査・評価・文字列への逆変換ができます。

クオート

'e は Quote{e} で、e の構文木を値にします。演算子は組み込み関数の Apply になります。`e は準クオートで、!e（UnQuote）の所だけ評価して埋めます。eval は木をトップレベルの式としてその場でコンパイルし、実行します。

M式で書く

M式はそのまま式として書けます。構文は M式への読み替えで、対応の一覧は構文にあります。

parse と eval の差し替え

トップレベルは式ごとに大域変数 parse（文字列 -> Tuple{M式, 残り}）と eval（M式 -> 値）を引き直します。差し替えると次の式から効きます。planck/syntax.pk も最後に parse を差し替えて planck の構文を入れています。

unparse

unparse は文法の規則を逆にたどって木を文字列に戻します。::= で足した規則で読める木も、その規則で戻ります。

長めの例は planck/examples にあります。処理系の側から見た同じ仕組みは処理系の実装にあります。
