8. レコード・局所関数・脱出

record は新しい型と、そのデータを作る関数を定義する宣言です。return・break・continue は5章のエフェクトとして実装されています。

型 Point と作る関数 point は別の名前です。x @ Point のパターンで型を調べ、with で欄を替えたコピーを作ります。

局所関数と脱出

互いに呼び合う関数は、先に fun f で名前を宣言し、あとで f(x) = ... で埋めます。

for の本体は関数ですが、その中の return は外の関数から抜けます。break・continue の対象は一番内側の while か for です。
