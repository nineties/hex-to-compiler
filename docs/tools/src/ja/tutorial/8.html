8. レコード・局所関数・脱出

record は M式の引数に名前を付ける宣言です。return・break・continue は5章のエフェクトとして実装されています。

record

record Point(x, y) は頭 Point の0番目と1番目の引数に名前を付けるだけで、値は Point{3, 4} のままです。パターンでも分解できます。. の前に空白は置けません。

局所関数

ブロックの中の f(x) := ... はトップレベルと同じ形の関数定義です。書いた場所で定義されるので、互いに呼び合う関数は先に fun f で名前を宣言し、あとで f(x) = ... で埋めます。関数の本体が見るのは定義した場所の変数で、呼んだ側の変数ではありません（変数の範囲）。

定義が足すとき・隠すとき

f(p, ...) := e は、同じ場所に f が定義済みなら場合を足し、なければ新しい f を定義します。場所は、トップレベルでは同じファイル、関数の中ではその関数の引数と、その関数でそれより前に定義した変数です。外の name は inner の中の場所の変数ではないので、inner の中の name(0) := "inner" は新しい name を定義し、外の name は変わりません。

別のファイルで定義した関数と組み込み関数も、プログラムのトップレベルでは同じ場所の変数ではありません。sum(xs) := ... は新しい sum を定義して use("list") の sum を隠します。ライブラリの関数に場合を足すときは last(Tuple{a, b}) = b のように = で書き、足した場合は元の場合のあとに試されます。

return・break・continue

return e は囲む関数から抜けます。for の本体は関数ですが、その中の return は外の find_first から抜けます。break・continue は一番内側の while か for に効きます。
