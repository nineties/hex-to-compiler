1. 式・束縛・関数

文はなく、if・while・ブロックも式です。

Hello, world

出力と整数

整数の / は0方向に切り捨てます。リテラルは10進のほかに 0x・0o・0b が使えます。式は改行か ; で区切ります。# から行末はコメントです。

print・println は値をソースに書く形で出し、put は文字列の中身だけを出します。

束縛

:= は定義、= は既存の変数への代入で、2つは別の操作です。関数の中で := した変数はその関数の変数で、外からは見えません（変数の範囲）。

関数

f(p, ...) := e で関数を定義します。x -> e・(a, b) -> e・() -> e は無名関数です。関数名と ( の間に空白は置けません。

if (c) a else b は式で、else がなければ値は none です。偽は false だけで、0 も none も真として扱います。論理演算は and・or・not です。

ブロックと閉包

{ ... } は順に評価して最後の式の値を返します。

関数はレキシカルスコープの閉包で、捕らえた変数を書き換えられます。

変数の範囲

変数の範囲は字句的で、名前がどの変数を指すかは、式を実行する前に、プログラムの書かれた位置から決まります。関数の本体から見えるのは、その関数と外側の関数の引数と変数、およびトップレベルでそれより前に定義した変数です。呼んだ側の変数は見えません。read_n() は caller の中の n ではなく、トップレベルの n を読みます。

同じ名前を := でもう一度定義すると新しい変数ができ、前に作った関数は前の変数を指したままです。get は最初の x を指すので、x = 10 が代入する新しい x は見えません。

どの変数も指さない名前があると、その式を実行する前にメッセージを出してプログラムが止まります。later は3行目で定義されていて、2行目からは見えません。1行目は先に実行されるので "start" は出ます。規則の全体は変数の範囲にあります。
