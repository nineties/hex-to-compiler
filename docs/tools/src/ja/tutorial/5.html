5. 代数的エフェクト

perform v は、一番近い handle のハンドラを h(v, k) で呼びます。k は perform の継続で、何度でも呼べるので、例外・生成器・非決定計算が同じ仕組みで書けます。

例外

ハンドラの値が handle 式の値です。k を呼ばなければ残りの計算は捨てられます。

再開と生成器

k(x) は perform が x を返したものとして計算を再開します。同じ walk でも、ハンドラが値の使い方を決めます。

多重再開

候補ごとに k を呼んで結果を連結しています。N クイーンは planck/examples/queens.pk にあります。
