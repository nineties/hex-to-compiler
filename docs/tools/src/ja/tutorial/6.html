6. クオートと評価器

ソースは M式に読まれてから評価されます。構文木は通常の値なので、組み立て・検査・評価・文字列への逆変換ができます。

  • 'e は e の構文木を値にします。`e は準クオートで、!e の所だけ評価して埋めます。
  • eval は木をその場でコンパイルして実行します。

parse と eval の差し替え

トップレベルは式ごとに大域変数 parse と eval を引き直すので、差し替えると次の式から使われます（文法の拡張）。

unparse

文法の規則を逆にたどって木を文字列に戻します。長めのサンプルは planck/examples にあります。
