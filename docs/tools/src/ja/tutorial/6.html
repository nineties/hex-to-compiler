6. クオートと評価器

ソースは M式に読まれてから評価されます。構文木は通常の値なので、組み立て・検査・評価・文字列への逆変換ができます。

クオート

  • 'e は Quote{e} で、e の構文木を値にします。演算子は組み込み関数の Apply になります。
  • `e は準クオートで、!e（UnQuote）の所だけ評価して埋めます。
  • eval は木をトップレベルの式としてその場でコンパイルし、実行します。

M式の直接の記述

M式はそのまま式として書けます。

parse と eval の差し替え

トップレベルは式ごとに大域変数 parse（文字列 -> Tuple{M式, 残り}）と eval（M式 -> 値）を引き直します。差し替えた関数は次の式から使われます。

unparse

unparse は文法の規則を逆にたどって木を文字列に戻します。::=（7章）で足した規則で読める木も、その規則で文字列に戻ります。

長めのサンプルは planck/examples を参照してください。
