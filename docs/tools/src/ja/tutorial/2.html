2. 値と M式

値は整数・文字列・シンボル・M式・関数・配列の6種類です。データ構造もプログラムも M式で表します。

typeof値
int整数。42・-1・0x1f
stringバイト列としての文字列。"abc"
symbol'apple。true・false・none もシンボル
mexprHead{a, ...}
function無名関数・融合・組み込み関数・継続
arrayarray(n) で作る固定長で書き換えられる配列

文字列

長さと位置はバイト単位で、0から数えます。substr(s, i, j) は半開区間 [i, j) です。f"..." は {式} の値を埋め込みます。

M式

Head{a, ...} は頭のシンボルと引数の列からなる木です。宣言は要りません。== は構造で比べます。planck0 は M式を intern するので、この比較はポインタの比較です。頭と { の間に空白は置けません。

リストと組

[1, 2, 3] は Cons{1, Cons{2, Cons{3, Nil{}}}}、x :: xs は Cons{x, xs} の構文です。(a, b) は Tuple{a, b} です。println は M式の形のまま出します。use("pretty") すると f"..." の埋め込みがリストを [...] の形で書きます。
