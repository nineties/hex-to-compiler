vasm の検査器

planck/lib/vasm/check.pkは、機械命令に近い低級な言語 vasm の読み込みと検査を planck で書いたライブラリです。use("vasm/check") で読み込みます。vasm{| ... |} に書いた関数と構造体の並びを、所有と借用の違反・解放後の使用・未初期化の読み出しについて型の規則だけで検査します。言語の規則はリファレンスの vasmにあります。

入口の関数

vasm{| ... |} は Module{[Struct{...}, Fn{...}, ...]} に読まれます。vasm_check.check(m) はこれを受け取り、VasmErr{kind, Pos{d}, msg} のリストを返します。vasm_check.errors(file, m) は位置をファイルの Loc{file, line, column} に直し、vasm_check.report(file, m) はそれを file:行:列: メッセージ で書きます。誤りのない関数は結果に現れず、1つの関数の誤りは最初の1件だけです。この頁の例は各ファイルの report で結果を1行ずつ書きます。

構文

vasm の構文は packrat パーサの規則として ::= で宣言します（[[planck/lib/vasm/check.pk vasm_kw ::=]]）。予約語は vasm_kw に集め、名前は予約語でない識別子です。文の規則は頭ごとに選択肢を並べ、読んだ結果を Decl{...}・IfS{...}・Assign{...} などの M式にします。

どの規則の結果にも位置の at が入っています。vasm_here は何も読まずに、次の字句から本文の終わりまでの文字数を Pos{d} として返す規則です（[[planck/lib/vasm/check.pk # vasm_here reads nothing .. _define_rule('vasm_same]]）。検査の誤りはこの Pos を持ち、vasm_check.errors が本文の長さから引いて行と列にします。

型と検査の状態

型も M式です。整数は I8{} から U64{}、箱は Own{u}、借用は Ref{'shr または 'mut, 領域, u}、配列は Arr{u}、構造体は Named{s} です。文字列リテラルは項 Str{at, s} で、型は Ref{'shr, 'static, Arr{U8{}}} です。static は予約語で、vasm_outlives がどの領域よりも長く続く領域として扱います。

検査器は関数ごとに、変数の宣言を vasm_info（名前から型へ）に、変数の状態を Vs{status, loans} の表に保持します。status は初期化済み・未初期化・move 済み・解放済み・中身を取り出した箱・フィールドを取り出した構造体のどれかで、loans はその変数を借りている借用の並びです。if や while は状態の表を複製して分岐ごとに検査し、あとで突き合わせます。

値が move されるかコピーされるかは型で決まります。own と own を持つ構造体は線形で、使うと move され、move と解放は合わせて高々1回です。整数・bool・own を持たない構造体と共有の借用はコピーされます。

所有

own i64 は box で確保した整数のただ1つの持ち主です。bump の [r] は呼び出しごとに決まる領域の引数です。&mut を借用の引数に渡す呼び出しは、vasm_reborrows が呼び出しの間だけ借り直すものとして扱い、move しません（[[planck/lib/vasm/check.pk # An &mut register given to a borrow parameter]]）。m がそのあとも使えるのはこのためです。

レジスタを読む前に vasm_need_init が状態を引き、未初期化・move 済み・解放済みならそれぞれ 'uninit・'moved・'freed の誤りにします（[[planck/lib/vasm/check.pk vasm_need_init(at, st, x) :=]]）。free した own が読めず、もう一度 free もできないのは、vasm_call が free の引数を解放済みにするからです。q を p に代入すると q が move 済みになり、所有が p に移ります。

自動の解放

own を持った値は持ち主がなくなる所で自動的に解放されます。その場所は、ブロックや関数の終わり、上書き、文として捨てた関数の結果、free した値の中に残ったものです。このため上の例はどれも誤りになりません。解放は実行時の動作で、検査の対象ではありません。return と関数の終わりで呼ぶ vasm_leak_all は本体が空の関数で、解放の場所を示すためにあります（[[planck/lib/vasm/check.pk # What an own value still owns]]）。上書きは vasm_assign が状態を初期化済みに戻すだけです（[[planck/lib/vasm/check.pk vasm_assign(at, st, x, t) :=]]）。free は早く解放したいときに書きます。

借用と領域

借用した変数の Vs には Loan{region, kind} が入ります。借りている間の move・解放・代入は vasm_no_loans が、&mut で借りている間の読み書きは vasm_no_mut_loan が誤りにします（[[planck/lib/vasm/check.pk vasm_no_loans(at, st, x, what) :=]]）。共有の借用は同時にいくつでも持てますが、&mut は1つだけで、借りている間は元の値を読むことも書き換えることも解放することもできません。region r { ... } の終わりでは、vasm_end_region が r の貸しを消します（[[planck/lib/vasm/check.pk vasm_end_region(st, r) :=]]）。

領域の内外は vasm_outlives(q, r) が決めます。q が r と同じか static のとき、または r が関数の中で開いた領域で q がそれより前に開いたものであるとき、q は r より長く続きます。関数の領域の引数どうしには順序がありません。

代入や引数で借用の型が合うかは vasm_fits が判定します。外側の領域の借用を内側の領域の借用として使うことは、外側のほうが長く続くので許され、逆は許されません。逆のうち、受け側が関数の中で開いた領域より外のレジスタである場合は、vasm_escapes で判定して 'escape の誤りにします。

分岐とループ

if は両方の分岐を複製した状態で検査し、vasm_merge が突き合わせます。片方の分岐だけで move や解放をした値は、あとで持ち主かどうかが決まらないので 'branch の誤りです。return で終わった分岐は .dead の印を付けて突き合わせから外します。while は本体を2周分検査し、vasm_loop_same が、ループで move した値が次の周の前に入れ直されているかを確かめます（'loop）。

整数の幅

整数の型は vasm_check.ints の表（型・名前・ビット数・符号）に並べてあります（[[planck/lib/vasm/check.pk # the integer types]]）。演算の両辺は同じ型で、幅や符号を変えるには as を使います。リテラルははじめ型のない Lit{n} で、整数の型と合わせるときに範囲を検査します。範囲は -32768 から 32767 までで、符号なしの型は 0 から、8 ビットの型はその型の範囲に狭まります（vasm_lit_lo・vasm_lit_hi、[[planck/lib/vasm/check.pk vasm_lit_lo(e) :=]]）。大きな値はシフトと | で組み立てます。

配列と構造体

組み込みの関数は、型変数 T を含む型 Sig{領域, 引数, 結果} の表 vasm_check.builtins に並べてあります（[[planck/lib/vasm/check.pk # the built-in functions]]）。alloc(n, v) は v を n 個並べた own [T] を作り、len は長さを返します。添字は i64 です。範囲の検査は実行時に行い、検査器が検査するのは型と所有だけです。構造体は全部のフィールドを1回ずつ書いて作り、own を持たなければ整数と同じくコピーされます。own を持つかどうかは vasm_owning がフィールドをたどって判定します（[[planck/lib/vasm/check.pk # t owns a value]]）。

own を持つ値の入れ替え

own を持つ値は、配列の要素やポインタの指す先から読んでコピーできません（持ち主が2人になるため）。swap(p[i], v) は v を入れて前の値を取り出します。引数の型 Place{T} は、*p・p[i]・p.f の形の場所だけを受け付けます。構造体のレジスタのフィールドへの書き込み img.body = b は、前の値を解放して入れ替えます。

誤りの返し方

検査の途中で誤りを見つけると vasm_fail が代数的エフェクト VasmFail{at, kind, msg} を起こします（代数的エフェクト）。vasm_check.check は構造体と関数ごとに handle でこれを受け、VasmErr にして検査を打ち切るので、1つの関数の誤りは最初の1件になります。kind の種類はリファレンスの表にあります。
