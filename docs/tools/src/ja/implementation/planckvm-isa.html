planckvm の命令

planckvm の外部仕様のうち、命令、組み込み関数、planck の各機能に対応する命令を説明します。機械と値についてはplanckvm: 実行モデルと値を、実装の中の設計についてはplanckvm の内部仕様を参照してください。

表記: スタックは左を底として書きます。a b -> r は2個取り出して1個積むことを表します。オペランドは、k が定数表の添字、c がセル（k の一種）、d i が環境の深さと添字、L が命令列の添字、n が個数、p が組み込みの命令の値です。列の印は、S が確保などで GC が走りうるセーフポイント、W がライトバリア、T が条件を満たさないと止まることを表します。

関数の入口には、パターンの数だけ命令列を並べます。照合に失敗すると L へジャンプし、そのときオペランドスタックを空にします。L には NEXT を置きます。引数がパターンの変数に束縛されるときは、STORE 0 i と POP で環境に書き込みます。

ADD SUB MUL DIV MOD LT GE は引数が数でなければ止まります。型の混在と結果の型については、実行モデルの「数」を参照してください。HEAD から PLAINSET までの命令は、引数の型が違うときと範囲外のときに止まります（ORD の範囲外を除く）。

組み込みと命令

高頻度で呼ばれるものだけを命令にします。実行のたびに通る定数、変数、制御、呼び出し、照合、エフェクト、演算子と、呼び出しの多い組み込みが該当します。それ以外は組み込み関数にして、命令を増やしません。型で分かれる演算は、値の型を見る1つの命令にします。

命令にしない組み込み

機械の組み込みです（実行モデルの「呼び出し」の表の組み込み）。GLOAD c と引数を積んで CALL n で呼びます。

機械の組み込みの確保とエラーは、呼んだ CALL の S と T に含まれます。mexpr substr _strcat intern symname array plain_array plain_len plain_kind は、引数の型が違うときと範囲外のときもエラーです。

ビット演算の引数は整数です。負の数も含めて無限桁の2の補数として扱います。

浮動小数点数を受け取る組み込みは整数も受け取り、浮動小数点数に揃えます。複素数を渡すとエラーです。

eval の実行中に PERFORM が起きても、eval の内側のフレームは通常のフレームとして複製できます。
