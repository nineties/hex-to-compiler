planckvm の命令

planckvm の外部仕様のうち、命令、組み込み関数、planck の各機能に対応する命令を説明します。機械と値についてはplanckvm: 実行モデルと値を、実装の中の設計についてはplanckvm の内部仕様を参照してください。

表記: スタックは左を底として書きます。a b -> r は2個取り出して1個積むことを表します。オペランドは、k が定数表の添字、c がセル（k の一種）、d i が環境の深さと添字、L が命令列の添字、n が個数、p が組み込みの命令の値です。列の印は、S が確保などで GC が走りうるセーフポイント、W がライトバリア、T が条件を満たさないと止まることを表します。

プログラムは _index_get のように大域の関数に代入できるので、a + b を ADD に決め打ちできません。CALLP を使えば、組み込みを上書きしたプログラムも正しく動きます。

関数の入口には、パターンの数だけ命令列を並べます。照合に失敗すると L へジャンプし、そのときオペランドスタックを空にします。L には NEXT を置きます。引数がパターンの変数に束縛されるときは、STORE 0 i と POP で環境に書き込みます。PARAM STORE POP を1つにまとめた命令は用意しません。

HANDLE の本体の末尾呼び出しは TCALL と書きますが、境界フレームは捨てません。

ADD SUB MUL DIV LT は引数が数でなければ止まります。型の混在と結果の型については、実行モデルの「数」を参照してください。HEAD から PLAINSET までの命令は、引数の型が違うときと範囲外のときに止まります（ORD の範囲外を除く）。

組み込みと命令

高頻度で呼ばれるものだけを命令にします。実行のたびに通る定数、変数、制御、呼び出し、照合、エフェクト、演算子と、呼び出しの多い組み込みが該当します。それ以外は組み込み関数にして、命令を増やしません。型で分かれる演算は、値の型を見る1つの命令にします。

命令にしない組み込み

種類が planck のものは、命令を使った planck の関数として、評価器のイメージに含めます。大域変数の名前と振る舞いは組み込みと同じです。種類が機械のものは、機械の組み込みです（実行モデルの「呼び出し」の表の組み込み）。どちらも GLOAD c と引数を積んで CALL n で呼びます。

機械の組み込みの確保とエラーは、呼んだ CALL の S と T に含まれます。mexpr substr _strcat intern symname array plain_array plain_len plain_kind は、引数の型が違うときと範囲外のときもエラーです。

ビット演算の引数は整数です。負の数も含めて無限桁の2の補数として扱います。

浮動小数点数を受け取る組み込みは整数も受け取り、浮動小数点数に揃えます。複素数を渡すとエラーです。数学関数は fexp flog fsin fcos fpow fatan2 の6つだけです。複素数の加減乗除と等値比較は ADD SUB MUL DIV EQ で書けます。

フレームを作る組み込みは eval だけです。その実行中に PERFORM が起きても、eval の内側のフレームは通常のフレームとして複製できます。

エラーメッセージに出る関数名は、呼んだ組み込みと異なることがあります。たとえば _mod の引数が整数でないときのメッセージには _div の名前が出ます。

planck のコードで定義する名前

仕様の組み込み関数の表にあって機械の組み込みでない名前は、planck のコードで定義するので命令を必要としません: _define_rule _index_get _index_set _not _record_declare _record_get _to_text false load none parse_mexpr peg_for peg_parse subst table table_get table_set true use used_libs。

planckvm が仕様に追加する組み込みは、plain_array、浮動小数点数の関数 fsqrt ffloor ftoi ftobits bitstof ftos stof fexp flog fsin fcos fpow fatan2、複素数の complex real imag、plain 配列の型ごとの作成関数、itof conj です。

場所によって変わる規則

命令の意味は場所によって変わりません。違いはコンパイラが選ぶ命令に現れます。

場所規則命令への影響
トップレベル（ブロックの外）の x := e大域変数。新しいセルを作るGSET c
トップレベルでも if や while のブロックの中にある x := e局所変数。トップレベルのコードの環境に置くSTORE 0 i
関数の中の x := e局所変数。同じ関数の新しいスロットに置くSTORE 0 i
Declare{x}（f(p) := e の前半）同じ場所に変数があれば何もしない。トップレベルで同じ場所にあたるのは、読み込み中のファイルで定義した大域変数だけ。別ファイルの大域変数は同じ場所ではないので、新しく作って隠す_set_file が示すファイルを使ってコンパイル時に判定する
関数の中の Declare{x}同じ場所にあたるのは同じ関数の環境にある変数だけ。外側の関数の変数は同じ場所ではないコンパイル時に判定する
末尾呼び出しどの場所でも TCALL。結果は同じで、スタックの深さだけが変わる命令の選択は場所で変わらない
