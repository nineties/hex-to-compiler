planckvm の命令

planckvm の命令、planck の各機能に対応する命令、命令になる組み込み関数を説明します。機械と値についてはplanckvm: 実行モデルと値を参照してください。planckvm はまだ実装していない設計です。

表記: スタックは左を底として書きます。a b -> r は2個取り出して1個積むことを表します。オペランドは、k が定数表の添字、c がセル（k の一種）、d i が環境の深さと添字、L が命令列の添字、n が個数、p が組み込みの命令番号です。印は、S が確保などで GC が走りうるセーフポイント、W がライトバリア、T が条件を満たさないと止まることを表します。

数

引数が数でなければ T です（EQ を除く）。型の混在と結果の型については、実行モデルの「数」を参照してください。

名前スタック意味組み込み
ADDa b -> ra + b。S_add
SUBa b -> ra - b。S_sub
MULa b -> ra * b。S_mul
DIVa b -> r整数どうしなら 0 方向へ切り捨てた商で、b が 0 なら T。それ以外は通常の割り算で、0 で割っても止まらない。S_div
LTa b -> ra < b を true か false で返す。複素数を含めば T_lt
EQa b -> r実行モデルの「値」の等しさ。数に限らずすべての値を受け取る。true か false を返す_eq

整数どうしの結果が小さい整数に収まるなら、確保せずに済ませてかまいません。確保が起きるのは桁が増えたときと、浮動小数点数や複素数の結果を作るときです。

組み込みと命令

他の命令と planck の式だけでは書けないものを命令にします。値の表現、ヒープ、OS、数値の機械演算、制御に触れるものが該当します。書けるものは planck の関数にして、命令を増やしません。ホットな関数を命令に昇格するかどうかは、測定してから別途決めます。型で分かれる演算は、値の型を見る1つの命令にします。

命令を使った planck の関数として、評価器のイメージに含めます。大域変数の名前と振る舞いは組み込みと同じです。

planck のコードで定義する名前

仕様の組み込み関数の表にあって機械の組み込みでない名前は、planck のコードで定義するので命令を必要としません: _define_rule _index_get _index_set _not _record_declare _record_get _to_text false load none parse_mexpr peg_for peg_parse subst table table_get table_set true use used_libs。

planckvm が仕様に追加する組み込みは、plain_array、浮動小数点数の関数 fsqrt ffloor ftoi ftobits bitstof ftos stof fexp flog fsin fcos fpow fatan2、複素数の complex real imag、plain 配列の型ごとの作成関数、itof conj です。

場所によって変わる規則

命令の意味は場所によって変わりません。違いはコンパイラが選ぶ命令に現れます。

場所規則命令への影響
トップレベル（ブロックの外）の x := e大域変数。新しいセルを作るGSET c
トップレベルでも if や while のブロックの中にある x := e局所変数。トップレベルのコードの環境に置くSTORE 0 i
関数の中の x := e局所変数。同じ関数の新しいスロットに置くSTORE 0 i
Declare{x}（f(p) := e の前半）同じ場所に変数があれば何もしない。トップレベルで同じ場所にあたるのは、読み込み中のファイルで定義した大域変数だけ。別ファイルの大域変数は同じ場所ではないので、新しく作って隠すSETFILE が示すファイルを使ってコンパイル時に判定する
関数の中の Declare{x}同じ場所にあたるのは同じ関数の環境にある変数だけ。外側の関数の変数は同じ場所ではないコンパイル時に判定する
末尾呼び出しどの場所でも TCALL。結果は同じで、スタックの深さだけが変わる命令の選択は場所で変わらない
HANDLE の本体の末尾呼び出しTCALL と書いても境界フレームは捨てない実行時の規則
名前が見つからないどの場所でも、式の実行前にコンパイル時に止める命令は生成しない
前方参照fun f で先に宣言する。関数の中でもトップレベルでも同じfun f は none で始まり、呼ぶと止まる（not a function: none）。GLOAD と LOAD は検査しない
