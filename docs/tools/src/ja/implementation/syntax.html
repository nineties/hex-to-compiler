構文の定義

planck/syntax.pk は、planck の構文を packrat パーサの規則として定義し、最後に parse を差し替えます。構文は処理系に組み込まれておらず、planck のプログラムの一部です。

字句

識別子・整数・文字列などの字句は、構文解析式でなく関数で書きます。読めたら次の位置を返す関数です。

予約語の表 peg_reserved の単語と f" の f は識別子になりません（[[planck/syntax.pk#10-26]]）。関数は _define_rule にそのまま渡せば規則になります（[[planck/syntax.pk#123-126]]）。

式

規則は結合の弱い順に expr・union・arrow・ternary・or_expr と続き、primary で終わります（[[planck/syntax.pk#145-307]]）。加減算の規則は次のとおりです。

add_expr は直接左再帰なので左結合です。動作 peg_binop は（左, 演算子, 右）を Apply{_add, Tuple{a, b}} にします（[[planck/syntax.pk#130-132]]）。二項の - の前の Same{} は次の字句が同じ行にあるときだけ成功するので、行頭の -1 は新しい式になります。

動作が返すのは評価器が受け取る M式そのものです。1 + 2 は Apply{_add, Tuple{1, 2}} になり、M式で直接書いた場合と同じ木です。

primary の最後の選択肢 sugar_primary が match・return・break・continue・for を持ちます（[[planck/syntax.pk#1146-1168]]）。

添字と置き換え

a[i] は規則 postfix の選択肢です。[ は a に空白なしで続け、] のあとが代入の = のときは読みません（[[planck/syntax.pk#247-256]]）。a[i] = e は規則 expr の選択肢が _index_set の呼び出しにします（[[planck/syntax.pk#161-162]]）。

[ ] の中は規則 index で、式1つか、t[p -> e | q if c -> g] の腕の列です（[[planck/syntax.pk#261-269]]）。腕は match と同じ形の関数にまとめ、ガードのある腕がどれも当てはまらないときは peg_skip を返すようにします（[[planck/syntax.pk#522-549]]）。

_index_get と _index_set は、種類ごとの Lambda を Fusion でつないだ関数です（[[planck/syntax.pk#1279-1335]]・[[planck/syntax.pk#1353-1405]]）。表は Table{t}、リストは Cons{x, xs} と Nil{} の頭で選ぶので、パターンだけで種類が決まります。関数 f を添字にすると subst(t, f) を呼びます（[[planck/syntax.pk#1200-1247]]）。subst は f の最後に「peg_skip を返す」腕を足し、それ以外の値が返った部分は置き換えて内側を試さず、peg_skip が返った部分は引数ごとに自分を呼びます。

利用者が _index_get = (K{...}, i) -> ... | _index_get と代入すると、新しい種類が元の関数の前に入ります。planck/lib/vector.pk の末尾はこの書き方です。

文法の宣言

::= も規則 syntax_decl が読み、_define_rule を呼ぶ木にします。

選択肢の項目と動作は g_alt が Act{Seq{...}, Lambda{Tuple{Tuple{ラベル, ...}}, 動作}} に組み替えます（[[planck/syntax.pk#326-336]]）。ラベルは動作の無名関数の引数パターンになります。

syntax_decl は expr の最初の選択肢なので、::= は式を書ける所ならどこにでも書けます。新しい規則は次のトップレベルの式から効きます。

return と break の読み替え

return・break・continue はエフェクトに読み替えます。return を読むたびに数を数え、関数の木を作るときに数が増えていれば本体を Handle で包みます（[[planck/syntax.pk#973-995]]）。

for の本体の return x は Perform{Return{x}} になり、関数の本体全体が Handle{..., (Return{v}, k) -> v} で包まれます。for は peg_for の呼び出しです。

規則で読む文字列

name{| text |} は関数で書いた規則 embed が読みます（[[planck/syntax.pk#1407-1432]]）。name と {| のあと規則 name をその位置から呼び、続く |} を求めます。規則の値は Quote{v} として木に入ります。

parse の差し替え

末尾の2行で切り替えます。

M式のリーダを parse_mexpr として残し、parse を規則 toplevel で1式読む関数にします。planck0 は式ごとに parse を引き直すので（planck0）、syntax.pk の次の式から planck の構文で読まれます。toplevel は expr を1つ読み、;・改行・次の式の始まりのどれかを確かめます（[[planck/syntax.pk#149-151]]）。

primary に ident{expr, ...} の選択肢があるので、M式もそのまま式として読めます。
