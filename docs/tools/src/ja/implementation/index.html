処理系の実装

planck の処理系を、手書きの機械語から planck の構文まで、ソースを引用しながら説明します。ステージの全体は概要にあります。各ステージは前のステージの成果物だけで作ります。planck0 から先は、planck 自身のファイルを実行時に読んで組み立てます。

ビルドの順序

plisp には実行ファイルがありません。pforth は起動のたびに bootstrap/plisp.fs を読んで Lisp を組み立て、その Lisp が bootstrap/sasm.lisp で bootstrap/plisp2.sv をコンパイルします。planck0 は plisp2 の上の同じ bootstrap/sasm.lisp でコンパイルします。planck0 は init.pk・peg.pk と syntax.pk の前半を M式として読みます。
