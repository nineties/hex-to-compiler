planckvm のデータ型

すべての値は type を持ち、head を持つのは M式だけです。HASH は EQ で等しい値に同じ値を返します。整数は 1 種類で、大きさに上限がありません。

型と head

M式の型は Expr、head は symbol です。M式以外の値に head を使うとエラーです。

arity と arg(v, i) は、M式なら引数の個数と i 番目の引数、ユーザーデータならフィールドの数と i 番目のフィールドです。それ以外の値はエラーです。

バイトコードの中の整数

命令の欄に収まる整数は、欄に符号つき（2 の補数）で書きます。収まらない整数は定数表に置き、命令は添字を持ちます。同じ値をどちらでも書けるときは、命令の欄を使います。

定数表の整数は、符号の word（0 は 0 以上、1 は負）、桁数の word、64 ビットの桁（下位から）の順です。

ハッシュ

HASH は 0 以上 230-1 以下の整数を返します。

  • 整数は値だけで決まります。符号を 0（0 以上）か 1（負）の acc とし、絶対値を下位から 16 ビットずつ取った各 d について acc = (acc * 31 + d + 7) mod 230 を繰り返します。0 のハッシュは 0 です。
  • 整数に等しい float と、虚部が 0 で実部が整数に等しい complex は、その整数と同じ値です。
  • それ以外の float・complex・文字列・symbol・M式は、中身が等しければ同じ値です。array と plain array は、要素から作った値で、equal な array は同じ値です。関数は、オブジェクトごとに値が変わりません。
