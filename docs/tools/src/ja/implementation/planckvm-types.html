planckvm のデータ型

この頁は、planckvm の値の種類、頭、等しさ、ハッシュを定めます。値のヒープ上の表し方はplanckvm の値の表し方にあります。実行モデルはplanckvm: 実行モデルと値、命令はplanckvm の命令にあります。

整数は 1 種類で、大きさに上限がありません。何ビットまでを語の中に入れるかは、言語の値の仕様には現れません。ビット数が現れるのは plain 配列の要素の型（'i8 から 'u64 まで）だけです。

頭

すべての値が頭（head）を持ちます。M式の頭は自分の頭のシンボルで、それ以外の値の頭は上の表の型名のシンボルです。型名のシンボルは M式の頭にできません。

  • true・false・none はシンボルなので、頭は Symbol です。
  • 値の種類の判別は head で行い、種類を返す別の組み込みは持ちません。
  • パターンの x @ Int は head が Int の値に合います。M式の頭を判別するパターン Head{p, ...} と同じ規則で、型名の頭は M式の頭にできないので、M式と取り違えません。

バイトコードの中の整数

バイトコードの形は、整数が語の中に入る幅に依りません。整数は次のどちらかで書きます。

  • 命令の欄に収まる整数は、欄に符号つき（2 の補数）で書きます。欄の幅は命令の形式で決まります（ABC 形式の C は 8 ビット、AD 形式の D は 16 ビット、J 形式の sJ は 24 ビット）。
  • 収まらない整数は、定数表に整数の定数として置き、命令は定数表の添字を持ちます。定数表の整数は、符号の語（0 は 0 以上、1 は負）、桁数の語、64 ビットの桁（下位の桁から、下位の語が先）の順に並べます。

どちらの形も、読み込むと通常の整数の値になります。同じ値を定数表と命令の欄の両方で書けるときは、命令の欄に書きます。

同一性と等しさ

  • 同じ値どうしは等しいです。ただし NaN は自分自身と等しくありません。
  • 整数は値が同じときに等しいです。
  • 浮動小数点数・複素数・文字列・M式は、別のオブジェクトでも中身が等しければ等しいです。M式は頭と引数を再帰的に比べます。
  • シンボルは名前ごとに一意なので、同一性で比べます。
  • 配列・plain 配列・関数は同一のオブジェクトだけが等しくなります。
  • 型をまたぐ数の等しさ（整数と浮動小数点数と複素数）はplanckvm: 実行モデルと値の「数」のとおりです。

ハッシュ

HASH は 0 以上 230-1 以下の整数を返します。EQ で等しい値は同じ値になります。

  • 整数は値だけで決まります。値の符号を 0（0 以上）か 1（負）の acc とし、絶対値を下位から 16 ビットずつ取った各 d について acc = (acc * 31 + d + 7) mod 230 を繰り返した結果です。0 のハッシュは 0 です。桁の幅には依りません。
  • 整数に等しい浮動小数点数と、虚部が 0 で実部が整数に等しい複素数は、その整数と同じ値です。
  • それ以外の浮動小数点数・複素数・文字列・シンボル・M式は中身で決まります。中身が等しければ値が同じで、具体的な値は定めません。
  • 配列・plain 配列・関数は、オブジェクトごとに決まり、そのオブジェクトの間は変わらない値です。
