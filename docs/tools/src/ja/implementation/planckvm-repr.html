planckvm の内部表現

word の下位 1 ビットが即値か参照かを分け、オブジェクトの種類はヘッダの kind が決めます。「生」の欄は数そのもので、それ以外の欄は値の word です。GC は値の欄だけをたどります。

word とヘッダ

ヒープ・レジスタ・フレームの word はすべて 32 ビットで、ビットの番号は最下位を 0 とします。

  • 整数の即値は 2n+1 で、n は 31 ビットの 2 の補数です。即値に収まる整数は必ず即値で表し、収まらないものだけを多倍長整数のオブジェクトで表します。float・complex・文字列・symbol はすべてオブジェクトです。
  • 参照は、オブジェクトのヘッダの添字（ヒープの先頭からの word 単位）の 2 倍です。
  • オブジェクトの先頭の word がヘッダで、値ではありません。size はヘッダの後の word 数です。r は GC がオブジェクトを移したときだけ 1 になります。移したあとの元のヘッダは、r が 1 で、上位 30 ビットが移した先のヘッダの添字です。

オブジェクトの中身

「word」はヘッダの次を 0 とした位置です。64 ビットの量は、下位の word を先に置きます。環境・セル・コードは、値としてプログラムに渡りません。

整数の即値の head も Int です。array・plain array・Lambda・Fusion・組み込み・継続・ユーザーデータの identity の番号は、最初の HASH が 1 以上の番号を割り当てるまで 0 で、そのあとは変わりません。

plain array の要素

型の番号は、'bool が 0、'i8 〜 'i64 が 1〜4、'u8 〜 'u64 が 5〜8、'f16 'f32 'f64 が 9〜11、'c64 'c128 が 12〜13 です。要素の大きさは、'bool が 1 バイトで、ほかは型名のビット数です。

  • 要素はタグを持たないビット列で、リトルエンディアンで隙間なく並べます。i 番目の要素はバイト位置 i * (要素のバイト数) から始まり、バイト位置 b は word 3 + b/4 の下位から b mod 4 番目のバイトです。
  • 整数型は 2 の補数、'bool は true が 1、浮動小数点型は IEEE 754 のビット列で、complex 型は実部、虚部の順です。最後の word の余りは 0 で、作った直後の要素は全ビットが 0 です。
