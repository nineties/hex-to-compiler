planckvm の値の表し方

planckvm の値のヒープ上の表し方を定めます。語の表し方、ヘッダ、種類ごとの中身、GC から見た扱いです。言語としての値の種類・等しさ・ハッシュはplanckvm のデータ型にあります。この頁は内部仕様で、イメージを書く側と処理系の実装が従います。

語

ヒープ・レジスタ・フレームの語はすべて 32 ビットで、ビットの番号は最下位を 0 とします。語の下位 1 ビットが値の種別を分けます。

種別下位ビット語の値
整数の即値12n+1。n は 31 ビットの 2 の補数で、-230 以上 230-1 以下
オブジェクトへの参照0オブジェクトのヘッダの、ヒープの先頭からの語単位の添字の 2 倍
  • 言語の整数は 1 種類です。即値に収まる値は必ず即値で表し、収まらない値だけを多倍長整数のオブジェクトで表します。
  • 即値は整数だけです。浮動小数点数・複素数・文字列・シンボルはすべてオブジェクトです。
  • 語の中にオブジェクトの種類は入りません。種類はオブジェクトのヘッダを読んで知ります。

ヘッダ

オブジェクトの先頭の語はヘッダです。オブジェクトはヘッダとそれに続く語でできています。

欄意味
sizeヘッダの後に続く語数。オブジェクトの大きさはヘッダを含めて size + 1 語
kindオブジェクトの種類。下の表のとおり
mGC が使う印。イメージでは 0
下位ビットヘッダでは 1

ヘッダの語は値ではなく、レジスタにもオブジェクトの欄にも入りません。下位ビットが 0 の語がヘッダの位置にあるときは、GC がそのオブジェクトを移した先の参照です。イメージにはありません。

kind は 0 から 14 を使い、15 は使いません。

整数の即値の head は Int です。環境・セル・コードは値としてプログラムに渡りません。

オブジェクトの中身

以降の表の「語」は、ヘッダの次の語を 0 とした位置です。「値」と書いた欄には値の語（即値か参照）を置きます。「生」と書いた欄は、値でなく語そのものの数です。64 ビットの量を 2 語に分けるときは、下位の語を先に置きます。

多倍長整数

語中身
0符号（生。0 は 0 以上、1 は負）
1桁数 n（生。1 以上）
2〜3桁 0（64 ビット。下位の語が先）
4〜5桁 1
…桁 n-1
  • 値は符号と絶対値で表します。絶対値の桁は底 264 で、下位の桁から並べます。
  • size は 2 + 2n です。桁数は size 欄に収まる範囲に限られます。
  • 最上位の桁は 0 ではありません。値が即値の範囲に収まる整数は、多倍長整数にしません。0 は即値です。

文字列

  • 作った直後の要素は全ビットが 0 で、false・0・0.0・complex(0, 0) を表します。

同一性の番号

配列・plain 配列・Lambda・Fusion・組み込み・継続は、語 0 に同一性の番号を持ちます。作った直後は 0 で、番号を割り当てるまで 0 のままです。最初の HASH が 1 以上の番号を割り当て、以降は変わりません。同じ機械で割り当てる番号は互いに異なります。
