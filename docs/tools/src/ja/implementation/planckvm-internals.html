planckvm の内部仕様

実装の中の設計です。呼び出しの状態はレジスタスタックとフレームスタックだけに置き、継続はその複製、GC は評価器自身が持ちます。評価器は native で書き、vasm にコンパイルして実行します。外部仕様は実行モデルと値と命令にあります。

方針

  • 評価器は、式を命令に変換して命令ループで実行するバイトコードインタプリタです。命令ループは自分を再帰呼び出しせず、ホストのエフェクトと継続も使いません。
  • 命令列は作成後に変わらず、パターン照合は呼ばれる側のコードの中にあります。

スタック

レジスタスタックとフレームスタックは連続した領域で、どちらも GC の根です。満杯になると stack overflow で止まります。

フレーム

フレームは 7 語で、fn（実行中の Lambda）・env（現在の環境）・alts（呼ばれた Fusion、無ければ none）・next（次に試す選択肢の番号）・base（窓の先頭のレジスタスタックの添字）・pc（別のフレームを呼んでいる間の次の命令の添字）・ret の順です。next・base・pc はタグなしの整数です。

  • kind: 0 は通常のフレーム、1 は境界（ハンドラが R[-1]、本体の Lambda が R[-2]）、2 は転送（PERFORM がハンドラを呼んだフレームで、R[0] が送られた値、R[1] が継続）。
  • mode: 0 は返り値を呼び出し元の R[reg] に入れる、1 と 2 は呼び出したのが k = 0、k = 1 の条件の命令、3 は捨てる。

呼び出しと復帰

  • CALL A B C が Lambda を選ぶと、pc を保存して、base が現在の base + B + 1、ret の reg が A のフレームを積みます。引数は動かしません。HANDLE A B は base + B + 2、kind = 1 のフレームを積みます。
  • RET はフレームを捨て、その ret のとおりに値を渡します。TCALL は引数を R[-1] から移して現在のフレームを置き換え、ret は kind だけ 0 にして引き継ぎます。
  • NEXT は next から順に、引数の個数が合う選択肢を選びます。Lambda なら fn と env を置き換えて pc を 0 にします。尽きたとき、kind が 2 なら転送に進み、それ以外は呼び出し元のフレームから PERFORM と同じ手順で MatchingFailed{f, args, loc} を送ります。継続の再開では、渡した値が失敗した呼び出しの結果になります。境界が無ければ matching failed で止まります。
  • 組み込みの上書きは、語 guard の各ビット（命令の組み込みの欄の名前に1つずつ対応）で判定します。SETGLOBAL が名前のセルに書くときにビットを更新し、命令はまず guard が 0 かを見ます。上書きされていれば R[nregs] に関数、その上に引数を置いて CALL と同じに呼びます。

継続

継続はヒープ上のオブジェクトで、フレームスタックとレジスタスタックの切片のコピーです。

  1. PERFORM A B は、現在のフレームから下へ kind = 1 のフレーム F を探します。無ければ unhandled effect で止まります（MatchingFailed は matching failed）。
  2. F から現在のフレームまでのフレームと、F.base - 2 から現在の R[nregs-1] までのレジスタをコピーして継続を作ります。コピーの base は切片の先頭からの差です。
  3. F より上を捨て、F の位置に kind = 2 のフレームを作り、送られた値と継続を R[0] と R[1] に入れてハンドラを選びます。一致が無ければ、下の次の境界 G までの切片に元の切片をつないだ新しい継続を作り、G で同じことを繰り返します。
  4. 再開は、切片を呼び出した窓の上にコピーして各フレームの base にその位置を足し、最後のフレームを現在のフレームにして、保存した pc から続けます。最初のフレーム（境界）の ret は CALL が積むフレームと同じに決めます。

ヒープとガベージコレクション

値の word とオブジェクトの中身は内部表現にあります。GC は若い世代と古い世代の2世代のコピー GC で、評価器の一部として native で書きます。確保は若い世代から行い、収まらないオブジェクトだけを古い世代に直接確保します。

  • 若い世代が満杯になると、根と記憶集合からたどれる若いオブジェクトを古い世代へコピーします。古い世代が満杯になれば、2つの半空間の間でコピーします。
  • 命令の表で S の付いた命令は、確保で GC が走ることがあります。GC は命令の副作用より前に走り、命令の入力は GC が更新するレジスタから読み直します。ループの途中のセーフポイントはありません。
  • 実行中の値はすべて、レジスタスタック・フレームスタック・セル・評価器の状態（シンボル表や組み込みの一時スロット）・記憶集合のどれかからたどれます。評価器のローカル変数にだけ存在する値はありません。

レジスタの生死の表は持たず、レジスタスタックの要素は常に有効な値か none です。起動時に全要素を none で埋め、GC が根より上の使われた範囲を none で埋めて、この状態を保ちます。範囲の上端は、窓を作るときに更新する語 high に記録します。

古い世代のオブジェクトに若いオブジェクトへの参照を書くとき（ENVSET SETGLOBAL ASET）、ヘッダの r が 0 ならそのオブジェクトを記憶集合に記録して r を 1 にします。

関数の identity（EQ と HASH）は、アドレスでなく、最初の HASH のときに割り当てる番号で表します。
