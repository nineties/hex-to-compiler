planck0

planck0 は M式だけを読む処理系です。トップレベルの M式を1つ読むたびにバイトコードにコンパイルし、ヒープ上にフレームを置く仮想機械で実行します。ソースは planck0.sv の1本です。

トップレベル

main は準備をしてから planck/init.pk を読み、続いて最初の引数のプログラムファイルを読みます。

ファイルは interpret_file が読みます（[[planck0.sv#2596-2625]]）。式ごとに大域変数 parse と eval を call_global で呼び直します。call_global は Apply{名前, Tuple{引数}} を組み立ててコンパイルし、実行します（[[planck0.sv#2591-2594]]）。このため parse を差し替えると次の式から新しい parse で読まれ、planck の構文はこの仕組みで入ります。

値の表現

値は32ビットの1語です。最下位ビットが1なら1ビット左シフトした整数、0ならヒープ上のオブジェクトへのポインタです。オブジェクトは先頭の1語のヘッダに種類と長さを持ちます。

シンボルと M式は intern します。同じ構造の M式はメモリ上で1つなので、等価性はポインタの比較です（[[planck0.sv#329-338]]）。

ヒープは起動時に mmap2 で確保する1GB の領域で、先頭から順に切り出します。GC はありません（[[planck0.sv#36-67]]）。

M式のリーダ

組み込みの parse が読むのは、シンボル・整数・文字列と、シンボルの直後に { が続く Head{...} の4種類です（[[planck0.sv#797-887]]）。M式の引数は16個までです。

planck の構文が入ったあとも、このリーダは parse_mexpr として残ります。

コンパイラ

compile は整数と文字列を定数に、シンボルを変数の参照にし、M式を compile_mexpr に渡します（[[planck0.sv#1477-1492]]）。

compile_mexpr は頭で分岐します（[[planck0.sv#1301-1475]]）。Apply・Def・Set・Do・If・While・Lambda・Fusion・Quote・QuasiQuote・Handle・Perform が特殊形式で、それ以外の頭は引数を評価して同じ頭の M式を作るコンストラクタになります。

局所変数はコンパイル時に（環境の深さ, 位置）の組に解決します。大域変数は欄（値と名前の2語）で、コンパイラは名前から最新の欄を引く表 global_table を持ちます。トップレベルの Def は新しい欄を作って表の項目を差し替え（[[planck0.sv#465-473]]）、命令 GLOAD・GDEF・GSET には名前でなく欄を埋め込みます（[[planck0.sv#1154-1181]]）。名前が指す変数は式を実行する前に決まり、前にコンパイルした関数は前の欄を指したままです。Set は今の欄に書き込みます。局所にも大域にも見つからない名前は、その式を実行する前にメッセージを出して止まります。

Def は右辺をコンパイルしたあとに欄を作るので、右辺からは前の変数が見えます。関数が自分自身を参照できるのは、構文が Def{f, none} で先に欄を作り、Set で関数を入れる形に読み替えるからです。埋める前に呼ぶと none を呼ぶことになって止まります。

仮想機械

命令は18個です。設計はソース中の注釈にあります。

フレームは機械のスタックでなくヒープに置き、仮想機械は自分自身を再帰呼び出ししません。計算の状態は現在のフレームからトップレベルまでのフレームの鎖だけで表せるので、継続はこの鎖へのポインタで済みます。

呼び出しとパターン照合

呼び出しでは select が引数に合う関数を選びます（[[planck0.sv#1648-1676]]）。Fusion は左、失敗すれば右を試します。Lambda は引数の数を比べてからパターンを順に照合します。

match_pat は、変数なら新しい環境の次の位置に値を書き、Quote なら等価性を比べ、_TypeOf なら種類を確かめてから内側を照合します。M式のパターンは頭と引数の数を比べ、引数ごとに再帰します。合う関数がなければ matching failed で止まります（[[planck0.sv#1730-1742]]）。

組み込みの eval は、M式をトップレベルの式としてコンパイルし、新しいフレームで実行します（[[planck0.sv#1707-1711]]）。

組み込み関数

組み込み関数は init_prims が defprim で大域の表に欄を作って登録します。名前・引数の数・実装の関数・種類を渡します（[[planck0.sv#2488-2496]]）。演算子と文字列の連結は糖衣の呼ぶ名前で登録され、_add・_sub・_mul・_div・_mod・_lt・_le・_gt・_ge・_eq・_ne・_strcat のように _ で始まります（[[planck0.sv#2498-2553]]）。_ のない add や strcat は登録しないので、プログラムの同名の変数が演算子の意味を変えません。

エフェクト

Handle は本体を新しいフレームで実行し、そのフレームにハンドラを記録します（[[planck0.sv#1854-1861]]）。Perform は現在のフレームから呼び出し元へ鎖をたどり、ハンドラを持つフレームを探します。

見つけたら継続 k（現在のフレームと境界のフレームの組）を作り、ハンドラを (v, k) で照合します。合わなければさらに外側を探します。ハンドラの値は境界のフレームの呼び出し元に返り、Handle 式の値になります。

k を呼ぶと、現在のフレームから境界までを複製し、複製を実行します（resume、[[planck0.sv#1678-1695]]）。元のフレームは実行しないので、同じ k を何度でも呼べます（多重継続）。
