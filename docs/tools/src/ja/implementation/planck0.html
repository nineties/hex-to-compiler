planck0

planck0 は M式だけを読む処理系です。トップレベルの M式を1つ読むたびにバイトコードにコンパイルし、ヒープ上にフレームを置く仮想機械で実行します。ソースは planck0.sv の1本です。

トップレベル

main は準備をしてから planck/init.pk を読み、続いてコマンドラインのファイルを順に読みます。

ファイルは interpret_file が読みます（[[planck0.sv#2566-2595]]）。式ごとに大域変数 parse と eval を call_global で呼び直します。call_global は Apply{名前, Tuple{引数}} を組み立ててコンパイルし、実行します（[[planck0.sv#2561-2564]]）。このため parse を差し替えると次の式から新しい parse で読まれ、planck の構文はこの仕組みで入ります。

値の表現

値は32ビットの1語です。最下位ビットが1なら1ビット左シフトした整数、0ならヒープ上のオブジェクトへのポインタです。オブジェクトは先頭の1語のヘッダに種類と長さを持ちます。

シンボルと M式は intern します。同じ構造の M式はメモリ上で1つなので、等価性はポインタの比較です（[[planck0.sv#329-338]]）。

ヒープは起動時に mmap2 で確保する1GB の領域で、先頭から順に切り出します。GC はありません（[[planck0.sv#36-67]]）。

M式のリーダ

組み込みの parse が読むのは、シンボル・整数・文字列と、シンボルの直後に { が続く Head{...} の4種類です（[[planck0.sv#784-874]]）。M式の引数は16個までです。

planck の構文が入ったあとも、このリーダは parse_mexpr として残ります。

コンパイラ

compile は整数と文字列を定数に、シンボルを変数の参照にし、M式を compile_mexpr に渡します（[[planck0.sv#1445-1460]]）。

compile_mexpr は頭で分岐します（[[planck0.sv#1270-1443]]）。Apply・Def・Set・Do・If・While・Lambda・Fusion・Quote・QuasiQuote・Handle・Perform が特殊形式で、それ以外の頭は引数を評価して同じ頭の M式を作るコンストラクタになります。

局所変数はコンパイル時に（環境の深さ, 位置）の組に解決します。トップレベルの Def と束縛されていない名前は大域変数で、実行時に表を引きます。トップレベルの関数が自分自身を参照できるのはこのためです。

仮想機械

命令は18個です。設計はソース中の注釈にあります。

フレームは機械のスタックでなくヒープに置き、仮想機械は自分自身を再帰呼び出ししません。計算の状態は現在のフレームからトップレベルまでのフレームの鎖だけで表せるので、継続はこの鎖へのポインタで済みます。

呼び出しとパターン照合

呼び出しでは select が引数に合う関数を選びます（[[planck0.sv#1616-1644]]）。Fusion は左、失敗すれば右を試します。Lambda は引数の数を比べてからパターンを順に照合します。

match_pat は、変数なら新しい環境の次の位置に値を書き、Quote なら等価性を比べ、_TypeOf なら種類を確かめてから内側を照合します。M式のパターンは頭と引数の数を比べ、引数ごとに再帰します。合う関数がなければ matching failed で止まります（[[planck0.sv#1698-1710]]）。

組み込みの eval は、M式をトップレベルの式としてコンパイルし、新しいフレームで実行します（[[planck0.sv#1675-1679]]）。

組み込み関数

組み込み関数は init_prims が defprim で大域の表に登録します。名前・引数の数・実装の関数・種類を渡します（[[planck0.sv#2459-2467]]）。演算子と文字列の連結は糖衣の呼ぶ名前で登録され、_add・_sub・_mul・_div・_mod・_lt・_le・_gt・_ge・_eq・_ne・_strcat のように _ で始まります（[[planck0.sv#2469-2524]]）。_ のない add や strcat は登録しないので、プログラムの同名の変数が演算子の意味を変えません。

エフェクト

Handle は本体を新しいフレームで実行し、そのフレームにハンドラを記録します（[[planck0.sv#1825-1832]]）。Perform は現在のフレームから呼び出し元へ鎖をたどり、ハンドラを持つフレームを探します。

見つけたら継続 k（現在のフレームと境界のフレームの組）を作り、ハンドラを (v, k) で照合します。合わなければさらに外側を探します。ハンドラの値は境界のフレームの呼び出し元に返り、Handle 式の値になります。

k を呼ぶと、現在のフレームから境界までを複製し、複製を実行します（resume、[[planck0.sv#1646-1663]]）。元のフレームは実行しないので、同じ k を何度でも呼べます（多重継続）。
