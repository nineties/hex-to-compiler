機械語から planck0 まで

16進ダンプで書いた Forth から、sasm で書いた planck0 までのブートストラップのステージです。

pforth

pforth.xxd は16進ダンプで、右側の注釈は xxd -r -c 8 が無視します。戻したバイト列がそのまま32ビット x86 Linux の ELF 実行ファイルです。

辞書の初期状態は1文字の名前の組み込み語だけです。k は1文字読む、t は1文字書く、f は文字から語を引く、x は語を実行する、などです。

最初の解釈器は k・f・x を繰り返すだけです。この段階の Hello World は次のとおりです。

plisp

plisp.fs は pforth への入力です。先頭は1文字の語だけの列です。空白と改行は何もしない語に、\ は行コメントの語に登録します（[[bootstrap/plisp.fs h@l@h@!h@C+h!k1k0-h@$k:k0 .. \ plancklisp -]]）。以降は自己拡張で Forth を組み立てます。

  • 2番目の解釈器は、名前で語を引き、コンパイル状態を持ちます（[[bootstrap/plisp.fs \ The 2nd Phase Interpreter .. \ '\'' ( "name"]]）。
  • 通常の Forth の語として、条件分岐・ループ・再帰・構造体を定義します（[[bootstrap/plisp.fs \ === Compilers === .. ( === 3rd Phase Interpreter === )]]）。
  • 3番目の解釈器は、辞書にない語を数として読み、数でもなければエラーを出して止まります（[[bootstrap/plisp.fs ( === 3rd Phase Interpreter === ) .. ( === Do-loop === )]]）。

その Forth で Lisp インタプリタを書きます（[[bootstrap/plisp.fs ( === Implementation of PlanckLISP === )]] 以降）。リスト、ノード、リーダとプリンタ、評価器の順に作ります。最後に bootstrap/plisp/init.lisp を読みます（[[bootstrap/plisp.fs s" bootstrap/plisp/init.lisp" eval-file]]）。

asm と sasm

どちらも plisp の上で動きます。性能と安全性より実装の単純さを優先しています。

asm/core.lisp は x86 32ビットのアセンブラです。S式の命令列から ELF を直接書き出し、ヘッダ・コード・データを読み書き実行可能な1つの PT_LOAD に置きます。

sasm/core.lisp は構造化アセンブリ言語 sasm のコンパイラです。sasm は型のない C 風の言語で、変数・関数・if・while があり、plisp の内部 DSL として実装されています。レジスタ割り付けはせず、スタックへの push と pop を繰り返すコードを生成して、asm で機械語にします。

plisp2

plisp2.sv は同じ Lisp を sasm で書き直したものです。構成は次の順です。

  • メモリ確保（[[bootstrap/plisp2.sv ; === Memory Allocation .. ; === Utilities]]）
  • ノード（[[bootstrap/plisp2.sv ; === Nodes .. ; === Parser and Printer]]）
  • リーダとプリンタ（[[bootstrap/plisp2.sv ; === Parser and Printer .. ; === Eval]]）
  • 評価器（[[bootstrap/plisp2.sv ; === Eval .. ; === Primitive Functions]]）
  • 組み込み関数（[[bootstrap/plisp2.sv ; === Primitive Functions ..]]）

ビルドは2段です。まず plisp の上の sasm で plisp2 をコンパイルします。次に、できた plisp2 の上で同じ sasm が bootstrap/planck0.sv をコンパイルします。

planck0

planck0.svも sasm で書かれています。中身はplanck0の頁にあります。
