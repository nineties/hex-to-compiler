機械語から planck0 まで

16進ダンプの Forth から sasm で書いた planck0 まで、各段は前の段の上で、次の段をより高級な言語で書き直します。

pforth

pforth.xxd は16進ダンプです。右側の注釈は xxd -r -c 8 が無視し、戻したバイト列がそのまま32ビット x86 Linux の ELF 実行ファイルです。

辞書は1文字の名前の組み込み語だけで、最初の解釈器は、1文字読む k、語を引く f、実行する x を繰り返します。

plisp

plisp.fs は pforth への入力です。1文字の語だけで書いた先頭から自己拡張して、名前で語を引く解釈器、条件分岐・ループ・構造体を順に作ります。その Forth で Lisp インタプリタを書き、最後に bootstrap/plisp/init.lisp を読みます。

asm と sasm

どちらも plisp の上で動き、性能と安全性より実装の単純さを優先します。asm/core.lisp は x86 32ビットのアセンブラで、S式の命令列から ELF を直接書き出します。sasm/core.lisp は、型のない C 風の言語 sasm のコンパイラです。レジスタ割り付けはせず、スタックへの push と pop を繰り返すコードを asm で機械語にします。

plisp2 と planck0

plisp2.sv は同じ Lisp を sasm で書き直したものです。ビルドは2段で、plisp の上の sasm で plisp2 をコンパイルし、できた plisp2 の上で同じ sasm が planck0.sv をコンパイルします。中身はplanck0にあります。
