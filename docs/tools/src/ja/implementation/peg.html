packrat パーサ

planck/peg.pk（M式で322行）は PEG を解釈実行するパーサです。文法は M式のデータで、規則の結果を位置ごとにメモ化します。

データとしての文法

構文解析式（規則の右辺）の形はファイルの先頭にあります。

"7" の1回以上の繰り返しは Many1{"7"}、その個数を値にするなら Act{Many1{"7"}, t -> arity(t)} です。_define_rule で名前を付けると規則になります。

::= を使わずに定義した規則も sevens{| ... |} で使えます。::= 自体も _define_rule の呼び出しに読み替えられます（構文の定義）。

解釈実行

peg_px(e, p) は構文解析式 e を位置 p から試し、成功すれば次の位置を返して値を peg_pv に置きます。失敗は -1 です。peg_px・peg_call_rule・peg_run_rule は互いに呼び合うので、Def{名前, none} で名前を宣言し、あとで Set で定義します（[[planck/peg.pk#114-116]]）。

文字列は空白を読み飛ばしてから照合し、シンボルは規則として呼び、関数はそのまま呼びます。Seq・Choice などの M式は、頭ごとの処理を表 peg_handlers から引きます（[[planck/peg.pk#175-210]]）。識別子や整数などの字句は、構文の定義の側で関数として実装しています。

失敗のたびに最も先まで進んだ位置を peg_far に記録し（[[planck/peg.pk#57-59]]）、構文エラーはその位置で報告します。

メモ化と直接左再帰

規則の結果を（位置, 規則）ごとにメモ化します（packrat 構文解析）。バックトラックしても同じ規則を同じ位置で再計算しません。

メモは位置ごとの配列で、規則ごとに終了位置・値・左再帰の印の3欄を持ちます。peg_call_rule はまずメモを引きます（[[planck/peg.pk#234-250]]）。

直接左再帰（sum ::= sum "+" term | term）もメモで扱います。規則の実行中はメモを実行中の印にしておき、同じ位置で再帰呼び出しされたら失敗を返します。これを種として得た結果をメモに置いて規則を再実行し、前より長く読めた間はこれを繰り返します（seed growing）。

この結果 1 - 2 - 3 は (1 - 2) - 3 になります。

規則の定義

_define_rule は規則に番号を振り、動作 Act{e, f} の f を評価してから表に入れます。選択肢の Prev{} はその規則の直前の定義に置き換えます。::= の ... はこの Prev{} です。

評価前の形は peg_sources に残します。unparse のように文法を読む道具はこの表を使います。

入口

peg_parse(rule, s) はメモを作り直してから規則を呼び、Tuple{値, 残り} を返します（[[planck/peg.pk#306-322]]）。失敗すると peg_far の位置から行末までを添えた SyntaxError{...} を返します。
