init.pk と M式

planck0 が最初に読むのが planck/init.pk です。この時点のリーダは M式しか読まないので、114行すべて M式で書かれています。以降で使う関数と表を定義します。

M式だけで書く

演算子も if の構文もないので、すべて特殊形式と関数呼び出しで書きます。not が呼ぶ _not の定義は次のとおりです。

Fusion で2つの Lambda をつなぎ、引数が false なら1つ目、それ以外は2つ目を選びます。Quote{false} はシンボル false に合うパターンです。トップレベルの文字列 " ... " は評価しても何もしないので、コメントとして使っています。

冒頭で true・false・none を同名のシンボルに束縛します（[[planck/init.pk#8-10]]）。

表

planck0 の組み込みは配列と hash までで、ハッシュ表は init.pk が配列で実装します（[[planck/init.pk#18-77]]）。

表は Table{a} で、a はバケットの配列と項目数を持つ配列です。項目数がバケット数を超えるとバケットを倍にします。キーは == と同じ比較で比べます。パーサのメモ表、規則の表、use の読み込み済みの記録などに使います。

ファイルを読む

load は planck0 の interpret_file と同じく、その時点の parse と eval でファイルを1式ずつ評価します。評価の間は _set_file でそのファイルを読み込み中のファイルにするので、ファイルのトップレベルで定義した大域変数は、どのファイルで定義したかが分かります（変数の範囲）。

use は読み込み済みを記録する load です（[[planck/init.pk#104-109]]）。

構文に切り替える

末尾で packrat パーサと構文を読み込みます。

planck/peg.pk は M式で書いたパーサ（packrat パーサ）、planck/syntax.pk はそのパーサで planck の構文を定義して parse を差し替えるファイルです（構文の定義）。以降に読むファイルは、planck/lib も利用者のプログラムも planck の構文で読まれます。
