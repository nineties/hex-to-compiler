init.pk と M式

planck0 が最初に読む planck/init.pk は、以降で使う関数と表を定義します。planck0 のリーダは M式しか読めないので、全体を M式で書き、末尾で構文に切り替えます。

M式だけの記述

演算子も if の構文もないので、特殊形式と関数呼び出しだけで書きます。_not は次のとおりです。

Fusion は2つの Lambda をつなぎ、引数が false なら1つ目、それ以外なら2つ目を使います。Quote{false} はシンボル false に合うパターンです。トップレベルの文字列 " ... " は評価しても何も起きないので、コメントに使います。

冒頭で true・false・none を同名のシンボルに束縛します（[[planck/init.pk Def{true, Quote{true}}]]）。

表

planck0 の組み込みは配列と hash までです。ハッシュ表は init.pk が配列で実装します（[[planck/init.pk " A table is Table{a} .. " === Loading files === "]]）。

表は Table{a} で、a はバケットの配列と項目数を持つ配列です。項目数がバケット数を超えるとバケットを倍にします。キーは == と同じ比較で比べます。

ファイルの読み込み

load は planck0 の interpret_file と同じく、その時点の parse と eval でファイルを1式ずつ評価します。評価の間は _set_file で読み込み中のファイルを切り替えます。そのため、トップレベルで定義した大域変数には、定義したファイルが記録されます（変数の範囲）。

use は、読み込み済みを記録して同じライブラリを1回だけ load する関数です。構文に切り替えたあとで planck/lib/use.pk が定義します（[[planck/lib/use.pk use(name) :=]]）。

構文への切り替え

末尾で packrat パーサ、構文、use を読み込みます。

読み込むのは次の3つです。

  • planck/peg.pk: M式で書いたパーサ（packrat パーサ）。
  • planck/syntax.pk: そのパーサで planck の構文を定義し、parse を差し替えるファイル（構文の定義）。
  • planck/lib/use.pk: 構文で書かれたファイル。

これ以降に読むファイルは、planck/lib も利用者のプログラムも planck の構文で読まれます。
