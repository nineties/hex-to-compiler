init.pk と M式

planck0 が最初に読むのが planck/init.pk です。この時点のリーダは M式しか読まないので、ファイル全体が M式で書かれています。このファイルは以降で使う関数と表を定義します。

M式だけの記述

演算子も if の構文もないので、すべて特殊形式と関数呼び出しで書きます。not が呼ぶ _not の定義は次のとおりです。

Fusion で2つの Lambda をつなぎ、引数が false なら1つ目、それ以外は2つ目を選びます。Quote{false} はシンボル false に合うパターンです。トップレベルの文字列 " ... " は評価しても何もしないので、コメントとして使います。

冒頭で true・false・none を同名のシンボルに束縛します（[[planck/init.pk Def{true, Quote{true}}]]）。

表

planck0 の組み込みは配列と hash までで、ハッシュ表は init.pk が配列で実装します（[[planck/init.pk " A table is Table{a} .. " === Loading files === "]]）。

表は Table{a} で、a はバケットの配列と項目数を持つ配列です。項目数がバケット数を超えるとバケットを倍にします。キーは == と同じ比較で比べます。規則の表、use の読み込み済みの記録などに使います。

ファイルの読み込み

load は planck0 の interpret_file と同じく、その時点の parse と eval でファイルを1式ずつ評価します。評価の間は _set_file でそのファイルを読み込み中のファイルにするので、ファイルのトップレベルで定義した大域変数には、定義したファイルが記録されます（変数の範囲）。

use は、読み込み済みを記録して同じライブラリを1回だけ load する関数です。構文に切り替えたあとで planck/lib/use.pk が定義します（[[planck/lib/use.pk use(name) :=]]）。読み込みのあと、_file_globals で得たそのファイルの大域変数からファイルの値を作って返します（[[planck/lib/use.pk file_value(name, path) :=]]）。

構文への切り替え

末尾で packrat パーサ、構文、use を読み込みます。

planck/peg.pk は M式で書いたパーサ（packrat パーサ）、planck/syntax.pk はそのパーサで planck の構文を定義して parse を差し替えるファイルです（構文の定義）。planck/lib/use.pk は構文で書かれています。以降に読むファイルは、planck/lib も利用者のプログラムも planck の構文で読まれます。
