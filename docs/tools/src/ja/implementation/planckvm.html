planckvm: 実行モデルと値

planckvm は planck の全機能を実行するバイトコードです。planck で書いた評価器が式を planckvm の命令に変換し、命令ループで実行します。この頁とplanckvm の命令が外部仕様で、VM の利用者や planck からコードを生成する側が前提にしてよい動作を定めます。この頁では機械、値、数を説明します。実装の中の設計はplanckvm の内部仕様に書きます。

実行モデル

機械はレジスタマシンです。すべての命令は現在のフレームのレジスタを読み書きします。

名前中身
コード（code）1つの Lambda または1つのトップレベルの式の命令列と定数表。不変。形はバイトコードのフォーマットのとおり
レジスタフレームごとの R[0] から R[nregs-1]。nregs はコードの欄。1つのレジスタに値を1つ入れる
フレーム1回の呼び出しの状態
環境（env）「変数の置き場所」で決まる変数を置くヒープ上の領域。呼び出しごとに作り、親の環境を持つ
セル大域変数1つを表すオブジェクト。値と名前を持つ

レジスタの窓

  • すべてのフレームのレジスタを1本のレジスタスタックの上に置きます。フレームのレジスタの範囲を窓と呼びます。
  • CALL A B C で呼ばれた Lambda の窓は、呼び出し元の R[B+1] から始まります。引数は呼び出し元が R[B+1] から R[B+C] に置くので、コピーせずに呼ばれた側の R[0] から R[C-1] になります。
  • 呼び出しの間、呼び出し元の R[B] には呼ばれた関数が入ったままです。R[B] より上のレジスタの値は呼び出しで失われます。呼び出しをまたいで使う値は R[B] より下に置きます。
  • 引数以外のレジスタの初期値は決まっていないので、読む前に書きます。
  • 窓がレジスタスタックに収まらなければ stack overflow で止まります。

変数の置き場所

変数の指す先は書かれた位置で決まり、コンパイル時に次の3つのいずれかへ解決されます。名前の解決はコンパイル時に終わるので、実行時に未定義の変数は生じません。

置き場所変数読み書き
セル大域変数GETGLOBAL SETGLOBAL
環境関数の変数のうち、(1) 内側の Lambda か Handle の本体から参照されるもの、(2) 代入され、かつ同じコードに CALL TCALL HANDLE PERFORM のどれかがあるものENVGET ENVSET
レジスタそれ以外の関数の変数命令のオペランドに直接書く
  • 「代入される」とは Set の対象になることです。
  • 環境は1回の呼び出しにつき最大1つで、環境に置く変数があるコードだけが NEWENV で作ります。スロットの初期値は none です。NEWENV を実行しないコードの現在の環境は、Lambda が保持する環境です。
  • 環境の変数はコンパイル時に（深さ d, スロット i）へ解決されます。d は現在の環境から親をたどる回数です。
  • Lambda は作られた場所の現在の環境を保持します。環境は共有されるので、Lambda の作成後に行った代入もその関数から見えます。
  • 定義を実行せずにレジスタの変数を読む経路があるときは、コードの入口で LOADNONE によりその変数を none にします。
  • 大域変数はセルで表し、初期値は none です。Def は新しいセルを作り、それ以降にコンパイルした式は新しいセルを指します。それ以前にコンパイルした式は古いセルを指したままです。Set は同じセルに書き込みます。
  • true false none はリテラルで、変数ではありません。レジスタにも環境にもセルにも置かず、定数としてコンパイルします。Def Set Declare の対象に書くとコンパイルエラーです。

呼び出し

CALL A B C は f = R[B] を C 個の引数 R[B+1] 〜 R[B+C] で呼び出します。動作は f の種類で決まります。

f選ぶ条件動作
Lambdaコードの arity が C に等しいとき新しいフレームを作り、コードの先頭から実行する
Fusion a | ba を先に試し、尽きたら b を試す選んだ関数の動作をする
組み込み引数の個数が合うときフレームを作らず、結果をその場で受け取る。eval だけは arity 0 のコードを作り、Lambda と同じくフレームで実行する
継続C が 1 のとき再開する
その他not a function で止まる

コードの入口の命令列がパターンを照合します。一致しなければ NEXT が同じ引数で次の選択肢を試します。入口の命令列は引数のレジスタを書き換えません。選択肢が尽きると matching failed で止まります。

呼ばれた側の RET の値は呼び出した命令に応じて受け取ります。

呼び出した命令受け取り方
条件の命令（TEST から TGEI まで）値が false 以外なら条件が真として、条件の命令の規則に従う
ASET PLAINSET捨てる
それ以外R[A] に入れる

命令の表の「組み込み」の欄に名前のある命令は、その名前のセルの値が元の組み込みのときだけ表の動作をします。セルに別の値が代入されていれば、窓の上に関数と引数を置いてその値を同じ引数で呼び、結果を上の表のとおりに受け取ります。即値は整数の引数として渡します。

継続とハンドラ

  • HANDLE は本体を境界フレームで実行します。本体が正常に終わると、その値が Handle の値になります。
  • PERFORM A B は呼び出し元をたどって最も内側の境界を探し、そこまでのフレームとレジスタを複製して継続 k を作ります。次に、境界より上を捨て、境界のハンドラを引数 (R[B], k) で呼びます。結果は Handle の値になります。
  • ハンドラのどの選択肢にも一致しなければ、次に外側の境界へ進みます。このとき k は外側の境界までの複製として作り直します。内側の境界もこの複製に含まれます。
  • 境界が見つからなければ unhandled effect: v で止まります。
  • k を呼ぶと、複製してあるフレームとレジスタを呼び出した窓の上に再び複製します。境界のハンドラは残ります（deep）。PERFORM の R[A] に k の引数を入れて実行を続けます。本体が終わると、その値は k を呼んだ側に返ります。
  • k は何度でも呼べます。
  • 再開しても環境とセルは複製しないので、環境とセルの変数は再開した複数のコピーで共有されます。レジスタの変数は値を複製します。レジスタの変数は捕捉の後で書き換わらないので、捕捉の時点で定義済みの変数はどのコピーからも同じ値に見えます。再開の後で実行した x := e は、レジスタの変数ならコピーごとに別の変数を定義します。

実行時エラー

実行時エラーが起きると、メッセージを標準エラー出力に書き、終了状態 1 で終了します。捕捉する手段はありません。error.at の Error エフェクトはこの種のエラーではなく、通常の PERFORM です。

トップレベル

  • トップレベルの式1つが arity 0 のコード1つになります。ブロック内の局所変数は関数の変数と同じ規則で、このコードのレジスタか環境に置きます。
  • 式を読んで実行するループは評価器の入口にあり、命令ではありません。式ごとに大域変数 parse と eval のセルを読み、次の入口のコードで呼び出します。
  • 入口のコードは CALL R0 R0 n と HALT R0 の2語です。評価器は R[0] に関数を、R[1] 以降に引数を置いて、レジスタスタックの底で実行します。
  • eval(e) は e をコンパイルしたコードを呼び出したのと同じように実行します。

数

  • 整数は多倍長です。言語の整数は1種類で、範囲外の整数はなく、ラップアラウンドも切り詰めも起きません。
  • 浮動小数点数は IEEE 754 の binary64 で、丸めは最近接偶数です。複素数は浮動小数点数2つの組です。
  • ADD SUB MUL DIV はそれぞれ引数の型を見て動く1つの命令で、整数、浮動小数点数、複素数を受け取ります。型が混在するときは、整数→浮動小数点数→複素数の順で高い方の型に揃えて計算し、結果もその型になります。
  • 整数を浮動小数点数に揃えると、最も近い値に丸められます。2^53 を超える整数は精度が落ちます（2^53 + 1 + 0.0 は浮動小数点数の 2^53）。浮動小数点数で表せる範囲（約 1.8 x 10^308）を超える整数を揃えようとするとエラーです。
  • 整数どうしの DIV は 0 方向へ切り捨てた商を返し、除数が 0 ならエラーです。浮動小数点数か複素数を含む割り算は、0 で割っても止まりません。浮動小数点数なら無限大か NaN になり、複素数なら各成分に同じ規則を適用した値になります。
  • LT と GE は整数と浮動小数点数が混在しても型を揃えず、数学的な値で比べます。NaN を含むと false です。複素数には順序がないので、LT と GE に複素数を渡すとエラーです。
  • EQ では型が違っても値が同じなら等しくなります（1 == 1.0 1 == complex(1, 0)）。NaN は自分自身とも等しくありません。複素数は実部と虚部がともに等しいときに等しくなります。
  • 浮動小数点例外が起きてもプログラムは止まりません。
  • 複素数は complex(re, im) で作ります。リテラルはありません。
