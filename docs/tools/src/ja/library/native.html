native

use("native/compile") が定義するシステム言語です。意味は vasm と同じで、書き方が高級です。native{| ... |} に書いた関数と構造体を native_compile.compile が vasm のモジュールに展開し、所有と借用は展開した vasm に対して検査します。型は変数と関数の宣言から決まり、書くのは宣言の所だけです。

プログラム

プログラムは構造体と関数の並びで、型・構造体・関数の宣言は vasm と同じ書き方です。関数の本体は文の並びで、文は改行か ; で区切ります。値を返す関数は、最後の文が式ならその値を返します。

ほかの単位を使うには、ファイルの先頭に import lib を1行に1つ書きます（vasmc）。native{| ... |} の値は PModule{[...]} で、先頭に import ごとの PImport{at, name} が並びます。

関数返す値
native_compile.compile(m)vasm の Module{[...]}。vasm_check と vasm_build がそのまま受け取る
native_compile.compile_all(m)Tuple{モジュール, 誤りのリスト}。誤りは VasmError{kind, loc, msg} で、関数ごとに最初の1件
native_compile.errors(file, 誤り)位置をファイルの Loc にした誤り

式と文

式の優先順位は、表の上から下へ強くなります。引数は左から順に計算します。

形意味
a or b a and b左で決まれば右を計算しない
== != < <= > >=比較。結果は bool
| ^ &ビットの or・xor・and。この順に強く、and は比較より強い
<< >> + - * / %シフト・加減算・乗除算の順に強い。* は左の項と同じ行に書く
e as T整数の型を変える
-e not e *p &r y &mutable r y符号の反転・否定・箱の中身・借用
a[i] s.f f(a, ...) S{f: a, ...}要素・フィールド・呼び出し・構造体の値

構造体の値は先頭にフィールドを書くので、if や for の本体の { と区別できます。'name・"text"・value H(a, ...)・fun f(a, ...)・true・false は vasm と同じ値です。

  • let x = e・let x: T = e・var x: T（未初期化）。同じ名前を宣言し直すと、前の変数は見えなくなります。
  • 代入 x = e・*p = e・a[i] = e・s.f = e は右辺を先に計算します。+= などの複合代入は左辺の場所を1回だけ読みます。
  • if c {...} else if c {...} else {...}・while c {...}。条件に括弧は要りません。
  • for i in a..b {...}：i は a から b の手前までで、本体の中だけで見えます。b は始めに1回だけ計算します。
  • region r {...}・return・return e は vasm と同じです。

型の決まり方

  • 型を書くのは let・var・パラメータ・関数の結果・as だけです。
  • 整数のリテラルはそれだけでは型がなく、代入先・引数・相手の項・関数の結果の型になります。手がかりのない let x = 5 は誤りで、let x: i64 = 5 か 5 as i64 と書きます。
  • for i in a..b の i は、リテラルでない方の型です。両方リテラルなら誤りで、0 as i64..10 のように一方に型を付けます。
  • 配列の添字は i64 で、ほかの整数型には as i64 が必要です。
  • 借用を結果に持つ関数の呼び出しは、結果の領域が引数から1つに決まるときだけ型を推論します。決まらないときは let x: T = f(...) と書きます。

大きなリテラル

vasm のリテラルは -32768 から 32767 までですが、native はそれを超える整数のリテラルを書けます。型の範囲に入らなければ誤りです。

誤り

展開の誤りの kind は 'type（型が決まらない・リテラルが型の範囲にない・式の文が呼び出しでない）と 'undefined（宣言のない変数・関数・構造体）です。所有・借用・初期化の誤りは、展開した vasm を vasm_check.check が調べます。誤りの位置は native のソースの位置です。
