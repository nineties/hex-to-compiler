vasm

use("vasm/check") が定義する低級言語です。vasm{| ... |} に書いた関数と構造体を、所有と借用の規則で検査します。own の値は持ち主がちょうど1つで、move か free を高々1回します。借用は領域の中でだけ有効で、借用されている間、借用元には触れられません。

プログラム

プログラムは構造体と関数の並びで、どちらもモジュールのどこに書いても全体から見えます。文は改行か ; で区切ります。

関数の [r, ...] は領域の引数です。呼び出しの引数の借用から決まり、決まらなければ誤りです。構造体や関数に、組み込みの関数と同じ名前は付けられません。

値と初期化

  • 読み出せるのは初期化済みのレジスタだけです。if の後は両方の分岐で初期化したものだけ、while の後はループの前の状態です。
  • 整数の演算の両辺は同じ型で、違う幅や符号は as で合わせます。広げるときは元の型の符号に応じて符号拡張かゼロ拡張をし、狭めるときは下位のビットを残します。
  • 整数のリテラルは、代入先・引数・相手の項の型に範囲が合うかを検査します。1つで書けるのは -32768 から 32767 までで、大きな値は m = 0x7F45、m = m << 16、m = m | 0x4C46 のように組み立てます。
  • 文字列リテラルは、読み取り専用のデータに置いた &static [u8] です。エスケープは planck の文字列と同じで、終端はなく、バイト数は len で分かります。項を取る所に書け（write(1, "hello\n")）、要素は書き換えられません。
  • 配列の添字は i64 で、範囲は実行時に検査します。検査器が見るのは型と所有だけです。配列は *p で丸ごと読み書きできません。
  • 構造体の値は、own を持たなければコピー、持てば move です。s.f は、s が構造体のレジスタならその値のフィールド、ポインタなら指す先のフィールドです。

所有

  • own の値は、move するか free するかのどちらかを高々1回します。解放した値・move した値を使うのも、もう一度解放するのも誤りです。
  • 持ち主がなくなる時点で、残っている own は自動的に解放されます。その時点は、ブロックや関数の終わりと return、上書き（p = box(2)・*p = v・p[i] = v・s.f = v の前の値）、文として捨てた関数の結果、free した値の中に残ったものです。
  • 片方の分岐だけで move や解放をした値は、その後の持ち主が決まらないので誤りです。ループは、中で move した値を次の周の前に入れ直す必要があります。
  • 関数は move された引数の持ち主になります。呼び出し元は渡した値をそのあと使えません。

own を持つ値の取り出し

借用や配列の要素から own をコピーして読めません。取り出すには次のどれかを使います。

  • x = *p：中身が own を持つとき中身を move します。p は借用されていない own でなければなりません。取り出したあとの p は中身の無い箱で、*p = v で入れ直すか free(p) するまで読めず、move も借用もできません。
  • x = s.f：構造体のレジスタ s の own を持つフィールドを move します。取り出したフィールドは s.f = v で入れ直すまで読めず、s は丸ごとは使えません。残ったフィールドは s がなくなる時点で解放されます。
  • swap(p[i], v)・swap(p.f, v)・swap(*p, v)：場所は借用されていない own か &mut から書けるものです。

val

val の値は種類を実行時に保持します。検査器は val とほかの型を区別するだけで、種類を検査しません。種類が違う値を操作すると実行時に異常終了します。レジスタの val は整数と同じくコピーされ、move も借用もありません。

借用と領域

  • x = &r p は、p が r より前に宣言され、r の終わりまで有効であることを求めます。借用は r の終わりで解消します。
  • 借用されている間は、p を move・解放・代入できません。&mut で借用されている間は、*p・p[i]・p.f も読めません。
  • 型 &r T は r の中でしか書けません。r の外のレジスタに入れるのも、外へ返すのも誤りです。外の領域 q の借用は、内側の領域 r の借用を期待する所に渡せます。
  • 共有の借用は複製され、いくつでも持てます。&mut はレジスタの間で使うと move されます。
  • 関数の借用の引数に渡した &mut は、呼び出しの間だけ借り直され、move されません。同じ呼び出しの別の引数にもう一度渡すことはできません。& の引数にも渡せます（呼び出しの間だけ共有）。ただし結果の型が借用した領域を含むときは、結果に借用が残るので借り直しにならず、&mut は move されます。
  • 関数の領域の引数どうしに内外の関係はなく、関数の領域は関数の中で開いた領域より外です。領域の引数は、渡された借用の領域のうち一番内側のものに決まります。ただし、ほかが全部それより外でなければなりません。
  • 領域 static はほかのどの領域より長く続き、static の借用はどの領域の借用を期待する所にも置けます。ほかに渡す借用がなければ、領域の引数は static に決まります。逆に、ほかの領域の借用を &static を期待する所に置くことはできません。static は領域や変数の名前にできず、その借用を作るのは文字列リテラルだけです。

誤りの種類

vasm_check.errors(file, m) は VasmErr{kind, loc, msg} のリストを返します。構造体と関数のそれぞれで、最初の誤り1件だけです。vasm_check.report(file, m) は誤りを file:行:列: メッセージ で書き、誤りがなければ ok を書きます。例は実装の vasm の検査器にあります。

kind誤り
'type 'undefined型が合わない（幅・符号・リテラルの範囲・フィールドの不足）・定義のない関数や構造体
'uninit 'moved 'freed初期化前の読み出し・move した値や取り出した中身の使用・解放した値の使用と二重の解放
'borrowed 'owner借りている間の move・解放・代入・読み書きと借用の重なり・own を持つ値を持ち主でない場所からコピーする

'branch 'loop分岐の後で所有の状態が揃わない・ループで move した値を入れ直さない
