変数束縛

束縛は定義（:=）と代入（=）の2つです。名前をまとめる module と import もここに書きます。

定義と代入

x := e は書いた場所で新しい変数を定義します。同じ名前をもう一度定義しても新しい変数で、前に作った関数は前の変数を指したままです。x = e は今ある変数への代入なので、前に作った関数からも新しい値が見えます。

右辺から見えるのは前の x で、なければ未定義です。自分を呼ぶ関数は f(p, ...) := e と書きます。

複合代入と組の分割

x += e は x = x + e と同じで、-=・*=・/=・%= も同じ形です。a[i] += e は a と i を1回だけ評価します。左辺は変数か a[i] で、t.f += e は書けません。

組の分割

(a, b) := e は組 e の要素で変数を定義し、(a, b) = e は定義済みの変数に代入します。右辺を先にすべて評価するので、(a, b) = (b, a) は入れ替えです。

要素の数が名前の数と違う組と、組でない値はエラーです。

module

module m { ... } は、本体の定義を名前 m の下にまとめます。本体が返す値が module の値で、export を付けた定義が欄になります。欄にない名前を . で読むとエラーです。

  • 本体の変数の範囲は引数のない関数の本体と同じです。あとで定義するものを前から呼ぶには fun f と f(p, ...) = e を使います（部分関数と融合）。
  • 本体の定義は本体の変数で、大域変数になりません。外から書き換えられず、外に同じ名前があっても隠しません。外から場合を足せるようにするには、足す関数を export します（m.f(p, ...) = e は書けません）。
  • m は本体を評価したあとに定義されるので、本体から m は見えません。
  • 本体の中で parse を差し替えても残りには反映されません。文法を差し替えるときは module の外に書きます。

export

  • 書けるのは、module の本体の直下にある f(p, ...) := e・x := e・module n { ... } の前だけです。ほかは構文エラーです。
  • export x := e の欄は、本体が値を返した時点の x の値です。あとで代入しても変わらないので、今の値を見せるには x を読む関数を export します（上の start と current）。
  • 内側の module n { ... } は本体の変数 n を定義し、外からは見えません。外に見せるには export module n { ... } と書きます。内側の本体からは、外側の本体でそれより前に定義した変数が見えます。

test

module の本体の直下に test { ... } を書けます。ふだんは何も実行されません。planck0 tools/test.pk <ライブラリ> ... が、使うライブラリの test も含めて実行します。

  • 変数の範囲は module の本体と同じで、export のない関数も呼べます。
  • test は本体の評価の途中で実行されるので、その前に定義した変数が見え、m はまだ定義されていません。
  • assert(c, msg) は c が真でなければ msg を書いてステータス 1 で止まります。
  • 1つのブロックに書ける式は 64 個までです。

import

import a::b は use("a/b") と同じ読み込みで、同じファイルは1度だけ読まれます。最後の名前が、そのファイルが定義する module の名前です。取り込み方はパスのあとに続けます。

書き方意味
import m読み込むだけ。欄は m.f で読む
import m as nn := m を足す
import m (x, y)x := m.x・y := m.y を定義する
import m (*)すべての欄を同じ名前で定義する
import m hiding (x, y)x と y 以外のすべての欄を同じ名前で定義する
  • as n は (x, y)・(*)・hiding (...) の前に置けます。as・(...)・hiding は m と同じ行に書きます。
  • m にない欄を (x, y) に書くと、. で読むときと同じエラーです。
  • 関数の中に書くと、(*) と hiding は大域変数を、(x, y) と as は局所変数を定義します。

定義と代入の左辺の !x

準クオートの中では、x := e と x = e の左辺を !x と書くと、x の値のシンボルに置き換わります（それぞれ Def{!x, e} と Set{!x, e}）。x の値が 'i のとき、`{ !x := 0; !x = !x + 1 } は Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}} です。x の値が 'true なら、Def{true, e} と同じくプログラムを止めます。
