vasm

use("vasm") が定義する低級言語です。vasm{| ... |} に書いた関数と構造体を、所有と借用の規則で検査します。解放後の使用・二重の解放・借用の違反・未初期化の読み出しは誤りです。検査は型の規則だけで、検査を外す口はありません。

プログラム

プログラムは構造体と関数の並びで、どちらもモジュールのどこに書いても全体から見えます。文は改行か ; で区切ります。

struct S { f: T, g: T }
fn f[r, ...](x: T, ...) -> T { ... }

関数の [r, ...] は領域の引数で、呼び出しの引数の借用から決まります。決まらなければ誤りです。構造体の名前や関数の名前に、組み込みの関数と同じものは使えません。

型

型意味

構造体の名前全部のフィールドを持つ値
own TT を指す持ち主。ちょうど1つ
&r T領域 r の中の共有の借用
&mut r T領域 r の中の排他の借用

構造体のフィールド・own の中身・配列の要素には own を入れられます。借用は入れられません。own を持つ型の値は、持ち主がいつも1人です。

組み込みの関数

値と初期化

  • 読み出せるのは初期化済みのレジスタだけです。if の後は両方の分岐で初期化したものだけ、while の後はループの前の状態です。
  • 整数の演算の両辺は同じ型です。幅や符号の違う整数は混ぜられず、as で合わせます。広げるときは元の符号で符号拡張かゼロ拡張、狭めるときは下位のビットを残します。
  • 整数のリテラルは代入先・引数・相手の項の型の範囲に入ることを検査します。リテラル1つで書けるのは -32768 から 32767 までです。大きな値は m = 0x7F45、m = m << 16、m = m | 0x4C46 のように組み立てます。
  • 配列の添字は i64 です。添字が範囲に入るかは実行時の検査に回り、検査器は型と所有だけを見ます。配列を *p で丸ごと読み書きすることはできません。
  • 構造体の値は、own を持たなければ整数と同じくコピーされ、own を持てば move されます。s.f は、s が構造体のレジスタならその値のフィールド、構造体を指すポインタなら指す先のフィールドです。

所有

  • own の値は、move するか free するかのどちらかを高々1回します。
  • 持ち主がなくなる所で、残った own は自動的に解放されます。ブロックや関数の終わり・return、上書き（p = box(2)・*p = v・p[i] = v・s.f = v の前の値）、文として捨てた関数の結果、free した値の中に残ったものです。箱の中身・構造体のフィールド・配列の要素のうち、取り出されていないものが解放されます。
  • 解放した値を使う・もう一度解放する・move した値を使うのは誤りです。
  • 片方の分岐だけで move や解放をした値は、その後に持ち主かどうかが決まらないので誤りです。ループは中で move した値を、次の周の前に入れ直す必要があります。
  • 関数は move した引数の持ち主を受け取ります。呼び出し元は渡した値をそのあと使えません。

own を持つ値の取り出し

  • x = *p は、中身が own を持つとき中身を move して取り出します。p は own で、借りられていないこと。取り出したあとの p は中身の無い箱で、*p = v で入れ直すか free(p) するまで、読む・move する・借りることはできません。借用からは取り出せません。
  • 構造体のレジスタ s からは x = s.f で own を持つフィールドを move して取り出せます。取り出した欄を読む・もう一度取り出すのは誤りで、s.f = v で入れ直せます。取り出したあとの s は丸ごとは使えず、残った欄は s がなくなる所で解放されます。
  • 配列の要素やポインタの指す構造体のフィールドは、swap(p[i], v)・swap(p.f, v) で入れ替えて取り出します。*p も swap(*p, v) で入れ替えられます。場所は own（借りられていない）か &mut から書けるものです。
  • own を持つ値を、配列の要素・ポインタの指す先・借用からコピーして読むことはできません。

借用と領域

  • x = &r p は、p が r より前に宣言され、r の中で生きていることを求めます。借りている間、p を move・解放・代入することはできません。&mut で借りている間は、*p・p[i]・p.f も読めません。r の終わりで貸しが消えます。
  • 共有の借用は複製され、いくつでも持てます。&mut はレジスタの間で使うと move されます。
  • 関数の借用の引数に渡した &mut は、呼び出しの間だけ借り直され、move されません。同じ呼び出しの別の引数にもう一度渡すことはできません。関数の結果の型が借りた領域を含むときは、結果が借用を持ち出すので借り直しにならず、move されます。
  • &mut は & の引数に渡せます（呼び出しの間だけ共有で借り直す）。
  • 外の領域 q の借用は、q の内側に開いた領域 r の借用の所に渡せます。代入・return・引数のどれでも同じです。関数の領域の引数どうしには内外の関係が無く、関数の領域は関数の中で開いた領域より外です。
  • 関数の領域の引数は、渡された借用の領域のうち一番内側のものに決まります（ほかが全部それより外であること）。
  • 型 &r T は r の中でしか書けません。r の外のレジスタに入れる、r の外へ返すのは誤りです。

誤りの種類

vasm_errors(file, m) は VasmErr{kind, loc, msg} のリストを返します。kind は次のシンボルです。構造体と関数のそれぞれで、最初の誤り1件だけを返します。

kind誤り
'type型が合わない。整数の幅や符号の違い、リテラルの範囲、フィールドの不足
'undefined定義のない関数や構造体
'uninit初期化前の読み出し
'movedmove した値、取り出した中身やフィールドの使用
'freed解放した値の使用、二重の解放
'borrowed借りている間の move・解放・代入・読み書き、借用の重なり
'ownerown を持つ値を持ち主でない場所からコピーする
'region領域が開いていない・すでに開いている・決まらない
'escape借用が領域の外に出る
'branch分岐の後で所有の状態が揃わない
'loopループで move した値を入れ直さない

例はチュートリアルの 11 章にあります。vasm_report(file, m) は誤りを file:行:列: メッセージ で書き、誤りがなければ ok を書きます。
