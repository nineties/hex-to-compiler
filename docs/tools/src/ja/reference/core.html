コア言語

コア言語は、値・特殊形式・パターンと融合・代数的エフェクトでできています。

M式

M式は Head{a, b, ...} と書く値で、head（symbol）と引数の列を持ちます。組は Tuple、リストは Cons と Nil を head とします。

  • 型は Expr で、immutable です。
  • 引数の数に限度はありません。mutable な値と NaN は引数に入れられず、作るときに実行時エラーです。
  • head(x) は M式だけに使えます。

atom

M式でない値が atom です。ユーザーデータで新しい型も作れます。

array と plain array は array_set・plain_set で書き換えます。範囲外と、plain array に入らない値はエラーです。

equality

_eq(a, b) は値として等しい（equal）かを調べます。

  • 整数・float・complex は、型が違っても値が同じなら equal です。NaN はどの値とも equal ではありません。
  • M式は head と引数が equal なら equal です。
  • array と plain array は、identical なら equal で、そうでなければ要素ごとに比べます。
  • hash(x) は 0 以上の整数で、equal な値は同じ値です。

identity

_is(a, b) は同じ物（identical）なら true です。identical な値は必ず equal です。型が違う値は identical ではなく、整数 1 と float 1.0 は equal でも identical ではありません。

intern は、equal な値を1つの object にまとめることです。intern する型では equal な値が identical で、_is は O(1) です（多倍長整数を除く）。

ユーザーデータ

  • 組み込み関数で作り、immutable か mutable かを必ず指定します。
  • immutable なユーザーデータは mutable な値を中身に持てず、作るときに実行時エラーです。
  • 型は作るたびに別の値です。名前は表示にしか使わず、同じ名前の型は _is で区別します。
  • 作るときに equal と hash の関数をまとめて渡せます。_is(a, b) なら _eq(a, b)、equal なら hash が同じであることは、作る人が守ります。
  • 渡さない型の hash は、immutable なら中身、mutable なら object で決まります。

数

型が混ざる演算は、高い型に揃えます。

  • _div は0方向へ切り捨て、_quo は負の無限大方向へ丸めます。_mod(a, b) は _sub(a, _mul(b, _quo(a, b))) で、符号は除数と同じです。
  • 除数が0なら実行時エラーです。float か complex を含む _div は無限大か NaN（complex は成分ごと）になります。
  • _lt _le _gt _ge は整数と float を数学的な値で比べます。NaN があれば false、complex は実行時エラーです。
  • 整数を float に揃えると最も近い float になり、範囲外は実行時エラーです。

リテラル

true・false・none は同じ名前の symbol を値とするリテラルで、変数ではありません。

定義と代入

Def{x, e} は書いた場所で新しい変数を定義します。同じ名前をもう一度定義しても新しい変数で、前に作った関数は前の変数を指したままです。Set{x, e} は今ある変数への代入なので、前に作った関数からも新しい値が見えます。

右辺から見えるのは前の x で、なければ未定義です。自分を呼ぶ関数は、先に Declare{f} で名前を作り、Set{f, Fusion{f, Lambda{...}}} で関数を足します（場合を足す）。

定義と代入の左辺の UnQuote

QuasiQuote の中では、Def と Set の左辺を UnQuote{x} と書くと、x の値のシンボルに置き換わります。x の値が Quote{true} なら、Def{true, e} と同じくプログラムを止めます。

部分関数と融合

関数はパターンで引数を取るので、合わない引数があり得る部分関数です。Fusion{f, g} は f を試し、どのパターンも合わなければ g を試します。

どの腕にも合わない呼び出しは、MatchingFailed を起こします。受け手がなければプログラムが止まります。

パターン

  • 変数：何にでも合い、値を束縛します。_ は何にでも合い、何も束縛しません。
  • 整数・文字列：equal な値に合います。Quote{s} は symbol s に合います。
  • Head{p, ...}：head が Head で、引数が順に p, ... に合う M式に合います。
  • _TypeOf{p, type}：type(x) が type で p が合う値に合います。type が Expr なら M式すべてに合います。

Apply{_add, Tuple{x, 1}} のような木に合わせるには、関数の位置を Quote{_add} と書きます。変数にすると、任意の関数の呼び出しに合います。

残りの引数

_Rest{x} は残りの引数を Tuple（なければ Tuple{}）に束縛します。

  • 書けるのは、Lambda の引数の最後と、パターン Head{p, ...} の最後の引数だけです。
  • 前の引数の数より少ない呼び出しは合いません。
  • 最後以外や呼び出しの引数に書くと、実行前にメッセージを出して止まります。

場合を足す

Declare{f} のあとに Set{f, Fusion{f, Lambda{Tuple{p, ...}, body}}} と書くと、書いた場所の変数に f があればその関数の後ろに場合を足し、なければ新しい f を定義します。

書いた場所場所の変数
トップレベル同じファイルの大域変数
関数の中その関数の引数と、それより前に定義した変数
トップレベルの If の枝・While の本体その中でそれより前に定義した変数

外側の関数・別のファイル（use で読んだライブラリ）の変数と組み込み関数は場所の変数ではありません。同じ名前の Declare{f} は外の f を変えず、隠す新しい f を定義します。別のファイルの f に足すには、Declare を付けずに Set します。

相互再帰

先に Def{f, none} で名前だけを宣言し、あとで Set{f, Fusion{f, Lambda{...}}} で埋めます。Fusion{none, g} は g なので、最初の Set は関数そのものを代入します。

埋める前に呼ぶと none を呼ぶことになって止まります。

MatchingFailed

どの腕にも合わなかった関数呼び出しと、融合の最後のつなぎ先は、止まる代わりに MatchingFailed{f, args, loc} を Perform します。

フィールド中身
f呼ばれた関数（融合なら融合全体）
args合わなかった引数の Tuple{...}
loc失敗した呼び出しの位置 Loc{file, line, column}
  • ハンドラの値が Handle の値になります。Apply{f, Tuple{7}} の値にはなりません。
  • 受け手のハンドラが無ければ、matching failed を出して止まります。unhandled effect にはなりません。
  • Return{v} や Break{} だけを受けるハンドラは通り抜けます。どのパターンにも合う Lambda{Tuple{e, k}, body} のハンドラは MatchingFailed も受けます。

腕の奥で起きた失敗

次の腕へ移るかどうかは、入口のパターンだけで決まります。入口が合った腕の本体の奥で起きた MatchingFailed は、外側へ伝わります。

代数的エフェクト

Perform{Ask{}} は、合うパターンを持つ一番近い Handle{body, h} のハンドラ Lambda{Tuple{Ask{}, k}, ...} を呼びます。k は継続を表す通常の関数で、k に渡した値が Perform の値になります。

  • k は Handle が値を返したあとでも、何度でも呼べます。
  • ハンドラは、再開した継続の中でも有効です。
  • 継続を捕捉した時点で定義済みの変数は、再開した計算のあいだで共有されます。再開のあとに定義した変数は別です。

どの腕にも合わなかった関数呼び出しが Perform する MatchingFailed（部分関数と融合）も k で再開できます。k に渡した値が、失敗した呼び出しの値になります。
