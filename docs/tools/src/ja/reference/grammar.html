文法の宣言

::= は文法の規則を定義するか置き換えます。planck の構文も同じ規則で定義されているので、宣言によって後続の式の構文を拡張できます。

::=

name ::= alternative | ... は文法の規則 name を定義するか置き換えます。構文の規則（expr・primary・block・add_expr ...・ident・integer・string）も同じ文法の規則です。選択肢の ... はその規則のそれまでの定義を表します。

選択肢は項目の列で、末尾に動作 { ... } を付けられます。項目と動作は ::= や | と同じ行に書きます。

文字クラス

[set] の set は文字と範囲の並びです。a-z のように、英字・数字・_ のあとに - と1文字を続けると、その範囲の文字です。それ以外の - は文字そのものです。\n・\t・\a・\b・\f・\r・\v・\0 はその制御文字で、ほかの \x は文字 x です（\]・\-・\\・\ ）。set の両端の空白は set に含めません。空の set と、逆順の範囲（[9-0]）や終わりが欠けた範囲（[a-]）は構文エラーです。

[^set] は set にない文字です。入力の終わりには、. も [set] も [^set] も合いません。

文字は1つずつ読み、その前で空白とコメントを読み飛ばします。cs:[0-9]+ の値は1文字ずつの文字列の Tuple{v, ...} です。

選択肢の順序と値

選択肢は順に試されます（PEG）。選択肢の値は、動作があれば動作の値、項目が1つならその項目の値、それ以外は項目の値の Tuple{v, ...} です。e* と e+ の値は Tuple{v, ...}、e? の値は Tuple{} か Tuple{v} です。

規則の結果は位置ごとにメモ化します（packrat 構文解析）。規則には直接の左再帰を書けます（sum ::= a:sum "+" b:term { ... } | term）。左再帰の規則は左結合です。

peg_parse

peg_parse(rule, s) は s の先頭を規則で読み、Tuple{値, 残り} を返します。空白しか残っていなければ Tuple{Eof{}, ""} を返し、読めなければ Tuple{SyntaxError{...}, ""} を返します。

規則で読む文字列

name{| text |} は、パーサがその式を読む時点で text を規則 name で読む式です。name と {| の間に空白は入れません。

text を読むのはその規則だけです（規則の文字列・単語・規則と、それらの空白とコメント）。まわりの式の字句では読みません。text の終わりは規則が読み終えた位置で、そのあと空白をはさんで |} が続きます。したがって規則が読む |} や }（規則の文字列や括弧の中のもの）は text の一部です。規則が失敗したときや |} がないときは、その式の構文エラーです。エラーの位置は規則が text の中で最も先まで読んだ位置です。

式の値は規則の値で、定数として扱います。

その文字列を含む式を読むより前に評価される式で、規則を定義しておきます。

peg_sources と peg_version

peg_sources は規則の名前から _define_rule に渡された構文解析式への表です。動作は評価する前の形で、... はそれまでの定義に置き換えてあります。peg_version は _define_rule を呼ぶたびに増えます。
