psys

use("psys/expand") が定義するシステム言語です。意味は vasm と同じで、書き方が高級です。式を入れ子にでき、let・for・複合代入・短絡の and と or を使え、大きな整数リテラルも書けます。psys{| ... |} に書いた関数と構造体を、psys_expand が vasm のモジュールに展開します。所有と借用の検査は展開した vasm に対して行います。

プログラム

プログラムは構造体と関数の並びです。型・構造体・関数の宣言は vasm と同じ書き方です。関数の本体は文の並びで、文は改行か ; で区切ります。

psys{| ... |} の値は PModule{[...]} です。psys_expand(m) は vasm の Module{[...]} を返し、vasm_check.check と vasm_build.build がそのまま受け取ります。psys_expand_all(m) は Tuple{モジュール, 誤りのリスト} を返します。誤りは VasmErr{kind, loc, msg} で、関数ごとに最初の1件です。psys_errors(file, 誤り) は位置をファイルの Loc にします。

式

式は入れ子にできます。優先順位は上から下へ強くなります。

括弧でまとめられます。引数は左から順に計算します。a[i] と s.f の a と s は変数です。構造体の値は、先頭にフィールドを書くので、if や for の本体の { と区別できます。

値を返す関数の本体は、最後の文が式なら、その値を返します。

型の決まり方

  • 式の型は、変数と関数の宣言と組み込みの型から決まります。型を書く場所は let・var・パラメータ・関数の結果・as だけです。
  • 整数のリテラルは、それだけでは型がありません。代入先・引数・相手の項・関数の結果の型が、リテラルの型になります。let x = 5 のように型を決める手がかりのないリテラルは誤りです。let x: i64 = 5 か 5 as i64 と書きます。
  • for i in a..b の変数の型は、a と b のうちリテラルでない方の型です。両方リテラルなら誤りで、0 as i64..10 のように一方に型を付けます。
  • 借用を結果に持つ関数の呼び出しは、結果の領域が引数から1つに決まるときだけ、型を推論します。決まらないときは let x: T = f(...) と書きます。
  • 配列の添字は i64 です。ほかの整数の型の添字には as i64 が付きます。
  • 同じ名前を宣言し直せます。前の変数は見えなくなります。

大きなリテラル

vasm のリテラルは -32768 から 32767 までです。psys はそれを超える整数のリテラルを書けます。リテラルは型の範囲に入らなければ誤りです。

展開は、15 ビットずつの部分を上の位から << と | でつないで値を作ります。負の値は最後に 0 から引きます。

誤り

展開の誤りの kind は 'type（型が決まらない・リテラルが型の範囲にない・式の文が呼び出しでない）と 'undefined（宣言のない変数・関数・構造体）です。所有・借用・初期化の誤りは展開では調べず、展開した vasm を vasm_check.check が調べます。誤りの位置は psys のソースの位置です。
