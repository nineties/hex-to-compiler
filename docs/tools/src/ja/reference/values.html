値・パターン・M式

評価の対象は M式です。値の種類、特殊形式、パターン、エフェクト、トップレベルを定めます。

M式

M式はシンボル（x）・整数（42・-1）・文字列（"abc"）・Head{a, b, ...} のいずれかです。トップレベルに置いた文字列は効果を持たないので、コメントとして使えます。

書き換えられる値は配列だけです。文字列・整数・シンボル・M式は不変で、リスト（Cons{x, xs}）と組（Tuple{a, ...}）も M式なので不変です。表 Table{a} とベクタ Vector{a} は、配列を持つ M式として作られ、a[i] = e で書き換えられる種類です（添字と置き換え）。

これ以外の頭の M式（Cons{x, y} など）はコンストラクタで、引数を評価して同じ頭の M式を作ります。

パターン

引数のパターンは次のいずれかです。

  • 変数 x。_ は何にでも合い、何も束縛しません
  • 整数・文字列。等しい値に合います
  • Quote{v}。等しい値に合います（例 Quote{false}）
  • Head{p, ...}。頭と引数の数が同じ M式に合います
  • _TypeOf{p, type}。p が合い、値の種類が typeof の示す type のときに合います

構文では 'none が Quote{none}、x @ int が _TypeOf{x, int}、x :: xs と [a, b] が Cons のパターンになります。

代数的エフェクト

Handle{body, handler} は body を評価します。Perform{v} は、合うパターンを持つ一番近い handler(v, k) を呼びます。k は Perform の継続です。ハンドラは深いハンドラで、継続の中でも有効です。どのパターンにも合わなければ、エフェクトは外側のハンドラに回ります。

k は通常の関数で、何度でも、Handle が値を返したあとでも呼べます。再開した複数の計算は変数を共有します。

トップレベル

トップレベルの式を読むたびに大域変数 parse と eval を引き直すので、プログラムが差し替えると次の式から新しい定義で処理されます。プログラムの中の Apply{eval, ...} も、差し替えた eval を呼びます。

  • parse：文字列 -> Tuple{M式, 文字列の残り}。空白は自分で読み飛ばし、空白しか残っていなければ Tuple{Eof{}, ""} を返します。差し替える parse は Eof{} をそのまま通します。
  • eval：M式 -> 値。
