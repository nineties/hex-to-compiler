値・パターン・M式

評価の対象は M式です。値の種類、特殊形式、パターン、エフェクト、トップレベルを定めます。

M式

M式はシンボル（x）・整数（42・-1）・浮動小数点数（1.5）・文字列（"abc"）・Head{a, b, ...} のいずれかです。シンボルは英字・_・% のどれかで始まり、英字・数字・_ が続きます。文字列は65535バイトまで、Head{...} の引数は64個までです。トップレベルに置いた文字列は効果を持たないので、コメントとして使えます。

true・false・none はリテラルです。それぞれ同じ名前のシンボルを値とするので、true と Quote{true} は同じ値です。変数ではないので、Def{true, e}・Set{true, e}・Declare{true} を書くと、式を実行する前にメッセージを出してプログラムが止まります。

値の型・immutability・equality はデータ型にあります。

数

  • 整数の範囲に制限はなく、ラップアラウンドも切り詰めも起きません。
  • 浮動小数点数の丸めは最近接偶数で、浮動小数点例外が起きてもプログラムは止まりません。複素数は complex(re, im) で作り、リテラルはありません。
  • _add _sub _mul _div は整数・浮動小数点数・複素数を受け取り、それ以外の値を渡すとプログラムは止まります。型が混ざると、整数・浮動小数点数・複素数の順で高いほうの型に被演算子を揃え、結果もその型になります。
  • 整数を浮動小数点数に揃えるときは最も近い値に丸めます。浮動小数点数の範囲を超える整数を揃えると実行時エラーです。
  • 整数どうしの _div は0方向へ切り捨てた商で、除数が0なら実行時エラーです。浮動小数点数か複素数を含む割り算は、除数が0でも止まりません。浮動小数点数は無限大か NaN になり、複素数は各成分に同じ規則を当てた値になります。
  • 整数どうしの _quo（演算子 //）は負の無限大方向へ丸めた商で、-7 // 2 は -4 です。除数が0なら実行時エラーです。
  • 整数どうしの _mod(a, b) は a - b * (a // b)（符号は除数と同じ） で、除数が0なら実行時エラーです。
  • _lt _le _gt _ge は整数と浮動小数点数を型を揃えずに数学的な値で比べます。NaN を含むと false です。数でない値か複素数を渡すとプログラムは止まります。
  • _eq は型が違っても値が同じ数を等しいとします（1 == 1.0）。NaN は自分自身とも等しくありません。複素数は両方の成分が等しいときに等しくなります。_ne は _eq の逆です。

これ以外の頭の M式（Cons{x, y} など）はコンストラクタで、引数を評価して同じ頭の M式を作ります。

パターン

引数のパターンは次のいずれかです。

  • 変数 x。_ は何にでも合い、何も束縛しません
  • 整数・文字列・true・false・none。等しい値に合い、何も束縛しません
  • Quote{v}。等しい値に合います（例 Quote{x} はシンボル x に合います）
  • Head{p, ...}。頭と引数の数が同じ M式に合います
  • Head{p, ..., _Rest{x}}。頭が同じで、_Rest の前の引数の数以上の引数を持つ M式に合い、残りの引数の Tuple を x に束縛します（構文は Head{p, ..., x...}）
  • _TypeOf{p, type}。値の種類（typeof の結果）が type で、p が合うときに合います

構文では 'none が Quote{none}、x @ int が _TypeOf{x, int}、x :: xs と [a, b] が Cons のパターンになります。

代数的エフェクト

Handle{body, handler} は body を評価します。Perform{v} は合うパターンを持つ一番近い handler(v, k) を呼びます。k は Perform の継続です。ハンドラは深いハンドラで、継続の中でも有効です。どのパターンにも合わなければ、さらに外側のハンドラを探します。

k は通常の関数で、何度でも、Handle が値を返したあとでも呼べます。継続を捕捉した時点で定義済みの変数は、再開した複数の計算で共有されます。再開のあとに x := e で定義した変数は、内側に書いた関数が参照しない限り、計算ごとに別の変数です。

トップレベル

トップレベルの式を読むたびに大域変数 parse と eval を引き直すので、プログラムが差し替えると次の式から新しい定義で処理されます。プログラムの中の Apply{eval, ...} も差し替えた eval を呼びます。

  • parse：文字列 -> Tuple{M式, 文字列の残り}。空白は自分で読み飛ばし、空白しか残っていなければ Tuple{Eof{}, ""} を返します。差し替える parse は Eof{} をそのまま通します。
  • eval：M式 -> 値。
