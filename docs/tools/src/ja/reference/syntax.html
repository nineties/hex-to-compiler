構文

構文は糖衣です。式は下の表の M式に読み替えられてから評価され、意味は M式で決まります。M式もそのままこの構文の式です。以下は表で足りない所、つまり束縛の範囲と、関数の定義が足し込まれる規則、module、パターンの書き方です。

結合

  • |・->・:: は右結合、+ - * / % は左結合です。比較は結合しません（a < b < c とは書けません）。
  • :: は比較より強く + - より弱く結合します（a + 1 :: b == c は Cons{a + 1, b} == c）。.. はさらに :: より強く + - より弱く、結合しません（a + 1..b * 2 は Range{a + 1, b * 2}）。
  • if と while の条件は括弧で囲みます。if の枝は括弧の外に | を含まない式で、if (c) a else b | g は (if (c) a else b) | g です。複数の式はブロック { ... } にします。else はまだ else のない最も近い if に対応します。

定義と代入の左辺の !x

x := e と x = e の左辺 x は !x とも書け、それぞれ Def{!x, e} と Set{!x, e} です。準クオートの中では、!x は x の値のシンボルに置き換わります。x の値が 'i のとき、`{ !x := 0; !x = !x + 1 } は Do{Def{i, 0}, Set{i, Apply{_add, Tuple{i, 1}}}} です。x の値が 'true のとき、Def{true, e} と同じくプログラムを止めます。

record

record T(f, g, ...) は、値 T{a, b, ...} の引数に欄の名前を付けます。値の作り方は変わりません。t.f は t の頭の宣言で f の位置にある引数で、. は左の式に空白なしで続けます。

  • 頭が違えば同じ名前の欄を持てます。同じ T をもう一度宣言すると名前が置き換わります。
  • 頭が宣言されていない値や、欄 f がない値に .f を使うと、メッセージを出してプログラムが止まります。
  • t with { f = e, g = e2 } は欄を替えた新しい値です（t は変わりません）。欄は左から順に替えるので、e は元の t の欄も参照できます。with { ... } は続けて書けます。

複合代入と組の分割

x += e は x = x + e と同じで、-=・*=・/=・%= も同じ形です。a[i] += e は a[i] = a[i] + e と同じですが、a と i は1回だけ評価します。左辺は変数か a[i] で、t.f += e は書けません。

組の分割

(a, b) := e は組 e の要素で変数を定義し、(a, b) = e は定義済みの変数に代入します。右辺を先にすべて評価するので、(a, b) = (b, a) は入れ替えです。要素の数が名前の数と違う値と、組でない値は、メッセージを出して止まります。

変数の範囲

変数の範囲は静的（字句的）で、名前がどの変数を指すかは式を実行する前に決まります。関数は作られた場所の変数を参照し、変数は共有されるので、作ったあとの代入も関数から見えます。呼んだ側の変数は見えません。どの変数も指さない名前があると、その式を実行する前にメッセージを出してプログラムが止まります。

  • 関数の本体から見えるのは、その関数か外側の関数の引数と、それらの関数でそれより前に定義した変数、トップレベルでそれより前に定義した変数（大域変数）です。
  • true・false・none はリテラルで変数の名前にできません。true := e・fun true・true(p) := e は構文エラーです。引数に書いた true は、値 true に合って何も束縛しないパターンです。

定義と代入

同じ名前を x := e か fun f でもう一度定義すると、新しい変数になります。前に作った関数は前の変数を指したままです。今ある変数を上書きするのは x = e で、同じ変数への代入なので、前に作った関数からも新しい値が見えます。

x := e は書いた場所で変数を定義します。右辺から見えるのは前の x で、前の x がなければ右辺の x は未定義です。自分を呼ぶ関数は f(p, ...) := e と書きます。トップレベルでもブロックの中でも同じです。

関数に定義が加わるとき

関数の定義 f(p, ...) := e は、書いた場所の変数に f があるかで読み方が変わります。あれば f(p, ...) = e と同じで、なければ新しい f をその場所で定義します（fun f のあとに f(p, ...) = e）。同じ場所に続けて書いた f の定義は1つの関数になり、書いた順に試されます。

書いた場所の変数は、トップレベルでは同じファイルで定義した大域変数、関数の中ではその関数の引数とそれより前に定義した変数、トップレベルの if の枝や while の本体ではその中でそれより前に定義した変数です。外側の関数の変数、関数の中から見た大域変数、別のファイル（use で読んだライブラリや planck/init.pk）の大域変数や組み込み関数は、書いた場所の変数ではありません。これらと同じ名前の f(p, ...) := e は、隠す新しい f を定義し、外の f を変えません。別のファイルの f に定義を追加するときは f(p, ...) = e と書きます。

ガードは定義にも付けられます。f(p, ...) if c := e は、引数が合って c が真のときに e を返す腕を足します。偽のときと合わないときは、同じ場所に続けて書いた次の定義を試します（間に別の式があると続きません）。f(x) if x > 0 := "正" のあとに f(_) := "それ以外" と書けば、f(-1) は "それ以外" です。export を付けた定義と f(p, ...) = e にはガードを付けられません。

互いに呼び合う関数

先に fun f で名前だけを宣言し（値は none）、あとで f(p, ...) = e で埋めます。f(p, ...) = e は f = f | (p, ...) -> e で、f の関数の後ろに足します。none | g は g なので、最初の f(p, ...) = e は関数そのものを代入します。埋める前に呼ぶと none を呼ぶことになって止まります。

値がガード付きの関数のとき（f = (n) if n > 0 -> 1 のあと）、ガードが偽でも f(p, ...) = e で追加した関数は呼ばれません。変数で渡したガード付きの関数は、あとにつないだ | g を呼ばないのと同じです。

for と return・break・continue

for (p in e) a は、リスト・ベクタ・範囲 e の要素ごとに、要素をパターン p と照合して a を評価します。値は none で、a から見えるループの外の変数は共有されます。

return e はそれを含む関数の呼び出しを値 e で終え（e がなければ none）、break と continue は最も内側の while か for を終えるか次の回に進めます。e は return と同じ行で始めます。これらはエフェクトに読み替えられます。

  • 本体に return がある関数は Handle{body, (Return{v}, k) -> v}、break があるループは Handle{loop, (Break{}, k) -> none}、continue があるループは本体が Handle{body, (Continue{}, k) -> none} になります。
  • for の本体や match の腕の中の return は、それらを囲む関数を終えます。中に書いた関数の中の return は、その関数を終えます。ループの外の continue は unhandled effect: Continue{} で止まります。

match

match e { f } は e を1回だけ評価し、その値を引数に関数 f を呼びます。f はふつう1引数の関数を | でつないだもので、つないだ各関数を腕と呼び、e に合うパターンを持つ最初の腕が選ばれます。どの腕にも合わなければ、関数呼び出しと同じく MatchingFailed を perform します（部分関数と融合）。腕の引数は1つで、組を取るのは ((a, b)) -> x です。| は行頭に書けます。

ガード (p, ...) if c -> e | g の c は、引数が合ったあとにその変数を使って評価されます。偽のとき、または引数が合わないときは、同じ引数で g を呼びます。g は、ソース上で | によってその関数の後ろにつないだ式です（括弧の中にあっても同じ）。h := p if c -> a のあとの h | g のように変数で渡したガード付きの関数は g を呼びません。

match のガードと e は or の階層までの式なので、無名関数は括弧で囲みます。

module

module m { ... } は定義をまとめて名前 m の下に置きます。本体が返す値が module の値で、export を付けた定義を欄に持ちます。欄にない名前（export のない helper など）を . で読むと、メッセージを出してプログラムが止まります。

この bitset の欄は new と add です。

  • 本体の変数の範囲は引数のない関数の本体と同じです。あとで定義するものを前から呼ぶには fun f と f(p, ...) = e を使います。
  • 本体の定義は本体の変数で、大域変数になりません。同じ名前が外にあっても隠さず、外から書き換えることもできません。外から場合を足せるようにするには、足す関数を export します（m.f(p, ...) = e とは書けません）。
  • m は本体を評価したあとに定義されるので、本体から m は見えません。本体の中の関数どうしは名前でそのまま呼び合います。
  • 本体は丸ごと読まれるので、本体の中で parse を差し替えても残りには反映されません。文法を差し替えるときは module の外に書きます。

export

export を書けるのは、module の本体の直下にある f(p, ...) := e・x := e・module n { ... } の前だけで、ほかの場所は構文エラーです。export x := e の欄の値は、本体が値を返した時点の x の値で、あとで代入しても欄は変わりません。今の値を見せるには、x を読む関数を export します。

内側の module n { ... } は本体の変数 n を定義し、外からは見えません。外に見せるには export module n { ... } と書きます。内側の本体からは、外側の本体でそれより前に定義した変数が見えます。

test

module の本体の直下に test { ... } を書けます。if (_testing) { ... } の糖衣で、_testing は初めは false なので、ふだんは何も実行されません。planck0 tools/test.pk <ライブラリ> ... は _testing を true にしてから読み込み、使うライブラリの test も含めて実行します。

変数の範囲は module の本体と同じで、export のない関数も呼べます。test は本体を評価する途中で実行されるので、その前に定義した変数が見え、m はまだ定義されていません。assert(c, msg) は c が真でなければ msg を書いてステータス 1 で止まります。1つのブロックに書ける式は 64 個までなので、多いときは test を分けます。

import

import a::b は use("a/b") と同じ読み込みで、同じファイルは1度だけ読まれます。最後の名前は、そのファイルが定義する module の名前です。式を書ける場所に書けます。取り込み方は、パスのあとに続けます。

  • m にない欄を (x, y) に書くと、. で読むときと同じメッセージで止まります。
  • (*) と hiding が定義する名前は、関数の中に書いても大域変数です。(x, y) と as が定義する名前は、関数の中では局所変数です。

糖衣が呼ぶ名前

糖衣の読み替え先の関数は名前が _ で始まり、_ のない同名の関数はありません。プログラムで add や index_get を定義しても、a + b や a[i] の意味は変わりません。演算子を引数に取る関数には、無名関数を渡します（sort((a, b) -> a < b, xs)）。

文字列・リスト・組・M式は不変なので、これらへの a[i] = e は、cannot assign to an element of a string, which is immutable: ... のようなメッセージを出して止まります。範囲外の添字と、どの種類にも合わない a[i] も止まります。利用者は _index_get と _index_set に代入して、独自の種類を先頭に足せます。

subst(t, f) は木 t を関数 f で書き換えます。t の各部分を根から順に試し、f のパターンが合えばその部分を f の値に置き換えて、その内側は試しません。合わなければ頭は残して引数を順に試し、M式でない部分はそれ以上分解しません。

t[p -> a | q -> b] は腕を順に試します。match と同じくガードを付けられ、t[p if c -> a | q -> b] は p が合って c が成り立つときにその腕を使います。どの腕も合わない部分は、その内側を試します。腕の本体は -> の階層までの式なので、中の | は括弧で囲みます。't[f] は t[f] のクオートなので、クオートした木を書き換えるには ('e)[f] と書きます。

残りの引数

関数の最後の引数は x... と書けます。x は残りの引数の Tuple（なければ Tuple{}）に束縛されます。関数 f(p, x...) := e・(p, x...) -> e とパターン Head{p, x...} の最後の引数にだけ書けて、前の引数の数より少ない呼び出しは合いません。最後以外・呼び出しの引数・ガード付きの関数に書くと、式を実行する前にメッセージを出して止まります。

引数のパターン

引数 p と for のパターンは、or の階層までの式として書きます。表の M式にしたうえで、パターンとして照合します。原則は、式と同じ書き方で、識別子が変数になることです。例外は次のとおりです。

  • 演算子と呼ばれる関数の名前はシンボルです。x + 1 は Apply{Quote{_add}, Tuple{x, 1}}、f(p, ...) は Apply{Quote{f}, Tuple{p, ...}} の木に合います。呼ばれる関数を変数にするには (f)(p, ...) と書きます（Apply{f, Tuple{p, ...}}）。
  • 'e は Quote{e}、p @ type は型の検査、x... は最後の引数の残りです。
  • 同じ名前を2回書く f(a, a) は、2つの値が == で等しいときだけ合います。
  • p or q はどちらかに合います。変数を書けるのは、どの枝も同じ変数を束縛するときだけです（f((x, 0) or (0, x)) := x）。式の or の M式 If{a, true, b} に合わせるには If{a, 'true, b} と書きます。
  • 書ける形は、演算子（or and not == != <= >= < > :: + - * / %、単項の - と '）・f(p, ...)・Head{p, ...}・識別子・true false none・整数・文字列・組・リストです。結合は式と同じです。

macro

macro p := e は、評価の前に木を書き換える規則を足します。p は引数のパターンと同じ書き方で木の形を表し、e は p の変数を使って評価されて新しい木になります。文字列を M式にする構文には触れません。

  • 読み終わった式を評価する前（eval に渡した木も同じ）に、根から順に各部分を書き換えます。規則は後に足したものから試し、合わなければそのままです。書き換えた部分は、変わらなくなるまで規則を当ててから、その中を書き換えます。
  • クオート 'e の中は書き換えません。準クオート `e の中は !e の中だけを書き換えます。関数の引数のパターンと、Def・Set・Declare が定義する名前も書き換えません。
  • 1つの式の書き換えで規則を 1000 回より多く当てるとエラーで止まります（終わらない規則も止まります）。
  • 規則が有効なのは、macro の位置から、それを囲む一番内側の関数か module の本体の終わりまでです。何も囲んでいなければ以降のすべての式です。module の中の export macro は、その module の定義のあとから module の外でも有効です。

字句

  • 識別子は [A-Za-z_][A-Za-z0-9_]*[?!]? です。予約語 if else while and or handle with perform match record for in return break continue fun macro module export import is とリテラル true false none は除きます。名前の直後に空白なしで付く ? か ! は名前の一部です（empty?(x)、x!=y は x != y）。
  • 整数は10進・0x1f・0o17・0b101 で、桁数に制限はありません。浮動小数点数は小数点の前後に数字が要り、指数を続けられます（1.5e-3・6.02e23）。虚数リテラルは直後に i を付けます（2i は complex(0, 2)）。
  • 文字列は1行の "..." で、エスケープ \0 \a \b \t \n \v \f \r \" \' \\ が使えます。f"...{e}..." は式 e の値を埋め込み（e には文字列や f 文字列も書ける）、{{ と }} は波括弧1つです。
  • # から行の終わりまではコメントです。
  • f(a) の f と ( の間、a[i] の a と [ の間、Head{a} の Head と { の間には空白を入れません。
  • ブロックの中の式は ; か改行で区切ります。トップレベルの式は ;・改行・次の式の始まりのどれかで終わります。二項の - は左の式と同じ行に書くので、-1 で始まる行は新しい式です。ほかの二項演算子は行頭に書けます。
