データ型

planck の値の型、immutability、equality と identity を定めます。式・パターン・特殊形式は値・パターン・M式にあります。

値の型は head で調べます。パターンの x @ Int は head が Int の値に合います。型名の symbol は M式の head にできません。

equality と identity

equality は a == b（_eq）で調べます。a != b（_ne）はその逆です。

identity は、2つの値が同じオブジェクトであることです。array・plain array・function は identity が同じときだけ equal です。identity だけを調べる組み込み関数はありません。

数の型をまたぐ equality

整数・float・complex は、型が違っても値が同じなら equal です。1 == 1.0 と 1 == complex(1, 0) は true です。

NaN は自分自身とも equal ではありません。x == x は x が NaN のとき false です。

順序の比較 < <= > >= は equality ではありません。整数と float を数学的な値で比べます。NaN を含むと false です。数を参照してください。

equality を使う所

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が == で equal なときだけ合います。
  • 組み込みの table（table_get・table_set・t[key]）は key を == で比べます。
  • hash(x) は 0 以上の整数です。== で equal な値は同じ値になります。
