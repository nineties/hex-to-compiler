データ型

M式と atom、atom の型、equality、identity。== は値として等しいか（equal）、is は同じ物か（identical）を調べます。identical な値は必ず equal で、intern する型では equal な値は identical です。

M式と atom

値は M式か atom のどちらかです。atom は M式でない値で、整数・float・complex・文字列・symbol・function・array・plain array・型の値・ユーザーデータです。

  • M式の head は symbol です。head は登録しないので、2つのライブラリが同じ head を使えます。同じ head の値は同じ形の値として扱われ、head はパターン Set{...} で見ます。
  • すべての値が型を持ち、型そのものが値（型の値）です。type(x) がそれを返します。M式なら Expr、symbol なら Symbol です。1 なら Int で、Int 自身の型は Type です。Expr も組み込みの型の値で、type(Expr) は Type です。
  • head(x) は M式だけに使います。head の symbol を返し、atom ならエラーです。
  • Int・String・Expr など組み込みの型の名前は、型の値を持つ変数です。x @ T は変数 T を読み、type(x) と比べます。だから x @ Expr はすべての M式に合い、x @ Int は整数に合います。

M式の Set{1} と、名前が Set の型は別物です。だから名前が M式の head とぶつかることはありません。

M式

  • head の symbol と任意の個数の引数を持ちます。型は Expr です。
  • immutable です。リテラルは Head{a, b} で、糖衣として (a, b)（Tuple）・[a, b] と ::（Cons）・[]（Nil）があります。
  • 次の値は引数に入れられず、M式を作るときに実行時エラーになります。
    • mutable な値
    • mutable な値を中に持つ immutable なユーザーデータ
    • NaN
  • intern します。== と is は同じ判定で、O(1) です。f{1} と f{1.0} は equal ではありません。
  • table の key にできます。a[i] は読めます。

型ごとの補足

整数

  • 多倍長で、範囲の制限はありません。
  • 多倍長整数も、値が同じなら identical です。

float

  • IEEE 754 の binary64 です。
  • NaN は自分自身を含め、どの値とも equal でも identical でもありません。x が NaN なら x == x も x is x も false です。
  • NaN は table の key にできません。NaN を key にするとエラーです。
  • 同じ値でも別の object は identical ではありません。
  • 整数と equal な float の hash は、その整数と同じです。それ以外は中身で決まります。

complex

  • 値が同じ整数・float と equal です。

文字列

  • バイト列で、0 のバイトも含み、65535バイトまでです。
  • 0 のバイトも含めた全長でバイトが同じ文字列は identical です。== と is は同じ判定です。
  • a[i] は読めます（長さ1の文字列）。

symbol

  • 名前ごとに一意で、== と is は同じ判定です。名前は英字・_・% で始まります。true false none は 字句を参照してください。

function

  • Lambda・Fusion・組み込み関数・継続です。
  • equal になるのは identical なときだけです。
  • hash はオブジェクトごとに決まり、そのオブジェクトの間は変わりません。

array

  • 固定長で、全要素は初め none です。array(n) で作ります。
  • 中身が同じ別の array は equal ですが identical ではありません。
  • == は、identical なら先に true を返します。そうでなければ要素ごとに比べます。だから NaN を持つ a は a == a が true です。同じ NaN の object を持つ別の array b は、NaN の要素が equal でないので a == b は false です。
  • a[i] = e は通ります。範囲外はエラーです。

plain array

  • 要素の型が1つです。要素の型は 'bool 'i8 から 'u64 まで・'f16 から 'f64 まで・'c64 'c128 です。
  • 中身が同じ別の plain array は equal ですが identical ではありません。
  • == は、array と同じく identical なら先に true を返し、そうでなければ要素ごとに比べます。
  • a[i] = e は通ります。範囲外と変換できない値はエラーです。

型の値

  • すべての値の型です。Int・String などの変数の値になります。
  • 表示では型の名前で出ます。同じ名前の別の型も表示は同じで、is で区別します。

ユーザーデータ

  • 組み込み関数で作ります。作るときに immutable か mutable かを必ず指定します。既定はありません。
  • ユーザーデータの型は、型を作るたびに一意の値になります。名前は表示に使うだけです。別の所で作った同じ名前の型は別の型です。
  • 作るときに == の関数と hash の関数を渡せます（渡すなら両方）。== を渡した型は intern せず、is は object の比較になります。このとき == と hash には、渡した関数が使われます。
  • 渡した関数について、a is b なら a == b であること、equal なら hash が同じであることは、型を作る人が守ります。
  • 渡さない型は、immutable は hash が中身で決まり、mutable はオブジェクトごとに決まります。== は identity です。

equality

equality は a == b（_eq）で調べます。a != b（_ne）はその逆です。

数の型をまたぐ equality

整数・float・complex は、型が違っても値が同じなら equal です。1 == 1.0 も 1 == complex(1, 0) も true で、hash も同じ値です。

equality を使う所

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が == で equal なときだけ合います。ユーザーデータは渡された == を使います。
  • table（table_get・table_set・t[key]）は、key が identical か equal なら同じ key です。ユーザーデータでは、渡された == と hash が使われます。array・plain array・NaN を key にするとエラーで、型の値は key にできます。
  • hash(x) は 0 以上の整数です。== で equal な値は同じ値になります。== を渡したユーザーデータは、渡された hash の値です。hash の具体的な値は定めません。

identity と is

a is b は、a と b が identical なら true、そうでなければ false です。否定は a is not b と書きます。優先順位は == と同じ比較演算子の段です。比較と同じく結合しないので、a is b is c はエラーです。パターンの中に is は書けません。

  • identical な値は必ず equal です。a is b なら a == b です。NaN は自分自身とも identical ではありません。
  • 整数・文字列・symbol・M式・== を渡していない immutable なユーザーデータは intern します。float・function・array・plain array・mutable なユーザーデータ・== を渡したユーザーデータは object です。
  • intern は、同じ値を1つの object にまとめて作ることです。intern する型は equal なら identical なので、== は is と同じ判定になり、O(1) です。== を渡したユーザーデータは intern しないので、equal でも identical とは限りません。
  • 型が違う値は identical ではありません。1 == 1.0 は true ですが、1 is 1.0 は false です。
  • identical の判定は多倍長整数を除き O(1) です。
