値の型は head で調べます。パターンの x @ Int は head が Int の値に合います。

型ごとの補足

整数

  • 多倍長で、範囲の制限はありません。
  • 多倍長整数も、値が同じなら identical です。

float

  • IEEE 754 の binary64 です。
  • NaN は自分自身とも equal ではありません。NaN の object は自分自身と identical です。
  • 同じ値でも別の object は identical ではありません。
  • 整数と equal な float の hash は、その整数と同じです。それ以外は中身で決まります。

文字列

  • バイト列で、0 のバイトも含みます。65535バイトまでです。
  • == は 0 のバイトも含めた全長で比べます。
  • a[i] は読めます（長さ1の文字列）。

symbol

  • 名前ごとに一意です。英字・_・% で始まる名前です。true false none は 字句を参照してください。

M式

  • head の symbol と任意の個数の引数を持ちます。
  • 糖衣は (a, b)（Tuple）・[a, b] と ::（Cons）・[]（Nil）です。
  • 引数に mutable な値は入れられません。mutable な値を中に持つ immutable なユーザーデータも入れられません。M式を作るときに実行時エラーになります。
  • a[i] は読めます。

function

  • Lambda・Fusion・組み込み関数・継続です。
  • equal になるのは identical なときだけです。
  • hash はオブジェクトごとに決まり、そのオブジェクトの間は変わりません。

array

  • 固定長で、全要素は初め none です。array(n) で作ります。
  • 中身が同じ別の array は equal ですが identical ではありません。
  • a[i] = e は通ります。範囲外はエラーです。

plain array

  • 要素の型が1つです。要素の型は 'bool 'i8 から 'u64 まで・'f16 から 'f64 まで・'c64 'c128 です。
  • plain_array(kind, n)・u8_array(n) などで作ります。
  • 中身が同じ別の plain array は equal ですが identical ではありません。
  • a[i] = e は通ります。範囲外と変換できない値はエラーです。

ユーザーデータ

  • 組み込み関数で作ります。作るときに immutable か mutable かを必ず指定します。既定はありません。
  • 型名が組み込みの型名や別のユーザーデータの型名と同じときは、型を作るときにエラーです。組み込みの8つの型名の symbol とユーザーデータの型名の symbol は、M式の head にできません。
  • immutable は hash が中身で決まります。mutable はオブジェクトごとに決まります。

equality

equality は a == b（_eq）で調べます。a != b（_ne）はその逆です。

数の型をまたぐ equality

整数・float・complex は、型が違っても値が同じなら equal です。1 == 1.0 も 1 == complex(1, 0) も true で、hash も同じ値です。

equality を使う所

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が == で equal なときだけ合います。
  • table（table_get・table_set・t[key]）は、key が identical か equal なら同じ key とみなします。同じ NaN の object を key にすれば引けます。array と plain array を key にするとエラーです。
  • hash(x) は 0 以上の整数です。== で equal な値は同じ値になります。hash の具体的な値は定めません。

identity と is

a is b は、a と b が identical なら true、そうでなければ false です。否定は a is not b と書きます。優先順位は == と同じ比較演算子の段です。比較と同じく結合しないので、a is b is c はエラーです。パターンの中に is は書けません。

  • identical な値は equal です。ただし NaN は除きます。
  • intern する型の値は、同じ型の値と equal なら identical です。float 以外の型はすべて intern します。
  • 型が違う値は identical ではありません。1 == 1.0 は true ですが、1 is 1.0 は false です。
  • identical の判定は多倍長整数を除き O(1) です。
