値の型は head で調べます。パターンの x @ Int は head が Int の値に合います。型名の symbol は M式の head にできません。

immutability

値は immutable か mutable のどちらかです。array と plain array は mutable です。整数・float・文字列・symbol・M式・function は immutable です。ユーザーデータは、作るときに immutable か mutable かを指定できます。

equality と identity

equality は a == b（_eq）で調べます。a != b（_ne）はその逆です。

identity と is

a is b は、a と b が identical なら true、そうでなければ false です。優先順位は == と同じ比較演算子の段です。

  • identical な値は equal です。ただし NaN は除きます。NaN は自分自身と identical ですが、自分自身とも equal ではありません。
  • intern する型の値は、同じ型の値と equal なら identical です。float 以外の型はすべて intern します。
  • 型が違う値は identical ではありません。1 == 1.0 は true ですが、1 is 1.0 は false です。
  • identical の判定は多倍長整数を除き O(1) です。

数の型をまたぐ equality

整数と float は、型が違っても値が同じなら equal です。1 == 1.0 は true です。complex との equality はこの頁に定めがありません。

equality を使う所

  • 同じ名前を2回書いたパターン（f(a, a)）は、2つの値が == で equal なときだけ合います。
  • 組み込みの table（table_get・table_set・t[key]）は、key が identical か equal なら同じ key とみなします。同じ NaN の object を key にすれば引けます。
  • hash(x) は 0 以上の整数です。== で equal な値は同じ値になります。
