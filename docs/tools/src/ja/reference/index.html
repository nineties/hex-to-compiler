リファレンス

planck は記号処理と言語処理のための言語です。この節で言語を定義します。

プログラムの読み込み

処理系は planck/init.pk を読み込んでから第1引数のプログラムファイルを実行します。トップレベルの式は1つずつ読んで評価します。

planck/init.pk・planck/peg.pk は M式で書かれています。planck/syntax.pk は planck/peg.pk の packrat パーサで構文を定義します。このファイルは ::= の文法と動作を書くための最小の構文までを M式で書き、そこで parse を差し替え、残りの構文を ::= で宣言します。したがって引数のファイルはこの構文で読みます。
