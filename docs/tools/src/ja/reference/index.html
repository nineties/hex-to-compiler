リファレンス

planck の言語の定義 planck/SPEC.rst を、例を付けて日本語で書いたものです。食い違う場合は SPEC が正です。

目次

  • 構文 — 式と M式の対応・結合の強さ・字句・if・for・return・match・fun・record・糖衣が呼ぶ名前・a[i] と t[p -> e | ...]
  • 値・パターン・M式 — 値の種類・特殊形式・パターン・エフェクト・トップレベル
  • 文法の宣言 — ::=・項目・name{| text |}・peg_parse
  • 組み込み関数 — 出力・整数・M式・文字列・配列・ファイル・言語
  • ライブラリ — list・vector・string・table・symbol・error・pretty・unparse・base

プログラムの読み込み

最初に planck/init.pk を読み、続いて引数のファイルを順に実行します。トップレベルの式は1つずつ読んで評価します。

planck/init.pk・planck/peg.pk・planck/syntax.pk は M式で書かれています。planck/syntax.pk は planck/peg.pk の packrat パーサで構文を定義して parse を差し替えるので、引数のファイルはこの構文で読まれます。
