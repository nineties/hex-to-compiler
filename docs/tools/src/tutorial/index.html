チュートリアル

planck をはじめて触る人のためのチュートリアルです。小さな例を動かしながら、1 章ずつ進みます。

各章の例はそのまま動きます。例の下の「出力」は、その例を実際に動かして出たものです。手元でも同じものが出るはずです。細かい決まりはリファレンスにまとめてあります。

用意するもの

x86 の Linux が要ります。32 ビットの実行ファイルを作るので、64 ビットの Linux でもそのまま動きます。ほかに要るのは make と xxd だけです。C コンパイラもアセンブラも使いません。

処理系を作る

$ git clone @REPO@.git
$ cd hex-to-compiler
$ make

make は手書きの機械語から始めて、Forth・Lisp を経て planck の処理系 planck0 を作ります。数分かかります。どう積み上がるのかは処理系の実装で読めます。

うまくできたか確かめるには試験を流します。

$ make test-planck0

プログラムを動かす

次の 1 行を hello.pk という名前で保存します。.pk が planck のプログラムの拡張子です。

リポジトリの一番上のディレクトリで動かします。

$ ./planck0 hello.pk
Hello, planck!

planck0 は起動するとまず planck/init.pk を読みます。だから一番上のディレクトリで動かしてください。ファイルを何個も渡すと、前から順に動かします。
