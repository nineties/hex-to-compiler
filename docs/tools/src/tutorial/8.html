8. 構文を広げる

planck の構文は文法の規則の集まりです。プログラムの中で ::= を書くと、その規則を足したり置き換えたりできます。次の行からは新しい構文で読まれます。

unless を作る

1 行目が文法の宣言です。読み方は次のとおりです。

  • primary ::= ... | ... は、式の一番小さな単位を表す規則 primary を定義し直します。最後の ... は「これまでの primary」です。だから新しい書き方を足しただけで、元の構文はそのまま使えます。
  • 'unless は単語 unless に合います。"(" は文字 ( に合います。
  • c:expr は「規則 expr で読み、結果を c と呼ぶ」です。
  • 最後の { ... } は、読めたときに作る値です。ここではプログラムの木を返しています。

`If{!c, none, !a} の ` は「この M式を、! の所だけ埋めて作る」という印です（9 章）。つまり unless (c) a を If{c, none, a} に読み替えています。If は if を読んだときにできる木です。

規則の項目と { ... } は ::= や | と同じ行に書きます。

演算子を足す

x |> f を f(x) と読む演算子です。union は関数の融合 | の規則で、x:union と自分自身から始めているので左から順にまとまります。3 |> double |> double は double(double(3)) です。

ブロックを受け取る構文

作る木はふつうの構文でも書けます。`repeat_fn(!n, () -> !body) は、repeat_fn(...) という呼び出しの木を作ります。!body の所に、読み込んだブロックが入ります。

自分の文法で計算する

規則は planck の構文のためだけのものではありません。好きな文法を書いて、その場で読ませることもできます。

calc ::= a:calc "+" b:term { a + b } | ... では、{ ... } が木ではなく計算した値を返しています。左再帰（自分自身から始まる規則）が書けるので、100 - 20 - 3 は左から順に計算されます。

calc{| ... |} は、{| と |} の間を規則 calc で読みます。読むのはプログラムを読み込んだ時で、値は定数として埋め込まれます。

実行中に手に入った文字列は peg_parse(規則, 文字列) で読みます。結果は Tuple{値, 読み残し} です。"1 + )" は先頭の 1 だけが読めて、残りが読み残しになります。先頭から読めなければ値の所に SyntaxError{...} が入ります。

文法の書き方の一覧はリファレンスの文法の宣言にあります。planck の構文の規則が全部ある所は処理系の実装で読めます。
