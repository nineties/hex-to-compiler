6. レコードと流れの制御

M式の引数に名前を付けるレコードと、ブロックの中の関数、途中で抜ける書き方を見ます。

レコード

M式の引数は位置で取り出しますが、数が増えると読みにくくなります。record で引数に名前を付けると、p.x のように名前で取り出せます。

record Point(x, y) は「頭が Point の M式の 0 番目を x、1 番目を y と呼ぶ」という宣言です。値はこれまでどおり Point{3, 4} で作ります。中身はただの M式なので、パターンで分けることもできます。

. の前に空白は入れません。

ブロックの中の関数

ブロックの中で fun 名前(引数) 本体 と書くと、そのブロックの中だけの関数ができます。

fun で作った関数は、ブロックの先頭で名前が用意されます。だから is_even は、あとに書いた is_odd を呼べます。ブロックの中で 名前(引数) := 本体 と書いた関数は、それより前に書いた関数からは呼べません。

途中で抜ける

return 値 は、それを含む関数をその場で終わらせ、値を返します。for の中に書いても、抜けるのは外の関数 find_first です。

break は一番内側の while か for を終わらせます。continue はその回の残りを飛ばして次の回に進みます。この例では 1 から 10 までの奇数をたしています。

return の値は return と同じ行に書き始めます。
