4. パターンで分ける

planck の関数は、引数の形で場合分けできます。場合ごとの関数を | でつなぐのが基本の書き方です。

関数をつなぐ

(0) -> 0 は「引数が 0 のときだけ呼べる関数」です。| でつないだ関数を呼ぶと、左から順に引数がパターンに合うかを試し、最初に合ったものが動きます。fib(5) は (0) にも (1) にも合わないので、3 つめの (n) が動きます。

| でつなぐことを関数の融合と呼びます。融合した結果もふつうの関数です。どのパターンにも合わない引数で呼ぶと、プログラムはエラーで止まります。

パターンの種類

パターン合う値
x何にでも合い、その値が変数 x に入ります
_何にでも合います。値は捨てます
0・"abc"等しい整数・文字列
'none等しいシンボル
Head{p, ...}頭と引数の数が同じで、引数がそれぞれ p, ... に合う M式
p :: q・[p, q]リスト
p @ intp に合い、値の種類が int のもの

リストを分ける

Nil{} と [] はどちらも空のリストに合います。x :: xs は先頭の要素 x と残り xs に分けます。[a, b] は要素がちょうど 2 つのリストにだけ合います。

種類で分ける

n @ int は「整数なら n に入れる」というパターンです。@ の右には typeof が返す名前を書きます。

あとから場合を足す

融合は値なので、あとから場合を足せます。

greet = ("ja") -> ... | greet は、新しい場合を前に置いて古い greet とつなぎ、入れ直しています。前に置いたほうが先に試されます。

match

関数を作らずにその場で値を分けたいときは match を使います。

match 値 { パターン -> 式 ... } は、上から順にパターンを試します。場合は改行か ; で区切ります。パターン if 条件 と書くと、パターンに合ったうえで条件が成り立つときだけ選ばれます。条件が成り立たなければ次の場合に進みます。

式を微分する

パターンと M式を組み合わせると、式を扱うプログラムが短く書けます。次は x での微分です。

2 つめの場合の本体はかっこで囲んであります。else のあとは式全体を読むので、かっこがないと次の行の | ... まで else の中に入ってしまいます。融合の途中で if を使うときは、かっこで囲んでください。

'Add{x, 3} の ' は、中を計算せずに M式のまま渡す印です（9 章）。結果は整理していないので Add{1, 0} のような形のまま出ます。整理する関数も同じようにパターンで書けます。リポジトリの planck/examples/deriv.pk に整理まで入れた版があります。
