4. ライブラリ

planck/lib のライブラリは planck の構文で書かれていて、use("name") で読み込みます。同じ名前の2回目以降の use は何もしません。

リスト

演算子は関数として渡せないので、(a, b) -> a + b のように無名関数に書きます。sort は安定なマージソートです。

for

for (p in xs) body はリストかベクタの要素を順にパターン p に当てます。値は none です。本体から外側の変数に代入できます。

文字列

表とベクタ

table()・table_get・table_set は init.pk にあり、use なしで使えます。キーは == で比べます。table_keys の順序は不定です。ベクタは末尾に伸ばせる配列です。表とベクタは t[key]・v[i] でも読み書きできます（9章）。
