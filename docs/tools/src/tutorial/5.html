5. ライブラリを使う

リスト・文字列・表を扱う関数は planck/lib のライブラリにあります。use("名前") で読み込みます。

リスト

use("list") でリストの関数が使えるようになります。range(a, b) は a から b - 1 までのリスト、map は各要素に関数を当てたリスト、filter は条件に合う要素だけのリストです。foldl(f, 初期値, xs) は左から順に f でまとめます。ここでは組み込みのたし算 add をそのまま渡しています。

sort(比べる関数, xs) は並べ替えです。lt は < と同じ働きの関数です。

同じライブラリを何度 use しても、読み込むのは最初の 1 回だけです。

for で回す

for (パターン in リスト) 本体 は、要素を 1 つずつパターンに当てて本体を動かします。2 つめの for のように、組を (name, n) で分けながら回すこともできます。本体からは外の変数 total を書き換えられます。

文字列

split で区切り、join でつなぎます。trim は両端の空白を落とします。str_to_int は数字の文字列を整数にします。

表とベクタ

表（ハッシュ表）は table() で作ります。table_get と table_set は最初から使えます。use("table") を読むと、キーの一覧などが使えるようになります。

table_get(t, キー, 既定値) は、キーがなければ既定値を返します。table_keys の順番は決まっていないので、ここでは sort で並べてから出しています。str_less は文字列を辞書の順で比べます。

ベクタは後ろに要素を足していける配列です。vec_push で足し、vec_get で取り出します。
