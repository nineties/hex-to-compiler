hex-to-compiler

16進で手書きした機械語から出発して、言語処理系をブートストラップするプロジェクトです。各段は前の段が作った成果物だけを使い、外部のアセンブラ・コンパイラ・ランタイム・コード生成器を使いません。

対象は x86 の32ビット Linux です。ビルドに必要なのは make と xxd だけです。今は第3段で、planck という言語の処理系 planck0 を作っています。

段の構成

3つの段で処理系と道具を順に作ります。矢印の横は Makefile が実行するコマンドです。

第1段　機械語 → Forth → Lisp

pforth.xxd16進ダンプ201行。右側の注釈は xxd -r が読み飛ばす
xxd -r -c 8 pforth.xxd > pforth
pforth1文字の語だけを持つ Forth インタプリタ。32ビット ELF
./pforth < plisp.fs
plispForth を自己拡張し、その Forth で書いた Lisp インタプリタ。ファイルにはならず、起動のたびに組み立てる

第2段　機械語を出す道具

asm・sasmplisp で書いた x86 アセンブラと、C 風の構造化アセンブリ言語のコンパイラ
./pforth < plisp.fs sasm.lisp plisp2.sv tmp-plisp2
plisp2plisp を sasm で書き直した Lisp インタプリタ

第3段　本格的な言語処理系

./plisp2 sasm.lisp planck0.sv planck0
planck0sasm で書いた planck の処理系。M式をバイトコードにして仮想機械で実行する
起動時に planck/init.pk → peg.pk → syntax.pk を読む
planckplanck0 の上に packrat パーサと構文を M式で載せた言語
成果物ソース言語役割
pforthpforth.xxd機械語1文字の語だけを持つ Forth インタプリタ。ここから自己拡張で育てる
plispplisp.fs・plisp/init.lispForth・Lisppforth を使える Forth まで拡張し、その上に構文木を直接扱える Lisp を作る
asmasm.lisp・asm/core.lispplispx86 32ビットのアセンブラ。ELF を直接書き出し、ヘッダ・コード・データを1つの PT_LOAD（RWX）に置く
sasmsasm.lisp・sasm/core.lisp・sasm/lib/std.svplisp型のない C 風の言語。plisp の内部 DSL で、レジスタ割り付けをせずスタックマシン型のコードを出す
plisp2plisp2.svsasmplisp の速度では足りない次の段のための Lisp。sasm を動かして planck0 を作る
planck0planck0.svsasmplanck の最小限の部分集合で、ブートストラップのための暫定の実装。M式のリーダ・バイトコードコンパイラ・仮想機械・代数的エフェクト
planckplanck/init.pk・peg.pk・syntax.pk・lib/M式・planck構文を文法の規則として持ち、プログラムから拡張できる言語

asm と sasm は次の段へ渡るための道具で、性能と安全性より実装の単純さを優先しています。各段のつくりは機械語から planck0 までにあります。

ビルドと試験

$ git clone @REPO@.git
$ cd hex-to-compiler
$ make                  # pforth・plisp2・planck0
$ make test             # plisp の試験 plisp/test.lisp
$ make test-planck0     # planck の試験と例
$ ./planck0 prog.pk

planck0 は起動時に相対パスで planck/init.pk を読むので、リポジトリの最上位で実行します。

ターゲット内容
makepforth・plisp2・planck0 をこの順に作る
make exampleasm/examples/*.s と sasm/examples/*.sv を実行ファイルにする
make test./pforth < plisp.fs plisp/test.lisp

CI（runtests.yaml）は main への push ごとに、pforth のビルド、plisp の試験、plisp2 のビルド、./plisp2 plisp/test.lisp、planck0 のビルド、make test-planck0 を順に実行します。

進んでいる所

  • 第3段の最初の処理系 planck0 は planck の部分集合で、ブートストラップのための暫定の実装です（[[planck0.sv#4-5]]）。
  • planck の言語仕様は planck/SPEC.rst です。planck/lib には処理系を書くためのライブラリ（リスト・ベクタ・文字列・表・gensym・位置つきエラー・整形・文法から作る unparse）があります。
  • planck/examples には13本の例があります。字句解析・構文解析・3番地コード生成・仮想機械を持つ電卓 calc.pk、記号微分、非決定性のエフェクトによる N クイーン、構文木の書き換えなどです。
  • planck0 のヒープは起動時に確保する1GB の固定領域で、GC はありません（[[planck0.sv#39-67]]）。
  • 動く環境は x86 の Linux だけです。
