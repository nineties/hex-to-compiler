planck

記号と言語を扱うための小さな言語です。構文そのものを planck のプログラムで書き足せます。

planck のプログラムはこんな見た目をしています。

関数はパターンで場合分けして書きます。| は関数どうしをつなぎ、合うパターンを持つほうが呼ばれます。

planck の構文は planck 自身で定義されています。だから自分のプログラムの中で新しい構文を足せます。次の例は repeat という構文を作ってすぐ使っています。

チュートリアル

はじめての人向け。小さな例を動かしながら順に読みます。

リファレンス

構文・組み込み関数・ライブラリを引くためのページです。

処理系の実装

手書きの機械語から planck まで、処理系を積み上げる仕組みを読みます。

動かしてみる

x86 の Linux で次のように打ちます。make は手書きの機械語から始めて処理系を順に作ります。

$ git clone @REPO@.git
$ cd hex-to-compiler
$ make
$ ./planck0 hello.pk

くわしくはチュートリアルのはじめにを見てください。言語の正式な定義は planck/SPEC.rst です。
