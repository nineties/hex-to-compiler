" load(path) parses and evaluates the file by the current parse and eval. " " The top-level definitions of the file are made while path is the file being loaded. " Def{load, Lambda{Tuple{path}, Do{ Def{s, Apply{read_file, Tuple{path}}}, Def{prev, Apply{_set_file, Tuple{path}}}, Def{r, none}, Def{e, none}, Def{go, true}, While{go, Do{ Set{r, Apply{parse, Tuple{s}}}, Set{e, Apply{arg, Tuple{r, 0}}}, If{Apply{_eq, Tuple{e, Eof{}}}, Set{go, false}, If{If{Apply{_eq, Tuple{Apply{typeof, Tuple{e}}, Quote{mexpr}}}, Apply{_eq, Tuple{Apply{head, Tuple{e}}, Quote{SyntaxError}}}, false}, Do{ Apply{put, Tuple{path}}, Apply{put, Tuple{": syntax error: "}}, Apply{println, Tuple{e}}, Apply{exit, Tuple{1}}}, Do{ Apply{eval, Tuple{e}}, Set{s, Apply{arg, Tuple{r, 1}}}}}}}}, Apply{_set_file, Tuple{prev}}, none}}}
