処理系の実装

planck の処理系を、手書きの機械語から planck の構文まで、ソースの行を引きながら読みます。ステージの全体は概要にあります。

ビルドの順序

pforth:  xxd -r -c 8 pforth.xxd > pforth
plisp2:  ./pforth < plisp.fs sasm.lisp plisp2.sv tmp-plisp2
planck0: ./plisp2 sasm.lisp planck0.sv planck0

plisp は実行ファイルを持ちません。pforth は起動のたびに plisp.fs を読んで Lisp を組み立て、その Lisp が sasm.lisp で plisp2.sv をコンパイルします。planck0 は plisp2 の上の同じ sasm.lisp でコンパイルします。planck0 から先は実行時に組み立てます。planck0 は init.pk・peg.pk・syntax.pk を M式として読み、syntax.pk が parse を差し替えた時点で planck の構文が入ります。
