vasm の検査器

planck/lib/vasm.pk（862行）は、機械命令に近い低級な言語 vasm の読み込みと検査を planck で書いたライブラリです。use("vasm") で読み、vasm{| ... |} に書いた関数と構造体の並びを、所有と借用の違反・解放後の使用・未初期化の読み出しについて型の規則だけで検査します。言語の規則はリファレンスの vasmにあります。

入口

planck/lib/vasm.pk:1–11

# vasm: a language with types, ownership and named regions, written in .pk files
# Copyright (C) 2026 nineties
#
# vasm{| struct ... fn ... |} reads structs and functions of the language and is Module{[Struct{...}, Fn{...}, ...]}.
# vasm_check(m) is the list of VasmErr{kind, Pos{d}, msg}, one for each struct or function with an error,
# and vasm_errors(file, m) gives the positions as Loc{file, line, column} of the file.

use("list")
use("table")
use("string")
use("error")

vasm{| ... |} は Module{[Struct{...}, Fn{...}, ...]} に読まれ、検査は vasm_check(m) がこれを受け取って VasmErr{kind, Pos{d}, msg} のリストを返します。vasm_errors(file, m) は位置をファイルの Loc{file, line, column} に直し、vasm_report(file, m) はそれを file:行:列: メッセージ で書きます。誤りのない関数は結果に現れず、1つの関数の誤りは最初の1件だけです。この頁の例は、各ファイルの report で結果を1行ずつ書きます。

構文

vasm の構文は packrat パーサの規則として ::= で宣言します（planck/lib/vasm.pk:38–39）。予約語は vasm_kw に集め、名前は予約語でない識別子です。文の規則は頭ごとに選択肢を並べ、読んだ結果を Decl{...}・IfS{...}・Assign{...} などの M式にします。

planck/lib/vasm.pk:123–134

vasm_stmt ::= at:vasm_here 'var x:vasm_name ":" t:vasm_type { Decl{at, x, t} }
    | at:vasm_here 'if "(" c:vasm_cond ")" a:vasm_block 'else b:vasm_block { IfS{at, c, a, b} }
    | at:vasm_here 'if "(" c:vasm_cond ")" a:vasm_block { IfS{at, c, a, []} }
    | at:vasm_here 'while "(" c:vasm_cond ")" a:vasm_block { WhileS{at, c, a} }
    | at:vasm_here 'region r:vasm_name a:vasm_block { RegionS{at, r, a} }
    | at:vasm_here 'return vasm_same a:vasm_operand { Ret{at, a} }
    | at:vasm_here 'return { Ret{at, none} }
    | at:vasm_here "*" p:vasm_name "=" a:vasm_operand { Store{at, p, a} }
    | at:vasm_here p:vasm_name "[" i:vasm_operand "]" "=" a:vasm_operand { IStore{at, p, i, a} }
    | at:vasm_here p:vasm_name "." f:vasm_name "=" a:vasm_operand { FStore{at, p, f, a} }
    | at:vasm_here x:vasm_name "=" r:vasm_rhs { Assign{at, x, r} }
    | at:vasm_here f:vasm_name "(" args:vasm_args? ")" { CallS{at, f, vasm_opt_list(args)} }

どの規則の結果にも、位置の at が入っています。vasm_here は何も読まずに、次の字句から本文の終わりまでの文字数を Pos{d} として返す規則です（planck/lib/vasm.pk:29–34）。検査の誤りはこの Pos を持ち、vasm_errors が本文の長さから引いて行と列にします。

型と検査の状態

型も M式です。整数は I8{} から U64{}、箱は Own{u}、借用は Ref{'shr または 'mut, 領域, u}、配列は Arr{u}、構造体は Named{s} です。

planck/lib/vasm.pk:186–198

# === Checker state ===
# vasm_info: name -> Info{type, regions open at the declaration}, for the variables in scope
# a state: name -> Vs{status, loans}, and ".dead" -> true after return
#   status: 'init, 'uninit, Moved{at}, Freed{at}, Taken{at} (an own value whose contents are moved out by x = *p)
#   or Parts{fields} (a struct value whose fields that own are moved out by x = s.f, U19); loans: [Loan{region, kind}, ...]
# vasm_regions: the regions in scope, the innermost first, ending with the regions of the function

vasm_sigs := table()
vasm_structs := table()
vasm_info := table()
vasm_regions := []
vasm_fn_regions := []
vasm_ret_type := Unit{}

関数ごとに、変数の宣言を vasm_info（名前から型へ）に、変数の状態を表の Vs{status, loans} に持ちます。status は初期化済み・未初期化・move 済み・解放済み・中身を取り出した箱・フィールドを取り出した構造体のどれかで、loans はその変数を借りている借用の並びです。if や while は状態の表を複製して分岐ごとに検査し、あとで突き合わせます。

値が move されるかコピーされるかは型で決まります。own と own を持つ構造体は線形で、使うと move され、ちょうど1回 move か解放しなければなりません。整数・bool・own を持たない構造体と共有の借用はコピーされます。

planck/lib/vasm.pk:217–222

# An integer literal is Lit{n} until it meets an integer type; Lit{none} is the result of an operation on literals.
# Integers, bool and structs without own are copied. own and a struct with own are linear: they are moved
# by a use and must be moved or freed once (U6, U19). &mut is moved by a use, except for an argument of a call
# (vasm_call). & is copied.
vasm_linear(t) := head(t) == 'Own or (head(t) == 'Named and vasm_owning(t))
vasm_moves(t) := vasm_linear(t) or (head(t) == 'Ref and arg(t, 0) == 'mut)

所有

vasm_box.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    fn bump[r](p: &mut r i64) {
        var v: i64
        v = *p
        v = v + 1
        *p = v
    }
    fn main() -> i64 {
        var p: own i64
        var v: i64
        p = box(41)
        region r {
            var m: &mut r i64
            m = &mut r p
            bump(m)
        }
        v = *p
        free(p)
        return v
    }
|}
report(m)

出力

ok

own i64 は box で確保した整数への、ただ1つの持ち主です。bump の [r] は呼び出しごとに決まる領域の引数です。&mut を借用の引数に渡す呼び出しは、vasm_reborrows が呼び出しの間だけ借り直すものとして扱い、move しません（planck/lib/vasm.pk:511–517）。m がそのあとも使えるのはこのためです。

レジスタを読む前に vasm_need_init が状態を引き、未初期化・move 済み・解放済みならそれぞれ 'uninit・'moved・'freed の誤りにします（planck/lib/vasm.pk:258–265）。free した own が読めず、もう一度 free もできないのは、vasm_call が free の引数を解放済みにするからです。q を p に代入すると q が move 済みになり、所有が p に移ります。

自動の解放

vasm_drop.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)

m := vasm{|
    struct Buf { data: own [u8], size: i64 }
    fn at_block_end(c: bool) {
        if (c) {
            var q: own i64
            q = box(2)
        }
    }
    fn overwrite() -> i64 {
        var p: own i64
        var v: i64
        p = box(1)
        p = box(2)
        box(3)
        v = *p
        return v
    }
    fn free_with_contents(b: own Buf) {
        free(b)
    }
|}
report(m)

出力

ok

own を持った値は、持ち主がなくなる所で自動的に解放されるので、上の例はどれも誤りになりません。その場所は、ブロックや関数の終わり、上書き、文として捨てた関数の結果、free した値の中に残ったものです。解放は実行時の動作で、検査器は何も数えません。ブロックや関数の終わりで残りを調べる関数 vasm_leak_all は、解放の場所を示すために残してある空の関数です（planck/lib/vasm.pk:654–657）。上書きは vasm_assign が状態を初期化済みに戻すだけです（planck/lib/vasm.pk:642–652）。free は早く手放したいときに書きます。

借用した変数の Vs には Loan{region, kind} が入ります。借りている間の move・解放・代入は vasm_no_loans が、&mut で借りている間の読み書きは vasm_no_mut_loan が拒みます（planck/lib/vasm.pk:294–295）。共有の借用は同時にいくつでも持てますが、&mut は1つだけで、借りている間は元の値を読むことも書き換えることも解放することもできません。region r { ... } は vasm_end_region で終わりに r の貸しを消します（planck/lib/vasm.pk:691）。

領域の内外は vasm_outlives(q, r) が決めます。q が r と同じか、r が関数の中で開いた領域で q がそれより前に開いたものなら、q は r より長く生きます。関数の領域の引数どうしには順序がありません。

planck/lib/vasm.pk:325–327

# q outlives r: q is r, or r is a region opened in the function and q was opened before it (U13).
# The regions of the function are not ordered.
vasm_outlives(q, r) := q == r or (not member(r, vasm_fn_regions) and index_of(q, vasm_regions) > index_of(r, vasm_regions))

planck/lib/vasm.pk:334–345

# a value of type t can be put where e is expected: an integer literal in the range of e,
# or a borrow of a region that outlives the region of e (U13)
vasm_fits(at, e, t) := if (head(t) == 'Lit and vasm_int(e)) {
    vasm_lit_range(at, arg(t, 0), e)
    true
} else if (head(e) == 'Own and head(t) == 'Own) vasm_fits(at, arg(e, 0), arg(t, 0))
else if (head(e) == 'Arr and head(t) == 'Arr) vasm_fits(at, arg(e, 0), arg(t, 0))
else if (head(e) == 'Ref and head(t) == 'Ref) arg(e, 0) == arg(t, 0) and vasm_outlives(arg(t, 1), arg(e, 1)) and vasm_fits(at, arg(e, 2), arg(t, 2))
else e == t

# a borrow that does not fit only because its region is opened inside the function and does not outlive the expected one
vasm_escapes(e, t) := head(e) == 'Ref and head(t) == 'Ref and arg(e, 0) == arg(t, 0) and arg(e, 2) == arg(t, 2) and not member(arg(t, 1), vasm_fn_regions)

代入や引数で借用の型が合うかは vasm_fits が見ます。外側の領域の借用を内側の領域の借用として使うのは外のほうが長く生きるので通り、逆は通りません。逆のうち、受け側が関数の中で開いた領域より外のレジスタである場合は、vasm_escapes が 'escape の誤りにします。

分岐とループ

planck/lib/vasm.pk:659–684

# the state after if: both branches must agree on own values
vasm_merge(at, a, b) := if (vasm_dead(a)) b else if (vasm_dead(b)) a else {
    m := table()
    each(x -> {
        t := arg(table_get(vasm_info, x, none), 0)
        sa := vasm_status(a, x)
        sb := vasm_status(b, x)
        if (vasm_owns(t, sa) != vasm_owns(t, sb)) vasm_fail(at, 'branch, f"{symname(x)} is owned after one branch and not after the other")
        if (vasm_linear(t) and vasm_key(t, sa) != vasm_key(t, sb)) vasm_fail(at, 'branch, f"{symname(x)} has different parts moved out after the two branches")
        s := if (sb == 'init) sa else sb
        la := vasm_loans(a, x)
        table_set(m, x, Vs{s, append(la, filter(l -> not member(l, la), vasm_loans(b, x)))})
    }, vasm_vars(a))
    m
}

vasm_replace(st, m) := {
    each(x -> table_set(st, x, table_get(m, x, none)), vasm_vars(st))
    table_set(st, ".dead", vasm_dead(m))
}

# a loop must give back the own and &mut values it moves
vasm_loop_same(at, a, b) := each(x -> {
    t := arg(table_get(vasm_info, x, none), 0)
    if (vasm_moves(t) and vasm_key(t, vasm_status(a, x)) != vasm_key(t, vasm_status(b, x))) vasm_fail(at, 'loop, f"{symname(x)} is moved or freed in the loop and not given a value again")
}, vasm_vars(a))

if は両方の分岐を複製した状態で検査し、vasm_merge が突き合わせます。片方の分岐だけで move や解放をした値は、あとで持ち主かどうかが決まらないので 'branch の誤りです。return で終わった分岐は、.dead の印を付けて突き合わせから外します。while は本体を2周分検査し、vasm_loop_same が、ループで move した値が次の周の前に入れ直されているかを見ます（'loop）。

line 12: the operands are u32 and u8

整数の型は vasm_ints の表（型・名前・ビット数・符号）に並べてあります（planck/lib/vasm.pk:159–166）。演算の両辺は同じ型で、幅や符号を変えるには as を使います。リテラルは、はじめ型のない Lit{n} で、整数の型に出会ったところで範囲を調べます。範囲は -32768 から 32767 までで、符号なしの型は 0 から、8 ビットの型はその型の範囲に狭まります（vasm_lit_lo・vasm_lit_hi、planck/lib/vasm.pk:167–170）。大きな値は、シフトと | で組み立てます。

配列と構造体

vasm_array.pk

use("vasm")

report(m) := {
    es := vasm_errors(argv()[0], m)
    if (es == []) put("ok\n")
    each((VasmErr{_, Loc{_, l, c}, msg}) -> put(f"line {l}: {msg}\n"), es)
}

m := vasm{|
    struct Section { offset: u64, size: u32 }
    fn total[r](ss: &r [Section]) -> u64 {
        var i: i64
        var n: i64
        var t: u64
        var s: Section
        var o: u64
        i = 0
        t = 0
        n = len(ss)
        while (i < n) {
            s = ss[i]
            o = s.offset
            t = t + o
            i = i + 1
        }
        return t
    }
    fn build() -> u64 {
        var a: own [Section]
        var s: Section
        var t: u64
        s = Section{offset: 64, size: 16}
        a = alloc(3, s)
        s = Section{offset: 128, size: 0}
        a[1] = s
        region r {
            var view: &r [Section]
            view = &r a
            t = total(view)
        }
        free(a)
        return t
    }
|}
report(m)

出力

ok

組み込みの関数は、型変数 T を含む型 Sig{領域, 引数, 結果} の表 vasm_builtins に並べてあります（planck/lib/vasm.pk:224–232）。alloc(n, v) は v を n 個並べた own [T] を作り、len は長さを返します。添字は i64 で、範囲の検査は実行時に回し、検査器は型と所有だけを見ます。構造体は全部のフィールドを1回ずつ書いて作り、own を持たなければ整数と同じくコピーされます。own を持つかどうかは vasm_owning が、フィールドをたどって決めます（planck/lib/vasm.pk:200–212）。

出力

line 25: the elements of parts own values and are not copied; use swap(parts[i], v)

own を持つ値は、配列の要素やポインタの指す先から読んでコピーすることができません（持ち主が2人になるため）。swap(p[i], v) は v を入れて前の値を取り出します。引数の型 Place{T} は、*p・p[i]・p.f の形の場所だけを受けます。構造体のレジスタのフィールドへの書き込み img.body = b は、前の値を解放して入れ替えます。

誤りの返し方

planck/lib/vasm.pk:830–848

# the errors of the module m: [VasmErr{kind, Pos{d}, msg}, ...], the first error of each struct and function
vasm_check(m) := {
    items := arg(m, 0)
    vasm_sigs = table()
    vasm_structs = table()
    each(d -> match d {
        Fn{_, f, rs, ps, ret, _} -> table_set(vasm_sigs, f, Sig{rs, map(p -> arg(p, 2), ps), ret})
      | Struct{_, s, _} -> if (table_get(vasm_structs, s, none) == none) table_set(vasm_structs, s, d)
    }, items)
    errs := []
    each(d -> {
        r := handle {
            if (head(d) == 'Struct) vasm_check_struct(d) else vasm_check_fn(d)
            none
        } with (VasmFail{at, kind, msg}, k) -> VasmErr{kind, at, msg}
        if (r != none) errs = r :: errs
    }, items)
    reverse(errs)
}

検査の途中で誤りに出会うと vasm_fail が代数的エフェクト VasmFail{at, kind, msg} を起こします（代数的エフェクト）。vasm_check は構造体と関数ごとに handle でこれを受け、VasmErr にして検査を打ち切るので、1つの関数の誤りは最初の1件になります。kind の種類はリファレンスの表にあります。
