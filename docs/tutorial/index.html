planck チュートリアル

planck は記号処理と言語処理のための言語です。式は M式に読み替えて評価し、構文そのものを packrat パーサの規則としてプログラムから拡張できます。

このチュートリアルは言語処理系を書いた経験のある読者向けに、例で要点を通します。例の出力はすべて planck0 で実行した結果です。規則の細部はリファレンス、正式な定義は planck/SPEC.rst にあります。

実行

$ ./planck0 prog.pk a b

リポジトリの最上位で実行します。REPL はありません。プログラムは argv() で引数を受け取ります。argv()[0] は prog.pk、続いて "a" と "b" です。

ファイルはトップレベルの式を1つ読んでは評価します。読むのは大域変数 parse、評価するのは eval で、どちらも式ごとに引き直します（6章）。
