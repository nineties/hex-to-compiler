planck チュートリアル

planck は記号処理と言語処理のための言語です。式は M式に読み替えて評価し、構文そのものを packrat パーサの規則としてプログラムから拡張できます。

このチュートリアルは言語処理系を書いた経験のある読者向けに、例で要点を通します。例の出力はすべて planck0 で実行した結果です。規則の細部はリファレンス、正式な定義は planck/SPEC.rst にあります。

t3_fib.pk

fib := (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

関数はパターンごとの無名関数を |（融合）でつないで定義します。構文は文法の規則なので、プログラムの中で足せます。

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

出力

planck!
planck!
planck!

実行

$ make                # pforth・plisp2・planck0 を作る
$ ./planck0 a.pk b.pk

planck0 は planck/init.pk を読んでから引数のファイルを順に実行します。init.pk を相対パスで読むので、リポジトリの最上位で実行します。REPL はありません。

ファイルはトップレベルの式を1つ読んでは評価します。読むのは大域変数 parse、評価するのは eval で、どちらも式ごとに引き直します（8章）。
