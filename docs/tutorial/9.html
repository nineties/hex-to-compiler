9. 添字と置き換え

a[i] と a[i] = v は _index_get と _index_set の呼び出しです。種類ごとの関数を | でつないだものなので、利用者が自分の種類を足せます。t[p -> e | ...] は構文木の書き換えです。

読み書き

t9_index.pk

record Point(x, y)
a := array(3)
a[0] = 10
a[1] = a[0] + 5
a[2] = a[1] * 2
println(a[2])
s := "planck"
println(s[1])
t := table()
t['x] = 1
t['y] = 2
println(t['x] + t['y])
println(t['z])
xs := [10, 20, 30]
println(xs[1])
p := Point{3, 4}
println(p[0] + p[1])
println(p['y])

出力

30
"l"
3
none
20
7
4

配列・文字列・表・リスト・M式に使えます。文字列の s[i] は i 番目の文字（長さ1の文字列）で、リストは0から数えます。M式は整数なら位置、シンボルなら record で宣言した欄です。表の存在しないキーは none です。

書き込めるのは配列・平らな配列・表・ベクタです。文字列・リスト・組・M式は不変で、s[0] = 1 は cannot assign to an element of a string, which is immutable: ... を出してプログラムを止めます。範囲外の添字も止まります。

種類を足す

t9_kind.pk

_index_get = (Counts{t}, k) -> table_get(t, k, 0) | _index_get
_index_set = (Counts{t}, k, n) -> table_set(t, k, n) | _index_set
c := Counts{table()}
for (w in ["a", "b", "a", "a"]) c[w] = c[w] + 1
println(c["a"])
println(c["b"])
println(c["z"])

出力

3
1
0

融合の先頭に自分の種類を置き、残りは元の _index_get に回します。ここでは頭が Counts の M式に対して、ないキーを0として数える表を書いています。ベクタも use("vector") が同じやり方で足しています。

木の書き換え

t9_rewrite.pk

use("unparse")
step(e) := e[
    Apply{'_add, Tuple{a @ int, b @ int}} -> a + b
  | Apply{'_mul, Tuple{a @ int, b @ int}} -> a * b
  | Apply{'_add, Tuple{a, 0}} -> a
  | Apply{'_mul, Tuple{a, 1}} -> a
]
simplify(e) := {
    println(unparse(e))
    n := step(e)
    while (n != e) {
        e = n
        println(unparse(e))
        n = step(e)
    }
    e
}
simplify('(x * 1 + (2 + 3) * 4 + 0))

出力

"x * 1 + (2 + 3) * 4 + 0"
"x * 1 + (2 + 3) * 4"
"x + 5 * 4"
"x + 20"

t[p -> a | q -> b] は subst(t, p -> a | q -> b) で、木 t の各部分を根から順に試します。腕のパターンが合えばその部分を置き換え、内側は試しません。どの腕も合わなければ引数を順に試します。腕には match と同じくガード p if c -> a を付けられます。

1回の置き換えで内側が残るので、変わらなくなるまで繰り返します。演算子の木の頭は '_add のように _ 付きの名前です。クオートした木は ('e)[f] と書きます（'t[f] は t[f] のクオートです）。
