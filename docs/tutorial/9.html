9. プログラムはデータ

planck のプログラムは読み込まれると M式の木になり、それが評価されます。木はふつうの値なので、作ったり調べたり評価したりできます。

クォート

t9_quote.pk

e := '(1 + 2 * x)
println(e)
x := 10
println(eval(e))

n := 5
println(`(n + !n))

出力

Apply{add, Tuple{1, Apply{mul, Tuple{2, x}}}}
21
Apply{add, Tuple{n, 5}}

'式 は式を評価せず、その木を値にします。1 + 2 * x は Apply{add, Tuple{1, Apply{mul, Tuple{2, x}}}} という木です。+ は組み込み関数 add の呼び出し Apply になっています。

eval(木) は木を評価します。x を作ったあとで評価したので、x は 10 です。

`式 は準クォートです。木を作りますが、!式 の所だけは評価した値で埋めます。`(n + !n) の 1 つめの n は名前のまま、2 つめは値 5 になっています。

M式で書く

M式はそれ自体が planck の式として書けます。x := 3 と Def{x, 3} は同じ木です。

t9_mexpr.pk

Def{y, 3}
Apply{println, Tuple{Apply{mul, Tuple{y, y}}}}
println('Def{y, 3} == '(y := 3))

出力

9
true

ふだんの構文は、この M式を読みやすく書くための書き方です。どの構文がどの M式になるかはリファレンスの構文に一覧があります。

評価のしかたを差し替える

planck はファイルを 1 つの式ずつ読みます。読むのは変数 parse の関数、評価するのは変数 eval の関数です。式ごとにこの 2 つの変数を見直すので、プログラムから差し替えられます。

t9_eval.pk

old_eval := eval
eval = e -> {
    v := old_eval(e)
    put("=> ")
    println(v)
    v
}
1 + 2
'(a + b)
Point{1, 2}

出力

=> 3
=> Apply{add, Tuple{a, b}}
=> Point{1, 2}

新しい eval は、元の eval で評価してから値を表示します。差し替えた次の式から、どの式も値が出るようになりました。

parse を差し替えれば読み方も変えられます。8 章の ::= も、文法の規則を足して parse の読み方を変えています。

木を文字列に戻す

use("unparse") の unparse は、木をふつうの構文の文字列に戻します。

t9_unparse.pk

use("unparse")
t := '(if (n < 0) -n else n * (n + 1))
println(t)
put(unparse(t)); put("\n")

出力

If{Apply{lt, Tuple{n, 0}}, Apply{sub, Tuple{0, n}}, Apply{mul, Tuple{n, Apply{add, Tuple{n, 1}}}}}
if (n < 0) -n else n * (n + 1)

unparse は文法の規則から作られています。::= で足した規則で読める木も、その規則を使って戻せます。
