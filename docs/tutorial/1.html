1. はじめの一歩

文字を出して、計算をしてみます。

文字を出す

まずは前のページで作った hello.pk をもう一度見てみましょう。

t1_hello.pk

# はじめての planck
put("Hello, planck!\n")

出力

Hello, planck!

put は文字列をそのまま画面に書く関数です。\n は改行です。# から行の終わりまではコメントで、動きには関係しません。

計算する

四則演算は見たとおりに書けます。println は値を 1 つ書いて改行します。

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

出力

7
9
3
1
-3
36

かけ算 * はたし算 + より先に計算されます。先にたしたいときはかっこで囲みます。

整数どうしのわり算 / は小数を切り捨てます。% はわり算の余りです。-7 / 2 は -3 になります。0 の側へ切り捨てるからです。

0x1f は 16 進数、0b101 は 2 進数です。0o17 と書けば 8 進数になります。

1 行に 1 つずつ式を書くと、上から順に動きます。1 行に 2 つ並べたいときは ; で区切ります。

3 つの書き方の違い

値を書く関数は 3 つあります。

t1_print.pk

print(42)
put(" と ")
println("文字列")
put("put は文字列をそのまま書きます\n")

出力

42 と "文字列"
put は文字列をそのまま書きます
  • print(x) は値 x を書きます。改行はしません。
  • println(x) は print のあとに改行します。
  • put(s) は文字列 s の中身をそのまま書きます。

println("文字列") では引用符 " も出ています。print と println は値を「プログラムに書くときの形」で出すからです。人に読ませる文を出すときは put を使います。

planck には対話式の画面はありません。ファイルに書いて ./planck0 ファイル名 で動かします。
