1. 式・束縛・関数

文はなく、if・while・ブロックも式です。

Hello, world

t1_hello.pk

put("Hello, world!\n")

出力

Hello, world!

出力と整数

t1_arith.pk

println(1 + 2 * 3)
println((1 + 2) * 3)
println(7 / 2)
println(7 % 2)
println(-7 / 2)
println(0x1f + 0b101)

出力

7
9
3
1
-3
36

整数の / は0方向に切り捨てます。リテラルは10進のほかに 0x・0o・0b が使えます。式は改行か ; で区切ります。# から行末はコメントです。

t1_print.pk

print(42)
put(" ")
println("abc")
println('abc)
println(Point{1, "a"})

出力

42 "abc"
abc
Point{1, "a"}

print・println は値をソースに書く形で出し、put は文字列の中身だけを出します。

束縛

t1_vars.pk

x := 10
y := x * 2
println(y)
x = x + 1
println(x)

出力

20
11

:= は定義、= は既存の変数への代入で、2つは別の操作です。関数の中で := した変数はその関数の変数で、外からは見えません（変数の範囲）。

関数

t1_func.pk

square(n) := n * n
println(square(12))

add3(a, b, c) := a + b + c
println(add3(1, 2, 3))

twice := f -> x -> f(f(x))
println(twice(square)(3))

出力

144
6
81

f(p, ...) := e で関数を定義します。x -> e・(a, b) -> e・() -> e は無名関数です。関数名と ( の間に空白は置けません。

t1_if.pk

abs(n) := if (n < 0) -n else n
println(abs(-5))

sign(n) := n < 0 ? -1 : n == 0 ? 0 : 1
println(sign(-3))
println(sign(0))
println(sign(8))

出力

5
-1
0
1

if (c) a else b は式で、else がなければ値は none です。偽は false だけで、0 も none も真として扱います。論理演算は and・or・not です。

ブロックと閉包

t1_block.pk

sum_to(n) := {
    s := 0
    i := 1
    while (i <= n) {
        s = s + i
        i = i + 1
    }
    s
}
println(sum_to(100))

出力

5050

{ ... } は順に評価して最後の式の値を返します。

t1_rec.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(10))

make_counter() := {
    n := 0
    () -> { n = n + 1; n }
}
c := make_counter()
c(); c()
println(c())

出力

3628800
3

関数はレキシカルスコープの閉包で、捕らえた変数を書き換えられます。
