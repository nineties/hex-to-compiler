8. クオートと評価器

ソースは M式に読まれてから評価されます。構文木は通常の値なので、組み立て・検査・評価・文字列への逆変換ができます。

クオート

t8_quote.pk

e := '(1 + 2 * x)
println(e)
x := 10
println(eval(e))

n := 5
println(`(n + !n))

出力

Apply{add, Tuple{1, Apply{mul, Tuple{2, x}}}}
21
Apply{add, Tuple{n, 5}}

'e は Quote{e} で、e の構文木を値にします。演算子は組み込み関数の Apply になります。`e は準クオートで、!e（UnQuote）の所だけ評価して埋めます。eval は木をトップレベルの式としてその場でコンパイルし、実行します。

M式で書く

t8_mexpr.pk

Def{y, 3}
Apply{println, Tuple{Apply{mul, Tuple{y, y}}}}
println('Def{y, 3} == '(y := 3))

出力

9
true

M式はそのまま式として書けます。構文は M式への読み替えで、対応の一覧は構文にあります。

parse と eval の差し替え

t8_eval.pk

old_eval := eval
eval = e -> {
    v := old_eval(e)
    put("=> ")
    println(v)
    v
}
1 + 2
'(a + b)
Point{1, 2}

出力

=> 3
=> Apply{add, Tuple{a, b}}
=> Point{1, 2}

トップレベルは式ごとに大域変数 parse（文字列 -> Tuple{M式, 残り}）と eval（M式 -> 値）を引き直します。差し替えると次の式から効きます。planck/syntax.pk も最後に parse を差し替えて planck の構文を入れています。

unparse

t8_unparse.pk

use("unparse")
t := '(if (n < 0) -n else n * (n + 1))
println(t)
put(unparse(t)); put("\n")

出力

If{Apply{lt, Tuple{n, 0}}, Apply{sub, Tuple{0, n}}, Apply{mul, Tuple{n, Apply{add, Tuple{n, 1}}}}}
if (n < 0) -n else n * (n + 1)

unparse は文法の規則を逆にたどって木を文字列に戻します。::= で足した規則で読める木も、その規則で戻ります。

長めの例は planck/examples にあります。処理系の側から見た同じ仕組みは処理系の実装にあります。
