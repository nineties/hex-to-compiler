5. レコード・局所関数・脱出

record は M式の引数に名前を付ける宣言です。return・break・continue はエフェクトとして実装されています。

record

t5_record.pk

record Point(x, y)
p := Point{3, 4}
println(p.x * p.x + p.y * p.y)

move(p, dx) := Point{p.x + dx, p.y}
println(move(p, 10))

出力

25
Point{13, 4}

record Point(x, y) は頭 Point の0番目と1番目の引数に名前を付けるだけで、値は Point{3, 4} のままです。パターンでも分解できます。. の前に空白は置けません。

fun

t5_fun.pk

parity(n) := {
    fun is_even(n) if (n == 0) true else is_odd(n - 1)
    fun is_odd(n) if (n == 0) false else is_even(n - 1)
    if (is_even(n)) "even" else "odd"
}
put(parity(10)); put("\n")
put(parity(7)); put("\n")

出力

even
odd

ブロックの中の fun は名前をブロックの先頭で宣言するので、相互再帰が書けます。ブロック内の f(x) := ... は、それより前の式からは見えません。

return・break・continue

t5_return.pk

find_first(p, xs) := {
    for (x in xs) if (p(x)) return x
    none
}
println(find_first(x -> x > 3, [1, 5, 2, 7]))
println(find_first(x -> x > 9, [1, 5, 2, 7]))

n := 0
odd_sum := 0
while (true) {
    n = n + 1
    if (n > 10) break
    if (n % 2 == 0) continue
    odd_sum = odd_sum + n
}
println(odd_sum)

出力

5
none
25

return e は囲む関数から抜けます。for の本体は関数ですが、その中の return は外の find_first から抜けます。break・continue は一番内側の while か for に効きます。

構文解析の時点で、本体に return を含む関数は Handle{body, (Return{v}, k) -> v} に、break を含むループは Break{} のハンドラで包まれます（構文）。return の値は return と同じ行から書きます。
