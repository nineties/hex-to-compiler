2. 値と M式

値は整数・文字列・シンボル・M式・関数・配列の6種類です。データ構造もプログラムも M式で表します。

t2_types.pk

println(typeof(42))
println(typeof("abc"))
println(typeof('apple))
println(typeof(true))
println(typeof(Point{1, 2}))
println(typeof(x -> x))

出力

string
symbol
symbol
mexpr
function

int整数。42・-1・0x1f
stringバイト列としての文字列。"abc"
symbol'apple。true・false・none もシンボル
mexprHead{a, ...}
function無名関数・融合・組み込み関数・継続
arrayarray(n) で作る固定長で書き換えられる配列

文字列

t2_strings.pk

s := "planck"
println(strlen(s))
println(substr(s, 0, 3))
println(f"{s}!")
println(ord(s, 0))
n := 3
put(f"{s} has {strlen(s)} characters, n = {n}\n")

出力

6
"pla"
"planck!"
112
planck has 6 characters, n = 3

長さと位置はバイト単位で、0から数えます。substr(s, i, j) は半開区間 [i, j) です。f"..." は {式} の値を埋め込みます。

M式

t2_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(Point{1, 2} == Point{1, 2})
println(push(p, 5))

出力

Point{3, 4}
Point
2
4
true
Point{3, 4, 5}

Head{a, ...} は頭のシンボルと引数の列からなる木です。宣言は要りません。== は構造で比べます。planck0 は M式を intern するので、この比較はポインタの比較です。頭と { の間に空白は置けません。

リストと組

t2_lists.pk

xs := [1, 2, 3]
println(xs)
ys := 0 :: xs
println(ys)

use("pretty")
put(f"{ys}\n")

println(())
println((1, "a"))

出力

Cons{1, Cons{2, Cons{3, Nil{}}}}
Cons{0, Cons{1, Cons{2, Cons{3, Nil{}}}}}
[0, 1, 2, 3]
Tuple{}
Tuple{1, "a"}

[1, 2, 3] は Cons{1, Cons{2, Cons{3, Nil{}}}}、x :: xs は Cons{x, xs} の構文です。(a, b) は Tuple{a, b} です。println は M式の形のまま出します。use("pretty") すると f"..." の埋め込みがリストを [...] の形で書きます。
