2. 変数と関数

値に名前を付け、関数を作ります。

変数

名前 := 値 で変数を作ります。作った変数に別の値を入れ直すときは = を使います。

t2_vars.pk

x := 10
y := x * 2
println(y)
x = x + 1
println(x)

出力

20
11

:= は「新しく作る」、= は「入れ直す」です。この 2 つは区別します。

関数

名前(引数, ...) := 式 で関数を作ります。呼ぶときは 名前(値, ...) です。

t2_func.pk

square(n) := n * n
println(square(12))

add3(a, b, c) := a + b + c
println(add3(1, 2, 3))

twice := f -> x -> f(f(x))
println(twice(square)(3))

出力

144
6
81

関数名と ( の間に空白を入れてはいけません。square (12) とは書けません。

x -> 式 は名前のない関数です。引数が 2 つ以上なら (a, b) -> 式、0 個なら () -> 式 と書きます。関数も値なので、変数に入れたり関数に渡したりできます。twice は関数 f を受け取り、「f を 2 回使う関数」を返します。

条件で分ける

t2_if.pk

abs(n) := if (n < 0) -n else n
println(abs(-5))

sign(n) := n < 0 ? -1 : n == 0 ? 0 : 1
println(sign(-3))
println(sign(0))
println(sign(8))

出力

5
-1
0
1

if (条件) A else B は条件が成り立てば A、成り立たなければ B になる式です。条件はかっこで囲みます。if も値を持つ式なので、そのまま関数の本体にできます。

短く書きたいときは 条件 ? A : B も使えます。else のない if (条件) A は、条件が成り立たないと none になります。

条件を組み合わせるときは and・or・not を使います。比べる演算子は ==・!=・<・<=・>・>= です。

ブロックと繰り返し

式を { ... } で囲むとブロックになります。中の式は上から順に動き、最後の式の値がブロックの値です。

t2_block.pk

sum_to(n) := {
    s := 0
    i := 1
    while (i <= n) {
        s = s + i
        i = i + 1
    }
    s
}
println(sum_to(100))

出力

5050

while (条件) 本体 は条件が成り立つ間、本体をくり返します。

ブロックの中で := で作った変数は、そのブロックの中だけで使えます。sum_to の s と i は外からは見えません。

再帰と閉包

関数は自分自身を呼べます。

t2_rec.pk

fact(n) := if (n == 0) 1 else n * fact(n - 1)
println(fact(10))

make_counter() := {
    n := 0
    () -> { n = n + 1; n }
}
c := make_counter()
c(); c()
println(c())

出力

3628800
3

make_counter は、呼ぶたびに数が 1 つ増える関数を返します。返された関数は、作られたときの変数 n を覚えています。このような関数を閉包（クロージャ）と呼びます。
