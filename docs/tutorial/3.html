3. パターンと融合

無名関数の引数はパターンです。f | g（融合）は f のパターンが合わなければ g を試す関数で、場合分けはこれで書きます。

t3_fib.pk

fun fib
fib = (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

融合は左から試し、最初に合った無名関数を呼びます。どれも合わなければ matching failed で止まります。| は右結合です。

f(p, ...) = e は f = f | (p, ...) -> e で、f の後ろに定義を追加します。同じ関数を定義ごとの行に分けて書けて、行は書いた順に試されます。

t3_fib_lines.pk

fib(0) := 0
fib(1) = 1
fib(n) = fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

同じ場所に f が定義済みなら f(p, ...) := e でも f に定義が加わるので、行はすべて := で書いても構いません。同じ名前で隠すときのことは後の節にあります。

パターン

パターン合う値
x・_任意。x は束縛し、_ は束縛しない
0・"abc"等しい整数・文字列
'none等しいシンボル（Quote{none}）
Head{p, ...}頭と引数の数が一致し、各引数が p, ... に合う M式
p :: q・[p, q]・[]Cons・Nil のパターン
p @ intp に合い、typeof が int の値

t3_list.pk

fun len
len = (Nil{}) -> 0 | (_ :: xs) -> 1 + len(xs)
println(len([5, 6, 7]))

fun sum
sum = ([]) -> 0 | (x :: xs) -> x + sum(xs)
println(sum([1, 2, 3, 4]))

swap2 := ([a, b]) -> [b, a] | (xs) -> xs
use("pretty")
put(f"{swap2([1, 2])} {swap2([1, 2, 3])}\n")

出力

3
10
[2, 1] [1, 2, 3]

t3_type.pk

describe := (n @ int) -> f"integer {n}"
          | (s @ string) -> f"string {s}"
          | (_) -> "other"
put(describe(1)); put("\n")
put(describe("abc")); put("\n")
put(describe('x)); put("\n")

出力

integer 1
string abc
other

定義の追加

t3_extend.pk

greet := (_) -> "hello"
put(greet("en")); put("\n")

greet = ("fr") -> "bonjour" | greet
put(greet("fr")); put("\n")
put(greet("de")); put("\n")

出力

hello
bonjour
hello

融合は値なので、既存の関数の前に定義を追加して代入し直せます。

関数に定義を追加する・同じ名前で隠す

t8_place.pk

fib(0) := 0
fib(1) := 1
fib(n) := fib(n - 1) + fib(n - 2)
println(fib(10))

name(x) := "outer"
inner() := {
    name(0) := "inner"
    name(0)
}
println(Tuple{inner(), name(0), name(1)})

出力

55
Tuple{"inner", "outer", "outer"}

f(p, ...) := e と書くと、同じ場所に f が定義済みなら f に定義が1つ加わり、なければ新しい f が定義されます。場所は、トップレベルでは同じファイル、関数の中ではその関数の引数と、その関数でそれより前に定義した変数です。外の name は inner の中の場所の変数ではないので、inner の中の name(0) := "inner" は新しい name を定義し、外の name は変わりません。

t8_library.pk

use("list")
last(Tuple{a, b}) = b
println(Tuple{last([1, 2, 3]), last(Tuple{4, 5})})
sum(xs) := "mine"
println(sum([1, 2]))

出力

Tuple{3, 5}
"mine"

別のファイルで定義した関数と組み込み関数も、プログラムのトップレベルでは同じ場所の変数ではありません。sum(xs) := ... は新しい sum を定義して use("list") の sum を隠します。ライブラリの関数に定義を追加するときは last(Tuple{a, b}) = b のように = で書き、追加した定義は元の定義のあとに試されます。名前がどの変数を指すかは9章にあります。

match

t3_match.pk

classify(n) := match n {
    0 -> "zero"
  | n if n < 0 -> "negative"
  | n if n % 2 == 0 -> "even"
  | _ -> "odd"
}
put(classify(0)); put(" ")
put(classify(-4)); put(" ")
put(classify(6)); put(" ")
put(classify(7)); put("\n")

出力

zero negative even odd

match e { f } は e を1回評価し、関数 f に渡して呼びます。f は腕を | でつないだ関数で、上から試します。p if c -> a はガードで、c が偽なら次の腕に進みます。

記号微分

t3_deriv.pk

fun d
d = (n @ int, x) -> 0
   | (y @ symbol, x) -> if (y == x) 1 else 0
   | (Add{a, b}, x) -> Add{d(a, x), d(b, x)}
   | (Mul{a, b}, x) -> Add{Mul{d(a, x), b}, Mul{a, d(b, x)}}

println(d('Add{x, 3}, 'x))
println(d('Mul{x, y}, 'x))

出力

Add{1, 0}
Add{Mul{1, y}, Mul{x, 0}}

'Add{x, 3} はクオートで、評価せずに M式のまま渡します（6章）。簡約まで入れた版は planck/examples/deriv.pk です。
