3. 値のかたち

planck が扱う値の種類を見ていきます。中心になるのは M式という木の形の値です。

値の種類

typeof は値の種類をシンボルで返します。

t3_types.pk

println(typeof(42))
println(typeof("abc"))
println(typeof('apple))
println(typeof(true))
println(typeof(Point{1, 2}))
println(typeof(x -> x))

出力

int
string
symbol
symbol
mexpr
function
種類例
int整数。42・-1・0x1f
string文字列。"abc"
symbolシンボル。'apple・true・false・none
mexprM式。Point{1, 2}
function関数
array書き換えられる配列。array(n) で作ります

シンボル

シンボルは名前そのものを表す値です。'apple のように ' を付けて書きます。' がないと、apple という変数の値を取り出そうとします。

true・false・none もシンボルです。if は false だけを「成り立たない」とみなします。0 や none は成り立つ側です。

文字列

t3_strings.pk

s := "planck"
println(strlen(s))
println(substr(s, 0, 3))
println(strcat(s, "!"))
println(ord(s, 0))
n := 3
put(f"{s} は {strlen(s)} 文字。n = {n}\n")

出力

6
"pla"
"planck!"
112
planck は 6 文字。n = 3

strlen は長さ、substr(s, i, j) は i 番目から j - 1 番目まで、strcat は連結です。ord(s, i) は i 番目の文字の番号を返します。位置は 0 から数えます。長さはバイトで数えるので、日本語は 1 文字が 3 バイトです。

先頭に f を付けた f"..." の中では、{式} の所に式の値が入ります。

M式

名前{値, ...} は M式です。頭（ヘッド）の名前と、いくつかの引数でできた木です。

t3_mexpr.pk

p := Point{3, 4}
println(p)
println(head(p))
println(arity(p))
println(arg(p, 1))
println(Point{1, 2} == Point{1, 2})
println(push(p, 5))

出力

Point{3, 4}
Point
2
4
true
Point{3, 4, 5}

head は頭、arity は引数の数、arg(m, i) は i 番目の引数です。push は引数を 1 つ足した新しい M式を返します。== は中身まで比べます。

M式は前もって宣言する必要がありません。Point{3, 4} と書けば、その場で Point という頭の M式ができます。データを表すのにも、あとで見るようにプログラムそのものを表すのにも使います。

頭の名前と { の間に空白は入れません。

リストと組

リストは [1, 2, 3] と書きます。中身は Cons{先頭, 残り} をつないだ M式で、最後が空のリスト Nil{} です。x :: xs は Cons{x, xs} と同じで、リストの先頭に要素を足します。

t3_lists.pk

xs := [1, 2, 3]
println(xs)
ys := 0 :: xs
println(ys)

use("pretty")
put(f"{ys}\n")

println(())
println((1, "a"))

出力

Cons{1, Cons{2, Cons{3, Nil{}}}}
Cons{0, Cons{1, Cons{2, Cons{3, Nil{}}}}}
[0, 1, 2, 3]
Tuple{}
Tuple{1, "a"}

println はリストを Cons の形で書きます。use("pretty") で整形のライブラリを読むと、f"..." の中では [0, 1, 2, 3] の形で書かれます。ライブラリは5 章でくわしく扱います。

(1, "a") は組で、Tuple{1, "a"} という M式です。() は空の組です。
