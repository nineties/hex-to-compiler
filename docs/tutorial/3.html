3. パターンと融合

無名関数の引数はパターンです。f | g（融合）は f のパターンが合わなければ g を試す関数で、場合分けはこれで書きます。

t3_fib.pk

fib := (0) -> 0
     | (1) -> 1
     | (n) -> fib(n - 1) + fib(n - 2)
println(fib(20))

出力

6765

融合は左から試し、最初に合った無名関数を呼びます。どれも合わなければ matching failed で止まります。| は右結合です。

パターン

パターン合う値
x・_任意。x は束縛し、_ は束縛しない
0・"abc"等しい整数・文字列
'none等しいシンボル（Quote{none}）
Head{p, ...}頭と引数の数が一致し、各引数が p, ... に合う M式
p :: q・[p, q]・[]Cons・Nil のパターン
p @ intp に合い、typeof が int の値

t3_list.pk

len := (Nil{}) -> 0 | (_ :: xs) -> 1 + len(xs)
println(len([5, 6, 7]))

sum := ([]) -> 0 | (x :: xs) -> x + sum(xs)
println(sum([1, 2, 3, 4]))

swap2 := ([a, b]) -> [b, a] | (xs) -> xs
use("pretty")
put(f"{swap2([1, 2])} {swap2([1, 2, 3])}\n")

出力

3
10
[2, 1] [1, 2, 3]

t3_type.pk

describe := (n @ int) -> f"整数 {n}"
          | (s @ string) -> f"文字列 {s}"
          | (_) -> "そのほか"
put(describe(1)); put("\n")
put(describe("abc")); put("\n")
put(describe('x)); put("\n")

出力

整数 1
文字列 abc
そのほか

場合の追加

t3_extend.pk

greet := (_) -> "hello"
put(greet("en")); put("\n")

greet = ("ja") -> "こんにちは" | greet
put(greet("ja")); put("\n")
put(greet("fr")); put("\n")

出力

hello
こんにちは
hello

融合は値なので、既存の関数の前に場合を足して代入し直せます。

match

t3_match.pk

classify(n) := match n {
    0 -> "zero"
  | n if n < 0 -> "negative"
  | n if n % 2 == 0 -> "even"
  | _ -> "odd"
}
put(classify(0)); put(" ")
put(classify(-4)); put(" ")
put(classify(6)); put(" ")
put(classify(7)); put("\n")

出力

zero negative even odd

match e { f } は e を1回評価し、関数 f に渡して呼びます。f は腕を | でつないだ関数で、上から試します。p if c -> a はガードで、c が偽なら次の腕に進みます。

記号微分

t3_deriv.pk

d := (n @ int, x) -> 0
   | (y @ symbol, x) -> if (y == x) 1 else 0
   | (Add{a, b}, x) -> Add{d(a, x), d(b, x)}
   | (Mul{a, b}, x) -> Add{Mul{d(a, x), b}, Mul{a, d(b, x)}}

println(d('Add{x, 3}, 'x))
println(d('Mul{x, y}, 'x))

出力

Add{1, 0}
Add{Mul{1, y}, Mul{x, 0}}

'Add{x, 3} はクオートで、評価せずに M式のまま渡します（8章）。簡約まで入れた版は planck/examples/deriv.pk です。
