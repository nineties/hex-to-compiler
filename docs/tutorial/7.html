7. エフェクト

perform で「頼みごと」を投げ、handle で受け取ります。例外・生成器・やり直しの探索が、この 1 つの仕組みで書けます。

例外を作る

t7_exception.pk

safe_div(a, b) := if (b == 0) perform Raise{"division by zero"} else a / b

try(f) := handle Ok{f()} with (Raise{msg}, k) -> Error{msg}

println(try(() -> safe_div(10, 2)))
println(try(() -> safe_div(10, 0)))
println(try(() -> { put("before\n"); safe_div(1, 0); put("after\n") }))

出力

Ok{5}
Error{"division by zero"}
before
Error{"division by zero"}

perform Raise{...} は、計算を止めて外に頼みごとを投げます。投げる値は何でもよく、ここでは Raise{メッセージ} という M式にしました。

handle 式 with ハンドラ は式を計算します。その途中で perform されると、ハンドラが (投げられた値, k) を引数にして呼ばれます。ハンドラの値が handle 全体の値になります。

3 つめの例では before は出ますが after は出ません。perform した所から先は捨てられたからです。

続きを再開する

ハンドラの 2 つめの引数 k は「perform した所から先の計算」です。k(値) と呼ぶと、perform がその値を返したことにして計算が再開します。

t7_resume.pk

ask() := perform Ask{}

with_answer(v, f) := handle f() with (Ask{}, k) -> k(v)

println(with_answer(21, () -> ask() * 2))
println(with_answer(5, () -> ask() + ask()))

出力

42
10

ask() の所で止まり、ハンドラが k(21) で再開します。だから ask() * 2 は 42 になります。ハンドラは再開した先でも有効です。2 つめの例では ask() が 2 回とも 5 を受け取っています。

ハンドラのパターンに合わない値が投げられたときは、さらに外側の handle に回ります。

生成器

木をたどりながら値を 1 つずつ外に渡す生成器も、perform で書けます。

t7_generator.pk

walk := (Leaf{}) -> none
      | (Node{l, v, r}) -> { walk(l); perform Yield{v}; walk(r) }

tree := Node{Node{Leaf{}, 1, Leaf{}}, 2, Node{Leaf{}, 3, Leaf{}}}

handle walk(tree) with (Yield{v}, k) -> { put(f"yield {v}\n"); k(none) }

to_list(t) := handle { walk(t); [] } with (Yield{v}, k) -> v :: k(none)
use("pretty")
put(f"{to_list(tree)}\n")

出力

yield 1
yield 2
yield 3
[1, 2, 3]

walk は値を見つけるたびに perform Yield{v} します。受け取る側が使い方を決めます。1 つめは見つけた値を表示し、2 つめは v :: k(none) で残りの結果の前に足してリストにしています。

何度も再開する

k はふつうの関数なので、何度でも呼べます。候補を 1 つずつ試す探索が書けます。

t7_choose.pk

use("list")
use("pretty")
choose(xs) := perform Choose{xs}

all_results(f) := handle [f()] with (Choose{xs}, k) -> concat_map(x -> k(x), xs)

put(f"{all_results(() -> (choose([1, 2]), choose(["a", "b"])))}\n")

出力

[Tuple{1, "a"}, Tuple{1, "b"}, Tuple{2, "a"}, Tuple{2, "b"}]

choose は候補のリストを投げます。ハンドラは候補ごとに k を呼び、出てきた結果を全部つなげます。2 つの choose の組み合わせ 4 通りが全部出ています。

この仕組みで N クイーン問題を解いた例が planck/examples/queens.pk にあります。
