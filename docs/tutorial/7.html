7. 文法の拡張

planck の構文は PEG の規則の集まりで、::= は規則を定義または置き換える式です。宣言の次のトップレベルの式から新しい規則で読みます。

構文の追加

t7_unless.pk

primary ::= 'unless "(" c:expr ")" a:expr { `If{!c, none, !a} } | ...

unless (1 > 2) put("1 > 2 is false\n")
unless (1 < 2) put("not printed\n")

出力

1 > 2 is false
  • primary ::= ... | ... の末尾の ... はその規則の直前の定義です。既存の規則の前に選択肢を足すことになります。
  • 'unless は単語、"(" は文字列、c:expr は規則 expr の値をラベル c に束縛する項目です。
  • { ... } は動作で、その値が規則の値になります。ここでは準クオートで構文木 If{c, none, a} を作っています。

項目と動作は ::= や | と同じ行に書きます。

二項演算子

t7_pipe.pk

union ::= x:union "|>" f:arrow { `Apply{!f, Tuple{!x}} } | ...

double(x) := 2 * x
3 |> double |> double |> println

出力

12

union は融合 | の規則です。直接の左再帰が書けるので、x:union "|>" ... は左結合になります。

ブロックを取る構文

t7_repeat.pk

repeat_fn(n, f) := while (n > 0) { f(); n = n - 1 }

primary ::= 'repeat n:add_expr body:block { `repeat_fn(!n, () -> !body) } | ...

repeat 3 { put("planck!\n") }

出力

planck!
planck!
planck!

準クオートの中は通常の構文で書けます。`repeat_fn(!n, () -> !body) は呼び出しの木に、読んだブロックを埋め込みます。

別の文法

t7_calc.pk

calc ::= a:calc "+" b:term { a + b } | a:calc "-" b:term { a - b } | term
term ::= a:term "*" b:atom { a * b } | atom
atom ::= integer | "(" e:calc ")" { e }

println(calc{| 1 + 2 * (10 - 4) |})
println(calc{| 100 - 20 - 3 |})

println(peg_parse('calc, "6 * 7"))
println(peg_parse('calc, "1 + )"))
println(peg_parse('calc, ")"))

出力

13
77
Tuple{42, ""}
Tuple{1, "+ )"}
Tuple{SyntaxError{"unexpected input", ")"}, ""}

動作は木でなく任意の値を返せます。規則は位置ごとにメモ化され（packrat）、左再帰は左結合です。

calc{| ... |} は {| と |} の間を規則 calc で読む式で、読むのは構文解析の時点です。値は定数として木に入ります。実行時の文字列は peg_parse(rule, s) で読み、結果は Tuple{値, 残り} です。先頭から読めなければ値は SyntaxError{...} です。
